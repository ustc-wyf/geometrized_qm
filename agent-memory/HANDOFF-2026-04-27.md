#### Important theoretical fact

For the current model

```text
f(R)=R/sqrt(1+(\ell^2 R)^2)
```

its flat-limit expansion is

```text
f(R)=R - (1/2)\ell^4 R^3 + O(R^5)
```

so

```text
f''(0)=0
```

This means:

```text
C is theoretically expected to stay close to B in weak curvature.
```

So if C barely separates from B at tiny lambda, that is not automatically a solver bug.
