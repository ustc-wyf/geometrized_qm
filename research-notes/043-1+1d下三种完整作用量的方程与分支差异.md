# 043 1+1d 下三种完整作用量的方程与分支差异

## 目标

把三种完整作用量在 `1+1d` 下的方程明确写出来，并回答一个关键问题：

```text
在 1+1d 里，
A: EH[g]
B: EH[g~]
C: f(R~)

这三种分支到底有没有真正不同的局域动力学？
```

## 1. 统一物质作用量

当前项目始终坚持的物质部分是：

```text
S_matter[g~,ρ~,S]
= ∫ d^2x sqrt(-g~) ρ~ ( g~^(μν) ∂_μ S ∂_ν S - m^2 )
```

这不是标准复 KG 拉氏量，
而是“量子势已几何化后”的 Bohm 型有效作用量。

因此它变分出的基本方程是：

```text
HJ:
g~^(μν) ∂_μ S ∂_ν S - m^2 = 0

Continuity:
∂_μ [ sqrt(-g~) ρ~ g~^(μν) ∂_ν S ] = 0
```

## 2. 1+1d 度规写法

在 `1+1d` 中任意 Lorentzian 度规局部都可写成 conformal gauge：

```text
ds^2 = e^{2σ(t,x)} ( dt^2 - dx^2 )
```

因此分别写：

```text
g_μν  = e^{2σ} η_μν
g~_μν = e^{2τ} η_μν
η_μν  = diag(1,-1)
```

于是

```text
sqrt(-g)  = e^{2σ}
sqrt(-g~) = e^{2τ}
g^(μν)    = e^{-2σ} η^(μν)
g~^(μν)   = e^{-2τ} η^(μν)
```

## 3. 物质方程在 conformal gauge 中的形式

把 `g~` 代入上面的 Bohm 型物质作用量，得到

```text
S_matter
= ∫ dtdx e^{2τ} ρ~ ( e^{-2τ} η^(μν) ∂_μ S ∂_ν S - m^2 )
= ∫ dtdx ρ~ [ η^(μν) ∂_μ S ∂_ν S - m^2 e^{2τ} ]
```

所以物质方程是：

### HJ 方程

```text
(∂_t S)^2 - (∂_x S)^2 = m^2 e^{2τ}
```

### 连续性方程

```text
∂_t (ρ~ ∂_t S) - ∂_x (ρ~ ∂_x S) = 0
```

注意这里一个重要点：

```text
在 1+1d conformal gauge 下，
连续性方程对 τ 不显含。
```

这是二维 conformal 结构的直接结果。

## 4. A 与 B 两个 Einstein-Hilbert 分支

### A 分支

```text
S_A
= (M_P^2/2) ∫ d^2x sqrt(-g) R[g] + S_matter[g~,ρ~,S] + S_constraint
```

### B 分支

```text
S_B
= (M_P^2/2) ∫ d^2x sqrt(-g~) R[g~] + S_matter[g~,ρ~,S] + S_constraint
```

但在二维里，

```text
∫ sqrt(-g) R[g]
和
∫ sqrt(-g~) R[g~]
```

都只是拓扑项（模边界）。

因此：

```text
如果不额外加入 dilaton、约束反馈或其他结构，
纯 EH 项本身不提供局域引力动力学。
```

### 4.1 结论

所以在最小 1+1d 版本里：

```text
A 分支和 B 分支
在局域动力学上不会自动分开。
```

更准确地说：

```text
它们共享同一套物质方程，
而纯 EH 部分只贡献边界/拓扑信息。
```

因此若只是做最小 1+1d 数值演化：

```text
A 和 B 会给出同一个基线演化。
```

这不是失败，而是 `1+1d` 的结构事实。

## 5. C 分支：f(R~)

现在考虑

```text
S_C
= (M_P^2/2) ∫ d^2x sqrt(-g~) f(R~) + S_matter[g~,ρ~,S]
```

其中当前选择

```text
f(R~) = R~ F(χ)
χ = ℓ^2 R~
F(χ) = 1 / sqrt(1 + χ^2)
```

### 5.1 辅助场重写

定义

```text
Φ = f_R(R~)
```

则等价地写成

```text
S_C
= (M_P^2/2) ∫ d^2x sqrt(-g~) [ Φ R~ - U(Φ) ]
 + S_matter[g~,ρ~,S]
```

在 conformal gauge 下，

```text
R~ = -2 e^{-2τ} (∂_t^2 - ∂_x^2) τ
```

因此

```text
sqrt(-g~) R~ = -2 (∂_t^2 - ∂_x^2) τ
```

模边界项积分分部后，
引力部分变成

```text
S_C
= (M_P^2/2) ∫ dtdx [ 2 ∂_μ Φ ∂^μ τ - e^{2τ} U(Φ) ]
 + ∫ dtdx ρ~ [ (∂_t S)^2 - (∂_x S)^2 - m^2 e^{2τ} ]
```

### 5.2 变分方程

对 `ρ~` 变分：

```text
(∂_t S)^2 - (∂_x S)^2 = m^2 e^{2τ}
```

对 `S` 变分：

```text
∂_t (ρ~ ∂_t S) - ∂_x (ρ~ ∂_x S) = 0
```

对 `Φ` 变分：

```text
2 (∂_t^2 - ∂_x^2) τ - e^{2τ} U'(Φ) = 0
```

对 `τ` 变分：

```text
2 (∂_t^2 - ∂_x^2) Φ + m^2 e^{2τ} ρ~ + (M_P^2/2) e^{2τ} U(Φ) = 0
```

所以 C 分支在 `1+1d` 里是一个真正非平凡的局域耦合系统：

```text
(τ, Φ, ρ~, S)
```

四个场耦合演化。

## 6. 当前最重要的结论

因此，在 `1+1d` 的最小版本下：

```text
A 分支：与 B 分支局域上不分家
B 分支：与 A 分支局域上不分家
C 分支：真正产生新的局域动力学
```

所以如果你现在要“先做一个最小可控模型并比较动力学”，那最正确的说法是：

```text
在 1+1d 里，真正有意义的比较是：

基线分支（A/B 共同）
vs
f(R~) 分支（C）
```

## 7. 这对数值模拟意味着什么

因此数值上最合理的第一步是：

### 基线分支（A/B）

直接解

```text
(∂_t S)^2 - (∂_x S)^2 = m^2 e^{2τ}
∂_t (ρ~ ∂_t S) - ∂_x (ρ~ ∂_x S) = 0
```

并在最小版本里把 `τ` 取为平直基线 `τ=0`。

### C 分支

解完整耦合系统：

```text
(∂_t S)^2 - (∂_x S)^2 = m^2 e^{2τ}
∂_t (ρ~ ∂_t S) - ∂_x (ρ~ ∂_x S) = 0
2 (∂_t^2 - ∂_x^2) τ - e^{2τ} U'(Φ) = 0
2 (∂_t^2 - ∂_x^2) Φ + m^2 e^{2τ} ρ~ + (M_P^2/2)e^{2τ}U(Φ) = 0
```

这就是当前最小可控模型中真正需要数值积分的非平凡方程组。
