# 020 最简单解的可逆性、签名、因果结构与经典极限

## 目标

继续检验当前最有力的最简单解：

```text
g~^(mu nu) = g^(mu nu) - (Q / X^2) u^mu u^nu
```

其中

```text
u_mu = ∂_mu S
X = g^(mu nu) u_mu u_nu
Q = Box sqrt(ρ) / sqrt(ρ)
```

并且在壳上有

```text
X - Q = m^2
```

这一份文档专门检查四件事：

1. 可逆性
2. 签名保持
3. 因果结构
4. 经典极限

## 1. 先写出 covariant 度规

我们已经有纯 rank-1 逆度规更新

```text
g~^(mu nu) = C g^(mu nu) + D u^mu u^nu
```

在最简单解中

```text
C = 1
D = - Q / X^2
```

其对应的 covariant 度规为

```text
g~_mu nu
= g_mu nu - [ D / (1 + D X) ] u_mu u_nu
```

因为

```text
1 + D X = 1 - Q/X = (X - Q)/X = m^2 / X
```

所以

```text
g~_mu nu
= g_mu nu + [ Q / (X m^2) ] u_mu u_nu
```

这就是后续全部分析的起点。

## 2. 可逆性

纯 rank-1 更新的可逆条件是

```text
1 + D X ≠ 0
```

对最简单解，这等价于

```text
m^2 / X ≠ 0
```

所以只要

```text
m^2 ≠ 0
X ≠ 0
```

即可。

在当前项目里我们研究的是有质量 Klein-Gordon 场，因此 `m^2 ≠ 0` 本身没问题。

真正的关键条件是：

```text
X ≠ 0
```

再用 HJ 方程

```text
X = m^2 + Q
```

可以把它写成

```text
Q ≠ -m^2
```

### 2.1 结论

```text
当 Q = m^2 时，
最简单解会奇异，不可逆。
```

这说明该解不能覆盖所有场构型，只能定义在

```text
X ≠ 0
```

的区域上。

## 3. 行列式与体积因子

对 contravariant metric 的 rank-1 更新有

```text
det(g~^(..)) = det(g^(..)) [ 1 + D X ]
```

所以对最简单解：

```text
det(g~^(..)) = det(g^(..)) m^2 / X
```

于是 covariant metric 的行列式满足

```text
det(g~) = det(g) X / m^2
```

因此体积元是

```text
sqrt(-g~) = sqrt(-g) sqrt( X / m^2 )
```

只要我们坚持 `sqrt(-g~)` 取实数，就必须要求

```text
X / m^2 > 0
```

对 `m^2 > 0` 的情形，这就是

```text
X > 0
```

也就是

```text
m^2 + Q > 0
```

## 4. 幅度变换的实数性

上一份文档已经得到，在允许 `ρ~` 真正变换后，

```text
sqrt(-g~) ρ~ = sqrt(-g) ρ X / m^2
```

所以对最简单解，

```text
ρ~ = ρ sqrt( X / m^2 )
```

这又一次要求

```text
X > 0
```

否则如果 `ρ` 仍被看成实的概率/粒子数幅度密度，那么 `ρ~` 会变成虚数或失去直接物理解释。

### 4.1 结论

```text
最简单解若要保持新视角下的波函数幅度仍为实数，
也自然要求 X > 0。
```

所以：

```text
X > 0
```

不是一个偶然的技术条件，而是几何和波函数两边都共同要求的条件。

## 5. 签名保持

为了判断签名，我们把任意向量分解成

```text
v_mu = a u_mu + w_mu
```

其中

```text
u^mu w_mu = 0
```

### 5.1 正交子空间

对任何与 `u_mu` 正交的向量 `w_mu`，

```text
g~_mu nu w^mu w^nu = g_mu nu w^mu w^nu
```

因为 rank-1 修正只沿 `u_mu` 方向。

所以正交子空间的符号完全保持不变。

### 5.2 u 方向

而在 `u_mu` 方向上，

```text
g~_mu nu u^mu u^nu
= X + [ Q / (X m^2) ] X^2
= X + Q X / m^2
= X (1 + Q/m^2)
```

再用

```text
X = m^2 + Q
```

得到

```text
g~(u,u) = X^2 / m^2
```

这是严格非负的，并且当 `X ≠ 0` 时严格为正。

### 5.3 结论

如果 `u_mu` 在原度规下是 timelike，也就是

```text
X > 0
```

那么：

- `u` 方向在新度规下仍是正的
- 与 `u` 正交的三维子空间仍保留原来的三个负方向

于是新度规仍是

```text
(+---)
```

型 Lorentzian 度规。

但如果

```text
X < 0
```

情况就完全不同。

此时 `u_mu` 在原度规下是 spacelike，而与它正交的子空间本身已经是 Lorentzian 型 `( +-- )`。
同时 `g~(u,u) = X^2/m^2 > 0` 仍为正。

所以总签名会变成

```text
(++--)
```

即 ultrahyperbolic，而不再是普通 Lorentzian。

### 5.4 最终结论

```text
最简单解保持标准 Lorentz 签名的充要自然条件是：
X > 0
```

也就是

```text
m^2 + Q > 0
```

## 6. 因果结构

这一点现在也可以清楚地说了。

因为：

- 在与 `u_mu` 正交的方向上，度规不变
- 只在 `u_mu` 方向上发生缩放

所以新光锥是沿 `u` 方向被“压缩/拉伸”的结果。

更具体地，沿 `u` 方向的系数从原来的

```text
g(u,u) = X
```

变成了

```text
g~(u,u) = X^2/m^2
```

所以比例因子是

```text
g~(u,u) / g(u,u) = X / m^2 = 1 + Q/m^2
```

### 6.1 若 Q > 0

则

```text
X = m^2 + Q > m^2
```

因此

```text
g~(u,u) > g(u,u)
```

也就是说沿 `u` 方向的“时间系数”增大，光锥相对原度规会变宽。

### 6.2 若 Q < 0

则

```text
X < m^2
```

因此

```text
g~(u,u) < g(u,u)
```

光锥相对原度规会变窄。

### 6.3 物理含义

所以最简单解提供的不是“无变化的因果结构”，而是：

```text
一种沿 Bohm 流方向被量子势重新调节的有效因果结构。
```

但只要

```text
X > 0
```

它仍然是 Lorentzian 的，因果结构仍有正常解释。

真正危险的是

```text
X ≤ 0
```

因为这时：

- `X = 0` 时新几何奇异
- `X < 0` 时新几何不再 Lorentzian

这与项目动机其实高度一致：

```text
原来在平直时空里看似“类空/超光速”的问题，
在新几何里只有在 X > 0 区域才被重新解释为良好的 Lorentzian 测地线。
```

## 7. 经典极限

经典极限要求

```text
Q -> 0
```

此时由 HJ 方程有

```text
X -> m^2
```

于是

```text
D = - Q / X^2 -> 0
```

从而

```text
g~^(mu nu) -> g^(mu nu)
g~_mu nu -> g_mu nu
sqrt(-g~) -> sqrt(-g)
ρ~ -> ρ
```

所以经典极限是完全正确的。

### 7.1 结论

```text
最简单解在经典极限上没有问题。
```

## 8. 当前总评

现在可以把这个最简单解的状态总结成非常清楚的表。

```text
项目                     结论
----------------------------------------------------------
拉氏量中消去 Q           成功
HJ 方程                  成功
连续性方程               成功（在允许 ρ~ 正确变换后）
测地线解释               成功
可逆性                   要求 X ≠ 0
Lorentz 签名保持         要求 X > 0
波函数幅度保持实数       要求 X > 0
经典极限                 成功
```

因此最核心的边界条件已经变得非常明确：

```text
最简单解的物理适用域是
X = m^2 + Q > 0
```

## 9. 这一步的意义

到这一步为止，我们已经不只是“找到一个可以消项的代数技巧”，而是得到了一个真正接近完整理论候选的结构：

```text
只要工作在 X > 0 的区域，
最简单纯 ansatz 已经同时满足：

1. 拉氏量消项
2. HJ 方程
3. 连续性方程
4. 测地线解释
5. 可逆性
6. Lorentz 签名保持
7. 正确经典极限
```

这已经比我们最初预期走得远得多。
