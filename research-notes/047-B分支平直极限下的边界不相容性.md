# 047 B 分支平直极限下的边界不相容性

## 目标

弄清楚当前 B/C 数值实现的问题到底在：

```text
1. 几何回授项
还是
2. 输入给 B/C 的边界数据本身
```

## 测试设计

做一个比弱耦合更强的隔离测试：

```text
把 B 分支几何完全冻结为平直：
τ = 0
β = 0
```

此时只保留 B 分支的物质方程：

```text
S_t = - sqrt(S_x^2 + S_z^2 + m^2)

n_t + ∂_x[(n/E) S_x] + ∂_z[(n/E) S_z] = 0

ρ = n / E
```

然后仍然给它喂入和 A benchmark 相同的边界 `ρ, S` 数据。

如果这时它已经和 A 差得很大，
那就说明问题不在几何回授，
而在：

```text
A benchmark 的边界数据对 B 物质方程本身就不相容。
```

## 结果

用 `debug_b_boundary_compatibility.py` 跑出的结果是：

```text
Bflat_vs_A_relL1 ≈ 2.7 × 10^3
```

也就是说：

```text
即使把 B 的几何完全冻平，
只用 B 的平直物质方程，
再喂 A benchmark 的边界，
它也不会接近 A。
```

## 结论

这一步把问题钉死了：

```text
当前 B/C 与 A 的巨大偏离，
不只是数值积分器或几何回授太 stiff，
而是因为我们一直在给 B/C 喂
“对 A 合法、但对 B/C 不合法”的边界准备。
```

换句话说，
当前用户认可的 A benchmark 图样是：

```text
原始 flat KG 的边界/解
```

而 B 的物质部分并不是原始 KG，
所以：

```text
同一组 ρ,S 边界数据
并不自动构成 B 的一个相容入射态。
```

## 下一步

要继续做可信比较，必须先重新定义

```text
“同一个实验准备”
```

在三支之间到底意味着什么。

当前最可能正确的方向是：

```text
不要把 A 的整个 ρ,S 边界图样直接搬给 B/C，
而要改成三支都共享的 incoming characteristic data。
```

也就是：

```text
先找出 B/C 物质系统在边界上的入射特征变量，
再把“相同实验准备”翻译成这些变量的相同。
```
