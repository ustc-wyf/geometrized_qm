# 004 四类度规变换的初步比较分析

## 目标

按当前项目的新约定，统一分析四类候选度规变换：

1. 共形变换
2. 相位单向 disformal
3. 振幅单向 disformal
4. 最小混合 disformal

本文件重点回答四个问题：

1. 它是否容易保持可逆？
2. 它是否容易保持 Lorentz 签名？
3. 它是否容易拥有正确的经典极限？
4. 它是否有希望实现“吸收量子势 + 轨迹几何化”？

说明：

- 为了便于人工阅读，本文件尽量使用纯文本公式
- 这里做的是“第一轮结构分析”，不是最终证明

## 1. 记号约定

从这一份文档开始，固定使用：

```text
u_mu = ∂_mu S
r_mu = ∂_mu sqrt(ρ)

X = g^(mu nu) ∂_mu S ∂_nu S
Y = g^(mu nu) ∂_mu S ∂_nu sqrt(ρ)
Z = g^(mu nu) ∂_mu sqrt(ρ) ∂_nu sqrt(ρ)
```

也就是：

```text
X = g^(mu nu) u_mu u_nu
Y = g^(mu nu) u_mu r_nu
Z = g^(mu nu) r_mu r_nu
```

背景度规记为 `g_mu nu`，新度规记为 `g~_mu nu`。

## 2. 类 I：共形变换

取

```text
g~_mu nu = A g_mu nu
```

其中 `A` 可以依赖 `ρ, X, Y, Z`，但先只做一般结构分析。

### 2.1 可逆性

逆度规直接是

```text
g~^(mu nu) = A^(-1) g^(mu nu)
```

所以可逆条件非常简单：

```text
A ≠ 0
```

### 2.2 行列式与签名

在四维时空中：

```text
det(g~) = A^4 det(g)
```

因此：

- 若 `A > 0`，签名类型保持不变
- 若 `A < 0`，整体符号翻转，但指标结构仍是 Lorentz 型

为了保持与原来相同的“1 正 3 负”约定，最自然是要求：

```text
A > 0
```

### 2.3 经典极限

经典极限下应要求：

```text
A -> 1
```

更准确地说，当量子效应消失时，例如 `r_mu -> 0`、`Q -> 0`，应有：

```text
g~_mu nu -> g_mu nu
```

### 2.4 对项目目标的匹配度

优点：

- 最稳定
- 最容易控制
- 最适合作为基线和对照组

缺点：

- 它只做各向同性缩放
- 无法优先照顾 Bohm 轨迹方向
- 也无法优先照顾振幅梯度方向

因此，共形变换最多可能做到：

- 改写某些整体尺度因子
- 在 very special case 下吸收一部分“标量型修正”

但它很难同时完成以下两件事：

1. 吸收量子势对应的振幅结构
2. 把 Bohm 轨迹改写成真正有方向性的测地线运动

### 2.5 初步结论

```text
共形变换适合作为基线，不太可能单独完成本项目目标。
```

它值得保留，但不应作为唯一主线。

## 3. 类 II：相位单向 disformal

取

```text
g~_mu nu = A g_mu nu + B u_mu u_nu
```

这里的优选方向来自 `u_mu = ∂_mu S`。

### 3.1 可逆性

这是标准 rank-1 更新。逆度规可写成

```text
g~^(mu nu)
= A^(-1) g^(mu nu)
 - [ B / ( A (A + B X) ) ] u^mu u^nu
```

其中

```text
u^mu = g^(mu alpha) u_alpha
```

所以可逆条件是

```text
A ≠ 0
A + B X ≠ 0
```

等价地也可写成

```text
1 + (B/A) X ≠ 0
```

### 3.2 行列式与签名

行列式为

```text
det(g~) = A^4 det(g) [ 1 + (B/A) X ]
```

因此一个很自然的 Lorentz 型保持条件是

```text
A > 0
1 + (B/A) X > 0
```

这不是所有情形下最一般的必要条件，但它是一个很干净、很实用的充分条件。

### 3.3 经典极限

要退回原度规，需要

```text
A -> 1
B -> 0
```

当量子势消失时，这个条件应自动满足。

### 3.4 对项目目标的匹配度

这一路线的最大优点是：

```text
它直接沿 Bohm 四动量方向变形度规。
```

因此它天然适合处理：

- 轨迹方向
- 有效质量壳条件
- “量子力是否能转成联络效应”这一问题

但它的弱点也很明显：

```text
量子势 Q 的来源是振幅结构，不是相位结构本身。
```

所以如果 `A` 和 `B` 不携带振幅信息，这一路线几乎不可能真正触及 `Q`。

更具体地说，它比较可能帮助我们做的是：

- 改写 `X = m^2 - Q` 这一类质量壳关系
- 尝试把 Bohm 轨迹测地线化

它不太擅长直接处理的是：

- 原始作用量中的振幅梯度项
- `ρ Q` 的来源结构

### 3.5 初步结论

```text
相位单向 disformal 对“轨迹几何化”很有希望，
但对“吸收量子势来源”偏弱。
```

所以它不能轻易淘汰，甚至很值得认真研究，但大概率不能单独完成全部目标。

## 4. 类 III：振幅单向 disformal

取

```text
g~_mu nu = A g_mu nu + C r_mu r_nu
```

这里的优选方向来自

```text
r_mu = ∂_mu sqrt(ρ)
```

### 4.1 可逆性

同样是 rank-1 更新。逆度规为

```text
g~^(mu nu)
= A^(-1) g^(mu nu)
 - [ C / ( A (A + C Z) ) ] r^mu r^nu
```

因此可逆条件为

```text
A ≠ 0
A + C Z ≠ 0
```

等价地写成

```text
1 + (C/A) Z ≠ 0
```

### 4.2 行列式与签名

行列式为

```text
det(g~) = A^4 det(g) [ 1 + (C/A) Z ]
```

一个实用的 Lorentz 型保持条件是

```text
A > 0
1 + (C/A) Z > 0
```

### 4.3 经典极限

与前面一样，最自然要求是

```text
A -> 1
C -> 0
```

当振幅趋于均匀、量子势趋于消失时，这一变换应自动退回原背景。

### 4.4 对项目目标的匹配度

这一路线的强项正好和类 II 相反。

它直接瞄准：

- 振幅梯度项
- 量子势来源结构
- 作用量中的“非经典修正”来源

因此它对以下任务更有吸引力：

- 吸收 `ρ Q`
- 吸收 `∂ sqrt(ρ) · ∂ sqrt(ρ)` 这一类项

但它的弱点是：

```text
轨迹方向是由 u_mu = ∂_mu S 决定的，不是由 r_mu 决定的。
```

所以即使它成功吸收了振幅结构，也不代表它自动能把 Bohm 轨迹测地线化。

### 4.5 初步结论

```text
振幅单向 disformal 对“吸收量子势来源”更有希望，
但对“轨迹几何化”偏弱。
```

因此它和类 II 一样，不能轻易淘汰，但单独使用时大概率仍不够。

## 5. 类 IV：最小混合 disformal

先考虑不含交叉项的最小混合子类：

```text
g~_mu nu = A g_mu nu + B u_mu u_nu + C r_mu r_nu
```

这正是前一阶段筛选出的主攻对象。

### 5.1 可逆性

这是 rank-2 更新。行列式因子为

```text
Delta = (1 + (B/A) X)(1 + (C/A) Z) - (BC/A^2) Y^2
```

因此可逆条件为

```text
A ≠ 0
Delta ≠ 0
```

也就是

```text
(A + B X)(A + C Z) - B C Y^2 ≠ 0
```

### 5.2 行列式与签名

行列式为

```text
det(g~) = A^4 det(g) Delta
```

所以一个自然的 Lorentz 型保持条件是

```text
A > 0
Delta > 0
```

这是一个很适合第一轮分析的条件。

### 5.3 经典极限

要求

```text
A -> 1
B -> 0
C -> 0
```

这样在量子效应消失时自然退回原度规。

### 5.4 对项目目标的匹配度

这一路线之所以成为主攻，不是因为它最简单，而是因为它第一次同时抓住了两边：

- `u_mu`：轨迹方向
- `r_mu`：量子势来源

所以它是目前最有希望同时处理以下两项的结构：

1. 作用量层面的量子势吸收
2. 轨迹层面的测地线解释

代价当然也更明显：

- 参数更多
- 约束更多
- 更容易在可逆性和签名上出问题

但这种复杂度是“逻辑上必要的复杂度”，不是无意义膨胀。

### 5.5 初步结论

```text
若目标是同时实现“吸收量子势 + 轨迹几何化”，
目前最有希望的是最小混合 disformal。
```

## 6. 四类方案的并排结论

为了方便快速查阅，可以把当前判断压缩成下面这张表。

```text
方案                    吸收量子势来源    轨迹几何化    技术难度    当前定位
---------------------------------------------------------------------------
共形                    弱                弱            低          基线/对照组
相位单向 disformal      中                强            中          高优先级
振幅单向 disformal      强                弱            中          高优先级
最小混合 disformal      强                强            中高        主攻路线
```

## 7. 对计划的修正

最开始我们把主线压得比较窄，优先盯住混合 ansatz。现在看，这样做虽然有逻辑，但还不够稳。

因为：

1. 共形变换是必要的基线，对照意义很强
2. 相位单向与振幅单向分别抓住了目标的两半
3. 若不先把这三类的能力边界看清楚，混合类的“必要性”就不够扎实

因此，计划应做如下修正：

```text
不再只分析混合 ansatz，
而是把共形、相位单向、振幅单向、混合四类
放进同一个比较框架中推进。
```

这不是跑偏，而是当前逻辑所要求的扩展。

## 8. 下一步建议

下一步最自然的任务是：

```text
把这四类变换分别代回到
I[ρ,S] ≃ ∫ d^4x ρ ( X - m^2 + Q )
```

所对应的结构里，检查它们各自最可能处理的是哪一部分：

- 哪一类更容易改写作用量
- 哪一类更容易改写 Hamilton-Jacobi 方程
- 哪一类更容易改写 Bohm 轨迹方程

这样我们就能从“结构判断”进入“真正代回去试”的阶段。
