# 006 HJ 层面的吸收 Q 求解与更广泛存在性

## 目标

这一份文档做两件事：

1. 在 HJ 方程层面，分别求出四类方案吸收 `Q` 的最简单选择
2. 回答一个更一般的问题：

```text
是否存在更广泛的一类变换，都可以在 HJ 层面实现这个目的？
```

这里“这个目的”先明确限定为：

```text
把原方程
X = m^2 - Q
改写成
g~^(mu nu) ∂_mu S ∂_nu S = m^2
```

也就是只讨论 HJ / 质量壳层面的吸收。

这还不是完整的“量子势几何化”最终证明，因为完整目标还要加上：

- 作用量层面兼容
- 轨迹测地线化
- 观测等价

但 HJ 层面的存在性是一个必须先拿下的台阶。

## 1. 起点

原方程是

```text
X = m^2 - Q
```

其中

```text
X = g^(mu nu) ∂_mu S ∂_nu S
Y = g^(mu nu) ∂_mu S ∂_nu sqrt(ρ)
Z = g^(mu nu) ∂_mu sqrt(ρ) ∂_nu sqrt(ρ)
```

我们的任务是：对每类候选 `g~_mu nu`，求参数使得

```text
g~^(mu nu) ∂_mu S ∂_nu S = m^2
```

在原方程成立时自动成立。

## 2. 类 I：共形变换

取

```text
g~_mu nu = A g_mu nu
```

则

```text
g~^(mu nu) ∂_mu S ∂_nu S = A^(-1) X
```

要求它等于 `m^2`，得到

```text
A^(-1) X = m^2
```

也就是

```text
A = X / m^2
```

再代入原方程 `X = m^2 - Q`，得到最简单解

```text
A = 1 - Q/m^2
```

### 2.1 解释

这说明：

```text
只要 A 不为零，
共形变换总能在 HJ 层面吸收 Q。
```

这已经给出一个明确存在性结果。

## 3. 类 II：相位单向 disformal

取

```text
g~_mu nu = A g_mu nu + B u_mu u_nu
```

其中

```text
u_mu = ∂_mu S
```

从前面的计算，我们有

```text
g~^(mu nu) u_mu u_nu = X / (A + B X)
```

要求它等于 `m^2`，得到

```text
X / (A + B X) = m^2
```

即

```text
A + B X = X / m^2
```

所以

```text
A = X/m^2 - B X
```

再代入 `X = m^2 - Q`，得到

```text
A = (1 - Q/m^2)(1 - B m^2) + B Q
```

但若希望写得更干净，可以直接保留成

```text
A = X(1/m^2 - B)
```

或者在把 `X = m^2 - Q` 代进去之后写成

```text
A = (m^2 - Q)(1/m^2 - B)
```

### 3.1 解释

这一类最关键的事实是：

```text
B 可以自由选，
然后 A 由上式决定。
```

所以相位单向 disformal 不是只有一个解，而是已经出现了一个函数自由度。

换句话说：

```text
在 HJ 层面，存在一整族相位单向 disformal 变换都可以吸收 Q。
```

## 4. 类 III：振幅单向 disformal

取

```text
g~_mu nu = A g_mu nu + C r_mu r_nu
```

其中

```text
r_mu = ∂_mu sqrt(ρ)
```

从前面的计算，我们有

```text
g~^(mu nu) u_mu u_nu
= [ X (A + C Z) - C Y^2 ] / [ A (A + C Z) ]
```

要求它等于 `m^2`，得到

```text
[ X (A + C Z) - C Y^2 ] / [ A (A + C Z) ] = m^2
```

把它改写成关于 `A` 的方程：

```text
X(A + C Z) - C Y^2 = m^2 A(A + C Z)
```

展开后得

```text
m^2 A^2 + C Z m^2 A - X A - C Z X + C Y^2 = 0
```

也就是

```text
m^2 A^2 + (C Z m^2 - X) A + C (Y^2 - X Z) = 0
```

这是一个关于 `A` 的二次方程。

### 4.1 最简单解的写法

若把 `C` 当作自由函数，则只要判别式非负，就可取

```text
A
= [ X - C Z m^2 ± sqrt( (C Z m^2 - X)^2 - 4 m^2 C (Y^2 - X Z) ) ] / (2 m^2)
```

再代入 `X = m^2 - Q`，便得到显式吸收 `Q` 的一族解。

### 4.2 一个特别简单的子情形

若取

```text
C = 0
```

就立刻退回共形情形：

```text
A = X/m^2 = 1 - Q/m^2
```

这说明振幅单向类至少不是空的。

但更重要的是：

```text
当 C ≠ 0 时，
振幅单向类通常也有非平凡解，
只不过 A 由一个二次方程决定。
```

### 4.3 解释

所以在 HJ 层面：

```text
振幅单向 disformal 也存在更广泛的一族解。
```

它不像相位单向那样线性干净，但存在性并不弱。

## 5. 类 IV：最小混合 disformal

取

```text
g~_mu nu = A g_mu nu + B u_mu u_nu + C r_mu r_nu
```

记

```text
alpha = B/A
gamma = C/A
Delta = (1 + alpha X)(1 + gamma Z) - alpha gamma Y^2
```

从前面的计算有

```text
g~^(mu nu) u_mu u_nu
= [ X (1 + gamma Z) - gamma Y^2 ] / [ A Delta ]
```

要求它等于 `m^2`，得到

```text
[ X (1 + gamma Z) - gamma Y^2 ] / [ A Delta ] = m^2
```

因此

```text
A = [ X (1 + gamma Z) - gamma Y^2 ] / [ m^2 Delta ]
```

而

```text
Delta = (1 + alpha X)(1 + gamma Z) - alpha gamma Y^2
```

所以写全就是

```text
A
= [ X (1 + gamma Z) - gamma Y^2 ]
 / [ m^2 ( (1 + alpha X)(1 + gamma Z) - alpha gamma Y^2 ) ]
```

再代入 `X = m^2 - Q` 即得一族显式解。

### 5.1 解释

这里最关键的是：

```text
alpha 和 gamma 可以先自由选，
然后 A 由上式决定。
```

所以混合类在 HJ 层面不仅存在解，而且存在一个两函数自由度的解族。

## 6. 一个统一的存在性结论

现在可以回答你问的更一般问题：

```text
是否存在更广泛的一类变换都可以实现这个目的？
```

若“这个目的”只指 HJ 层面的吸收，即

```text
X = m^2 - Q
```

改写成

```text
g~^(mu nu) ∂_mu S ∂_nu S = m^2
```

那么答案是：

```text
是，存在。
而且不是零散几个解，而是一个很大的解族。
```

### 6.1 为什么会这样

原因很简单：

HJ 层面的要求本质上只给出一个标量方程：

```text
g~^(mu nu) u_mu u_nu = m^2
```

但候选度规变换通常包含多个自由函数。

于是典型情况就是：

```text
一个标量约束
去限制
多个函数自由度
```

这自然会留下一个无限维的剩余自由度。

### 6.2 在当前四类中，这个结论如何体现

```text
共形类：一个函数 A，直接被唯一确定
相位单向类：两个函数 A,B，一个方程 -> 留下一个自由函数
振幅单向类：两个函数 A,C，一个方程 -> 通常留下一个自由函数分支
混合类：三个函数 A,B,C，一个方程 -> 留下两个自由函数
```

这已经说明“更广泛的一类变换存在”不是猜测，而是 HJ 层面上的结构事实。

## 7. 但要注意：这还不是最终存在性证明

虽然上面已经给出一个强存在性结论，但它还只是：

```text
HJ 层面的存在性
```

而不是：

```text
完整量子势几何化的存在性
```

后者还要额外满足：

1. 作用量层面兼容
2. 变分后场方程等价
3. 轨迹能写成测地线
4. 经典极限正确
5. 可逆、签名、因果结构可控

也就是说，我们现在已经证明了：

```text
“把 Q 吸收到 HJ 方程里”这件事有很大的变换自由度。
```

但还没有证明：

```text
“这些解里有很大一类也同时满足作用量与测地线要求”。
```

这是下一层问题。

## 8. 当前最稳的表述

到目前为止，最稳妥、最严格的说法是：

```text
在 HJ 层面，量子势 Q 的几何吸收并不唯一；
它对应一个更广泛的变换族。
```

如果以后能进一步证明这个更广泛族中的一个非空子类还能：

- 兼容作用量
- 导出测地线

那我们就能把“HJ 层面的存在性”升级成“完整几何化层面的存在性”。

## 9. 下一步建议

下一步最自然的是：

```text
从这四类在 HJ 层面的最简单解出发，
逐一代回作用量，
检查哪些选择能真正把
L_geom / (sqrt(-g) ρ)
逼近或化成
X - m^2 + Q
```

更具体地说：

1. 先对共形类做最简单尝试：
   A = 1 - Q/m^2
   看作用量差什么

2. 再对相位单向类选一个最简单 gauge：
   例如先指定 B，再由 A 解出

3. 再对振幅单向类选一个最简单 C，
   解出对应 A

4. 最后看混合类是否能统一前面三类的优点
