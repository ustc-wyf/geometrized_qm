# D支 1550nm 物理标定时空收敛检查

日期：2026-05-03

## 目的

延续 `research-notes/133-D支1550nm物理标定active边界与trusted核心诊断.md`。

上一轮发现：

- `active_dilation=2` 可去掉 active 截断边界伪故障；
- `trusted_erosion=1` 后 trusted core 可完成 400 步；
- `n=64` 全窗口下原始 support 外圈仍会出现严重尖峰。

本轮检查：

- 时间步误差是否主导；
- 空间分辨率是否主导；
- `n=96` 是否足以压住原始 support 外圈；
- `n=128` 半窗口是否继续显著改变结论。

## 固定设置

- 1550nm 光学 massive KG 近似；
- \(m=\omega_0/10\)；
- KG 正频内积归一化；
- \(\ell/l_P=10^{60}\)；
- `active_dilation=2`；
- `trusted_erosion=1`；
- `stop_mask=trusted`；
- `interface_every=0`。

## 半窗口结果

共同物理时间：

\[
t_{\rm old}=5\times10^{-5},
\qquad
t\simeq2.4686\times10^{-4}\,{\rm fs}.
\]

### `n=64, dt_old=2.5e-7`

- `measure_rel_l1_trusted = 7.189e-5`
- `n_cons_rel_l1_trusted = 4.812e-5`
- `disc_min_trusted = 3.865e-6`
- `measure_rel_l1_support = 7.124e-3`
- `disc_min_support = 1.001e-8`

### `n=64, dt_old=1.25e-7`

- `measure_rel_l1_trusted = 7.189e-5`
- `n_cons_rel_l1_trusted = 4.812e-5`
- `disc_min_trusted = 3.865e-6`
- `measure_rel_l1_support = 7.119e-3`
- `disc_min_support = 1.001e-8`

时间步减半几乎不改变结果，因此此窗口内时间离散误差不是主导。

### `n=96, dt_old=2.5e-7`

- `measure_rel_l1_trusted = 1.448e-5`
- `n_cons_rel_l1_trusted = 2.012e-5`
- `disc_min_trusted = 3.190e-2`
- `measure_rel_l1_support = 1.648e-5`
- `disc_min_support = 8.080e-3`

相对 `n=64`，support 外圈从 `7e-3` 量级改善到 `1.6e-5`，质量壳判别式也从 \(10^{-8}\) 的危险边缘变成 \(8.08\times10^{-3}\)。

### `n=128, dt_old=2.5e-7`

- `measure_rel_l1_trusted = 1.165e-5`
- `n_cons_rel_l1_trusted = 2.752e-5`
- `disc_min_trusted = 1.500e-2`
- `measure_rel_l1_support = 1.228e-5`
- `disc_min_support = 6.199e-3`

`n=96 -> n=128` 仍有小幅变化，但不再是数量级变化。support 和 trusted 指标已经同阶，说明 `n=96` 已经基本压住原来的 support 外圈伪故障。

## 全窗口结果

共同物理时间：

\[
t_{\rm old}=10^{-4},
\qquad
t\simeq4.9372\times10^{-4}\,{\rm fs}.
\]

### `n=64, dt_old=2.5e-7`

- `measure_rel_l1_trusted = 1.437e-4`
- `n_cons_rel_l1_trusted = 9.622e-5`
- `disc_min_trusted = 3.867e-6`
- `measure_rel_l1_support = 17.981`
- `disc_min_support = -5.554e-8`

trusted core 仍稳定，但原始 support 外圈已经严重爆掉。

### `n=96, dt_old=2.5e-7`

- `measure_rel_l1_trusted = 2.895e-5`
- `n_cons_rel_l1_trusted = 4.024e-5`
- `disc_min_trusted = 3.190e-2`
- `measure_rel_l1_support = 3.295e-5`
- `disc_min_support = 8.080e-3`

`n=96` 在全窗口中也压住了原始 support 外圈；support 与 trusted 指标同阶，且质量壳判别式保持明显正值。

## 判断

本轮最重要结论：

\[
\boxed{
\text{当前 1550nm D 支三域原型的主要数值病灶是空间分辨率/支撑边缘解析度，而不是时间步误差。}
}
\]

具体说：

- `n=64` 下把 `dt` 减半几乎不改变结果；
- `n=64 -> n=96` 给出数量级改善；
- `n=96 -> n=128` 半窗口只给出小幅变化；
- `n=96` 全窗口中原始 support 外圈也不再爆掉。

因此，先前 `n=64` 全窗口 support 外圈的负判别式和巨大测度误差，不应解释为 D 支主体物理失败，而应解释为空间解析度不足导致的阈值边缘伪故障。

## 下一步

建议：

- 当前默认工作分辨率从 `n=64` 提升到 `n=96`；
- 后续长跑可优先使用 `n=96, dt_old=2.5e-7`；
- 只有在需要更严格的收敛图时才补 `n=128` 全窗口；
- 下一步比继续盲目加密更重要的是处理 support 边缘表达：
  - 平滑权重/tapered support；
  - body-fitted 低密度边界；
  - 或把 support/trusted 诊断改为基于连续权重而不是硬阈值。
