# 081 共同初始几何的第一版构造与 `A/B` 源差异

## 目标

在新的统一四维 `ADM` 原型下，真正接近

\[
\text{同一组 }(\rho,S,g)\text{ 初值}
\]

的第一步，是不再从“平直几何 + 手工零动量”硬启动，而是显式构造一组共同初始几何。

本笔记记录第一版结果：

1. 先检查 `A` 与 `B` 在同一组 `\rho,S` 上的初始约束源到底差多少；
2. 再在时间对称、共形平坦 ansatz 下构造一组共同初始几何；
3. 再把它接回统一四维 `ADM` 原型。

## 1. A 支与 B 支在同一组 `\rho,S` 上的初始源差异

### 1.1 A 支复标量初值

`A` 支不能再用手工

\[
\Pi_1=\Pi_2=0
\]

启动。  
若给定同一组 `(\rho,S,g)`，则应先由

\[
\psi=\sqrt{\rho}e^{iS}=\phi_1+i\phi_2
\]

重构

\[
\phi_1,\phi_2,
\]

并在时间对称几何假设

\[
N=1,\qquad N^x=N^z=0,\qquad K_{ij}=0,\qquad K_\beta=0
\]

下，用共同物质守恒系统求出

\[
S_t,\qquad \rho_t,
\]

再得

\[
\Pi_1=\partial_t\phi_1,\qquad \Pi_2=\partial_t\phi_2.
\]

对应实现见：

```text
kg_examples/adm_initial_data_abc.py
```

中的

```text
a_complex_state_from_rho_s_time_symmetric(...)
```

### 1.2 平直几何下的 A/B 源比较

在初始平直几何

\[
h_{xx}=h_{zz}=1,\qquad h_{xz}=0,\qquad \beta=0
\]

下，用用户指定的 `±45^\circ` 双束高斯波包初值比较 `A/B` 两支的应力能量投影，得到：

- `energy` 的相对 `L^1` 差异约 `0.645`
- `mom_x` 的相对 `L^1` 差异约 `2.997`
- `mom_z` 的相对 `L^1` 差异约 `0.049`
- `s_xx` 的相对 `L^1` 差异约 `0.791`
- `s_xz` 的相对 `L^1` 差异约 `1.230`
- `s_zz` 的相对 `L^1` 差异约 `0.781`
- `s_yy` 的相对 `L^1` 差异约 `1.000`

所以：

\[
\boxed{
\text{同一组 }(\rho,S)\text{ 在 }A\text{ 与 }B\text{ 支中对应的约束源并不接近。}
}
\]

这意味着：

\[
\boxed{
\text{若坚持三支“同一组 }g\text{ 初值”，则该初值一般不能同时严格满足三支的约束方程。}
}
\]

## 2. 时间对称共形平坦的共同初始几何

### 2.1 共同空间度规

先采用最简单 ansatz：

\[
h_{ij}=e^{2\omega}\delta_{ij},\qquad h_{xz}=0,\qquad \beta=0,
\]
\[
K_{ij}=0,\qquad K_\beta=0.
\]

这时 Hamilton 约束变成

\[
{}^{(3)}R=\frac{2\mathcal E}{M_P^2}.
\]

对当前 ansatz，有

\[
{}^{(3)}R=-2e^{-2\omega}\Delta\omega,
\]

因此得到非线性 Poisson 型方程

\[
\Delta\omega
=
-\,e^{2\omega}\frac{\mathcal E}{M_P^2}.
\]

由于 `A/B` 的源不同，严格共同解并不存在。  
第一版构造采取一个中性的平均：

\[
\mathcal E_{\text{common}}

=
\frac12(\mathcal E_A+\mathcal E_B).
\]

在 Dirichlet 边界

\[
\omega|_{\partial\Omega}=0
\]

下，用松弛迭代求得 `\omega`。

### 2.2 共同外曲率

双束入射具有明显的非零动量密度，因此单纯取

\[
K_{ij}=0
\]

并不自然。  
第一版共同外曲率采用最简单的 York 型向量势近似：

\[
K=0,\qquad K_\beta=0,
\]
\[
K_{ij}
=
\partial_i W_j+\partial_j W_i-\delta_{ij}\partial_k W^k,
\]
\[
\Delta W_i=\frac{\mathcal P_i^{\text{common}}}{M_P^2},
\qquad
\mathcal P_i^{\text{common}}
=
\frac12(\mathcal P_i^{(A)}+\mathcal P_i^{(B)}).
\]

这一步的作用不是“严格完成全部动量约束”，而是至少不再从“非零动量束流却令 `K_{ij}=0`”的明显不相容状态启动。

## 3. 数值结果

### 3.1 各自分支的时间对称共形几何量级

若分别用 `A`、`B`、`(A+B)/2` 的能量源解时间对称共形因子，则得到：

- `A` 源：`omega_max ≈ 5.66e-3`
- `B` 源：`omega_max ≈ 7.25e-3`
- 平均源：`omega_max ≈ 6.45e-3`

这说明：

\[
\boxed{
\text{虽然 }A/B\text{ 的源差异很大，但由于 }M_P\text{ 很大，解出的初始几何只在千分量级偏离平直。}
}
\]

因此“同一组 `g` 初值”在当前弱场参数下可作为近似成立，但不是严格的共同约束解。

### 3.2 接回统一原型后的初始 Hamilton 残差

把这组共同初始几何接回

```text
kg_examples/simulate_ab_adm_synchronous.py
```

后，`t=0` 时三支的 Hamilton 残差最大值降到：

- `A`：`8.34e-2`
- `B`：`8.83e-2`
- `C`：`8.83e-2`

相比此前从“平直几何 + 零外曲率”硬启动时的 `O(1)` 量级，这是明显改善。

## 4. 这一步的意义与边界

### 已完成的事

1. `A` 支终于从同一组 `(\rho,S,g)` 正确重构出 `(\phi_1,\phi_2,\Pi_1,\Pi_2)` 初值。
2. 三支共同初始几何不再是纯手工平直猜测。
3. `C` 支仍保持了先前已经通过的

\[
\Phi=1,\ \Pi_\Phi=0 \Rightarrow C\text{ 支退回 }B\text{ 支}
\]

校准条件。

### 还没有完成的事

1. 这仍不是严格满足三支全部约束的共同初值。
2. 当前只把 Hamilton 约束和动量约束的最小近似版纳入了构造。
3. 后续仍需决定：
   - 是否接受“共同 `g` 初值只能近似满足三支约束”
   - 或者改成“三支各自严格满足约束，但共享同一组 `\rho,S` 初值”

## 5. 下一步

当前最自然的下一步有两件：

1. 给 `C` 支加入非平凡 `\Phi` 初值；当前已实现第一条最小入口
   \[
   \Phi_0=(1+(\ell^2 R_{\text{proxy}})^2)^{-3/2},
   \]
   其中 `R_proxy` 取共同初始几何的空间曲率。
2. 显式计算并比较三支的动量约束残差，决定当前共同初值是否已足够用于第一轮正式比较。
