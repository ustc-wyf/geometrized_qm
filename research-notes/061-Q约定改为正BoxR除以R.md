# 061 `Q` 约定改为 `+\Box R / R`

## 目标

记录当前项目对量子势记号的一次明确约定迁移：

```text
旧约定：
Q_old = - Box R / R

新约定：
Q = + Box R / R
```

其中

```text
R = sqrt(ρ)
```

这次迁移的目的不是修正先前推导中的代数错误，而是让当前项目的 `Q` 在非相对论极限下和 Bohm 原始文献里的量子势记号更同向、更直观。

## 1. 迁移后的基本方程

在当前固定号规

```text
η_(μν) = diag(1,-1,-1,-1)
Box = ∂_μ ∂^μ = ∂_t^2 - ∇^2
```

下，新的定义是

```text
Q = Box sqrt(ρ) / sqrt(ρ)
```

于是原始 KG 的 Madelung 方程写成

```text
HJ:
X = m^2 + Q

Continuity:
∂_μ [ sqrt(-g) ρ u^μ ] = 0
```

其中

```text
X = g^(μν) ∂_μ S ∂_ν S
u_μ = ∂_μ S
```

分部积分后的作用量写成

```text
I[ρ,S] ≃ ∫ d^4x sqrt(-g) ρ ( X - m^2 - Q )
```

## 2. 和旧约定的映射

所有旧文档里的 `Q_old` 都与现在的 `Q` 满足

```text
Q_old = -Q
```

因此：

```text
X = m^2 - Q_old
```

现在统一改写为

```text
X = m^2 + Q
```

旧文档里凡是出现

```text
X - m^2 + Q_old
```

都应理解为现在的

```text
X - m^2 - Q
```

## 3. 最简单 rank-1 几何化解如何改写

旧约定下最简单解写成

```text
g~^(μν) = g^(μν) + (Q_old / X^2) u^μ u^ν
```

把 `Q_old = -Q` 代入后，新的写法是

```text
g~^(μν) = g^(μν) - (Q / X^2) u^μ u^ν
```

更一般地，原来的吸收条件

```text
D X^2 + (C - 1) X - Q_old = 0
```

现在改写成

```text
D X^2 + (C - 1) X + Q = 0
```

所以最简单解变成

```text
C = 1
D = - Q / X^2
```

而

```text
C + D X = 1 - Q/X = (X - Q)/X = m^2 / X
```

因此密度变换律

```text
sqrt(-g~) ρ~ = sqrt(-g) ρ X / m^2
```

并没有改变。

## 4. 为什么这更贴近 Bohm 原始量子势

Bohm 1952 的非相对论量子势是

```text
U_B = - (ħ^2 / 2m) ∇^2 R / R
```

在 `ħ = 1`、并且忽略 `∂_t^2 R` 的非相对论极限下，

```text
Q = Box R / R ≈ - ∇^2 R / R
```

因此

```text
Q ≈ 2m U_B
```

这说明新的 `Q` 与 Bohm 原始量子势同号，只是量纲不同：

- `U_B` 是能量
- 当前项目的 `Q` 是质量平方修正

## 5. 使用说明

从这份笔记开始，当前项目的“默认 `Q` 约定”统一为

```text
Q = + Box sqrt(ρ) / sqrt(ρ)
```

若查阅更早的历史笔记，看到其中写的是

```text
Q = - Box sqrt(ρ) / sqrt(ρ)
```

应自动按

```text
Q_old = -Q
```

换回当前约定再读。
