# 056 同初值下 2+1d 高斯波包干涉的 A/B/C 后续演化比较

## 目标

在当前最可信的 `2+1d` 数值骨架上，
对同一组双束高斯波包干涉初值，
比较三种作用量对应分支在后续演化中的偏离：

```text
A: 原始参考支
B: EH[g~] 几何化分支
C: F(R~)R~ 分支
```

用户当前关心的是：

```text
物质场作用量对应的方程在变换前后已知是一致的，
但引力作用量在量子区的差别仍未知，
因此应直接看同一实验准备下 A/B/C 后续演化是否出现可见分裂。
```

## 口径说明

当前这一步采用的是**受控 shared-baseline 动态比较**，而不是 full backreacted A/B/C：

```text
1. A 用当前最可信的谱 Laplacian + 吸收层 + 精确边界骨架做动态演化
2. B/C 在同一组 A 的 rho,S 历史上推进几何子系统
3. 再由几何场重构 rho_B, rho_C
```

因此这一步回答的是：

```text
在相同初值、相同物质主干演化下，
三种引力作用量会把几何-重构后的 rho 拉开多少
```

而不是：

```text
三支完全自洽 backreaction 之后的最终闭合比较
```

之所以先采用这个口径，是因为它是当前项目里最稳定、最可解释、也最适合看“引力作用量差异入口”的版本。

## 数值设置

共同参数：

```text
alpha = 0.5
mp = 300
ell = 0.02
inner = 10
outer = 15
nx = nz = 181
nkx = nkz = 61
dt ~ 0.0249893
steps = 455
```

为了让这一版“图样比较脚本”本身不要过重，
这里把 A 对精确 benchmark 的检查降为**最终时刻一次 spot check**，
而不再每一步都做精确对照。

当前这版轻量配置下，
最终 A 对精确 benchmark 的相对 `L1` 仍为：

```text
A_num_vs_exact_relL1 ~ 1.77e-2
```

这比正式校准脚本的最佳值差一些，
但足以支撑当前“分支间相对偏离”可视化。

## 代表参数点

根据上一份 continuation 笔记 `055`，
这里选了两组代表点：

```text
lambda = 1, c_substeps = 4
lambda = 3, c_substeps = 8
```

解释：

```text
lambda = 1 : B 相对 A 已进入 1e-6 ~ 1e-5 的 onset 区
lambda = 3 : C 相对 B 已更稳健地进入几 1e-5 的可读区
```

## 结果总表

### 1. lambda = 1

最终时刻 `t/T = 1`：

```text
B_vs_A_relL1 = 4.22e-6
C_vs_A_relL1 = 1.89e-5
C_vs_B_relL1 = 1.47e-5
```

首次过阈时间：

```text
B_vs_A >= 1e-6  于 t/T ~ 0.341
C_vs_A >= 1e-5  于 t/T ~ 0.505
C_vs_B >= 1e-5  于 t/T ~ 0.576
```

### 2. lambda = 3

最终时刻 `t/T = 1`：

```text
B_vs_A_relL1 = 1.26e-5
C_vs_A_relL1 = 4.55e-5
C_vs_B_relL1 = 3.29e-5
```

首次过阈时间：

```text
B_vs_A >= 1e-6  于 t/T ~ 0.174
C_vs_A >= 1e-5  于 t/T ~ 0.299
C_vs_B >= 1e-5  于 t/T ~ 0.365
```

## 图样层面的观察

### 1. 差异不是从初值立刻跳出来的

在两组参数里，
`t/T = 0` 时三支几乎重合。
主要偏离是在双束逐步重叠之后积累出来的，
而不是一开始就存在一个大静态差别。

### 2. B 的偏离更弱、更晚、更平滑

`|B-A|` 在全过程都比 `|C-A|`、`|C-B|` 小一档左右，
而且主要是沿着束流热点和后期中心干涉脊慢慢积累。

### 3. C 的偏离更早出现，也更集中在干涉主结构上

`|C-A|` 与 `|C-B|` 在

```text
斜向干涉臂
中心重叠区
后期主亮纹
```

上更明显。

也就是说，
`C` 的额外引力结构并不是均匀地给整张图加一个小修正，
而是优先改变最强干涉主结构附近的重构密度。

## 当前最核心结论

在当前最可信的同初值动态比较口径下，
已经可以清楚地说：

```text
1. A/B/C 的差别会在后续演化中积累出来，而不是只停留在抽象作用量层面
2. B 相对 A 的偏离是小而平滑的
3. C 相对 B 的偏离更早、更强，也更集中在干涉主结构附近
4. 把 lambda 从 1 提到 3 后，这种层级关系会被进一步拉开
```
