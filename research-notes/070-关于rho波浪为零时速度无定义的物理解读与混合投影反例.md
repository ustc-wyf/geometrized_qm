# 070 关于 `ρ~ = 0` 时速度无定义的物理解读与混合投影反例

## 目标

澄清一个很自然但容易混淆的判断：

```text
若在 X=0 邻域有 ρ~ -> 0，
那么即使 g~ 表象下“速度场”发散，
也未必代表物理问题，
因为该点本来就没有粒子流过。
```

这个判断在某些分支上是成立的，但不能自动推广到所有混合 ansatz。

---

## 1. 三个层级必须分开

### 1.1 粒子/流解释

若在某个边界上

```text
ρ~ -> 0
```

且电流

```text
J~^μ = sqrt(|g~|)ρ~ g~^(μν)u_ν
```

保持有限，那么把该边界解释成“没有粒子，因此 Bohm 速度无需定义”的确是合理的。

### 1.2 连续性方程

这时连续性方程可能仍然是 regular 的，因为真正进入方程的是 `J~^μ`，不是裸的 `g~^(μν)u_ν`。

### 1.3 图册/几何变量

但这并不自动说明 `g~` 图册本身在该面正则。若 `g~^(μν)` 的系数仍然发散，那么更准确的理解仍是：

```text
这是一张在该面失效的 chart，
只是它的 current-level 物理量可以有良好的边界行为。
```

---

## 2. rank-1 `C=1` 分支：用户的解释是成立的

在 rank-1 `C=1` 分支上，

```text
A_u = κ/X
R = det(g~^(..))/det(g^(..)) = κ/X
```

所以

```text
ρ~ = ρ sqrt(R)/A_u
    = ρ sqrt(X/κ) .
```

于是

```text
X -> 0  ==>  ρ~ -> 0 .
```

因此在这条分支里，用户的物理解读是成立的：

```text
X=0 邻域可以看成零密度边界，
速度场即便发散，也不对应真实粒子流。
```

---

## 3. 但这不自动推广到混合投影块 `D=Z,E=-Y,F=X`

这里必须区分两种不同的构造。

### 3.1 未缩放的原始投影块

若取

```text
g~^(μν)=C g^(μν)+M^(μν)
```

其中

```text
M^(μν)=Z u^μu^ν-Y(u^μr^ν+r^μu^ν)+X r^μr^ν ,
```

则

```text
g~^(μν)u_ν = (C+Δ)u^μ,
qquad
Δ = XZ-Y^2 .
```

若要求变换后 HJ 壳约束

```text
g~^(μν)u_μu_ν = κ ,
```

则必有

```text
C+Δ = κ/X .
```

四维下逆度规行列式比值是

```text
R_inv = C^2(C+Δ)^2 = C^2 (κ/X)^2 .
```

若再要求强连续性匹配

```text
sqrt(|g~|)ρ~(C+Δ) = sqrt(|g|)ρ ,
```

则由于

```text
sqrt(|g~|)=sqrt(|g|)/sqrt(R_inv),
```

得到

```text
ρ~ = ρ sqrt(R_inv)/(C+Δ) = ρ |C| .
```

因此：

```text
ρ~ = 0
```

并不是自动推出的。它只有在

```text
C -> 0
```

时才成立。

而对这条未缩放分支，若原变量正则使 `Δ` 有限，则

```text
C = κ/X - Δ  ~  κ/X
```

从而

```text
ρ~ ~ ρ |κ/X|
```

反而发散。

### 3.2 真正的 `C=1` 投影型主分支

当前项目更常用的不是上面的 raw block，而是

```text
g~^(μν)=g^(μν)+λ M^(μν),
```

其中 `λ` 被选成使

```text
1 + λΔ = κ/X .
```

这时

```text
R_inv = (κ/X)^2 ,
```

并且强连续性匹配给出

```text
ρ~ = ρ .
```

所以在这条主分支上也没有

```text
ρ~ -> 0 .
```

---

## 4. 因而用户思路应如何修正

用户的物理直觉本身没有错：

```text
若某条变换分支上 ρ~ -> 0，
则“速度发散但无粒子”是一个合理解释。
```

但要非常精确：

### 4.1 这是分支依赖的，不是一般真理

- rank-1 `C=1` 分支：成立
- 某些 genuinely mixed 分支：也成立
- 当前最常用的 `C=1` 投影型主分支：不成立
- 未缩放 raw 投影块 `D=Z,E=-Y,F=X`：一般也不成立

### 4.2 不能把 `sqrt(|g|)ρ = sqrt(|g~|)ρ~` 当成普适关系

在当前问题里，真正受连续性方程控制的是

```text
J~^μ = sqrt(|g~|)ρ~ g~^(μν)u_ν ,
```

因此普适关系不是单纯的测度密度相等，而是带有 `g~u` 因子的电流关系。

对投影块来说，若忽略这点，就会误把 `sqrt(|g~|)->0` 直接读成 `ρ~->0`，从而得到错误结论。

---

## 5. 最终判断

```text
“X=0 时若 ρ~ = 0，则速度无定义但不代表物理问题”
```

这是一个合理且重要的物理解读。

但它只能用于那些确实满足

```text
ρ~ -> 0
```

的分支。

对用户举的混合投影块例子：

- 若指 raw `D=Z,E=-Y,F=X`，则一般推出 `ρ~ = ρ|C|`，并不自动为零；
- 若指当前项目主用的 `C=1` 投影型分支，则甚至有 `ρ~ = ρ`。

所以这里真正应该保留的是：

```text
用户的物理解读是对某些分支成立的，
但用混合投影块来证明它时，需要重新区分具体分支和正确的连续性关系。
```
