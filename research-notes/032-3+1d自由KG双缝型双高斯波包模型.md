# 032 3+1d 自由 KG 双缝型双高斯波包模型

## 目标

把当前用于几何化与引力作用量比较的基线模型，
从 1+1d 切换到更物理、更适合讨论 Einstein 作用量的 3+1d 自由 KG 双缝型模型。

当前只做最小但实用的版本：

```text
自由 Klein-Gordon
+ 双高斯波包
+ 双缝型空间分束
+ 精确正频 Fourier 演化
```

## 1. 为什么要切到 3+1d

前面的 1+1d 模型仍然有用，但它有一个根本限制：

```text
纯 Einstein-Hilbert 在 1+1d 中是拓扑型的，
不能像 3+1d 那样提供局域引力动力学。
```

因此，如果后续要认真比较

```text
S_EH[g]
vs
S_EH[g~]
```

或者任何 Q 依赖的引力作用量，
3+1d 才是更自然的舞台。

## 2. 几何与坐标约定

工作在 Minkowski 背景：

```text
η_μν = diag(1,-1,-1,-1)
```

采用坐标：

```text
(t, x, y, z)
```

其中：

- `z`：传播方向
- `y`：双缝分束方向
- `x`：另一条横向方向

这对应一个标准的双缝几何：

```text
两束波包主要沿 z 传播，
在 y 方向上分开，
最后在后方屏幕上形成干涉。
```

## 3. 自由 KG 方程

```text
(∂_t^2 - ∂_x^2 - ∂_y^2 - ∂_z^2 + m^2) ψ = 0
```

正频色散关系：

```text
ω(k) = sqrt(k_x^2 + k_y^2 + k_z^2 + m^2)
```

## 4. 双缝型双高斯波包

总波函数写成

```text
ψ = ψ_L + ψ_R
```

其中左右两束的动量空间谱取为：

```text
a_L(k) = A_L * exp[-(k_x-kx0)^2/(4σ_kx^2)
                   -(k_y-ky0)^2/(4σ_ky^2)
                   -(k_z-k0 )^2/(4σ_kz^2)]
         * exp[-i (k_x x0 + k_y y_L0 + k_z z0)]

a_R(k) = A_R * exp[-(k_x-kx0)^2/(4σ_kx^2)
                   -(k_y-ky0)^2/(4σ_ky^2)
                   -(k_z-k0 )^2/(4σ_kz^2)]
         * exp[-i (k_x x0 + k_y y_R0 + k_z z0)] * exp[i φ0]
```

我们取最自然的双缝对称设置：

```text
kx0 = 0
ky0 = 0
kz0 = k0
x0  = 0
y_L0 = -d/2
y_R0 = +d/2
```

并令

```text
A_L = alpha
A_R = sqrt(1-alpha)
```

说明：

- `d`：双缝分束间距
- `σ_kx, σ_ky, σ_kz`：动量空间宽度
- `k0`：共同中心传播波矢
- `ω0 = sqrt(k0^2 + m^2)`：共同中心频率
- `φ0`：两束的相对初相位

## 5. 精确演化

总波函数的精确正频演化写成

```text
ψ(x,y,z,t)
= ∭ d^3k a(k)
   exp[i(k_x x + k_y y + k_z z) - i ω(k) t]
```

这比任何抛物近似/慢变包络更基础。

## 6. 这个模型中要计算的量

### 6.1 基本量

```text
ψ
∂_t ψ
∂_x ψ
∂_y ψ
∂_z ψ
∂_t^2 ψ
∂_x^2 ψ
∂_y^2 ψ
∂_z^2 ψ
```

### 6.2 Bohm / Madelung 量

```text
ρ = |ψ|^2
S = arg ψ
```

### 6.3 电流

在当前签名约定下：

```text
j^0 = Im( ψ* ∂_t ψ )
j^x = - Im( ψ* ∂_x ψ )
j^y = - Im( ψ* ∂_y ψ )
j^z = - Im( ψ* ∂_z ψ )
```

于是

```text
∂_t S = j^0 / ρ
∂_i S = - j^i / ρ
```

### 6.4 X

```text
X = ∂_μ S ∂^μ S
  = (∂_t S)^2 - (∂_x S)^2 - (∂_y S)^2 - (∂_z S)^2
```

### 6.5 Q

记

```text
R = sqrt(ρ)
```

则

```text
Q = - Box R / R
  = (∂_x^2 + ∂_y^2 + ∂_z^2 - ∂_t^2) R / R
```

## 7. 计算策略

由于 3+1d 直接全网格计算非常重，
第一版脚本采用分层策略：

### 第 1 层：任意采样点/屏幕面上的精确 ψ 与一阶导数

用于：

- 干涉条纹
- 流线
- 相位结构

### 第 2 层：固定时刻或固定屏幕面的局部二阶导数与 Q

用于：

- 估计 `Q/m^2`
- 识别节点尖峰
- 给几何化与引力作用量测试提供输入

这样做的好处是：

```text
先把“实验可见的屏幕物理”算稳，
再逐步扩展到更重的全 3d Q 结构。
```

## 8. 为什么这个模型比 1+1d 更适合作用量比较

因为在 3+1d 里：

```text
S_EH[g]
和
S_EH[g~]
都会产生真正的局域引力动力学差异，
不再有 1+1d 的拓扑退化问题。
```

所以后续若发现

```text
g~ 在双缝干涉区诱导出显著几何结构，
```

那这些结构就可能真正反馈到引力作用量比较中，
而不是只停留在“局域曲率看起来非零”的层面。
