# 064 纯共形变换能否满足几何化要求

## 目标

单独讨论纯共形变换：

```text
g~^(μν) = C g^(μν)
```

看它能否满足我们此前对更一般非共形变换所提出的几项要求。

这里我们明确分成两个层级：

1. 方程级要求：
   - 恢复 `g` 系的 Hamilton-Jacobi 方程
   - 恢复 `g` 系的连续性方程
   - 在 `g~` 系中得到测地线解释
2. 更强的作用量级要求：
   - 把该变换直接拉回旧变量后，作用量不退化成恒等零

---

## 1. 原 `g` 系方程

采用当前项目的新约定：

```text
Q = Box sqrt(ρ) / sqrt(ρ)
u_μ = ∂_μ S
X = g^(μν) u_μ u_ν
```

原 `g` 系的两条基本方程是：

```text
Hamilton-Jacobi 方程：
X = m^2 + Q

连续性方程：
∂_μ [ sqrt(|g|) ρ u^μ ] = 0
```

---

## 2. 变换后的物质作用量

从新变量侧的作用量出发：

```text
I~[ρ~,S;g~]
= ∫ d^n x sqrt(|g~|) ρ~ ( g~^(μν) u_μ u_ν - κ )
```

这里：

- `κ` 是变换后壳约束里的常数
- `n` 是时空维数

本笔记在中间先保留一般 `n`，最后再代 `n=4`

---

## 3. 纯共形 ansatz

取

```text
g~^(μν) = C g^(μν)
```

则协变度规满足

```text
g~_(μν) = C^(-1) g_(μν)
```

因此

```text
sqrt(|g~|) = |C|^(-n/2) sqrt(|g|)
```

若限制在 `C>0` 的 patch 上，则可直接写成

```text
sqrt(|g~|) = C^(-n/2) sqrt(|g|)
```

---

## 4. HJ 方程

对 `ρ~` 变分，得到

```text
g~^(μν) u_μ u_ν = κ
```

代入纯共形 ansatz：

```text
C X = κ
```

所以

```text
C = κ / X
```

这已经说明：

```text
只要 X ≠ 0，
纯共形变换就足以在方程级把原 HJ 方程重写成常壳约束。
```

若要求它与原 `g` 系方程

```text
X = m^2 + Q
```

精确等价，则有

```text
C = κ / (m^2 + Q)
```

最自然的 massive 选择是

```text
κ = m^2
```

于是

```text
C = m^2 / X = m^2 / (m^2 + Q)
```

---

## 5. 连续性方程

对 `S` 变分得到

```text
∂_μ [ sqrt(|g~|) ρ~ g~^(μν) u_ν ] = 0
```

代入共形形式：

```text
∂_μ [ sqrt(|g|) C^(1 - n/2) ρ~ u^μ ] = 0
```

若要它精确恢复原连续性方程

```text
∂_μ [ sqrt(|g|) ρ u^μ ] = 0
```

一个最自然的充分条件是定义

```text
C^(1 - n/2) ρ~ = ρ
```

也就是

```text
ρ~ = C^(n/2 - 1) ρ
```

在 `n=4` 时，简化成

```text
ρ~ = C ρ
```

因此：

```text
纯共形变换并不是注定失败；
若允许 ρ~ 真正跟着变换，
它在方程级也可以精确恢复原连续性方程。
```

---

## 6. 测地线解释

定义

```text
u~^μ := g~^(μν) u_ν = C u^μ
```

又因为 `u_μ = ∂_μ S` 是一个 exact one-form，所以

```text
∇~_μ u_ν = ∇~_ν u_μ
```

于是

```text
u~^ν ∇~_ν u_μ
= u~^ν ∇~_μ u_ν
= (1/2) ∇~_μ ( g~^(αβ) u_α u_β )
= (1/2) ∂_μ κ
= 0
```

因此 `u~^μ` 的积分曲线满足新度规 `g~` 下的测地线方程。

所以：

```text
纯共形变换在方程级也保留了测地线解释。
```

---

## 7. 经典极限

### 7.1 `m ≠ 0`

若取

```text
κ = m^2
```

则

```text
C = m^2 / (m^2 + Q)
```

当 `Q -> 0` 时，

```text
C -> 1
```

所以有

```text
g~ -> g
ρ~ -> ρ
```

因此 pure conformal 在 massive 主分支上有正确的经典恢复。

### 7.2 `m = 0`

这时原 HJ 方程是

```text
X = Q
```

若仍取固定非零 `κ`，则

```text
C = κ / Q
```

所以当 `Q -> 0` 时，`C` 发散。

因此：

```text
m = 0, κ ≠ 0
```

的纯共形 patch 也没有经典恢复。

若强行取 `κ = 0`，则当前作用量又退化成 null-shell 的奇异极限。

---

## 8. 因果结构

纯共形变换的一个特殊优点是：

```text
它不改变 null cone 的集合。
```

因为

```text
g~_(μν) v^μ v^ν = C^(-1) g_(μν) v^μ v^ν
```

所以对任何向量 `v^μ`：

```text
g(v,v) = 0   ⇔   g~(v,v) = 0
```

若 `C>0`，则 timelike / spacelike / null 的符号分类完全保持。

这说明：

```text
纯共形变换不会像一般 disformal 那样主动弯曲光锥。
```

因此在“局域因果锥是否被改坏”这件事上，共形变换反而最安全。

但代价是：

```text
它也无法用新锥去重新解释原先的类空/超光速结构。
```

---

## 9. 最强的保留：直接拉回旧变量后，作用量会退化

上面的成功都发生在：

```text
先对新变量作用量变分，
再把共形关系代回方程
```

这一层级。

但如果我们把

```text
C = κ / X
ρ~ = C^(n/2 - 1) ρ
```

直接代回新作用量本身，则有

```text
I~
= ∫ d^n x sqrt(|g~|) ρ~ ( C X - κ )
```

由于

```text
sqrt(|g~|) ρ~
= C^(-n/2) sqrt(|g|) · C^(n/2 - 1) ρ
= C^(-1) sqrt(|g|) ρ
```

故

```text
I~
= ∫ d^n x sqrt(|g|) ρ C^(-1) ( C X - κ )
= ∫ d^n x sqrt(|g|) ρ ( X - κ/C )
```

而由 `C = κ/X`，

```text
κ/C = X
```

所以

```text
I~ = 0
```

恒等成立。

这说明：

```text
纯共形变换在“先变分后代回”的方程级是成功的，
但若把匹配条件直接硬编码回旧变量作用量，
则会退化成零作用量。
```

因此它不能满足“拉回旧变量后仍保留一个非退化有效作用量”这一更强要求。

---

## 10. 总结

纯共形变换的最终判断要分层说：

### 10.1 若只问方程级要求

答案是：

```text
可以。
```

更具体地说：

1. 它可以恢复原 HJ 方程
2. 它可以恢复原连续性方程
3. 它可以给出 `g~` 下的测地线解释
4. 对 `m ≠ 0` 主分支，它还能有正确的经典极限

### 10.2 若再问“拉回旧变量后的非退化作用量”

答案是：

```text
不可以。
```

因为一旦把

```text
C = κ/X
```

直接硬编码进拉回后的作用量，integrand 就恒等塌成零。

### 10.3 若再问“它能否替代一般 disformal 的全部功能”

答案也是：

```text
不可以。
```

因为它不改变 null cone，因此不能承担那些依赖“新因果锥”和“类时/类空重解释”的任务。

---

## 当前结论

因此，纯共形变换的地位应写成：

```text
它在“方程级几何化”上比早期直觉中更强，
但在“非退化作用量重写”和“改变因果锥结构”上比一般 disformal 更弱。
```

这就是它与 rank-1 / 混合 ansatz 的最核心区别。
