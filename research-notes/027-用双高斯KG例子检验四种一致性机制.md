# 027 用双高斯 KG 例子检验四种一致性机制

## 目标

不再停留在抽象猜测，而是用已经建立的 1+1d 自由 KG 双高斯干涉模型，直接检验下面四种思路在一个具体例子里是否站得住：

```text
1. 大 Q 根本不出现在已观测系统里
2. Q 虽然大，但几乎是常数
3. 可观测物质都普适地耦合到同一个几何
4. 存在某种屏蔽/筛选机制
```

我们当前的目的不是“宇宙学终判”，而是：

```text
用一个明确模型先筛掉明显不靠谱的解释，
把可行思路与不可行思路分开。
```

## 1. 作为检验台的具体例子

使用前一份文档已经建立的 1+1d 自由 KG 双高斯干涉模型。

参数组为：

```text
m = 1.0
alpha = 0.6
sigma_l = 0.35
sigma_r = 0.28
k0 = 2.0
phi0 = 0.7
x_l0 = -6.0
x_r0 =  6.0
t_sample ≈ 9.58
```

这个例子的重要数值结果是：

### 1.1 主支撑区

```text
ρ >= 0.01 ρ_max  时， |Q|/m^2_max ≈ 0.239
ρ >= 0.001 ρ_max 时， |Q|/m^2_max ≈ 0.585
ρ >= 0.0001 ρ_max 时，|Q|/m^2_max ≈ 0.845
```

### 1.2 节点附近低密度区

```text
全域最大值： |Q|/m^2_max ≈ 2.406
```

这意味着：

```text
这个模型不是“只有极小量子势”。
```

相反，它已经是一个：

```text
主支撑区内 Q/m^2 达到 O(10^-1 ~ 1)，
节点附近出现更强尖峰
```

的非常合适的检验台。

## 2. 四种机制的具体判别标准

### 机制 1：大 Q 根本不出现在已观测系统里

在这个双高斯干涉模型里，这个机制意味着：

```text
Q/m^2 在实验真正有概率支撑的区域里必须一直很小。
```

也就是不只要求全域最大值小，而是要求：

```text
在主支撑区内也小。
```

### 机制 2：Q 虽然大，但几乎是常数

在这个模型里，这意味着：

```text
Q 的空间变化很弱，
即便数值大，也不产生大的 ∇Q、∇∇Q。
```

因为两种 Einstein 作用量的差异不只看 `Q`，还看

```text
ε = Q/m^2
∇ε
∇∇ε
```

### 机制 3：可观测物质都普适地耦合到同一个几何

在这个模型里，这意味着：

```text
哪怕 g 与 g~ 不同，
真正实验可测的传播、相位、轨道、时间尺度
都只依赖同一个几何对象。
```

换句话说，差异必须可以通过“表象重定义”整体吃掉。

### 机制 4：存在某种屏蔽/筛选机制

在这个模型里，这意味着：

```text
虽然 Q 可以在理论上变大，
但它对可观测量的影响只在低密度、节点附近、
或者实验实际不敏感的区域出现。
```

这是一个非常具体的说法，不再是口号。

## 3. 对机制 1 的检验

机制 1 说：

```text
大 Q 根本不出现在已观测系统里。
```

但在这个双高斯模型中，我们已经算到：

```text
在 ρ >= 0.01 ρ_max 的主支撑区里，
|Q|/m^2_max ≈ 0.239
```

在更宽一点的主支撑区里：

```text
ρ >= 0.001 ρ_max 时，
|Q|/m^2_max ≈ 0.585
```

这说明：

```text
Q/m^2 在实验真正有概率支撑的区域里
并不总是可以忽略。
```

### 3.1 判断

因此，对这个具体模型来说：

```text
机制 1 不成立。
```

更准确地说：

```text
“大 Q 完全不出现”不能作为当前理论恢复实验预测的普适解释。
```

至少对干涉类量子现象，这条路是不够的。

## 4. 对机制 2 的检验

机制 2 说：

```text
Q 虽然可能大，但几乎是常数，
所以几何差异不一定大。
```

但在双高斯干涉模型中，`Q` 的大值主要来自：

```text
条纹节点附近的快速弯曲
```

也就是说，大 `Q` 不是一个平坦高台，而是带有强烈空间结构的尖峰。

从前面的结果也能看出来：

- 主支撑区平均值不大
- 但最大值上升很快
- 尤其在低密度条纹附近急剧变大

这已经足以说明：

```text
Q 不仅大，而且通常变化很快。
```

### 4.1 判断

因此，对这个具体模型来说：

```text
机制 2 一般不成立。
```

更温和的说法是：

```text
它最多只在局部近似、或单个波包远离干涉时可能成立；
在真正的双束干涉区并不成立。
```

## 5. 对机制 3 的检验

机制 3 说：

```text
可观测物质都普适地耦合到同一个几何，
因此 g 与 g~ 的差别不直接成为实验差别。
```

这个机制的特点是：

```text
它不依赖 Q 小，也不依赖 Q 慢变。
```

即使 `Q` 在干涉区不小，
只要：

- 物质传播
- 时钟
- 尺子
- 探测器响应

都只看 `g~`（或都只看 `g`），
那么很多“差异”就不再是直接可观测的。

### 5.1 在这个模型里能否直接否掉？

不能。

因为这个 1+1d 自由 KG 例子只告诉我们：

```text
Q 的大小和结构是什么。
```

它并没有单独指定：

```text
实验中的探测器、其他物质自由度、时钟和尺子
到底耦合到 g 还是 g~。
```

### 5.2 判断

因此，对这个具体模型来说：

```text
机制 3 不能被当前例子否定。
```

并且它仍然是非常值得认真对待的一条思路。

但它确实如用户所说，已经开始涉及：

```text
相互作用与测量模型
```

而不只是单个自由 KG 场。

## 6. 对机制 4 的检验

机制 4 说：

```text
存在某种屏蔽/筛选机制，
使得即便 Q 大，
它对可观测量的影响也被压住。
```

在这个双高斯模型里，最自然的版本是：

```text
Q 的最大尖峰主要出现在低密度节点附近，
而这些区域对实验信号的加权贡献可能很小。
```

这一点在当前模型中是有明确支持的。

因为我们已经看到：

```text
主支撑区内 |Q|/m^2 是 O(10^-1 ~ 1)
而更极端的大尖峰主要在低密度区
```

这意味着：

```text
若某类实验可观测量天然按 ρ 或流密度加权，
那么节点尖峰的影响可能被削弱。
```

### 6.1 但这不等于自动安全

必须小心：

```text
主支撑区里的 Q/m^2 也并不总是很小。
```

所以机制 4 不是“自动成立”，而是：

```text
在这个模型上看起来有希望，
但需要具体可观测量的权重来判定。
```

### 6.2 判断

因此，对这个具体模型来说：

```text
机制 4 是四条里目前最有希望的一条，
但它需要进一步把“什么算实验信号”写清楚。
```

## 7. 四条机制的阶段判决

现在可以直接给出一个面向这个具体模型的判断表。

```text
机制   内容                                 在当前双高斯模型中的判断
-----------------------------------------------------------------------
1      大 Q 根本不出现                      不成立
2      Q 大但几乎是常数                    一般不成立
3      可观测物质普适耦合到同一几何         不能被当前模型否定，值得保留
4      存在屏蔽/筛选机制                    最有希望，但需结合具体观测量
```

## 8. 当前最稳的结论

这个具体例子已经告诉我们：

```text
若想解释“为什么两种 Einstein 作用量在现有实验上差异不显著”，
最不靠谱的解释是：
Q 根本不大，或者 Q 虽大但几乎常数。
```

相反，更值得继续推的是：

```text
1. 普适耦合到同一几何
2. 某种对低密度/快速振荡区不敏感的筛选机制
```

其中：

```text
机制 3 更深，但牵涉相互作用；
机制 4 更接近我们现在手头这个自由场模型能继续检验的东西。
```

## 9. 下一步建议

顺着这个判断，最自然的下一步是：

```text
不要立刻跳去完整相互作用，
而是先把“可观测量如何按 ρ、j^μ、相位梯度加权”
这件事写清楚。
```

也就是说，下一步应直接问：

```text
对于这个双高斯模型，
哪些自然定义的实验信号
会对节点附近的大 Q 尖峰不敏感，
哪些又会高度敏感？
```

这样就能把机制 4 从“有希望”推进到“是否真的成立”。
