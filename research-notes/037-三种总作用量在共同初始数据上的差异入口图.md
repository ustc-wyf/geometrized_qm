# 037 三种总作用量在共同初始数据上的差异入口图

## 目标

在同一组初始/边界条件下，先不做完全自洽的联合反馈演化，而是直接比较三种总作用量在当前双束模型上的“差异入口”：

```text
1. S_total^(g)
   = S_EH[g] + S_matter

2. S_total^(g~)
   = S_EH[g~] + S_matter

3. S_total^(F)
   = ∫ sqrt(-g~) F(Q) R~ + S_matter
```

这里三者共享：

```text
- 相同的初始波函数（两束分开的高斯波包）
- 相同的渐近边界：Q -> 0 处时空平直
```

## 1. 当前阶段的原则

当前先不直接解三套完整联立 PDE，
而是先画出它们在共同初始数据上的差异入口量。

这样做的理由是：

```text
如果某种作用量的差异入口只在节点极窄区域出现，
那么未必值得上完整耦合；
如果它在主支撑区已经显著，
那就值得继续做联合演化。
```

## 2. 三种作用量的差异入口

### 2.1 `S_total^(g)`

若前变换背景取 Minkowski，

```text
g = η
R[g] = 0
```

因此它的引力部分在当前共同初始数据上没有新的局域入口。

所以它的“入口图”本质上是：

```text
基线物质图样本身。
```

### 2.2 `S_total^(g~)`

它的差异入口主要来自：

```text
ε = Q / m^2
g~ - g
以及由 g~ 诱导出的几何量
```

### 2.3 `S_total^(F)`

若取

```text
F(Q) = 1 / (1 + (κQ)^2)
```

则差异入口主要来自：

```text
F(Q)
∇F
∇^2 F
```

这些量在节点附近尤其重要。

## 3. 当前可视化对象

因此，本阶段实际绘图比较的量是：

```text
ρ
Q
X
ε = Q/m^2
F(Q)
|∇F|
```

它们都在同一组初始数据上计算，
从而告诉我们：

```text
三种总作用量的差异“从哪里冒出来”。
```

## 4. 当前最重要的解释

这些图不是最终实验预测，
而是：

```text
联合演化前的诊断图。
```

它们的用途是判断：

```text
差异主要是主支撑区主导，
还是节点附近尖峰主导，
以及是否值得继续求三套完全耦合的演化。
```
