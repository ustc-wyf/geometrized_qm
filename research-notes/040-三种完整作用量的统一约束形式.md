# 040 三种完整作用量的统一约束形式

## 目标

把三种候选总作用量放到同一个统一框架里，便于严格比较和后续数值积分：

```text
1. gravity on g:      S_EH[g]
2. gravity on g~:     S_EH[g~]
3. gravity on g~:     S_f[g~] = ∫ sqrt(-g~) f(R~)
```

同时坚持当前项目的原始物质场目标：

```text
L_matter = sqrt(-g~) ρ~ ( g~^(μν) ∂_μ S ∂_ν S - m^2 )
```

也就是：

```text
我们要的是几何化后的 Bohm 型有效物质拉氏量，
不是标准 g~-KG 的复场拉氏量。
```

## 1. 统一变量

采用独立变分变量：

```text
g_{μν}
g~_{μν}
ρ~
S
Λ^{μν}   (约束 g~ 与 g 的关系)
λ        (约束密度关系)
```

## 2. 约束关系

当前主线的最简单几何化关系是：

```text
g~^(μν) = C g^(μν) + D u^μ u^ν
u_μ = ∂_μ S
```

其中

```text
C,D
```

可以是由 `(ρ~,S)` 及其导出量构造的标量函数。

为了写成独立变分形式，
引入张量乘子 `Λ_{μν}` 强制：

```text
g~^(μν) - C g^(μν) - D u^μ u^ν = 0
```

同时，连续性方程要恢复原形式时，对密度关系采用：

```text
sqrt(-g~) ρ~ (C + D X) = sqrt(-g) ρ
```

若以 `ρ` 作为给定基线密度，可用标量乘子 `λ` 约束：

```text
sqrt(-g~) ρ~ (C + D X) - sqrt(-g) ρ = 0
```

这里

```text
X = g^(μν) ∂_μ S ∂_ν S
```

## 3. 三种总作用量

### 3.1 分支 A：gravity on g

```text
S_A
= (M_P^2 / 2) ∫ d^4x sqrt(-g) R[g]
 + ∫ d^4x sqrt(-g~) ρ~ ( g~^(μν) ∂_μ S ∂_ν S - m^2 )
 + S_constraint
```

### 3.2 分支 B：gravity on g~

```text
S_B
= (M_P^2 / 2) ∫ d^4x sqrt(-g~) R[g~]
 + ∫ d^4x sqrt(-g~) ρ~ ( g~^(μν) ∂_μ S ∂_ν S - m^2 )
 + S_constraint
```

### 3.3 分支 C：gravity = f(R~)

```text
S_C
= (M_P^2 / 2) ∫ d^4x sqrt(-g~) f(R~)
 + ∫ d^4x sqrt(-g~) ρ~ ( g~^(μν) ∂_μ S ∂_ν S - m^2 )
 + S_constraint
```

并且当前指定

```text
f(R~) = R~ F(χ)
χ = ℓ^2 R~
F(χ) = 1 / sqrt(1 + χ^2)
```

## 4. 共同的物质方程

无论哪一分支，
对 `ρ~` 变分都给出

```text
g~^(μν) ∂_μ S ∂_ν S - m^2 = 0
```

即

```text
HJ equation in g~
```

对 `S` 变分则给出

```text
∂_μ [ sqrt(-g~) ρ~ g~^(μν) ∂_ν S ] + (来自约束的链式项) = 0
```

如果后续在数值实现里把约束强行代入，
那么会退化成当前已经熟悉的连续性结构。

## 5. 三者真正不同的地方

三者差异不在物质拉氏量，而在引力方程：

### 分支 A

对 `g_{μν}` 变分得到：

```text
M_P^2 G_{μν}[g] = T^{(constraint)}_{μν}
```

因为物质直接耦合在 `g~` 上，不直接耦合在 `g` 上。

### 分支 B

对 `g~_{μν}` 变分得到：

```text
M_P^2 G~_{μν}[g~]
= T^{(matter)}_{μν}[ρ~,S;g~] + T^{(constraint)}_{μν}
```

### 分支 C

对 `g~_{μν}` 变分得到标准 `f(R)` 型方程：

```text
M_P^2 [ f_R R~_{μν} - 1/2 f g~_{μν}
        - (∇~_μ ∇~_ν - g~_{μν} □~) f_R ]
= T^{(matter)}_{μν} + T^{(constraint)}_{μν}
```

其中

```text
f_R = d f / dR~
```

## 6. 为什么不能直接数值做 3+1d 全系统

到这一步已经能看出：

```text
三套系统都至少包含：
- 约束
- 非线性 metric-matter 耦合
- (对 C 分支) f(R) 的高阶结构
```

因此若直接在完整 3+1d 上数值积分，
等于做一个小型数值相对论项目。

这不是做不了，
而是：

```text
必须先降维/定 gauge/选变量，
否则根本不是“先试一下”能完成的。
```

## 7. 当前可行的下一步

因此，完整作用量推导之后，
最自然的数值化方向不是直接 3+1d 全系统，
而是先做：

```text
2+1d 对称约化：
(t, x, z)
```

并固定一种简单 gauge，
再分别积分三套方程。

这才是“从完整作用量出发，还能真正跑起来”的路线。
