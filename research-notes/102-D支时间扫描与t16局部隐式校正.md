### 时间扫描的主要结论

1. 不需要对每个时间切片都做隐式校正。
   - `t = 6, 8, 10, 12, 16` 的主支撑区残差 `p95` 都在 `10^{-2}` 量级。
   - 这说明 bulk 参考解本身已经很接近候选场方程。

2. 当前“坏时间切片”分成两类。
   - `t = 0, 2, 4`：
     代表性残差偏大，其中 `t = 0` 的全局建议显式步长被压到极小。
   - `t = 14, 16`：
     `p95` 仍小，但 `abs_max` 和局部加密比例重新抬头，说明后期是“少数尖峰重新主导”的状态。

3. `t = 8` 仍然是“无需主动校正”的代表时刻。
   - 这一点与前一轮 `t=8` 局部隐式校正自动给出 `delta_chi = 0` 完全一致。

### t=16 的量化结果

主支撑区迹残差：

- 校正前 `abs_max`：`108.03502511808556`
- 校正后 `abs_max`：`62.697182259797884`
- 校正前 `abs_mean`：`0.09018400621864664`
- 校正后 `abs_mean`：`0.049719241797634095`
- 校正前 `p95`：`1.5071285659407896e-4`
- 校正后 `p95`：`1.5073020858745765e-4`

局部加密掩膜内迹残差：

- 校正前 `abs_max`：`108.03502511808556`
- 校正后 `abs_max`：`62.697182259797884`
- 校正前 `abs_mean`：`5.175302748410733`
- 校正后 `abs_mean`：`2.8493861560688085`
- 校正前 `p95`：`16.355651933463605`
- 校正后 `p95`：`6.107417575954614`

迭代历史：

- 第 0 步后，掩膜内 `p95` 从 `16.36` 压到约 `6.81`
- 随后两步继续小幅收缩到约 `6.46`
- 典型更新量很小：
  主掩膜 `delta_chi` 的 `p95` 只有 `5.78e-5`
- 最大单点更新量约 `2.31e-3`

### 解释

1. `t=16` 的校正不是“完全不动”，而是已经能实质压低尖峰。
2. 主支撑区的 `p95` 几乎不变，说明 bulk 本来就很好，校正器没有去破坏正确的主体区域。
3. 真正被修正的是局部加密掩膜内那少数 stiff 尖点。
4. 这进一步支持后续路线：
   - 不做全域统一隐式；
   - 只对坏切片、坏区域做局部隐式校正。

### 当前结论

目前最稳妥的数值路线已经进一步明确为：

1. 先做参考解时间扫描；
2. 只筛出少数坏时间切片；
3. 在这些切片上，只对局部加密区域做 `chi` 的隐式校正；
4. 后续再把这个局部校正器接进真正的物理时间推进器。
