# D 支饱和区代表度规准则落地

日期：2026-05-03

## 本轮目标

用户要求尽快把“饱和区代表 metric 的选择准则”定下来并落实到代码。

## 准则

当前正式采用的代码准则叫：

\[
\boxed{\texttt{restricted\_extension}}
\]

它不是新的物理作用量，也不是削发散项，而是在 \(f_R\to0\) 后局部 metric 方程退化时，为饱和区代表度规指定一个闭合规则。

准则按以下顺序执行：

1. 只在 saturated bulk 内部尝试更新代表 metric；
2. weak / transition / interface 侧的数据作为物理 Dirichlet 锚点；
3. 若某个饱和连通块没有接触这些物理锚点，则该块视作 orphan saturated component，保持原代表；
4. 对有锚点的饱和块，用离散 harmonic / 最小 metric-gradient 延拓选代表；
5. 延拓后必须通过 Lorentz 签名、质量壳判别式和正 \(\tilde\rho\) 检查；
6. 若不通过，则回溯减小更新幅度，仍不通过则退回原代表。

这条规则体现了用户强调的点：

- 过渡层确实是边界约束；
- 但如果当前切片没有弱区/过渡区锚点，就不能让 support 外人工边界替代物理边界；
- 饱和区内部代表不是任意平均，而是“界面/弱区锚定下的受限延拓”。

## 关键实现判断

最初测试显示，若无条件把整个 saturated support 做最小曲率延拓，外侧 support 边界会牵引内部 metric，导致质量壳判别式快速穿零。

因此加入硬约束：

\[
\boxed{
\text{无 weak/transition/interface 物理锚点的饱和连通块不做 harmonic 延拓。}
}
\]

这不是退回旧方案，而是避免把数值裁剪边界误当作物理边界。

## 结论

当前准则已经落地，但在物理参数 \(\ell/l_P=10^{60}\)、\(t_{\rm old}=8\) 的干涉窗口上，它判断为：

\[
\boxed{
\text{当前整个 support 是一个无物理锚点的 saturated orphan bulk，所以不能改代表 metric。}
}
\]

因此当前场景下新准则退回为保持原代表，不是因为没有准则，而是因为准则禁止用人工边界决定饱和区内部 metric。

下一步如果要让 `restricted_extension` 真正发挥作用，需要研究存在 weak/transition anchor 的参数窗口，或把 direct tensor interface reconstruction 接进来作为物理锚点。
