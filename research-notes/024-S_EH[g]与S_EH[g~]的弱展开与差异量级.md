# 024 `S_EH[g]` 与 `S_EH[g~]` 的弱展开与差异量级

## 目标

比较两种候选引力作用量：

```text
S_grav^(g)   = (1 / 16πG_N) ∫ d^4x sqrt(-g)  R[g]
S_grav^(g~)  = (1 / 16πG_N) ∫ d^4x sqrt(-g~) R[g~]
```

并回答三个问题：

1. 一阶/二阶差异如何展开？
2. 在弱场、弱量子势区域差异量级多大？
3. 哪些量会在“强引力 + 强量子”或“弱引力但强变化量子”场景下放大差异？

同时显式吸收用户的提醒：

```text
即使背景 g 很弱，
如果量子势 Q 很大，
则 g~ 本身也可能是一个很大的几何变形。
```

所以不能简单用“g 近似平直”来推出两种 Einstein 作用量一定接近。

## 1. 从最简单 branch 写成更清楚的形式

在 timelike branch 中，

```text
X = m^2 - Q > 0
```

定义单位 timelike 1-形式

```text
n_mu = u_mu / sqrt(X)
```

于是

```text
g^(mu nu) n_mu n_nu = 1
```

并且最简单纯 ansatz 可写成：

```text
g~_mu nu = g_mu nu - ε n_mu n_nu
```

其中

```text
ε = Q / m^2
```

这是因为

```text
g~_mu nu = g_mu nu - [ Q / (X m^2) ] u_mu u_nu
         = g_mu nu - (Q/m^2) n_mu n_nu
```

这是比较引力作用量时最方便的写法。

对应的逆度规为

```text
g~^(mu nu) = g^(mu nu) + [ ε / (1 - ε) ] n^mu n^nu
```

其中要求

```text
1 - ε = X / m^2 > 0
```

也就是 timelike branch 的适用域。

## 2. 行列式与体积元

rank-1 更新直接给出：

```text
det(g~) = det(g) (1 - ε)
sqrt(-g~) = sqrt(-g) sqrt(1 - ε)
```

因此：

```text
若 |ε| << 1，
sqrt(-g~) = sqrt(-g) [ 1 - ε/2 - ε^2/8 + O(ε^3) ]
```

这已经给出作用量差异的一部分来源。

## 3. 精确的曲率差异公式

定义两套 Levi-Civita 联络之差：

```text
C^rho_{mu nu} = Γ~^rho_{mu nu} - Γ^rho_{mu nu}
```

则有精确恒等式：

```text
R~_{mu nu}
= R_{mu nu}
 ∇_rho C^rho_{mu nu}
 - ∇_nu C^rho_{mu rho}
 + C^rho_{rho lambda} C^lambda_{mu nu}
 - C^rho_{nu lambda} C^lambda_{mu rho}
```

于是

```text
R[g~] = g~^(mu nu) R~_{mu nu}
```

这说明差异来源精确上由两类量控制：

```text
1. 背景曲率 R[g], G[g]
2. 几何变形 h_mu nu = - ε n_mu n_nu 的导数
```

所以：

```text
即使 g 本身很弱，
只要 ε 或 n_mu 变化足够快，
R[g~] 仍然可以明显不小。
```

这正是用户提醒的关键点。

## 4. 一阶弱变形展开

令

```text
h_mu nu = g~_mu nu - g_mu nu = - ε n_mu n_nu
```

若

```text
|ε| << 1
```

则对 Einstein-Hilbert 作用量的标准一阶变分给出

```text
S_EH[g~] - S_EH[g]
= -(1 / 16πG_N) ∫ d^4x sqrt(-g) G^(mu nu)[g] h_mu nu
 + boundary
 + O(h^2)
```

代入 `h_mu nu = - ε n_mu n_nu`：

```text
ΔS^(1)
= (1 / 16πG_N) ∫ d^4x sqrt(-g) ε G^(mu nu)[g] n_mu n_nu
 + boundary
```

也就是

```text
ΔL_bulk^(1) ~ (Q / m^2) G_nn
```

其中

```text
G_nn = G^(mu nu) n_mu n_nu
```

### 4.1 一阶结论

因此：

```text
若背景 g 本身接近满足 Einstein 方程，
尤其是近似平直时空里 G_nn 很小，
则一阶 bulk 差异会被强烈压低。
```

这支持用户的原始直觉：

```text
在弱引力背景下，两种 Einstein 作用量可能差异不大。
```

但这还不是全部，因为下一阶和导数项仍可能重要。

## 5. 二阶与导数控制项

对 Einstein-Hilbert 作用量，若继续展开到更高阶，
差异会包含

```text
∇h ∇h
R[g] h^2
```

型项。

对这里的

```text
h_mu nu = - ε n_mu n_nu
```

有

```text
∇_lambda h_mu nu
= - (∇_lambda ε) n_mu n_nu
 - ε (∇_lambda n_mu) n_nu
 - ε n_mu (∇_lambda n_nu)
```

所以二阶/导数项的量级由以下几类量控制：

```text
∇ε
∇n
∇∇ε
∇∇n
```

更具体地说，差异的代表性项会像：

```text
(∇ε)^2
ε ∇∇ε
ε^2 (∇n)^2
ε (∇ε)(∇n)
```

### 5.1 这一步的物理含义

这说明：

```text
哪怕背景 g 非常接近平直，
如果 ε = Q/m^2 很大或变化很快，
则 S_EH[g~] 与 S_EH[g] 的差异依然可能很大。
```

所以更准确的判断应当是：

```text
弱引力 + 弱且缓变的量子势
  ⇒ 两者差异小

弱引力 + 强或快速变化的量子势
  ⇒ 两者也可能明显不同
```

这比“只有强引力 + 强量子才会不同”更精细，也更符合用户刚刚的提醒。

## 6. 在近似平直背景中的特别说明

若

```text
g_mu nu ≈ η_mu nu
```

则

```text
R[g] ≈ 0
G[g] ≈ 0
```

所以一阶 bulk 项近乎消失。

但这不意味着差异自动很小。

因为在这种背景上：

```text
R[g~]
```

几乎完全由

```text
∂ h
和
∂∂ h
```

决定，而 `h = - ε n n`。

若 `ε` 与 `n` 近似常数，则 `g~` 也近似平直，差异很小。

但若 `ε` 或 `n` 快速变化，则：

```text
g 本身近似平直，
g~ 却可能已是强曲率几何。
```

这正是用户提醒的那句

```text
“g 虽然小，但 g~ 可能很大”
```

在引力作用量层面的精确定义。

## 7. 两种候选 Einstein 作用量何时差异小

现在可以把“差异不大”的条件写得更准确：

### 7.1 充分小差异条件（弱展开意义下）

若同时满足

```text
|ε| = |Q|/m^2 << 1
|∇ε| L << 1
|∇n| L << 1
|G_nn| L^2 << 1
```

其中 `L` 是问题的典型长度尺度，
则

```text
S_EH[g~] - S_EH[g]
```

在一阶/二阶上都被压低。

### 7.2 不足以保证差异小的条件

仅仅有

```text
g ≈ η
```

并不足以保证差异小。

因为还必须控制：

```text
ε = Q/m^2
及其导数
```

## 8. 哪些量会成为判别量

现在可以把两种引力作用量的“判别量”列得很清楚。

### 8.1 背景曲率投影

```text
G_nn = G^(mu nu)[g] n_mu n_nu
R_nn = R^(mu nu)[g] n_mu n_nu
```

这类量控制强引力背景里的一阶差异。

### 8.2 量子势幅度

```text
ε = Q / m^2
```

它控制几何变形本身有多大。

### 8.3 量子势的变化率

```text
∇ε
∇∇ε
```

这类量控制即使在弱背景里，`g~` 自身还能产生多大曲率。

### 8.4 Bohm 流的几何量

把 `n_mu` 看成单位 timelike/spacelike 方向场后，其

```text
expansion
shear
vorticity
acceleration
```

对应的量都进入 `∇n` 和 `∇∇n`，因此也是判别量。

### 8.5 分支边界

```text
X = m^2 - Q ≈ 0
```

附近会出现：

- 可逆性退化
- 分支切换
- 体积元/幅度敏感

所以这是非常重要的差异放大窗口。

## 9. 当前最稳的判断

到这一步，最准确的结论不是一句“差异大/小”，而是：

```text
1. 在弱引力 + 弱且缓变量子势区域，
   S_EH[g] 与 S_EH[g~] 的差异通常很小。

2. 在强引力 + 强量子势区域，
   差异会放大。

3. 但即使背景引力弱，
   只要量子势本身大或变化快，
   差异也可能明显。
```

这正是对用户提醒的最精确回应。
