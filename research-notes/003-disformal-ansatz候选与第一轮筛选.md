# 003 Disformal Ansatz 候选与第一轮筛选

## 目标

在已经明确量子势对象与成功判据之后，系统列出可用于“量子势几何化”的候选度规变换，并做第一轮筛选。

本文件的任务不是直接求出正确变换，而是回答：

- 哪些协变对象可以合法进入 `\tilde g_{\mu\nu}`？
- 哪些 ansatz 太弱，不足以吸收量子势？
- 哪些 ansatz 值得优先推进？
- 哪些 ansatz 虽然看似强大，但会过早引入病态风险？

## 1. 可用的协变对象

在当前最小模型里，我们有以下自然对象：

### 1.1 背景度规

```math
g_{\mu\nu}
```

这是所有候选变换的基底。

### 1.2 相位流四矢量

定义

```math
u_\mu := \partial_\mu S.
```

它直接决定 Bohm 四动量

```math
p_\mu = \partial_\mu S.
```

因此若目标之一是把 Bohm 轨迹改写成测地线，那么 `u_\mu` 很自然应出现在候选 ansatz 中。

### 1.3 振幅梯度四矢量

定义

```math
r_\mu := \partial_\mu \sqrt{\rho}.
```

量子势

```math
Q = -\frac{\Box \sqrt{\rho}}{\sqrt{\rho}}
```

虽然含有二阶导数，但其根源正是振幅结构，因此 `r_\mu` 是吸收 `Q` 时最自然的候选对象之一。

### 1.4 可构造的标量不变量

按当前项目约定，由 `u_\mu = \partial_\mu S` 与 `r_\mu = \partial_\mu \sqrt{\rho}` 定义

```math
X := g^{\mu\nu}u_\mu u_\nu,
Y := g^{\mu\nu}u_\mu r_\nu,
Z := g^{\mu\nu}r_\mu r_\nu.
```

再加上 `\rho` 本身，我们就有一组自然的系数函数自变量：

```math
A(\rho,X,Y,Z),\;
B(\rho,X,Y,Z),\;
C(\rho,X,Y,Z),\;
D(\rho,X,Y,Z).
```

## 2. 最一般但仍可控的局部 rank-2 ansatz

若暂时不允许度规显含二阶导数，那么由当前对象构造出的最一般对称 rank-2 候选可写成

```math
\tilde g_{\mu\nu}
= A g_{\mu\nu}
+ B u_\mu u_\nu
+ C r_\mu r_\nu
+ D(u_\mu r_\nu + u_\nu r_\mu).
```

这里：

- `A` 是广义 conformal 因子
- `B` 是沿相位流方向的 disformal 变形
- `C` 是沿振幅梯度方向的 disformal 变形
- `D` 是相位流与振幅流混合项

这已经比标准单向 Bekenstein 形式更一般，但仍在可分析范围内。

## 3. 候选族分类

为了后续逐步推进，我们把它拆成几个层级。

### 类 I：纯 conformal 路线

```math
\tilde g_{\mu\nu} = A(\rho) g_{\mu\nu}
```

也可放宽为 `A(\rho,X,Y,Z)g_{\mu\nu}`，但第一轮优先看最简单的 `A(\rho)`。

#### 优点

- 最简单
- 自动协变
- 可逆性条件清楚：`A \neq 0`
- 经典极限也容易控制

#### 缺点

- 太弱
- 只能各向同性地缩放光锥与长度结构
- 很难把 Bohm 轨迹中的“量子力方向性”解释成联络效应

#### 第一轮判断

作为基线模型值得保留，但不应作为主攻路线。

原因是量子势不只影响“尺度”，还通过振幅结构影响动力学方向；纯 conformal 变换大概率不足以完成完整几何化。

### 类 II：相位流 disformal 路线

```math
\tilde g_{\mu\nu}
= A g_{\mu\nu} + B u_\mu u_\nu.
```

这是最接近标准 Bekenstein disformal 形式的一类，其中“优选方向”由 `u_\mu = \partial_\mu S` 给出。

#### 优点

- 直接围绕 Bohm 四动量构造
- 若目标是把轨迹方程几何化，这一方向天然相关
- 与“测地线化”目标契合度高

#### 缺点

- 量子势 `Q` 的根源在振幅 `\rho`，而不是 `S` 本身
- 若系数不显式依赖振幅结构，仅靠 `u_\mu` 可能无法吸收 `Q`

#### 第一轮判断

高优先级保留。

但要加一条限制：`A,B` 不能只依赖 `X`，至少还应允许依赖 `\rho` 或与振幅有关的不变量，否则它几乎不可能处理 `Q`。

### 类 III：振幅梯度 disformal 路线

```math
\tilde g_{\mu\nu}
= A g_{\mu\nu} + C r_\mu r_\nu.
```

这里“优选方向”直接由振幅梯度给出。

#### 优点

- 与量子势来源更直接相关
- 若目标是吸收 `Q` 或原始振幅梯度项，这一类更自然

#### 缺点

- Bohm 轨迹方向是由 `u_\mu` 决定的，不是由 `n_\mu`
- 因此这一路线对“测地线化”的帮助可能不如类 II 或混合类

#### 第一轮判断

中高优先级保留。

它在“吸收量子势来源”方面很有吸引力，但单独使用时未必能完成轨迹的几何化。

### 类 IV：混合双向 disformal 路线

```math
\tilde g_{\mu\nu}
= A g_{\mu\nu}
+ B u_\mu u_\nu
+ C r_\mu r_\nu
+ D(u_\mu r_\nu + u_\nu r_\mu).
```

这是当前最值得关注的一类。

#### 优点

- 同时包含 Bohm 轨迹方向和量子势来源方向
- 既有机会处理作用量中的 `Q`，又有机会几何化轨迹方程
- 混合项 `D` 允许相位流与振幅流发生非平凡耦合

#### 缺点

- 参数更多
- 可逆性、签名保持、经典极限检查更复杂
- 若控制不好，很容易只是在做“过拟合式改写”

#### 第一轮判断

主攻路线。

若本项目要找到一个真正能同时满足“吸收量子势 + 测地线化”要求的 ansatz，当前看最有希望的是这一类。

## 4. 是否允许显含二阶导数？

这是一个必须尽早做出的策略判断。

由于量子势本身含

```math
\Box\sqrt{\rho},
```

最直接的想法是让 `\tilde g_{\mu\nu}` 直接依赖 `Q` 或 `\Box\rho`。例如：

```math
\tilde g_{\mu\nu}
= A g_{\mu\nu} + E(\rho,Q) g_{\mu\nu}.
```

### 4.1 这种做法的吸引力

- 可以更直接对准 `Q`
- 在形式上更容易“把量子势塞进度规”

### 4.2 这种做法的问题

- 度规若显含二阶导数，联络就会含三阶导数
- 变分后更容易出现高阶病态
- 很难保证等价性与可逆性

### 第一轮判断

暂不作为主线。

因此当前策略是：

- 第一轮只考虑 `\tilde g_{\mu\nu}` 依赖 `g_{\mu\nu}, u_\mu, r_\mu` 及其标量不变量
- 不让度规显含 `Q`、`\Box \rho` 这类二阶导数量

这样可以把风险控制在可分析范围内。

## 5. 第一轮筛选结果

结合上一份文档中的判据，得到如下结论。

### 5.1 低优先级：纯 conformal

```math
\tilde g_{\mu\nu} = A(\rho) g_{\mu\nu}
```

保留作为基线和对照组，但不作为主攻。

原因：

- 协变、可逆、经典极限都容易
- 但对轨迹测地线化和量子势定向结构的处理能力太弱

### 5.2 高优先级：相位流单向 disformal

```math
\tilde g_{\mu\nu} = A g_{\mu\nu} + B u_\mu u_\nu
```

保留并优先研究。

原因：

- 与 Bohm 动量方向直接相关
- 最接近标准 Bekenstein disformal 思想
- 有希望先解决“轨迹几何化”问题

限制：

- 系数必须允许感受到振幅信息，否则无法触及 `Q`

### 5.3 中高优先级：振幅梯度单向 disformal

```math
\tilde g_{\mu\nu} = A g_{\mu\nu} + C r_\mu r_\nu
```

保留，但优先级略低于相位流路线。

原因：

- 对吸收量子势来源更直接
- 但对 Bohm 轨迹的几何解释不如 `u_\mu` 路线直接

### 5.4 最高优先级：混合双向 disformal

```math
\tilde g_{\mu\nu}
= A g_{\mu\nu}
+ B u_\mu u_\nu
+ C r_\mu r_\nu
+ D(u_\mu r_\nu + u_\nu r_\mu)
```

当前主攻候选。

原因：

- 同时对准“轨迹方向”和“量子势来源”
- 最有潜力满足 S1 到 S5 的全部要求

代价：

- 技术复杂度显著增加
- 必须非常早就检查签名与可逆性

### 5.5 暂缓：显含二阶导数的几何变换

暂不进入主线。

原因：

- 太容易引入高阶病态
- 在当前阶段会把问题复杂度迅速放大

## 6. 一个更具体的主攻子类

虽然类 IV 最一般，但直接全推太重。为了让下一步可执行，建议先研究它的一个较简化子类：

```math
\tilde g_{\mu\nu}
= A(\rho,X,Y,Z)\, g_{\mu\nu}
+ B(\rho,X,Y,Z)\, u_\mu u_\nu
+ C(\rho,X,Y,Z)\, r_\mu r_\nu.
```

即先令混合项 `D=0`。

原因：

- `u_\mu u_\nu` 负责轨迹方向
- `r_\mu r_\nu` 负责振幅结构
- 暂时去掉混合项，可以降低代数复杂度
- 若这都不够，再把 `D` 打开

这是一种“从混合类出发，但先做最小非平凡子类”的策略。

## 7. 当前结论

到这一步，本项目对候选 ansatz 的态度已经比较明确：

1. 纯 conformal：保留为基线，不主攻
2. `u_\mu` 单向 disformal：高优先级
3. `r_\mu` 单向 disformal：中高优先级
4. `u_\mu + r_\mu` 混合 disformal：主攻路线
5. 显含 `Q` 或二阶导数的度规：暂缓

因此，下一步最自然的任务已经明确：

先针对

```math
\tilde g_{\mu\nu}
= A g_{\mu\nu}
+ B u_\mu u_\nu
+ C r_\mu r_\nu
```

这一“最小非平凡混合子类”，分析：

- 可逆条件
- Lorentz 签名保持条件
- 经典极限条件

只有先过这三关，后面再谈它是否真的能吸收 `Q` 才有意义。
