# 050 B分支单束下更像动力学差异而非积分器异常

## 目的

用户提出一个很直接的问题：

```text
B 的 rho 现在看起来仍然不像传播模式，
这到底是作用量本身的问题，
还是数值积分器还没修好？
```

为此，做最小测试：

```text
alpha = 1
单束
同一初始切片
比较 A exact / Bflat / Bfull
```

并对 `Bflat/Bfull` 做时间步减半检查。

脚本：

```text
kg_examples/debug_b_single_beam_propagation.py
```

输出：

```text
visualizations/debug_b_single_beam/
```

## 结果

### 1. Bflat 与 Bfull 几乎重合

在当前参数下：

```text
Bflat rho_max_220 ≈ 0.2844
Bfull rho_max_220 ≈ 0.2844

Bflat rho_max_440 ≈ 1.0821
Bfull rho_max_440 ≈ 1.0821
```

几何回授量本身仍很小：

```text
tau_max ~ 6e-5
beta_max ~ 6e-5
```

说明：

```text
当前单束结果的主导差异不是几何回授，
而是 B 的平直物质动力学本身。
```

### 2. 时间步减半后形状变化很小

用 `steps = 220` 与 `steps = 440` 比较：

```text
rel_between_220_440 ~ 4.5e-3
```

这表示：

```text
当前单束 B 结果对时间步已经相当稳定，
不像是一个“积分器还没收敛”的状态。
```

### 3. 但它与 A exact 仍明显不同

```text
rel_to_exact_220 ~ 0.327
rel_to_exact_440 ~ 0.327
```

即：

```text
B 单束在当前实现下稳定，
但稳定地不同于 A。
```

## 结论

这一轮最强判断是：

```text
单束情形下，
B 与 A 的明显差异更像是动力学差异，
而不是时间积分异常。
```

当然，这个结论只限定在：

```text
当前已经修正过守恒通量后的 Bflat/Bfull solver
```

它说明我们已经可以把“积分器明显坏掉”这一层大体放下，
转而认真面对一个更物理的问题：

```text
B 的 Bohm 型平直物质系统，
在单束下本来就不生成和 KG 一样的传播图样。
```
