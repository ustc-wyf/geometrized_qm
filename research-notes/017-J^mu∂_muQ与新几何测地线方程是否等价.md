# 017 `J^mu ∂_mu Q = 0` 与新几何测地线方程是否等价

## 目标

回答当前的具体问题：

```text
在最简单消项解下，
条件
J^mu ∂_mu Q = 0
与
新几何下的测地线方程
是否等价？
```

结论先说：

```text
不等价。
```

更准确地说：

```text
测地线方程来自新 HJ 方程，
而 J^mu ∂_mu Q = 0 是为了让新旧连续性方程重合而出现的额外标量条件。
```

## 1. 最简单消项解回顾

我们当前的最简单消项解是

```text
g~^(mu nu) = g^(mu nu) + (Q/X^2) u^mu u^nu
```

其中

```text
u_mu = ∂_mu S
X = g^(mu nu) u_mu u_nu
Q = - Box sqrt(ρ) / sqrt(ρ)
```

并且新 HJ 方程给出

```text
g~^(mu nu) u_mu u_nu = m^2
```

也就是

```text
X + Q = m^2
```

## 2. 新几何中的速度与动量

定义新几何中的 contravariant 速度

```text
u~^mu = g~^(mu nu) u_nu
```

直接代入最简单解：

```text
u~^mu
= u^mu + (Q/X^2) u^mu (u^nu u_nu)
= u^mu + (Q/X) u^mu
= (1 + Q/X) u^mu
```

再用

```text
X + Q = m^2
```

得到

```text
u~^mu = (m^2 / X) u^mu
```

另一方面，covariant 速度是

```text
u~_mu = g~_mu nu u~^nu
```

但对这个最简单解可以直接算出

```text
u~_mu = u_mu = ∂_mu S
```

这点很关键：

```text
新几何中的 covariant 动量
与旧的相位梯度完全相同。
```

## 3. 新几何中的测地线方程

在新几何中，测地线方程写成

```text
u~^nu ∇~_nu u~_mu = 0
```

由于这里

```text
u~_mu = u_mu = ∂_mu S
```

而且新 HJ 方程是

```text
g~^(alpha beta) u_alpha u_beta = m^2
```

对其做新协变导数：

```text
∇~_mu ( g~^(alpha beta) u_alpha u_beta ) = 0
```

利用新度规的 metric compatibility，
得到

```text
2 u~^alpha ∇~_mu u_alpha = 0
```

再用 `u_alpha = ∂_alpha S` 是梯度场这一事实：

```text
∇~_mu u_alpha = ∇~_alpha u_mu
```

于是

```text
u~^alpha ∇~_alpha u_mu = 0
```

这正是测地线方程。

### 3.1 结论

因此：

```text
在最简单消项解下，
只要新 HJ 方程成立，
新几何测地线方程就成立。
```

也就是说：

```text
测地线方程不是额外条件，
它是新 HJ 结构自动带出的。
```

## 4. `J^mu ∂_mu Q = 0` 从哪里来

另一方面，原连续性方程定义

```text
J^mu = sqrt(-g) ρ u^mu
```

新连续性方程我们已经算出是

```text
∂_mu [ (m^2 / X) J^mu ] = 0
```

原连续性方程是

```text
∂_mu J^mu = 0
```

把 `X = m^2 - Q` 代入并比较，得到两者重合的精确条件：

```text
J^mu ∂_mu Q = 0
```

所以这个条件的真正意义是：

```text
它不是“测地线条件”，
而是“新旧连续性方程重合条件”。
```

## 5. 为什么二者不等价

现在已经可以非常清楚地比较：

### 5.1 测地线方程

它是

```text
u~^nu ∇~_nu u_mu = 0
```

这是一个向量方程。

它控制的是：

```text
轨迹在新几何中是否为测地线。
```

### 5.2 `J^mu ∂_mu Q = 0`

它是

```text
J^mu ∂_mu Q = 0
```

这是一个标量方程。

它控制的是：

```text
量子势 Q 是否沿 Bohm 流线保持常数，
从而让新旧连续性方程重合。
```

### 5.3 直接比较

因此：

```text
测地线方程管的是“动力学轨迹”
J^mu ∂_mu Q = 0 管的是“守恒结构是否与旧理论一致”
```

它们解决的是两件不同的事。

## 6. 更强一点的说明

在这个最简单消项解下，

```text
新几何测地线方程已经由新 HJ 方程自动保证。
```

但

```text
J^mu ∂_mu Q = 0
并不会由新 HJ 方程自动推出。
```

所以如果二者等价，那么测地线方程就应自动推出 `J^mu ∂_mu Q = 0`。

但我们已经知道：

```text
最简单消项解下，
HJ / 测地线是成功的，
连续性方程一般仍然不成功。
```

这本身就说明：

```text
测地线方程 ≠ J^mu ∂_mu Q = 0
```

## 7. 最准确的关系

在当前最简单消项解下，三者关系应写成：

```text
新 HJ 方程
    ⇒ 新几何测地线方程

J^mu ∂_mu Q = 0
    ⇔ 新连续性方程与原连续性方程重合
```

而不是

```text
J^mu ∂_mu Q = 0
    ⇔ 测地线方程
```

## 8. 当前结论

所以，当前这个问题的最准确回答是：

```text
不等价。
```

并且它们各自代表：

```text
测地线方程：
HJ 几何化是否成功

J^mu ∂_mu Q = 0：
守恒结构是否也一起被几何化完成
```

这再次说明：

```text
最简单消项解已经完成了前者，
但还没有完成后者。
```
