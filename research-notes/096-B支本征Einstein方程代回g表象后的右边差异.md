# 096 B 支本征 Einstein 方程代回 `g` 表象后的右边差异

时间：2026-05-01

## 目标

比较下面两条**本征** Einstein 方程：

```text
A 支（自由场：g）:
M_P^2 G_{μν}[g] = T^{(A)}_{μν}[g,ρ,S]

B 支（自由场：g~）:
M_P^2 G~_{μν}[g~] = T~^{(B)}_{μν}[g~,ρ~,S]
```

然后只把 `B` 支本征方程中的变量代回 `g` 表象：

```text
g~ = g~[g,ρ,S],   ρ~ = ρ~[g,ρ,S].
```

这里不做 `δS_B/δg`，只做“先变分、后代换”。

## 1. 当前分支下的基本关系

当前固定在 `m != 0, C = 1` 的混合投影分支，记

```text
u_μ := ∂_μ S,
r_μ := ∂_μ √ρ,
X   := g^(αβ) u_α u_β,
Q   := □_g √ρ / √ρ.
```

则有

```text
g~^(μν) u_μ u_ν = X - Q.
```

并且在 `X > 0` 的 timelike branch 上，

```text
√(-g~) / √(-g) = X / m^2,
```

以及共同连续性关系给出

```text
√(-g~) ρ~ = (X/m^2) √(-g) ρ.
```

因此在这个 branch 上

```text
ρ~ = ρ.
```

## 2. A 支右边

沿用项目中已固定的符号约定（同 `076-A支应作为g上Einstein-KG系统而非g与g波浪混合基本作用量.md`），

```text
T^{(A)}_{μν}
= 2 r_μ r_ν
+ 2ρ u_μ u_ν
- g_{μν} [ r^2 + ρ X - m^2 ρ ] ,
```

其中

```text
r^2 := g^(αβ) r_α r_β.
```

## 3. B 支本征右边先写在 `g~` 表象

`B` 支物质作用量是

```text
S_B^m
= ∫ d^4x √(-g~) ρ~ ( g~^(μν) u_μ u_ν - m^2 ).
```

对自由场 `g~_{μν}` 变分，按与 A 支相同的应力张量记号约定，有

```text
T~^{(B)}_{μν}
= 2ρ~ u_μ u_ν
- g~_{μν} ρ~ ( g~^(αβ) u_α u_β - m^2 ).
```

## 4. 把 B 支本征右边代回 `g` 表象

直接代回

```text
g~^(αβ) u_α u_β = X - Q,
```

以及

```text
g~_{μν} = g_{μν} + (Q/m^2) Π_{μν},
```

得到

```text
T~^{(B→g)}_{μν}
= 2ρ~ u_μ u_ν
- ( g_{μν} + (Q/m^2) Π_{μν} ) ρ~ ( X - m^2 - Q ).
```

在 `X>0` branch 上再代入 `ρ~=ρ`，

```text
T~^{(B→g)}_{μν}
= 2ρ u_μ u_ν
- ( g_{μν} + (Q/m^2) Π_{μν} ) ρ ( X - m^2 - Q ).
```

这就是 **B 支本征 Einstein 方程右边** 在 `g` 表象下的精确写法。

## 5. 与 A 支右边的差

因此右边差值精确为

```text
ΔT_{μν}^{(B-A)}
:= T~^{(B→g)}_{μν} - T^{(A)}_{μν}
```

即

```text
ΔT_{μν}^{(B-A)}
= - 2 r_μ r_ν
+ g_{μν} [ r^2 + ρ X - m^2 ρ ]
- ( g_{μν} + (Q/m^2) Π_{μν} ) ρ ( X - m^2 - Q ).
```

## 6. 在共同 HJ 壳上

如果进一步限制在共同 Bohm-HJ 壳上

```text
X - m^2 - Q = 0,
```

则上式最后一项完全消失，于是

```text
ΔT_{μν}^{(B-A)}
= - 2 r_μ r_ν
+ g_{μν} ( r^2 + ρ Q ).
```

又因为

```text
ρ Q = √ρ □_g √ρ,
```

所以也可写成

```text
ΔT_{μν}^{(B-A)}
= - 2 r_μ r_ν
+ g_{μν} [ r^2 + √ρ □_g √ρ ].
```

进一步利用

```text
∇_α ( √ρ ∇^α √ρ ) = r^2 + √ρ □_g √ρ,
```

可改写成

```text
ΔT_{μν}^{(B-A)}
= - 2 r_μ r_ν
+ g_{μν} ∇_α ( √ρ ∇^α √ρ ).
```

## 7. 结论

所以，按“先对各自自由场变分，再把 B 支本征方程代回 `g` 表象”的正确规则，

```text
B 支右边相对 A 支右边的差异，
主要来自振幅梯度项 r_μ = ∂_μ √ρ，
而不是来自 u_μ = ∂_μ S 的主流项。
```

在共同 HJ 壳上，差异精确压缩成

```text
ΔT_{μν}^{(B-A)}
= - 2 ∂_μ√ρ ∂_ν√ρ
+ g_{μν} [ (∂√ρ)^2 + √ρ □_g √ρ ].
```

因此 A/B 在 `g` 表象下是否等价，接下来就要看：

```text
M_P^2 [ G~_{μν}(g,ρ,S) - G_{μν}(g) ]
```

是否恰好等于这个 `ΔT_{μν}^{(B-A)}`。
