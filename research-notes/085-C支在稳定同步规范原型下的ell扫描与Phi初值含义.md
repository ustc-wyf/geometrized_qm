# 085 `C` 支在稳定同步规范原型下的 `\ell` 扫描与 `\Phi` 初值含义

## 目标

在 [084-B与C两支同步规范原型的主要问题来自几何边界条件而非时间推进.md](/Users/wangyunfei/Desktop/量子势几何化_codex/research-notes/084-B与C两支同步规范原型的主要问题来自几何边界条件而非时间推进.md) 中，已经确认：

1. `B` 支在当前双束 `\pm45^\circ` 高斯束问题下是弱场稳定的；
2. `C` 支在 `\Phi=1` 时严格退回 `B` 支；
3. 默认 `r3_proxy` 初值与默认 `\ell=0.02` 下，`C-B` 分离极小。

这一份笔记只做两件事：

1. 用统一数值摘要重新量化 `C-B` 分离随 `\ell` 的变化；
2. 检查能否用一个纯局域代数条件直接生成更强的 `\Phi` 初值。

---

## 数值设定

统一使用：

\[
\text{steps}=200,\qquad dt=2.5\times 10^{-4},\qquad M_P=300.
\]

物质初值是当前主原型中的两束准单色高斯束，在 `x-z` 平面内沿 `\pm45^\circ` 相交。

`C` 支初值模式取

\[
\Phi_{\text{init}} = \left(1 + (\ell^2 R_{\text{proxy}})^2 \right)^{-3/2},
\qquad
R_{\text{proxy}} = \max(R^{(3)}_{\text{init}},0),
\]

即当前代码中的 `r3_proxy` 模式。

---

## 直接可比较的 `C-B` 终态差异量

为了避免只盯着 `\max|\Phi-1|`，统一记录以下终态差异：

\[
\max|h^{(C)}_{xx}-h^{(B)}_{xx}|,\quad
\max|h^{(C)}_{xz}-h^{(B)}_{xz}|,\quad
\max|\beta^{(C)}-\beta^{(B)}|,\quad
\max|\rho^{(C)}-\rho^{(B)}|,
\]

并同时记录约束残差差距

\[
|\mathcal H_C-\mathcal H_B|,\qquad
|\mathcal M_C-\mathcal M_B|.
\]

### 2. 解释

这张表说明：

1. 在默认 `\ell=0.02` 下，`C` 与 `B` 的分离确实只有 `10^{-8}` 量级，几乎完全不可见；
2. `\ell` 从 `0.02` 增大到 `0.2` 后，分离量只增长到 `10^{-6}` 左右，仍处于极弱水平；
3. 直到 `\ell \sim 0.5`，几何差异才开始进入 `10^{-6} \sim 10^{-5}` 量级；
4. `\ell = 1.0` 时，`C-B` 分离已经达到

\[
\max|h_{xx}^{(C)}-h_{xx}^{(B)}| \sim 10^{-4},
\]

但这时约束残差差距也已经升到

\[
|\Delta \mathcal H| \sim 10^{-2},\qquad
|\Delta \mathcal M| \sim 10^{-3}\text{ 到 }10^{-2},
\]

说明此时虽然分离更明显，但数值与物理解释都应更谨慎。

### 3. 当前最稳结论

在当前双束弱场问题与当前 `f(R)` 模型下，

\[
f(R)=\frac{R}{\sqrt{1+(\ell^2 R)^2}},
\qquad
\Phi=f_R=(1+(\ell^2 R)^2)^{-3/2},
\]

`C` 支对 `B` 支的偏离本来就被高曲率抑制得很强。  
因此：

- 默认 `\ell=0.02` 的“几乎完全重合”不是数值器没分开，而是模型本身在当前弱场区间就应当很接近 `B`；
- 若要看到明显的 `C-B` 分离，要么增大 `\ell`，要么改变 `\Phi` 初值构造，使其不再只依赖极弱的 `R^{(3)}` 代理。

## 纯局域代数 `\Phi` 初值是否可行

当前 `C` 支代码里，辅助场满足的关键组合是

\[
\Box \Phi

=
\frac{\operatorname{tr}T_B}{3M_P^2}
-\frac{2U(\Phi)-\Phi U_\Phi(\Phi)}{3}.
\]

对本模型，代码中记

\[
2U(\Phi)-\Phi U_\Phi(\Phi)=2u(\Phi)-\Phi u_\Phi(\Phi).
\]

若试图在初始时刻用一个**纯局域代数条件**来固定 `\Phi`，最自然的想法是令

\[
\Box\Phi \approx 0
\]

并要求

\[
2u(\Phi)-\Phi u_\Phi(\Phi)
=
\frac{\operatorname{tr}T_B}{M_P^2}.
\]

但当前模型有一个非常关键的符号性质：

\[
0<\Phi\le 1
\quad\Longrightarrow\quad
2u(\Phi)-\Phi u_\Phi(\Phi)\le 0,
\]

并且对 `\Phi<1` 严格为负。

而当前物质迹

\[
\operatorname{tr}T_B = 2m^2\rho >0.
\]

因此在 `0<\Phi\le1` 的物理取值范围内，不可能用一个纯局域代数条件满足

\[
2u(\Phi)-\Phi u_\Phi(\Phi)
=
\frac{\operatorname{tr}T_B}{M_P^2}>0.
\]

这说明：

\[
\boxed{
\text{不能仅靠纯局域代数平衡来构造一个更强的 } \Phi \text{ 初值。}
}
\]

若要让 `C` 支在初始时刻产生更明显偏离，必须依赖：

1. `\Phi` 的空间拉普拉斯项；
2. 或 `\Pi_\Phi` 的时间导数项；
3. 或二者兼有。

换句话说，下一步若要构造“更强但仍自洽”的 `\Phi` 初值，正确方向应是：

\[
\text{求解一个椭圆型初值方程，}
\]

而不是继续寻找纯局域代数公式。

## 当前结论

1. `B` 支稳定性问题已经基本解决；
2. 当前 `C-B` 分离的主控制参数，首先是 `\ell`；
3. 在默认 `\ell=0.02` 下，`C` 几乎退回 `B`；
4. 若要继续研究 `C` 的可观测偏离，下一步最合理的技术方向不是继续微调 `r3_proxy`，而是直接为 `\Phi` 构造一个真正的椭圆型非平凡初值。
