## 1. 为什么要先引入 `q_ab`

对于 `g~` 表象的 `B/C` 两支，`3+1 -> 2+1` 一致约化后的原始引力因子是

```text
sqrt(-h~) e^β
```

这说明 `β` 还黏在三维引力项前面。  
为了把它改成标准爱因斯坦形式，定义新的三维度规

```text
q_ab := e^{2β} h~_ab .
```

于是

```text
h~_ab = e^{-2β} q_ab .
```

这不是新的近似，而只是重新参数化。

在这个重新参数化下，

```text
sqrt(-h~) e^β = sqrt(-q) .
```

同时三维 Ricci 标量部分会变成标准 Einstein-Hilbert 形式。

因此后续对 `B/C` 两支，真正应该推进的三维度规不是旧的 `h~_ab`，而是

```text
q_ab .
```

## 3. B 支的协变场方程

### 3.1 物质方程

对 `ρ` 变分：

```text
q^(ab) ∂_a S ∂_b S = m^2 e^{-2β} .
```

对 `S` 变分：

```text
∇_a [ ρ q^(ab) ∂_b S ] = 0 .
```

其中协变导数 `∇` 是相对于 `q_ab` 的。

### 3.2 `β` 方程

对 `β` 变分得到

```text
M_P^2 □_q β + m^2 e^{-2β} ρ = 0 .
```

这里

```text
□_q β := q^(ab) ∇_a ∇_b β .
```

### 3.3 三维 Einstein 方程

对 `q_ab` 变分后，可写成

```text
M_P^2 G_ab[q]
= T_ab^(β) + T_ab^(m) .
```

其中

```text
T_ab^(β)
= 2 M_P^2
   [ ∂_aβ ∂_bβ - 1/2 q_ab (∂β)^2_q ]
```

而物质应力张量为

```text
T_ab^(m)
= 2ρ ∂_aS ∂_bS
 - q_ab ρ [ q^(cd)∂_cS∂_dS - m^2 e^{-2β} ] .
```

在物质壳约束上，

```text
q^(cd)∂_cS∂_dS = m^2 e^{-2β}
```

因此第二项消失，得到

```text
T_ab^(m) = 2ρ ∂_aS ∂_bS .
```

## 4. B 支的 `ADM` 约束—演化结构

现在把 `q_ab` 写成一般 `ADM` 形式：

```text
ds_q^2
= N^2 dt^2
- h_ij (dx^i + N^i dt)(dx^j + N^j dt),
qquad i,j ∈ {x,z}.
```

定义外曲率

```text
K_ij
:= - (1/2N)
   [ ∂_t h_ij - D_i N_j - D_j N_i ] .
```

其中 `D_i` 是相对于二维空间度规 `h_ij` 的协变导数。

于是 B 支可按标准爱因斯坦初值问题组织成：

### 4.1 几何变量演化

```text
∂_t h_ij = -2N K_ij + D_i N_j + D_j N_i .
```

### 4.2 Hamilton 约束

```text
R^(2) + K^2 - K_ij K^ij
= (1/M_P^2) 𝓔_B .
```

### 4.3 Momentum 约束

```text
D_j ( K^j_i - δ^j_i K )
= (1/M_P^2) 𝓟_i^(B) .
```

### 4.4 外曲率演化

```text
(∂_t - 𝓛_N) K_ij
= - D_i D_j N
 + N [ R^(2)_ij + K K_ij - 2 K_i^k K_kj ]
 - (N/M_P^2) 𝓢_ij^(B) .
```

这里：

- `𝓔_B` 是总能量密度投影  
- `𝓟_i^(B)` 是总动量密度投影  
- `𝓢_ij^(B)` 是应力张量投影组合  
- 它们都由 `β` 与 Bohm 物质共同给出

也就是说，B 支现在已经被整理成一个标准的：

```text
2+1 Einstein + scalar + matter
```

初值问题。

## 6. C 支的协变场方程

### 6.1 物质方程

这部分与 B 支完全相同：

```text
q^(ab) ∂_a S ∂_b S = m^2 e^{-2β}
```

```text
∇_a [ ρ q^(ab) ∂_b S ] = 0 .
```

### 6.2 `Φ` 方程

对 `Φ` 变分：

```text
R[q]
 + 2 □_q β
 - 2 (∂β)^2_q
 - e^{-2β} U_Φ(Φ)
= 0 .
```

### 6.3 `β` 方程

对 `β` 变分：

```text
M_P^2
[ □_q Φ + 2 ∇_a ( Φ ∇^a β ) + e^{-2β} U(Φ) ]
 + 2 m^2 e^{-2β} ρ
= 0 .
```

### 6.4 标量-张量 Einstein 方程

对 `q_ab` 变分后得到：

```text
Φ G_ab[q]
 + ( q_ab □_q - ∇_a∇_b ) Φ
= (1/M_P^2) T_ab^(m)
 + T_ab^(β,Φ) .
```

其中

```text
T_ab^(β,Φ)
= ( ∂_aΦ ∂_bβ + ∂_bΦ ∂_aβ )
 - q_ab (∂Φ·∂β)
 + 2Φ [ ∂_aβ ∂_bβ - 1/2 q_ab (∂β)^2_q ]
 - 1/2 q_ab e^{-2β} U(Φ) .
```

这条式子就是 C 支在一般度规下的真正几何动力学核心。
