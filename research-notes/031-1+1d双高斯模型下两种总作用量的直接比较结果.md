# 031 1+1d 双高斯模型下两种总作用量的直接比较结果

## 目标

直接回答当前问题：

```text
在 1+1d 平直背景的双高斯 KG 干涉模型下，
两种总作用量

1. S_total^(g)  = S_EH[g]  + S_matter
2. S_total^(g~) = S_EH[g~] + S_matter

预测出的结果到底差多少？
```

## 1. 直接数值结果

计算脚本：

[`kg_compare_total_actions_1p1.py`](E:\量子势几何化_codex\kg_examples\kg_compare_total_actions_1p1.py)

本轮得到：

```text
EH[g] 的 bulk 密度 = 0
```

因为背景取

```text
g = η
```

所以

```text
R[g] = 0
```

而由波函数诱导的 `g~` 则给出非平凡曲率：

```text
R~_abs_max_all ≈ 2.3515 × 10^10
R~_abs_max_support_1e-2 ≈ 1.998
```

对应的 Einstein-Hilbert 密度

```text
sqrt(-g~) R~
```

也非零：

```text
|sqrt(-g~) R~|_max_all ≈ 4.49 × 10^9
|sqrt(-g~) R~|_max_support_1e-2 ≈ 1.855
```

这说明：

```text
在这个双高斯模型里，
g~ 的局域几何并不平凡。
```

## 2. 但为什么这还不等于“实验预测已经不同”

关键点是：

```text
当前模型是 1+1d。
```

而纯 Einstein-Hilbert 项在 1+1d 中是拓扑型的。

所以：

```text
即使 R~ 局域上不为零，
纯 EH[g~] 也不会像 3+1d 那样提供独立的 bulk 局域引力动力学。
```

因此，对这个具体 1+1d 双高斯模型，最准确的比较结论是：

```text
1. 局域几何量（R~、sqrt(-g~)R~）的确和 g-方案不同；
2. 但纯 EH 项在 1+1d 中不会把这种差异直接转成新的 bulk 波包动力学预测。
```

## 3. 这意味着什么

因此，在这个 1+1d 例子里：

```text
若只比较“纯 EH[g]” 与 “纯 EH[g~]”，
那么你看到的是：

- 几何描述差异：有
- 3+1d 式的局域引力动力学差异：没有
```

换句话说：

```text
这个例子已经说明 g~ 的几何可以非常不平凡，
但它还不能作为最终舞台去区分纯 EH[g] 与纯 EH[g~] 的 bulk 实验预测。
```

## 4. 当前最直接的判断

所以对你现在这个双高斯例子，最直接的回答是：

```text
在 1+1d 平直背景里，
两种总作用量的“局域几何密度”差异很大，
但在纯 Einstein-Hilbert 形式下，
这种差异还不会自动变成新的 bulk 可观测预测。
```

## 5. 下一步

这意味着，如果我们真要在这个双高斯模型里得到“总作用量预测差异”，需要至少满足下面之一：

```text
1. 升到 3+1d
2. 在 1+1d 中加入非纯 EH 的 Q 依赖引力项
3. 或引入额外约束/辅助场，使引力部分不再是纯拓扑项
```

在当前项目节奏下，最自然的是：

```text
继续沿你已经提出来的
F(Q) R~
这类作用量走，
因为那在 1+1d 里就会给出真正的局域差异。
```
