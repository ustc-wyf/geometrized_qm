# 033 3+1d 对射双高斯波包模型

## 目标

建立一个更符合当前需求的 3+1d 基线模型：

```text
1. σ/k0 为 O(0.1)
2. 模拟区域中心为 (x,z) = (0,0)
3. x_range = z_range
4. 两束在 x-z 平面中以约 45° 对射
5. 狭缝中心取 (x,y)=(-a/2,0),(+a/2,0)
6. y 作为狭缝延伸方向
```

## 1. 坐标约定

采用

```text
(t, x, y, z)
```

其中：

- `z`：传播主方向
- `x`：双束分离/干涉条纹展开方向
- `y`：狭缝延伸方向

当前先取

```text
y = 0
```

的中心切面做第一轮分析。

## 2. 两束初始中心与波矢

取两束初始中心：

```text
packet A: (x_A0, z_A0) = (-a/2, -a/2)
packet B: (x_B0, z_B0) = (+a/2, +a/2)
```

取两束中心波矢分别指向原点：

```text
k_A = k0 ( cosθ, 0, sinθ )
k_B = k0 ( -cosθ, 0, -sinθ )
```

默认

```text
θ = π/4
```

即 45° 对射。

## 3. 动量宽度

取各向同性横向宽度：

```text
σ_kx = σ_kz = σ_k
```

并要求

```text
σ_k / k0 ~ 0.1
```

这是当前基线模型的重要要求。

## 4. 当前建议参数

第一轮建议取：

```text
m = 1.0
k0 = 6.0
σ_k = 0.6
σ_k / k0 = 0.1
θ = π/4
phi0 = 0.0
a = 16.0
```

并取对称区域：

```text
x ∈ [-28, 28]
z ∈ [-28, 28]
```

这样：

- 中心在 `(0,0)`
- `x_range = z_range`
- 两束从对角线方向射向中心

## 5. 边界要求

希望在边界上满足

```text
ρ_boundary / ρ_max << 1
```

这意味着在边界处两束都已经近似“回到自身”，
不会明显污染中心对射区。

## 6. 当前输出物

配套脚本将提供：

```text
1. 对射双高斯波包的 2+1（x,z; y=0）切面
2. 边界比值 ρ_boundary / ρ_max
3. 后续继续接 Bohm 量与引力作用量比较的接口
```
