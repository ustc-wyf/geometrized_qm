# 015 最简单拉氏量消项解的后续检验

## 目标

上一份文档已经得到按用户指定方式“直接在拉氏量中消去 `Q`”的最简单解：

```text
g~^(mu nu) = g^(mu nu) + (Q / X^2) u^mu u^nu
```

其中

```text
u_mu = ∂_mu S
X = g^(mu nu) u_mu u_nu
Q = - Box sqrt(ρ) / sqrt(ρ)
```

并且有

```text
L_geom = L_orig
```

这一份文档继续做后续检验，但严格采用当前已确认的正确顺序：

```text
先对新作用量变分，
再把这个最简单解代回方程。
```

检验三件事：

1. HJ 方程是否正确
2. 连续性方程是否正确
3. 是否支持测地线解释与基本可逆性

## 1. 新作用量与基本方程

新作用量取为

```text
I_geom[ρ~,S;g~]
= ∫ d^4x sqrt(-g~) ρ~ ( g~^(mu nu) ∂_mu S ∂_nu S - m^2 )
```

并采用密度变换约定

```text
sqrt(-g) ρ = sqrt(-g~) ρ~
```

先变分得到：

```text
HJ:
g~^(mu nu) ∂_mu S ∂_nu S = m^2

Continuity:
∂_mu [ sqrt(-g~) ρ~ g~^(mu nu) ∂_nu S ] = 0
```

再代回密度关系，连续性方程化为

```text
∂_mu [ sqrt(-g) ρ g~^(mu nu) ∂_nu S ] = 0
```

所以真正要检查的是

```text
g~^(mu nu) u_mu u_nu
以及
g~^(mu nu) u_nu
```

## 2. 把最简单解代回 HJ 方程

取

```text
g~^(mu nu) = g^(mu nu) + (Q / X^2) u^mu u^nu
```

则

```text
g~^(mu nu) u_mu u_nu
= X + (Q / X^2) X^2
= X + Q
```

所以新 HJ 方程变成

```text
X + Q = m^2
```

即

```text
X = m^2 - Q
```

这正是原来的 HJ 方程。

### 2.1 结论

```text
这个最简单消项解在 HJ 方程层面完全成功。
```

## 3. 把最简单解代回连续性方程

先计算

```text
g~^(mu nu) u_nu
= u^mu + (Q / X^2) u^mu (u^nu u_nu)
= u^mu + (Q / X^2) u^mu X
= (1 + Q/X) u^mu
```

因此新连续性方程变成

```text
∂_mu [ sqrt(-g) ρ (1 + Q/X) u^mu ] = 0
```

而原理论的连续性方程是

```text
∂_mu [ sqrt(-g) ρ u^mu ] = 0
```

### 3.1 与原方程比较

两者只有在特殊情形下才一致，例如：

```text
1 + Q/X = 常数
```

更具体地，用原 HJ 方程

```text
X + Q = m^2
```

可写成

```text
1 + Q/X = m^2 / X
```

所以新连续性方程也可写成

```text
∂_mu [ sqrt(-g) ρ (m^2 / X) u^mu ] = 0
```

这与原连续性方程仍然一般不同。

### 3.2 结论

```text
这个最简单消项解虽然完美重现了 HJ 方程，
但一般不能重现原连续性方程。
```

所以它不是完整动力学等价解。

## 4. 测地线解释

虽然连续性方程有问题，但 HJ 方程已经被改写成

```text
g~^(mu nu) ∂_mu S ∂_nu S = m^2
```

这是标准 relativistic Hamilton-Jacobi 形式。

因此只要把

```text
p_mu = ∂_mu S
```

理解为新几何中的共变动量，那么由 HJ 理论的标准结构可知：

```text
对应的经典轨迹可解释为 g~_mu nu 下的测地线流。
```

这里的关键点是：

```text
HJ / 测地线解释是成功的；
连续性方程 / 守恒结构还没有一起成功。
```

这说明该最简单解完成了“几何化的一半”。

## 5. 对应的 covariant 度规

从

```text
g~^(mu nu) = g^(mu nu) + (Q / X^2) u^mu u^nu
```

求逆可得

```text
g~_mu nu
= g_mu nu - [ Q / ( X (X + Q) ) ] u_mu u_nu
```

再用 HJ 方程 `X + Q = m^2`，可写成

```text
g~_mu nu
= g_mu nu - [ Q / (X m^2) ] u_mu u_nu
```

### 5.1 可逆性条件

可逆要求

```text
X ≠ 0
X + Q ≠ 0
```

后者在壳上就是

```text
m^2 ≠ 0
```

所以对有质量情形，关键条件主要是

```text
X ≠ 0
```

### 5.2 行列式因子

rank-1 更新给出

```text
det(g~^(..)) = det(g^(..)) (1 + Q/X)
```

也就是

```text
det(g~^(..)) = det(g^(..)) (X + Q)/X
= det(g^(..)) m^2 / X
```

因此若要保持与原 Lorentz 签名同型，一个自然条件是

```text
X > 0
```

也就是说：

```text
最简单解天然更适合 timelike Bohm 流区域。
```

## 6. 当前总评

这个最简单解的表现可以非常简洁地概括为：

```text
拉氏量消项：成功
HJ 方程：成功
测地线解释：成功（在 HJ 层面）
连续性方程：一般失败
可逆性：要求 X ≠ 0
签名保持：自然要求 X > 0
```

所以它不是最终完整解，但它并不是失败路线。

更准确的说：

```text
它是一个非常成功的“几何化 HJ 核心”的解，
但还没有把守恒结构一起几何化完成。
```

## 7. 这说明下一步该做什么

现在已经很清楚：

```text
单纯沿 u^mu u^nu 方向加一项，
足以把 Q 吸收到拉氏量和 HJ 方程中，
但不足以自动修正连续性方程。
```

所以如果我们想继续保持“直接在拉氏量里消项”的优点，同时修复连续性方程，最自然的下一步不是回到纯类 II，而是：

```text
把振幅结构也引入逆度规 ansatz。
```

也就是考虑更一般的形式，例如

```text
g~^(mu nu)
= C g^(mu nu)
 + D u^mu u^nu
 + E r^mu r^nu
 + F (u^mu r^nu + r^mu u^nu)
```

其中

```text
r_mu = ∂_mu sqrt(ρ)
```

因为只有这样，连续性方程中的流向和权重才有机会同时感受到振幅信息，而不仅仅是 `X`。

## 8. 下一步建议

下一步最合适的是：

```text
保留当前最简单成功机制
g~^(mu nu) = g^(mu nu) + (Q/X^2) u^mu u^nu
```

作为基底，然后加入最少量的振幅结构修正项，检查：

1. 能否继续保持拉氏量中的 Q 消项
2. 能否同时把连续性方程拉回到原来的形式

这一步很可能会把我们自然引向混合类。
