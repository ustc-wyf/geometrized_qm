# 062 混合投影型逆度规解的统一整理

## 目标

整理最近得到的一类非常漂亮的混合逆度规解。

这一份笔记只做三件事：

1. 把混合块的核心代数结构写清楚
2. 把 `m≠0, C=1` 的主分支整理成一条统一公式
3. 把 `m=0, C=1, κ≠0` 的局域 patch 分支整理成一条统一公式

本笔记刻意暂时不讨论以下退化面：

```text
X = 0
Q = 0
Δ = XZ - Y^2 = 0
```

这些边界情况留到下一步单独讨论。

---

## 1. 记号和基本约定

继续使用当前项目的新约定：

```text
Q = Box sqrt(ρ) / sqrt(ρ)
```

并定义

```text
u_μ = ∂_μ S
r_μ = ∂_μ sqrt(ρ)

X = g^(μν) u_μ u_ν
Y = g^(μν) u_μ r_ν
Z = g^(μν) r_μ r_ν
```

在原 `g` 系中：

- 若 `m ≠ 0`，Hamilton-Jacobi 方程是

```text
X = m^2 + Q
```

- 若 `m = 0`，Hamilton-Jacobi 方程退化成

```text
X = Q
```

我们考虑的逆度规 ansatz 是

```text
g~^(μν)
= C g^(μν)
+ D u^μ u^ν
+ E (u^μ r^ν + r^μ u^ν)
+ F r^μ r^ν
```

---

## 2. 漂亮的混合块

取

```text
D = Z
E = -Y
F = X
```

并定义混合块

```text
M^(μν)
:= Z u^μ u^ν
 - Y (u^μ r^ν + r^μ u^ν)
 + X r^μ r^ν
```

再记

```text
Δ := XZ - Y^2
```

则直接收缩可得

```text
M^(μν) u_ν = Δ u^μ
M^(μν) r_ν = Δ r^μ
```

而对于任何同时满足

```text
u·v = 0
r·v = 0
```

的向量 `v_ν`，有

```text
M^(μν) v_ν = 0
```

因此：

```text
M
在 span{u,r} 上按标量 Δ 作用，
在其正交补上为 0。
```

这说明它本质上是一个 `u-r` 二维平面上的投影型修正。

---

## 3. 最自然的重参数化

令

```text
g~^(μν) = C g^(μν) + λ M^(μν)
```

并定义有效缩放量

```text
s := λ Δ
```

则由于 `M` 的上述性质，有

```text
g~^(μν) u_ν = (C + s) u^μ
g~^(μν) r_ν = (C + s) r^μ
g~^(μν) u_μ u_ν = (C + s) X
```

所以原本四个系数的问题，在这个特殊混合结构下，实际上被压缩成了两个量：

```text
C
s = λΔ
```

这正是该解特别漂亮的地方。

---

## 4. 行列式

在四维下，该 ansatz 的行列式比值直接化成

```text
det(g~^(..)) / det(g^(..)) = C^2 (C + s)^2
```

因此：

```text
它总是 manifestly 非负
```

并且在

```text
C ≠ 0
C + s ≠ 0
```

的 patch 上严格为正。

---

## 5. HJ 方程与连续性方程的统一写法

若变换后 `g~` 系的 Hamilton-Jacobi 方程写成

```text
g~^(μν) u_μ u_ν = κ
```

则在当前混合解下变成

```text
(C + s) X = κ
```

也就是

```text
C + s = κ / X
```

但这里要小心：

```text
κ / X
```

只是从 `g~` 系方程本身解出的局部比例。

若我们进一步要求它等价于 `g` 系的原 HJ 方程，则右边要按原方程的具体形式来重写：

- `m ≠ 0` 时用 `X = m^2 + Q`
- `m = 0` 时用 `X = Q`

连续性方程方面，由

```text
g~^(μν) u_ν = (C + s) u^μ
```

可知

```text
∂_μ [ sqrt(|g~|) ρ~ g~^(μν) u_ν ] = 0
```

只要定义

```text
sqrt(|g~|) ρ~ (C + s) = sqrt(|g|) ρ
```

就能精确拉回原 `g` 系连续性方程

```text
∂_μ [ sqrt(|g|) ρ u^μ ] = 0
```

---

## 6. `m ≠ 0, C = 1` 的主分支

现在要求：

```text
C = 1
κ = m^2
```

并要求 `g~` 系 HJ 方程等价于原方程

```text
X = m^2 + Q
```

则必须有

```text
(1 + s) X = m^2
```

也就是

```text
1 + s = m^2 / X = 1 - Q/X
```

所以

```text
s = -Q / X
```

即

```text
λ = - Q / (X Δ)
```

从而

```text
D = - Q Z / (X Δ)
E = + Q Y / (X Δ)
F = - Q / Δ
```

于是这一支的逆度规可写成

```text
g~^(μν) = g^(μν) - [Q / (XΔ)] M^(μν)
```

并满足

```text
g~^(μν) u_ν = (m^2 / X) u^μ
g~^(μν) u_μ u_ν = (m^2 / X) X = m^2
```

因此：

- `g~` 系 HJ 方程精确推出原 `g` 系 HJ 方程
- 只要定义

```text
sqrt(|g~|) ρ~ (m^2 / X) = sqrt(|g|) ρ
```

连续性方程也精确恢复

行列式比值变成

```text
det(g~^(..)) / det(g^(..)) = (m^2 / X)^2
```

所以在 `X ≠ 0` 的 patch 上严格为正。

### 6.1 经典极限

当 `Q -> 0` 时，

```text
X -> m^2
```

从而

```text
s = -Q/X -> 0
```

于是

```text
g~^(μν) -> g^(μν)
```

所以这一支自动恢复经典极限。

---

## 7. `m = 0, C = 1, κ ≠ 0` 的局域 patch 分支

现在切到质量零情形。

原 `g` 系 HJ 方程是

```text
X = Q
```

继续坚持

```text
C = 1
κ ≠ 0
```

并要求 `g~` 系 HJ 方程

```text
g~^(μν) u_μ u_ν = κ
```

等价于原方程 `X = Q`，则必须有

```text
(1 + s) X = κ
```

同时又要它等价于 `X = Q`，因此正确的选择是

```text
1 + s = κ / Q
```

也就是

```text
s = κ/Q - 1
```

从而

```text
λ = (κ/Q - 1) / Δ
```

于是

```text
D = Z (κ/Q - 1) / Δ
E = -Y (κ/Q - 1) / Δ
F = X (κ/Q - 1) / Δ
```

并得到

```text
g~^(μν) u_ν = (κ/Q) u^μ
g~^(μν) u_μ u_ν = (κ/Q) X
```

所以

```text
g~^(μν) u_μ u_ν = κ
```

确实精确推出

```text
X = Q
```

同样，若定义

```text
sqrt(|g~|) ρ~ (κ/Q) = sqrt(|g|) ρ
```

则连续性方程也精确恢复。

### 7.1 行列式

此时

```text
det(g~^(..)) / det(g^(..)) = (κ/Q)^2
```

因此在

```text
Q ≠ 0
```

的 patch 上严格为正。

### 7.2 代价

这一支的代价也非常清楚：

```text
Q -> 0
```

时，

```text
s = κ/Q - 1
```

发散，因此：

```text
这一支没有经典恢复
```

它只能被理解成定义在

```text
X ≠ 0
Q ≠ 0
Δ ≠ 0
```

上的局域 patch 几何化。

---

## 8. 两条分支的统一对照

这两条分支其实可以统一写成：

```text
g~^(μν) = g^(μν) + λ M^(μν)
```

其中 `C=1` 固定，而 `λ` 由“想让 `g~` 系壳方程等价于哪条 `g` 系 HJ 方程”来决定。

### 分支 A：`m ≠ 0`

```text
λ = - Q / (XΔ)
s = -Q/X
det ratio = (m^2/X)^2
```

优点：

- 恢复原 HJ 方程
- 恢复原连续性方程
- 行列式严格正
- 自动恢复经典极限

### 分支 B：`m = 0, κ ≠ 0`

```text
λ = (κ/Q - 1)/Δ
s = κ/Q - 1
det ratio = (κ/Q)^2
```

优点：

- 恢复原 HJ 方程
- 恢复原连续性方程
- 行列式严格正

代价：

- 无经典恢复
- 只能局域 patch 化

---

## 9. 本笔记范围外的未决问题

这一份笔记暂时不讨论：

1. `X = 0`
2. `Q = 0`
3. `Δ = XZ - Y^2 = 0`
4. 如何跨 patch 拼接
5. 当 `κ/Q < 0` 时 signature 如何变化
6. `m=0` 时是否应改用更标准的 null-shell 作用量

这些问题都属于“退化面/分支边界”的后续讨论。

---

## 10. 结论

当前这类混合投影型逆度规解可以压缩成一句话：

```text
通过把 u-r 混合块组织成一个只在 Bohm 平面上起作用的投影型结构，
原本四个系数的问题被压缩成了一个有效缩放量 s = λΔ。
```

在此基础上：

- `m ≠ 0, C = 1` 给出一条自动具有经典极限的主分支
- `m = 0, C = 1, κ ≠ 0` 给出一条无经典极限但局域自洽的 patch 分支

这说明用户发现的漂亮解不是偶然凑巧，而是当前混合 ansatz 中最自然、最几何化的一类结构。
