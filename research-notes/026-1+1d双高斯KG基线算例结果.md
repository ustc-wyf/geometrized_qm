## 2. 数值结果

### 2.1 全域统计

脚本给出的全域最大值为：

```text
Q_abs_max_all ≈ 2.4059
eps_abs_max_all = |Q|/m^2 ≈ 2.4059
```

这说明：

```text
在该基线模型里，
Q/m^2 的确可以超过 1。
```

但这个最大值出现在低密度区域附近，因此还需要结合支撑区统计一起看。

### 2.2 相对密度支撑区统计

若只看

```text
ρ >= 0.01 * ρ_max
```

则有：

```text
|Q|_max ≈ 0.2389
|Q|/m^2_max ≈ 0.2389
```

若只看

```text
ρ >= 0.001 * ρ_max
```

则有：

```text
|Q|_max ≈ 0.5848
|Q|/m^2_max ≈ 0.5848
```

若只看

```text
ρ >= 0.0001 * ρ_max
```

则有：

```text
|Q|_max ≈ 0.8452
|Q|/m^2_max ≈ 0.8452
```

而到

```text
ρ >= 10^-6 * ρ_max
```

时，尖峰增长到：

```text
|Q|_max ≈ 2.4059
|Q|/m^2_max ≈ 2.4059
```

## 3. 对 Q 大小的解释

这组结果非常符合我们对双缝/双包干涉的直觉：

### 3.1 主支撑区

在主支撑区，也就是

```text
ρ 不是特别小
```

的区域里，

```text
Q/m^2 通常是 10^-1 到 10^0 之间
```

也就是说：

```text
量子势已经不算微弱，
但还没有达到“极端尖峰”。
```

### 3.2 节点附近

当接近干涉暗纹或节点时，

```text
ρ -> 0
```

而

```text
Q = - Box sqrt(ρ) / sqrt(ρ)
```

会出现明显放大。

因此：

```text
Q 的大值主要集中在低密度、接近节点的区域。
```

这也是为什么：

```text
全域最大值
和
主支撑区最大值
差很多。
```

## 4. 这对后续几何化检验的意义

这一基线算例说明：

```text
双高斯干涉模型已经足够产生“非平凡但可控”的 Q 结构。
```

更具体地：

### 4.1 好处

- 它在主支撑区就能给出 `Q/m^2 ~ 0.1 - 1` 的量级
- 又能在节点附近给出更强尖峰
- 因此既能测试“温和量子几何修正”，也能测试“接近分支/奇异边界”的行为

### 4.2 风险

若后续某种几何化方案对

```text
ρ -> 0
```

区域极端敏感，那么它可能会被节点附近的 `Q` 尖峰主导。

所以后续比较时必须明确区分：

```text
1. 主支撑区行为
2. 节点附近尖峰行为
```

不能只报一个全局最大值。

## 5. 对后续背景推广的建议

这一基线模型现在已经适合直接搬到下列场景：

### 5.1 Schwarzschild 弱场背景

最先比较的应是：

```text
地球表面近似的弱 Schwarzschild 修正
```

因为这能看出：

- 背景弱引力
- 非平凡量子势

共同作用时，`Q` 与几何修正如何叠加。

### 5.2 引力波背景

其次适合放入小振幅引力波背景，
因为这能直接测试：

```text
外部时变几何
和
内部干涉驱动的 Q 结构
```

之间的耦合。

## 6. 当前最稳的阶段结论

这一步的最稳结论可以压成三句：

```text
1. 这个 1+1d 双高斯自由 KG 模型已经足够作为统一基线例子。
2. Q 在主支撑区可达 O(10^-1 ~ 1)；在节点附近可出现更大尖峰。
3. 后续比较任何曲背景或几何化方案时，都必须把“主支撑区”和“节点附近”分开分析。
```
