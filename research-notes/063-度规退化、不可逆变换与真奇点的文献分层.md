# 063 度规退化、不可逆变换与真奇点的文献分层

## 问题

当前项目在混合投影型逆度规解中，已经自然遇到三类边界：

```text
X = 0
Q = 0
Δ = XZ - Y^2 = 0
```

它们到底应被理解成：

1. 原 `g` 系本身的物理奇点
2. 变换坐标或变量时出现的坏 chart / 坏 patch
3. 非可逆变换面
4. 新几何中的 signature change / 退化度规面

必须先做文献分层，否则后续讨论会把完全不同的问题混在一起。

---

## 1. 四类“奇异”必须严格区分

### 1.1 坐标奇点（coordinate singularity）

这是最温和的一类。它只说明当前坐标 chart 不好，不说明时空本身坏掉。

黑洞例子里最经典的是 Schwarzschild 地平线。标准做法不是“改物理”，而是换到
Eddington-Finkelstein 或 Kruskal 这类 chart，把原先的发散穿过去。

因此：

```text
若发散可由普通坐标变换消去，
它只是 chart 问题，不是真奇点。
```

### 1.2 场重定义奇点（field-redefinition singularity）

这类问题和上面不同。它不是换坐标，而是把同一个物理系统改写成另一组场变量，例如
disformal / Bekenstein 变换。

只要变换保持可逆，通常还能把它当成“同一理论的不同表象”。

一旦变换失去可逆性，就不能再把它当作全局等价改写。继续取这一极限，常常会得到新的约束理论，而不是原理论本身。文献里最典型的关联例子是 mimetic gravity。

因此：

```text
若奇异只出现在变换系数里，而原变量本身仍光滑，
应先怀疑“变量图册失效”而不是真物理奇点。
```

### 1.3 真曲率奇点（curvature singularity）

若曲率不变量发散，或者时空 geodesically incomplete 且无法只靠换 chart 修复，
这才是经典广义相对论里真正强意义下的奇点。

这类奇点不能通过“聪明变换”真正移除，只能：

1. 承认经典理论失效
2. 改用更高层理论
3. 或证明原先看见的并不是真曲率发散

### 1.4 signature 变化 / 退化度规（signature change / degenerate metric）

标准 Lorentzian 广义相对论默认：

```text
度规连续
度规非退化
signature 固定
```

因此若某个“变换后度规”在某处改变 signature，那么那一点附近一定伴随：

1. `det g = 0` 的退化面
2. 或度规不连续

这已经不再是普通 Lorentzian GR 的常规定义域。标准做法通常是：

1. 把不同 signature 的区域分开处理
2. 在中间退化面上补额外拼接条件
3. 或改用一阶形式、密度化变量、四重标架等更宽结构

---

## 2. Bekenstein / disformal 文献给出的启示

### 2.1 Bekenstein 原始路线的精神

Bekenstein 原始 disformal 方案的出发点，是在等效原理与因果结构约束下，构造
“物理度规（physical metric）”与“引力度规（gravitational metric）”的关系。

这里隐含的重要前提是：

```text
你讨论的仍是一张真正的、可用来定义物理因果结构的度规。
```

也就是说，原始 Bekenstein 路线本身并不是把“退化度规”当成默认主角。

### 2.2 非可逆 disformal 极限不再是单纯重写

后续文献表明，一旦 disformal 变换变成 non-invertible，它就不再只是原理论的等价表述。

最值得记住的不是某个公式，而是这条方法论分界：

```text
可逆时：不同变量表象
不可逆时：往往进入新理论或新约束分支
```

这正是 mimetic-type 结构反复出现的背景。

---

## 3. 黑洞与奇点文献给出的标准理解

黑洞文献里最清楚的教训是：

```text
“发散”这个词本身不够，必须先问它发散在什么对象上。
```

### 3.1 只在某组坐标分量上发散

若只是 `g_tt`、`g_rr` 一类分量在某 chart 上炸掉，但换 chart 后一切正常，
那就是坐标奇点。

### 3.2 曲率不变量或潮汐量发散

若像 Kretschmann 标量这类几何不变量发散，那么就不是 chart 问题了。

因此，判断奇点时，标准优先级应是：

1. 先看不变量
2. 再看 geodesic completeness
3. 最后才看某个坐标表达式是不是爆掉

## 4. 对当前项目的直接翻译

当前最应该做的，不是先把 `X=0`、`Q=0`、`Δ=0` 都当成“真奇点”，而是先按下面顺序排查。

### 4.1 先问原 `g` 系是否真的坏了

若原始变量

```text
g_{μν}, ρ, S
```

以及它们构造出的局域不变量都保持有限，而只是变换系数

```text
1/X
1/Q
1/Δ
```

爆掉，那么更自然的解释是：

```text
这是变换图册（atlas）或变量表象的边界，
而不是原系统本身的物理奇点。
```

### 4.2 `Δ = 0` 时优先使用未归一化对象

当前混合投影型解里，真正几何上更稳的对象是

```text
M^(μν)
s = λΔ
```

而不是

```text
P^(μν) = M^(μν) / Δ
```

因为 `Δ=0` 时，`P` 会坏，但 `M` 不一定坏。

所以：

```text
讨论退化面时，优先保留未归一化混合块 M，
不要过早除以 Δ。
```

### 4.3 `m = 0` 时的 `Q = 0` 更像分支边界

当前 `m=0, C=1, κ≠0` 的局域 patch 分支中，

```text
det(g~^(..)) / det(g^(..)) = (κ / Q)^2
```

所以 `Q=0` 不是普通内部点，而是这条 patch 的边界。

这更像：

```text
当前 massless patch 几何在该处失去坐标/变量图册，
```

而不是自动说明原 `g` 系那里出现了真曲率奇点。

## 5. 对三个“绕过方案”的阶段判断

### 5.1 在分母加小虚部 `iε`

可作为：

1. 数值正则化
2. 解析延拓
3. 复度规路径积分式启发

但若字面把它当成经典 Lorentzian 几何的一部分，那么度规就会变成复的。

因此它更适合当：

```text
计算 regulator
```

而不适合当：

```text
标准经典几何解释
```

### 5.2 认为真空场会阻止这种情况

这没有一般性文献支持。

Schwarzschild 本身就是真空解，但仍同时存在：

1. 地平线 coordinate singularity
2. `r=0` true singularity

所以“真空”本身并不自动排除退化、边界或发散。

### 5.3 通过某些变换把发散绕过去

这要分两类：

1. 若只是 chart singularity，可以，而且这正是标准做法
2. 若只是某组变量表象坏掉，也往往可以换 patch 或换变量

但若遇到的是：

1. 真曲率奇点
2. 非可逆 disformal 面
3. signature-changing 退化面

那么“绕过去”这件事本身就会改变理论层级：

```text
不是仍在同一套全局等价表述里，
而是进入新分支、新 patch，甚至新理论。
```

---

## 6. 当前阶段最稳的工作性结论

### 结论 A

`X=0`、`Q=0`、`Δ=0` 应先被当作：

```text
变换图册边界 / 非可逆面候选
```

而不是先被当作：

```text
原 g 系本身的真物理奇点
```

### 结论 B

若要判断它们是否真是物理奇点，必须进一步检查：

1. 原 `g` 系曲率不变量是否发散
2. `ρ, S` 及其协变导数是否发散
3. 是否出现 geodesic incompleteness

### 结论 C

在当前项目里，最自然的下一步不是立刻给这些面“定性”，而是：

1. 先建立 `X`、`Q`、`Δ` 的 patch 图册
2. 逐个分析哪些面只是变量退化
3. 哪些面会让 `g~` 真的失去 Lorentzian 结构
