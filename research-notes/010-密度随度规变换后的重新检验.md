# 010 密度随度规变换后的重新检验

## 目标

修正上一轮变分筛选中的一个关键前提：

```text
ρ 不能在变换后保持不变，
而应与体积元一起变换。
```

采用新的约定：

```text
sqrt(-g) ρ = sqrt(-g~) ρ~
```

也就是

```text
ρ~ = [ sqrt(-g) / sqrt(-g~) ] ρ
```

在这个前提下，重新检查：

1. 最简单共形方案
2. 类 II 的 A = 1 最简单解

看上一轮结论哪些需要修正，哪些仍然成立。

## 1. 新的几何作用量写法

如果几何作用量写成

```text
I_geom = ∫ d^4x sqrt(-g~) ρ~ ( g~^(mu nu) ∂_mu S ∂_nu S - m^2 )
```

再使用

```text
sqrt(-g~) ρ~ = sqrt(-g) ρ
```

则它可改写成

```text
I_geom = ∫ d^4x sqrt(-g) ρ ( g~^(mu nu) ∂_mu S ∂_nu S - m^2 )
```

这里一个非常重要的变化是：

```text
体积因子不再额外参与筛选，
它与 ρ~ 一起正好回到原来的 sqrt(-g) ρ。
```

因此后续比较时，要检查的是

```text
g~^(mu nu) ∂_mu S ∂_nu S
```

而不是上一轮里那个带 `sqrt(-g~)` 的组合。

## 2. 连续性方程如何变化

在这个新约定下，对 `S` 变分得到

```text
∂_mu [ sqrt(-g) ρ g~^(mu nu) ∂_nu S ] = 0
```

而原理论的连续性方程是

```text
∂_mu [ sqrt(-g) ρ g^(mu nu) ∂_nu S ] = 0
```

所以：

```text
新的修正并不会让连续性方程自动恢复原状；
它只是去掉了上一轮里多余的体积因子差异。
```

真正要比较的对象现在是：

```text
g~^(mu nu) ∂_nu S
```

是否能在动力学上等价于

```text
g^(mu nu) ∂_nu S
```

## 3. 最简单共形方案的重算

取

```text
g~_mu nu = A g_mu nu
```

则

```text
g~^(mu nu) = A^(-1) g^(mu nu)
```

几何作用量变成

```text
I_conf = ∫ d^4x sqrt(-g) ρ ( A^(-1) X - m^2 )
```

### 3.1 HJ 方程

由对 `ρ` 的变分得到

```text
A^(-1) X - m^2 = 0
```

所以仍有

```text
X = A m^2
```

为了匹配原 HJ 方程

```text
X = m^2 - Q
```

最简单仍可取

```text
A = 1 - Q/m^2
```

### 3.2 连续性方程

对 `S` 变分得到

```text
∂_mu [ sqrt(-g) ρ A^(-1) ∂^mu S ] = 0
```

而原理论是

```text
∂_mu [ sqrt(-g) ρ ∂^mu S ] = 0
```

所以除非

```text
A = 常数
```

或发生特殊抵消，否则仍然不等价。

### 3.3 结论

因此上一轮关于共形最简单解的“连续性方程不对”的结论没有被推翻，只是形式要改成：

```text
问题不在于体积因子，
而在于逆度规里的 A^(-1)。
```

所以：

```text
最简单共形方案
在新的 ρ~ 变换规则下，
仍然一般不能保留原连续性方程。
```

## 4. 类 II 的 A = 1 最简单解重算

取

```text
g~_mu nu = g_mu nu + B u_mu u_nu
```

并取 `A = 1`。

我们已有

```text
g~^(mu nu) u_mu u_nu = X / (1 + B X)
```

因此几何作用量现在变成

```text
I_II = ∫ d^4x sqrt(-g) ρ [ X/(1 + B X) - m^2 ]
```

注意：

```text
这里不再有上一轮那种 sqrt(1 + B X) 的体积因子。
```

所以必须重算，上一轮“作用量恒等为零”的结论不能直接沿用。

### 4.1 代入最简单唯一解

HJ 条件仍给出

```text
B = (X - m^2) / (m^2 X)
```

于是

```text
1 + B X = X / m^2
```

从而

```text
X / (1 + B X) = m^2
```

所以几何作用量密度成为

```text
L_II = sqrt(-g) ρ ( m^2 - m^2 ) = 0
```

### 4.2 结论

因此：

```text
即使把 ρ~ 一起正确变换，
类 II 的 A = 1 最简单唯一解
仍然会使几何作用量恒等为零。
```

这说明上一轮关于类 II 的核心结论没有变：

```text
这一具体 gauge 仍然是动力学退化的，
可以继续排除。
```

## 5. 一般性的结构性结论是否改变

现在重新看一般几何作用量：

```text
I_geom = ∫ d^4x sqrt(-g) ρ ( g~^(mu nu) u_mu u_nu - m^2 )
```

如果你通过选系数让

```text
g~^(mu nu) u_mu u_nu = m^2
```

在 integrand 中恒等成立，那么仍然有

```text
I_geom ≡ 0
```

所以这个结构性结论完全保留：

```text
不能通过“把 HJ 条件硬编码进 integrand”
来构造完整理论。
```

## 6. 这一轮修正后的筛选结果

### 被修正的部分

上一轮共形方案的分析里，体积因子处理方式需要修正。

正确处理后：

```text
筛选连续性方程时，
真正要看的是 g~^(mu nu)，
不是额外的 sqrt(-g~) 因子。
```

### 不变的部分

```text
1. 最简单共形方案仍然一般不能保留原连续性方程
2. 类 II 的 A = 1 最简单唯一解仍然使作用量恒等为零
3. “不能把 HJ 条件硬编码进 integrand”这一结构性结论仍然成立
```

## 7. 下一步建议

现在下一步就更清楚了：

```text
要继续做的不是再纠结体积因子，
而是直接对一般共形类和一般类 II 的
g~^(mu nu)
做变分筛选。
```

具体就是：

1. 一般共形类：
   `g~_mu nu = A g_mu nu`
   检查什么时候能同时给出正确 HJ 与连续性方程

2. 一般类 II：
   `g~_mu nu = A g_mu nu + B u_mu u_nu`
   检查什么时候不会退化，同时还能保住正确动力学
