# 054 `f(R)=R/sqrt(1+(\ell^2 R)^2)` 在平直极限下先天贴近 EH 分支

## 1. 目的

解释当前统一 baseline 下看到的一个现象：

```text
在很小到中等的 lambda_grav 范围里，
C 分支几乎一直贴着 B 分支，
并没有立刻显出和 B 不同的新结构。
```

这不一定只是数值器的问题，
也可能是当前选定的 `f(R)` 模型本来就在 flat limit 上非常接近 Einstein-Hilbert。

## 2. 模型

当前 C 分支采用：

```text
f(R) = R / sqrt(1 + (\ell^2 R)^2)
```

这等价于：

```text
f(R) = R F(\ell^2 R),   F(x)=1/sqrt(1+x^2)
```

## 3. 平直极限展开

对 `R=0` 做展开：

```text
f(R) = R - (1/2) \ell^4 R^3 + (3/8) \ell^8 R^5 + O(R^6)
```

关键点在于：

```text
没有 R^2 项。
```

并且：

```text
f'(R) = (1 + \ell^4 R^2)^(-3/2)
f''(0) = 0
f'''(0) = -3 \ell^4
```

## 4. 含义

这意味着：

```text
当前这个 f(R) 模型和 EH 的第一个非平凡差异，
不是从二阶曲率修正开始，
而是从三阶曲率修正开始。
```

因此在：

```text
R~ 很小
```

的区域里，C 分支本来就应当非常接近 B 分支。

## 5. 对当前数值现象的解释

所以当前 continuation baseline 下看到：

```text
lambda_grav = 1e-4, 1e-3, 1e-2
```

时 `C` 与 `B` 都几乎贴着 `A`，
以及 `C` 很难迅速从 `B` 里分离出来，
至少有一部分是模型本身的自然结果：

```text
这个 C 分支在 flat / weak-curvature limit 上本来就不会很快偏离 B。
```

## 6. 但这不替代 solver debug

这条理论观察只能解释：

```text
为什么 C 在弱场下本来就很像 B
```

但不能解释：

```text
phi 被 clipping 钉死
dt 敏感
phi -> 1 附近变量病态
```

这些仍然是求解器层面的真实问题。

## 7. 当前结论

```text
“C 很像 B”
并不自动说明 solver 有问题；
因为当前选定的 f(R) 模型在 flat limit 上确实先天贴近 EH。
```

但：

```text
C solver 仍然有问题，
只是这个问题叠加在一个本来就很难和 B 拉开的理论模型之上。
```
