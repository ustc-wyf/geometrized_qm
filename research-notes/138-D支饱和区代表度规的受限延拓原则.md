# D 支饱和区代表度规的受限延拓原则

日期：2026-05-03

## 问题

用户追问：

1. 饱和区代表 metric 到底应该怎么选；
2. 度规虽然有任意性，但实际应满足哪些约束；
3. 过渡层作为边界是不是已经给出了约束，为什么还要讨论饱和区内部代表。

## 先给结论

\[
\boxed{
\text{饱和区代表 metric 不是任意取值，而是“在接口约束下的受限延拓”。}
}
\]

它不是新物理，也不是简单平滑平均；它是当 \(f_R\to0\) 导致局部几何方程退化后，为了继续演化必须额外指定的闭合规则。

## 当前代码里实际怎么做

当前 `inert_tridomain` 版本里：

- 初始 metric 由混合 disformal 逆变换 `tilde_inverse_from_flat_mixed_transform` 给出；
- `localized_direct_tilde_coordinate_initial(... )` 只是在初始时刻把这套 algebraic metric 及其时间导数提取出来；
- 演化过程中 `metric_cov` 在 active/support 内并没有由完整 metric 方程重新求解，而是保持惯性代表；
- active/support 外则被 sanitize 成平直度规。

因此当前数值里实际采用的是：

\[
\text{初始 algebraic 代表} \;\to\; \text{inert freeze 续延}
\]

这只是第一版可执行闭合，不是唯一物理解。

## 为什么过渡层边界还不够

过渡层/interface 确实是一种约束，但它只约束边界上该满足什么：

- metric 的连续性；
- 法向 jump law；
- 速度/生成/消失条件；
- 由张量 jump 反推的局部法向协向量。

问题在于，当 \(f_R\to0\) 时，饱和区内部的主部已经退化，接口条件本身并不能唯一决定整个内部 metric。换句话说：

- interface 是边界约束；
- saturated bulk 还需要内部代表原则；
- 两者缺一不可。

所以“过渡层作为边界”不是和“代表 metric”重复，而是分工不同。

## 约束排序

当前最合理的选择顺序是：

1. Lorentz 签名与可逆性；
2. 与弱曲率 bulk / 外侧区域连续匹配；
3. 满足 direct tensor jump / body-fitted matching；
4. 尽量压低 plateau tensor residual；
5. 尽量保持 metric 随时间与空间最平滑，不制造新尖峰；
6. 只在上述约束满足后，再在 admissible family 中选最小失稳的代表。

这比“取平直 metric”或“取平均 metric”更准确。

## 哪些候选原则可以保留

可以保留的候选原则：

- 接口连续延拓；
- 最小曲率延拓；
- 与外侧 bulk 最小差异延拓；
- 使 `disc_min` 尽量远离零的延拓；
- 在 admissible family 中选最小 residual 的延拓。

不能单独作为原则的：

- 直接取平直度规；
- 直接取数值平均；
- 直接把 support 边缘当作完整物理边界并忽略内部闭合。

## 当前数据给出的判断

对 `t_old=8` 的三组固定参数结果：

- `n96 dt` 与 `n96 dt/2` 在 support/trusted/edge/taper 四种口径下几乎完全一致；
- `n128` 没有系统改善；
- `plateau_relative_p95` 始终接近 `1`；
- `interface_solved_fraction = 0`，说明当前切片上尚未进入可用的 interface 主闭合阶段；
- 饱和区里 `f_R` 已下溢，`f_{RR}` 符号混杂，scalaron 质量平方基本不可用。

这意味着当前数据还不支持“某一个简单的代表 metric 自动胜出”。

## 实际结论

\[
\boxed{
\text{饱和区 metric 选择应视为“接口约束下的最小失稳延拓问题”，而不是平均问题。}
}
\]

下一步如果继续，应该：

1. 先把 interface 条件写成显式可求的边界约束；
2. 再把饱和区内部 metric 的选取写成一个最小化问题；
3. 优先比较“与外部连续 + 最小 plateau residual + 最小 curvature variation”的候选。

只有这样，代表 metric 才有理论含义。
