# 097 B 支本征 Einstein 张量代回 `g` 表象后的左边差异

时间：2026-05-01

## 目标

按“先对各自自由场变分，再把 B 支本征 Einstein 方程中的变量代回 `g` 表象”的规则，计算

```text
ΔG_{μν}^{(B-A)}
:= G~_{μν}[ g~(g,ρ,S) ] - G_{μν}[g].
```

这里不做 `δS_B/δg`，只比较两条**本征** Einstein 方程在同一 `g` 表象下的左边差。

## 1. 一般 `3+1d` 的精确公式

定义两套 Levi-Civita 联络之差

```text
ΔΓ^ρ_{μν}
:= Γ~^ρ_{μν}[g~] - Γ^ρ_{μν}[g].
```

则 Ricci 张量差的标准恒等式是

```text
R~_{μν}
= R_{μν}
+ ∇_ρ ΔΓ^ρ_{μν}
- ∇_ν ΔΓ^ρ_{μρ}
+ ΔΓ^ρ_{ρλ} ΔΓ^λ_{μν}
- ΔΓ^ρ_{νλ} ΔΓ^λ_{μρ}.
```

记

```text
K_{μν}
:=
∇_ρ ΔΓ^ρ_{μν}
- ∇_ν ΔΓ^ρ_{μρ}
+ ΔΓ^ρ_{ρλ} ΔΓ^λ_{μν}
- ΔΓ^ρ_{νλ} ΔΓ^λ_{μρ}.
```

于是

```text
R~_{μν}=R_{μν}+K_{μν}.
```

再记

```text
h_{μν}:=g~_{μν}-g_{μν}.
```

则 Einstein 张量差的精确公式是

```text
ΔG_{μν}^{(B-A)}
= K_{μν}
- (1/2) h_{μν} R[g]
- (1/2) g~_{μν}
   [ (g~^{αβ}-g^{αβ}) R_{αβ}[g] + g~^{αβ} K_{αβ} ] .
```

这条式子没有做任何近似。

## 2. 当前分支下的 `ΔΓ`

当前固定在 `m != 0, C = 1` 的混合投影分支，并在 `X>0` 的 timelike branch 上，

```text
h_{μν} = (Q/m^2) Π_{μν},
```

其中

```text
Q := □_g √ρ / √ρ,
```

`Π_{μν}` 是 Bohm 二维平面的协变投影子。

因此

```text
ΔΓ^ρ_{μν}
= (1/2) g~^{ρσ}
   [ ∇_μ h_{σν} + ∇_ν h_{σμ} - ∇_σ h_{μν} ] .
```

代入 `h_{μν}=(Q/m^2)Π_{μν}`，

```text
ΔΓ^ρ_{μν}
= (1/2) g~^{ρσ}
   [ ∇_μ( (Q/m^2) Π_{σν} )
   + ∇_ν( (Q/m^2) Π_{σμ} )
   - ∇_σ( (Q/m^2) Π_{μν} ) ] .
```

所以左边差异的根源只有两个：

```text
(1) ∇(Q/m^2)
(2) (Q/m^2) ∇Π .
```

## 3. 一阶弱形变展开

若把

```text
h_{μν}=(Q/m^2)Π_{μν}
```

视为小形变，则 Einstein 张量的一阶差是标准线性化结果

```text
ΔG_{μν}^{(1)}
= δG_{μν}[h].
```

在平直背景 `g≈η` 下，可写成

```text
δG_{μν}[h]
= (1/2)
 [ -□ h_{μν}
   - ∂_μ ∂_ν h
   + ∂^σ ∂_μ h_{νσ}
   + ∂^σ ∂_ν h_{μσ}
   - η_{μν} ( ∂^α ∂^β h_{αβ} - □ h )
 ] .
```

代入 `h_{μν}=(Q/m^2)Π_{μν}`，量级上得到

```text
ΔG_{μν}^{(1)}
~ ∂∂(Q/m^2) Π
 + ∂(Q/m^2) ∂Π
 + (Q/m^2) ∂∂Π .
```

也就是说，左边一阶差至少含有

```text
∂∂Q .
```

由于

```text
Q = □_g √ρ / √ρ,
```

这意味着左边一般会吃到 `√ρ` 的四阶导数。

## 4. 与右边差异的阶数比较

上一份笔记 `096` 已得出，在共同 Bohm-HJ 壳

```text
X - m^2 - Q = 0
```

上，

```text
ΔT_{μν}^{(B-A)}
= - 2 r_μ r_ν + g_{μν}(r^2 + ρQ),
```

其中

```text
r_μ := ∂_μ √ρ.
```

所以右边差只含：

```text
∂√ρ · ∂√ρ,
√ρ □_g √ρ.
```

也就是至多 `√ρ` 的二阶导数。

因此：

```text
左边差 ΔG_{μν}^{(B-A)} 在一般 3+1d 下含有 Q 的二阶导数，
从而一般含有 √ρ 的四阶导数；
右边差 ΔT_{μν}^{(B-A)} 在共同壳上只到二阶。
```

## 5. 阶数结论

所以在一般 `3+1d` 下，除非发生非常特殊的结构性消项，

```text
M_P^2 ΔG_{μν}^{(B-A)} = ΔT_{μν}^{(B-A)}
```

不可能作为一个普遍恒等式成立。

更准确地说：

1. 左边的主导差异是“几何重定义后的高阶导数效应”；
2. 右边的主导差异是“振幅梯度 / 量子势项”；
3. 两边的微分阶数一般不匹配。

因此从一般 `3+1d` 的结构判断，

```text
A 支本征 Einstein 方程
```

与

```text
B 支本征 Einstein 方程代回 g 表象后的方程
```

一般不应期待严格等价。

## 6. 渐近一致的可能性

虽然严格等价一般不成立，但在下面的极限里，两边都可能变小：

```text
|Q|/m^2 << 1,
|∇(Q/m^2)| 小,
|∇Π| 小.
```

## 7. 平直背景 `g = η` 时，高阶导数项会不会自动消失

不会。  
平直背景只会消掉背景曲率项

```text
R[g] = 0,
R_{μν}[g] = 0,
```

但不会自动消掉由几何重定义诱导出的

```text
K_{μν}[ΔΓ]
```

项。

在这种情况下，精确公式简化成

```text
ΔG_{μν}^{(B-A)}
= K_{μν}
- (1/2) g~_{μν} g~^{αβ} K_{αβ}.
```

所以只要 `ΔΓ` 不为零，左边差一般就不为零。

### 7.1 一阶下的最简判断

在平直背景上一阶展开时，

```text
ΔG_{μν}^{(1)} = δG_{μν}[h],
```

其中

```text
h_{μν}=(Q/m^2) Π_{μν}.
```

因此

```text
ΔG_{μν}^{(1)}
~ ∂∂Q · Π
 + ∂Q · ∂Π
 + Q · ∂∂Π .
```

所以：

```text
g = η
```

并不推出这些项趋于零；  
只有在下面额外条件下它们才会小：

```text
Q ≈ 常数,
Π_{μν} ≈ 常投影,
或者更一般地，
|∂Q|, |∂∂Q|, |∂Π|, |∂∂Π| 都很小。
```

### 7.2 一个最简单的反例

取平直背景

```text
g_{μν} = η_{μν} = diag(1,-1,-1,-1),
```

并假设 Bohm 平面在某一区域内近似固定为 `t-x` 平面：

```text
Π_{μν} = diag(1,-1,0,0).
```

再取

```text
q(x) := Q(x)/m^2,
qquad
h_{μν} = q(x) Π_{μν}.
```

则一阶线性化 Einstein 张量中，`11` 分量直接给出

```text
δG_{11}[h] = - 2 q''(x).
```

所以只要

```text
q''(x) ≠ 0,
```

即使背景完全平直，

```text
ΔG_{11}^{(B-A)} ≠ 0.
```

这说明：

```text
平直背景并不会把这些高阶导数项自动杀掉；
它只是去掉了背景曲率，
剩下的差异仍由 Q 与 Π 的导数控制。
```

在这种“弱且缓变量子势”区，`ΔG_{μν}^{(B-A)}` 和 `ΔT_{μν}^{(B-A)}` 都可能同时变小，因此 A/B 仍有渐近一致的可能。
