# 025 1+1d 自由 KG 双高斯波包基线模型

## 目标

建立一个可复用的 1+1d 自由 Klein-Gordon 基线模型，用作后续放入：

- 渐近平直背景
- “地球表面”近似的 Schwarzschild 背景
- 引力波背景

中的统一测试例子。

当前只做：

```text
平直背景下的自由 KG 双高斯波包
```

并把以下量的计算模块化：

```text
ψ
ρ = |ψ|^2
S = arg ψ
j^μ
X = ∂_μ S ∂^μ S
Q = - Box sqrt(ρ) / sqrt(ρ)
```

## 1. 模型定义

我们在 1+1d 平直时空上工作，度规取

```text
η_μν = diag(1, -1)
```

自由 KG 方程为

```text
(∂_t^2 - ∂_x^2 + m^2) ψ = 0
```

### 1.1 双高斯初始态的参数

我们把波包写成两束正频高斯模的叠加：

```text
ψ(x,t) = ψ_L(x,t) + ψ_R(x,t)
```

用到的参数是：

- `m`：KG 质量
- `alpha`：左束振幅系数
- `sqrt(1-alpha)`：右束振幅系数
- `sigma_l, sigma_r`：左右束在动量空间的宽度参数
- `k0`：共同中心波矢
- `ω0 = sqrt(k0^2 + m^2)`：共同中心频率
- `φ0`：两束的相对初相位
- `x_l0, x_r0`：两束在 `t=0` 的中心位置

说明：

```text
用户只显式给出了 α、sqrt(1-α)、σ_l、σ_r、ω0、k0、φ0；
为了定义“双缝”型左右两束，还必须再引入左右中心位置 x_l0, x_r0。
```

这是一个必要补参数，不是额外物理假设。

## 2. 为什么采用动量空间表示

对自由 KG，最干净的精确演化写法是正频 Fourier 叠加：

```text
ψ(x,t) = ∫ dk a(k) exp[i k x - i ω(k) t]
ω(k) = sqrt(k^2 + m^2)
```

这有几个好处：

1. 它是自由 KG 的精确解，不靠慢变包络近似。
2. 时间和空间导数都能通过 Fourier 乘子精确得到。
3. 后续算 `j^μ`、`X`、`Q` 时可避免不必要的数值噪声。

## 3. 双高斯谱函数

我们定义左右两束的动量谱为

```text
a_L(k) = A_L * exp[-(k-k0)^2 / (4 sigma_l^2)] * exp[-i k x_l0]
a_R(k) = A_R * exp[-(k-k0)^2 / (4 sigma_r^2)] * exp[-i k x_r0] * exp[i φ0]
```

其中

```text
A_L = alpha
A_R = sqrt(1-alpha)
```

总谱函数是

```text
a(k) = a_L(k) + a_R(k)
```

则

```text
ψ(x,t) = ∫ dk a(k) exp[i k x - i ω(k) t]
```

### 3.1 关于“解析解”的说明

这个模型的 Fourier 表示是精确解析的。

若要求把 `ψ(x,t)` 化成初等函数闭式，
对有质量色散关系

```text
ω(k) = sqrt(k^2 + m^2)
```

一般并不简单。

因此本项目采用：

```text
解析定义 + 数值精确求积/FFT 演化
```

这在理论和数值上都是合适的。

## 4. Bohm 量的计算

### 4.1 密度与相位

```text
ρ = |ψ|^2
S = arg ψ
```

### 4.2 Noether / Bohm 电流

在当前约定下

```text
j^μ = ρ ∂^μ S
```

也可直接由 `ψ` 计算：

```text
j^0 = Im( ψ* ∂_t ψ )
j^1 = - Im( ψ* ∂_x ψ )
```

因此

```text
∂_t S = j^0 / ρ
∂_x S = - j^1 / ρ
```

### 4.3 X

```text
X = ∂_μ S ∂^μ S
  = (∂_t S)^2 - (∂_x S)^2
  = (j^0)^2 / ρ^2 - (j^1)^2 / ρ^2
```

### 4.4 量子势 Q

记

```text
R = sqrt(ρ)
```

则

```text
Q = - Box R / R
  = - (∂_t^2 - ∂_x^2) R / R
  = (∂_x^2 R - ∂_t^2 R) / R
```

为了降低误差，我们不直接对 `R` 做粗差分，而是通过 `ψ` 的一、二阶导数先构造 `ρ` 的导数，再构造 `R` 的导数。

## 5. 这个模型里 Q 会在哪里变大

在双高斯干涉模型中，`Q` 通常会在以下区域变大：

### 5.1 干涉条纹节点附近

当两束波相消导致

```text
ρ -> 0
```

时，`R = sqrt(ρ)` 变小，而 `Box R / R` 容易变大。

因此：

```text
Q 在干涉暗纹/节点附近通常会出现尖峰。
```

### 5.2 波包包络快速弯曲处

若 `sigma_l`、`sigma_r` 较小，包络弯曲强，`∂_x^2 R` 较大，也会推高 `Q`。

### 5.3 相对相位驱动的条纹压缩

`φ0` 改变条纹位置和节点结构，从而明显改变 `Q` 的空间分布。

### 5.4 振幅不均衡 α ≠ 1/2

当左右束不等强时，节点不再完全对称，`Q` 的极大值和偏置也会改变。

## 6. 这个基线模型为什么适合后续放入曲背景

因为它已经把问题拆成了三层：

1. 自由正频波包的定义
2. 几何/Bohm 量的后处理
3. 背景几何的替换接口

后续若放入 Schwarzschild 或引力波背景，通常只需修改：

- 演化方程
- 导数算子
- 守恒流定义中的度规缩并

而参数层和后处理层可以保留。
