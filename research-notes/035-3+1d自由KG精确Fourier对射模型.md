# 035 3+1d 自由 KG 精确 Fourier 对射模型

## 目标

建立一个新的 3+1d 自由 KG 模型，满足：

```text
1. 两束在 x-z 平面中沿 ±45° 束轴传播
2. y=0 的 x-z 切片可直接观测
3. alpha=0 和 alpha=1 时是单束
4. alpha=0.5 时是双束干涉
5. 不再使用近似束流包络，而直接使用自由 KG 的正频 Fourier 精确表示
```

## 1. 模型

取两束动量空间高斯谱：

```text
a_A(k) ~ exp[-((kx-kx0)^2 + ky^2 + (kz-kz0)^2)/(4σ_k^2)] * exp[-i(k·x_A0)]
a_B(k) ~ exp[-((kx+kx0)^2 + ky^2 + (kz+kz0)^2)/(4σ_k^2)] * exp[-i(k·x_B0)] * exp[iφ0]
```

其中

```text
(kx0, kz0) = (k0/√2, k0/√2)
```

和

```text
x_A0 = (-a/2, 0, -a/2)
x_B0 = (+a/2, 0, +a/2)
```

总波函数为

```text
ψ(x,y,z,t) = ∭ d^3k [a_A(k)+a_B(k)] exp[i(k·x - ω(k)t)]
ω(k)=sqrt(kx^2+ky^2+kz^2+m^2)
```

这就是自由 KG 的精确正频表示。

## 2. 计算策略

为了避免内存爆炸，计算只在

```text
y = 0
```

的 `x-z` 切片上进行，并且沿 `x` 分块求积，而不是一次性广播整个四维大数组。

这样既保持了精确 Fourier 结构，又能稳定结束。
