# 065 混合 ansatz 新解 `D=Z, E=-aY, F=aX`

## 目标

检查用户提出的一组新的混合逆度规系数：

```text
D = Z
E = -aY
F = aX
C = aXZ
```

其中：

```text
u_μ = ∂_μ S
r_μ = ∂_μ sqrt(ρ)

X = g^(μν) u_μ u_ν
Y = g^(μν) u_μ r_ν
Z = g^(μν) r_μ r_ν
Δ = XZ - Y^2
```

要回答四个问题：

1. 它能否恢复 `g` 系 HJ 方程
2. 它能否恢复 `g` 系连续性方程
3. 行列式比值是什么
4. 奇异点出现在哪里

---

## 1. ansatz

取

```text
g~^(μν)
= C g^(μν)
+ Z u^μ u^ν
- aY (u^μ r^ν + r^μ u^ν)
+ aX r^μ r^ν
```

并同时要求

```text
C = aXZ
```

因此也可写成

```text
g~^(μν)
= aXZ g^(μν)
+ Z u^μ u^ν
- aY (u^μ r^ν + r^μ u^ν)
+ aX r^μ r^ν
```

---

## 2. 收缩一次：`g~^(μν) u_ν`

逐项计算：

```text
C g^(μν) u_ν = C u^μ = aXZ u^μ
Z u^μ u^ν u_ν = ZX u^μ
-aY (u^μ r^ν u_ν + r^μ u^ν u_ν)
= -aY (Y u^μ + X r^μ)
+aX r^μ r^ν u_ν
= +aXY r^μ
```

其中 `r^μ` 项正好相消，所以得到

```text
g~^(μν) u_ν
= [ aXZ + XZ - aY^2 ] u^μ
= [ XZ + a(XZ - Y^2) ] u^μ
```

也就是

```text
g~^(μν) u_ν = [ XZ + aΔ ] u^μ
```

这是这组解最漂亮的地方：

```text
虽然不是投影型解，
但它仍把连续性方程的流方向压回到了 u^μ。
```

---

## 3. 收缩两次：`g~^(μν) u_μ u_ν`

再收缩一次 `u_μ`：

```text
g~^(μν) u_μ u_ν
= X [ XZ + aΔ ]
```

所以若变换后 `g~` 系 HJ 方程写成

```text
g~^(μν) u_μ u_ν = κ
```

则条件是

```text
X [ XZ + aΔ ] = κ
```

只要 `X ≠ 0` 且 `Δ ≠ 0`，就可解得

```text
a = [ κ/X - XZ ] / Δ
  = [ κ - X^2 Z ] / (XΔ)
```

因此：

```text
在 XΔ ≠ 0 的 patch 上，
这组 ansatz 可以恢复 HJ 方程。
```

---

## 4. 连续性方程

变换后连续性方程是

```text
∂_μ [ sqrt(|g~|) ρ~ g~^(μν) u_ν ] = 0
```

代入上面的结果：

```text
∂_μ [ sqrt(|g~|) ρ~ (XZ + aΔ) u^μ ] = 0
```

因此只要定义密度变换

```text
sqrt(|g~|) ρ~ (XZ + aΔ) = sqrt(|g|) ρ
```

就能精确恢复原 `g` 系连续性方程

```text
∂_μ [ sqrt(|g|) ρ u^μ ] = 0
```

所以：

```text
在同一个 XΔ ≠ 0 的 patch 上，
它也可以恢复连续性方程。
```

---

## 5. 结论：两个方程是否都能恢复

答案是：

```text
可以，
但要加条件。
```

更准确地说：

### 5.1 在一般 `a` 下

- 这组 ansatz 自动把流向量压回 `u^μ`
- 但未必自动满足固定常数壳约束

### 5.2 若把 `a` 取成

```text
a = [ κ - X^2 Z ] / (XΔ)
```

则：

1. `g~` 系 HJ 方程恢复
2. 连续性方程也恢复

所以这是一个可行的解族。

---

## 6. 行列式比值

四维下，一般混合 ansatz 的行列式比值公式是

```text
det(g~^(..)) / det(g^(..))
= C^2 [ C^2 + C(DX + 2EY + FZ) + (DF - E^2)(XZ - Y^2) ]
```

代入

```text
C = aXZ
D = Z
E = -aY
F = aX
```

化简后得到

```text
det(g~^(..)) / det(g^(..))
= a^3 X^2 Z^2 (2XZ - Y^2) (XZ + aΔ)
```

这是这组解的一般行列式比值。

若再代入恢复 HJ 所需条件

```text
XZ + aΔ = κ/X
```

则可写成

```text
det(g~^(..)) / det(g^(..))
= a^3 κ X Z^2 (2XZ - Y^2)
```

进一步把 `a = [κ - X^2 Z]/(XΔ)` 代回，则得到

```text
det(g~^(..)) / det(g^(..))
= κ Z^2 (2XZ - Y^2) (κ - X^2 Z)^3 / (X^2 Δ^3)
```

---

## 7. 奇异点出现在哪里

这里要分两层说。

### 7.1 bare ansatz 自己的退化面

即使不强行要求恢复方程，这个 ansatz 的行列式比值也已经表明以下面会使变换退化：

```text
a = 0
X = 0
Z = 0
2XZ - Y^2 = 0
XZ + aΔ = 0
```

也就是说：

```text
X = 0
```

不是只在“解方程时”才出问题，而是这个具体 ansatz 本身就在这里退化。

同理：

```text
Z = 0
```

也是这个 ansatz 自身的退化面。

### 7.2 为了恢复两个方程而解出 `a` 后的新奇异面

若要求

```text
a = [ κ - X^2 Z ] / (XΔ)
```

则额外出现了显式分母：

```text
X
Δ
```

所以：

```text
X = 0
Δ = 0
```

都会成为“这组解作为恢复 HJ+连续性的图册”中的显式边界。

这里有一个重要区分：

- `X=0`：bare ansatz 本身就退化
- `Δ=0`：bare ansatz 不一定自动退化，但解出 `a` 的参数化会发散

换句话说：

```text
Δ = 0
```

更像是“这组解的 matching chart 坏了”，  
而

```text
X = 0
```

则更强，是 ansatz 自身就退化。

### 7.3 额外的退化面 `κ = X^2 Z`

若

```text
κ = X^2 Z
```

则

```text
a = 0
C = 0
```

从而上面的行列式比值直接为零。

因此这也是一个新的退化面。

---

## 8. 与前面投影型解的比较

这组新解和前面 `D=Z, E=-Y, F=X` 的投影型解相比，有三个鲜明特点：

### 8.1 优点

它仍然把

```text
g~^(μν) u_ν
```

压回 `u^μ` 方向，因此连续性方程的恢复机制仍然很干净。

### 8.2 缺点

它引入了更多显式退化面：

```text
X = 0
Z = 0
2XZ - Y^2 = 0
κ = X^2 Z
```

而不只是 `Δ=0`。

### 8.3 经典极限不自然

因为这里

```text
C = aXZ
```

并且为了恢复 HJ 方程有

```text
a = [ κ - X^2 Z ] / (XΔ)
```

所以一般并不会自动得到

```text
C -> 1
```

当 `Q -> 0`。

这说明：

```text
它是一个代数上可行的解，
但从“经典恢复自然性”看，
比前面 `C=1` 的投影型解弱得多。
```

---

## 9. 总结

最终结论如下：

### 9.1 能否恢复两个方程

```text
能。
```

在 `XΔ ≠ 0` 的 patch 上，只要取

```text
a = [ κ - X^2 Z ] / (XΔ)
```

并定义

```text
sqrt(|g~|) ρ~ (XZ + aΔ) = sqrt(|g|) ρ
```

就能同时恢复：

1. `g` 系 HJ 方程
2. `g` 系连续性方程

### 9.2 行列式比值

一般为

```text
det(g~^(..)) / det(g^(..))
= a^3 X^2 Z^2 (2XZ - Y^2) (XZ + aΔ)
```

### 9.3 奇异点

至少有三类：

1. bare ansatz 自身退化面：
   ```text
   X = 0
   Z = 0
   2XZ - Y^2 = 0
   a = 0
   XZ + aΔ = 0
   ```
2. 为恢复方程而解出 `a` 后的 matching singularities：
   ```text
   X = 0
   Δ = 0
   ```
3. 额外参数退化面：
   ```text
   κ = X^2 Z
   ```

### 9.4 当前判断

```text
这组解代数上成立，
而且在“恢复连续性方程”这一步非常漂亮；
但它的退化结构比前面的投影型主解更复杂，
并且没有显然自然的经典极限。
```
