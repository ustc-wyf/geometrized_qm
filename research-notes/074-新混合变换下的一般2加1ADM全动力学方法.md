# 074 新混合变换下的一般 2+1 `ADM` 全动力学方法

## 目标

在当前新的混合变换下，不再沿用旧的对角 conformal gauge

```text
ds^2 = e^{2τ}(dt^2-dx^2-dz^2)-e^{2β}dy^2
```

而是直接建立一套能容纳 `t-x`、`t-z`、`x-z` 非对角分量的 `2+1` 一般 `ADM` 方法。

这份笔记只做第一步：

1. 明确旧数值框架为什么已经不适用  
2. 给出新的 `2+1` 度规 ansatz  
3. 在这个一般 ansatz 下，重新写出共同的物质全动力学方程  
4. 说明三种引力作用量在这个新框架下应怎样推进

这里刻意不把旧 shared-baseline 或旧对角 gauge 的公式继续混进来。

---

## 1. 为什么旧的对角 gauge 不再适用

当前新变换是一般混合逆度规 ansatz

```text
g~^(μν)
= C g^(μν)
+ D u^μ u^ν
+ E (u^μ r^ν + r^μ u^ν)
+ F r^μ r^ν
```

其中

```text
u_μ = ∂_μ S
r_μ = ∂_μ sqrt(ρ)
```

而用户当前主用的漂亮混合块是

```text
D = Z
E = -Y
F = X
```

在 `x-z` 平面内沿 `±45°` 方向传播的双高斯干涉初值上，
`u_t, u_x, u_z, r_t, r_x, r_z` 一般都不为零，
因此混合块会 generically 生成：

```text
g~^(tx), g~^(tz), g~^(xz)
```

这说明旧的纯对角 ansatz

```text
g~_(ab) = diag(e^{2τ}, -e^{2τ}, -e^{2τ})
```

已经不再与当前变换相容。

所以后续若还坚持用旧的 `τ,β` 数值器，就不是在算当前这条新变换下的全动力学。

---

## 2. 新的一般 `2+1` 度规 ansatz

继续保留：

```text
y 方向是 Killing 方向
```

并把 `g~` 表象的 `t-x-z` 三维部分写成一般 `ADM` 分解：

```text
ds^2_(g~)
= N^2 dt^2
- h_ij ( dx^i + N^i dt ) ( dx^j + N^j dt )
- e^{2β} dy^2
```

其中

```text
i,j ∈ {x,z}
```

变量是：

```text
N(t,x,z)          lapse
N^x(t,x,z), N^z(t,x,z)   shift
h_xx, h_xz, h_zz         2d spatial metric
β(t,x,z)                 y 方向约化标量
```

于是

```text
sqrt(-g~_4) = N e^β sqrt(h)
```

这里

```text
h := det(h_ij) = h_xx h_zz - h_xz^2 .
```

逆度规分量为

```text
g~^(tt) = 1 / N^2
g~^(ti) = - N^i / N^2
g~^(ij) = - h^(ij) + N^i N^j / N^2
g~^(yy) = - e^{-2β}
```

这套 ansatz 可以自然容纳：

```text
g~_(tx), g~_(tz), g~_(xz)
```

也就是当前混合变换真正会生成的几何结构。

## 3. 共同物质作用量

继续使用项目中一直固定的物质作用量：

```text
S_matter
= ∫ dt dx dz N e^β sqrt(h)
   ρ [ g~^(ab) ∂_a S ∂_b S - m^2 ]
```

其中 `a,b ∈ {t,x,z}`。

记

```text
p_i := ∂_i S
π   := ∂_t S - N^i p_i
```

则

```text
g~^(ab) ∂_a S ∂_b S
= π^2 / N^2 - h^(ij) p_i p_j .
```

于是 `ρ` 变分给出新的 `HJ` 方程：

```text
π^2 / N^2 - h^(ij) p_i p_j = m^2 .
```

选取未来指向、正频支后，

```text
π = - N E
```

其中

```text
E := sqrt( m^2 + h^(ij) p_i p_j ) .
```

因此

```text
∂_t S = N^i p_i - N E .
```

这就是一般 `ADM` 度规下的相位演化方程。

---

## 4. 一般 `ADM` 下的连续性方程

对 `S` 变分：

```text
∂_a [ N e^β sqrt(h) ρ g~^(ab) ∂_b S ] = 0 .
```

定义守恒密度

```text
n := e^β sqrt(h) ρ E .
```

则

```text
J^t = N e^β sqrt(h) ρ g~^(tb) ∂_b S = - n
```

而空间流为

```text
J^i
= N e^β sqrt(h) ρ g~^(ib) ∂_b S
= - n N^i - (N n / E) h^(ij) p_j .
```

因此连续性方程

```text
∂_t J^t + ∂_i J^i = 0
```

改写成真正的一阶守恒型系统：

```text
∂_t n
= - ∂_i F^i
```

其中

```text
F^i := n N^i + (N n / E) h^(ij) p_j .
```

展开就是

```text
∂_t n
= -∂_x [ n N^x + (N n / E)( h^(xx) S_x + h^(xz) S_z ) ]
   -∂_z [ n N^z + (N n / E)( h^(zx) S_x + h^(zz) S_z ) ] .
```

并且

```text
ρ = n / ( e^β sqrt(h) E ) .
```

所以在一般 `ADM` 度规下，物质变量的自然演化形式就是：

```text
(n, S)
```

而不是旧对角 gauge 里的 `ρ,S` 直接推进。

## 5. 这一步的意义

到这里为止，我们已经得到一套完全不依赖旧对角 gauge 的共同物质骨架：

```text
S_t = N^i S_i - N E
```

```text
n_t = - ∂_i [ n N^i + (N n / E) h^(ij) S_j ]
```

```text
ρ = n / ( e^β sqrt(h) E )
```

这就是三种引力作用量后续统一数值化时，真正应共享的物质推进器。

## 6. 三种引力作用量在新框架下如何推进

### 6.1 B 表象：`sqrt(-g~) R[g~]`

这条支现在不应再写成旧的 `τ,β` 波动方程，
而应改写成：

```text
3 维 metric γ_ab = ADM(N, N^i, h_ij)
+ 约化标量 β
+ 物质变量 (n,S)
```

的 `ADM` 演化系统。

也就是说，它在数值上应被当成：

```text
2+1 Einstein + scalar β + Bohm matter
```

的标准初值问题。

### 6.2 C 表象：`sqrt(-g~) f(R~)`

这条支同样不应再写成旧的 `τ,β,Φ` 对角波动系统，
而应写成：

```text
2+1 scalar-tensor ADM system
+ β
+ 辅助场 Φ
+ Bohm matter (n,S)
```

### 6.3 A 表象：`sqrt(-g) R[g]`

这条支最麻烦，但现在思路反而更清楚：

```text
先把 g 用自己的 ADM 变量推进，
再通过当前混合变换
g -> g~
把物质作用量写到 g~ 上，
从而形成约束耦合系统。
```

也就是说：

```text
A 支真正缺的不是“物质方程”，
而是一般 ADM 变量下的 g ↔ g~ 闭合关系。
```

当前新方法的第一步已经定下来：

```text
把 B/C/A 三支都搬到这个一般 ADM 骨架上。
```

这才是当前新混合变换下 honest 的全动力学路线。
