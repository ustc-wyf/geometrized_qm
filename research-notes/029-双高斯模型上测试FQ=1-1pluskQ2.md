# 029 双高斯模型上测试 `F(Q)=1/(1+(κQ)^2)` 的结果

## 目标

用当前 1+1d 双高斯 KG 基线模型，直接测试第一优先候选引力修正：

```text
F(Q) = 1 / (1 + (κQ)^2)
```

关心三件事：

1. 主支撑区内 `F` 偏离 1 多大
2. 节点附近偏离多大
3. `∇F`、`∇∇F` 是否比 `F` 本身更危险

## 1. 测试设置

基线模型参数采用前一份文档同一组：

```text
m = 1.0
alpha = 0.6
sigma_l = 0.35
sigma_r = 0.28
k0 = 2.0
phi0 = 0.7
x_l0 = -6.0
x_r0 =  6.0
t_sample ≈ 9.58
```

并取一组代表性的 `κ`：

```text
κ = 0.25, 0.5, 1.0, 2.0
```

这里主要看：

```text
F(Q)
∂_x F
∂_x^2 F
```

在不同密度支撑区上的统计。

## 2. 主支撑区里的结果

### 2.1 `κ = 0.25`

在

```text
ρ >= 0.01 ρ_max
```

上，

```text
F_min ≈ 0.9964
abs(dF)_max ≈ 0.0062
abs(d2F)_max ≈ 0.0094
```

结论：

```text
几乎完全贴近 1，非常温和。
```

### 2.2 `κ = 0.5`

在

```text
ρ >= 0.01 ρ_max
```

上，

```text
F_min ≈ 0.9859
abs(dF)_max ≈ 0.0243
abs(d2F)_max ≈ 0.0358
```

结论：

```text
仍然温和，主支撑区里偏离不大。
```

### 2.3 `κ = 1.0`

在

```text
ρ >= 0.01 ρ_max
```

上，

```text
F_min ≈ 0.9460
abs(dF)_max ≈ 0.0894
abs(d2F)_max ≈ 0.1192
```

结论：

```text
已经不是“极小修正”，
但主支撑区仍可算温和。
```

### 2.4 `κ = 2.0`

在

```text
ρ >= 0.01 ρ_max
```

上，

```text
F_min ≈ 0.8142
abs(dF)_max ≈ 0.2648
abs(d2F)_max ≈ 0.3090
```

结论：

```text
主支撑区里修正已经明显。
```

## 3. 节点/低密度区的结果

当支撑区放宽到

```text
ρ >= 10^-6 ρ_max
```

也就是把接近节点的区域也纳入时，情况变化很快。

### 3.1 `κ = 0.25`

```text
F_min ≈ 0.7343
abs(dF)_max ≈ 1.71
abs(d2F)_max ≈ 27.0
```

### 3.2 `κ = 0.5`

```text
F_min ≈ 0.4086
abs(dF)_max ≈ 4.47
abs(d2F)_max ≈ 104.5
```

### 3.3 `κ = 1.0`

```text
F_min ≈ 0.1473
abs(dF)_max ≈ 9.59
abs(d2F)_max ≈ 367.2
```

### 3.4 `κ = 2.0`

```text
F_min ≈ 0.0414
abs(dF)_max ≈ 19.31
abs(d2F)_max ≈ 943.9
```

## 4. 第一结论：F 本身看起来比导数项安全得多

这个模型给出一个非常明确的信号：

```text
在主支撑区里，
F(Q) 本身通常相当温和；
真正更危险的是它的导数项，
尤其是在低密度、接近节点的区域。
```

这和我们之前对一般要求的判断完全一致：

```text
判断一个候选 F(Q) 是否可行，
不能只看 F(0)=1 和 F 是否有界，
更要看 F'(Q)、F''(Q) 在节点附近是否过大。
```

## 5. 第二结论：κ 不能取得太大

从当前双高斯例子来看：

### `κ <= 0.5`

在主支撑区内仍然相当温和，
更像“合理的小修正”。

### `κ ~ 1`

主支撑区已经出现可见偏离，
节点附近导数项明显增大。

### `κ >= 2`

即使主支撑区里 `F` 也已经偏得比较明显，
而节点附近导数项会非常大。

### 5.1 判断

因此在这个具体模型上：

```text
若把 κ 取得过大，
这个候选作用量会变得很危险。
```

所以它若要作为现实候选，最自然的可能是：

```text
κ 不是 O(1) 的大参数，
而是相对小的有效参数。
```

## 6. 第三结论：这个模型支持“筛选机制”但不支持“自动安全”

这条很重要。

从结果看：

```text
F(Q) = 1/(1+(κQ)^2)
```

确实具有筛选/抑制大 `Q` 的直观效果：

- 主支撑区里通常仍接近 1
- 节点附近才明显下压

所以它在“机制 4”意义下是有希望的。

但它并不是自动安全的，
因为：

```text
节点附近的导数项会比 F 本身更快变大。
```

也就是说：

```text
它更像一个“可行但带警告”的候选，
而不是已经通过检验的最终形式。
```

## 7. 当前最稳的判断

对于这个具体双高斯模型，最准确的阶段结论是：

```text
1. F(Q)=1/(1+(κQ)^2) 确实是目前最值得优先测试的屏蔽型作用量候选。
2. 它在主支撑区表现明显好于节点尖峰区。
3. 真正的危险量往往不是 F 本身，而是 ∇F、∇∇F。
4. 若 κ 过大，这个模型会迅速变得不安全。
```

## 8. 下一步建议

现在最自然的下一步不是继续扫更多 `F(Q)`，而是：

```text
把这个测试模型放进一个具体弱曲背景里，
看看背景曲率和节点导数项谁主导。
```

也就是：

1. 先做地球表面近似的 Schwarzschild 背景
2. 继续用同样的“双重口径”报告
   - 主支撑区
   - 节点附近

这样就能直接回答：

```text
在现实可接近的弱引力环境里，
这个候选作用量到底危险不危险。
```
