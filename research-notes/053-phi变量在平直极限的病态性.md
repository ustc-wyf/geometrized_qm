# 053 `phi` 变量在平直极限的病态性

## 1. 背景

当前 `C` 分支使用的辅助变量是

```text
phi = f_R(R~) = (1 + (\ell^2 R~)^2)^(-3/2)
```

它满足：

```text
0 < phi <= 1
R~=0  => phi = 1
```

看起来很自然，但数值上它在平直极限附近有非常严重的病态。

## 2. 直接数值诊断

新增脚本：

```text
kg_examples/debug_c_phi_pathology.py
```

输出：

```text
visualizations/debug_c_phi_pathology/
```

摘要在：

```text
visualizations/debug_c_phi_pathology/summary.json
```

### 2.1 `src_phi` 的符号

在当前统一 baseline、`phi=1`、`tau=beta=0` 的平直极限下，
得到：

```text
positive_fraction = 1.0
negative_fraction = 0.0
```

也就是说：

```text
整个 `src_phi` 场都是正的。
```

### 2.2 一步更新后会发生什么

取一个很小的一步：

```text
phi_trial = phi + dt * src_phi
```

诊断结果：

```text
fraction_above_1 = 1.0
fraction_changed_by_clip = 1.0
```

也就是说：

```text
一步之后整个场都会跑到 phi > 1，
然后又被硬裁剪回 phi = 1。
```

## 3. 这意味着什么

当前 `C` 求解器里，

```text
phi 的动态并不是“真实地没有被激发”，
而是：
它试图往允许域之外走，
然后被数值裁剪整个压回去。
```

所以此前出现的现象：

```text
lambda_grav 较大时，
C 反而看起来又贴近 B，
且 phi_dev_max = 0
```

不是物理结果，而是数值实现把 `phi` “关掉”了。

## 4. 更深的原因：`phi -> chi` 映射在 flat 极限下奇异

由

```text
phi = (1 + (\ell^2 chi)^2)^(-3/2)
```

可反解得

```text
chi(phi) = (1/\ell^2) sqrt(phi^(-2/3) - 1)
```

在 `phi -> 1` 时：

```text
dchi/dphi -> -infinity
```

脚本里的数值扫描也验证了这一点。比如：

```text
phi = 0.9999      => dchi/dphi ~ -1.0e5
phi = 0.999999    => dchi/dphi ~ -1.0e6
phi = 0.99999999  => dchi/dphi ~ -1.0e7
```

这说明：

```text
`phi` 在 flat limit 附近不是一个良态变量。
```

它既：

1. 丢掉了 `R~` 的符号分支；
2. 又在 `phi=1` 附近把 `chi` 的尺度压缩得极端奇异。

## 5. 当前最强结论

因此：

```text
当前 C 分支数值问题的核心，
不是单纯“时间步太大”或“阻尼太强”，
而是 `phi=f_R` 本身就是一个糟糕的平直极限传播变量。
```

## 6. 对 solver 的启示

后续如果还想让 `C` 真正活起来，
更合理的方向不是继续修 `phi` 的 clipping，
而是：

```text
改用带符号的 `chi = R~`（或等价 signed curvature 变量）
作为主辅助变量。
```

这会同时解决：

1. 平直极限 `chi=0` 的自然性
2. `R~` 符号分支丢失
3. `phi<=1` 裁剪带来的数值锁死

## 7. 当前一句话总结

```text
`phi` 不是“有点难算”的变量，
而是在 flat limit 上就病态的变量。
这正是当前 C solver 最核心的问题。
```
