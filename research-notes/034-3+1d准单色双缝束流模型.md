# 034 3+1d 准单色双缝束流模型

## 目标

替换掉前一版“不像真正双缝束流”的对射高斯包模型，改用一个更贴近实验直觉的 3+1d 准单色双缝束流模型。

这个模型满足：

```text
1. z 是主传播方向
2. x 是双缝分束方向
3. y 是狭缝延伸方向
4. alpha=1 时是一束沿 z 传播的单束
5. alpha=0.5 时在屏幕 z=z_screen 上出现沿 x 方向变化的干涉条纹
```

## 1. 模型形式

采用准单色标量波写法：

```text
ψ(x,y,z,t) = e^{i k0 z - i ω0 t} [ ψ_L(x,y,z) + e^{iφ0} ψ_R(x,y,z) ]
```

其中：

- `ω0 = sqrt(k0^2 + m^2)`
- `ψ_L, ψ_R` 是左右两束的慢变包络

我们取两个狭缝中心在：

```text
(x,y) = (-a/2, 0), (+a/2, 0)
```

并用高斯狭缝/高斯束流近似描述它们。

## 2. 参数

主要参数为：

- `m`：KG 质量
- `alpha`：左束振幅系数
- `sqrt(1-alpha)`：右束振幅系数
- `k0`：主传播波矢
- `σx`：分束方向上的狭缝/束宽
- `σy`：狭缝延伸方向上的束宽
- `a`：双缝中心间距
- `φ0`：相对相位
- `z_screen`：屏幕位置

其中：

```text
σx / k0
```

将控制近单色/准直程度。

## 3. 传播近似

当前版本使用的是：

```text
准单色 + paraxial/Fresnel 型传播近似
```

不是完整自由 KG 的全频精确解。

这是有意选择，因为当前任务首先是：

```text
得到一个“看起来像双缝实验”的主算例，
而不是先把最重的全频三维演化啃下来。
```

后续如果这个模型成为正式主算例，
再升级到更严格的 KG 传播版本。
