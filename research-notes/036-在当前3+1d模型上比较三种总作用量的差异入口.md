# 036 在当前 3+1d 模型上比较三种总作用量的差异入口

## 目标

回到当前真正的核心问题：

在已经确认几何配置正确的 3+1d 双束模型上，比较以下三种总作用量：

```text
1. S_total^(g)
   = S_EH[g] + S_matter

2. S_total^(g~)
   = S_EH[g~] + S_matter

3. S_total^(F)
   = S_grav^(F) + S_matter
   = ∫ sqrt(-g~) F(Q) R~ + S_matter
```

这里的任务不是立即把三者全部数值闭合，而是先明确：

```text
在当前模型和当前层级下，
它们分别通过什么渠道改变预测，
哪些已经可以比较，
哪些还需要额外输入才能比较。
```

## 1. 当前已经固定的对象

我们当前已经固定的是：

### 1.1 物质态

一个 3+1d 的双束/双缝型自由 KG 模型。

当前可直接从它得到：

```text
ψ
ρ
S
j^μ
X
Q
```

### 1.2 由物质态诱导的有效几何

当前主线中最简单的有效几何仍是 rank-1 形式：

```text
g~^(mu nu) = g^(mu nu) + (Q / X^2) u^mu u^nu
```

其中

```text
u_mu = ∂_mu S
```

这意味着：

```text
只要给定 ψ，
我们就能算出 g~，
从而也能算 R~。
```

这就是三种总作用量比较的共同基底。

## 2. 三种总作用量分别“改什么”

### 2.1 作用量 1：S_EH[g] + S_matter

在当前主问题中，
若前变换背景取 Minkowski，

```text
g = η
```

则

```text
R[g] = 0
```

所以：

```text
S_EH[g]
```

在这个基线模型里不会直接贡献新的局域引力结构。

因此它的预测就是：

```text
自由 KG 双束模型本身的预测。
```

这可以当作“参考基线”。

### 2.2 作用量 2：S_EH[g~] + S_matter

这里真正的变化入口是：

```text
g~ = g~[ψ]
```

因此

```text
R~ = R[g~[ψ]]
```

会成为物质态诱导出的额外几何项。

但要小心：

```text
要比较它的预测，
必须明确这种引力项如何反过来反馈到 ψ 的演化。
```

仅仅知道 `R~` 非零还不够。

所以作用量 2 的问题在当前层级下是：

```text
我们已经知道“差异入口”在哪里，
但还没有完全闭合它的反馈方程。
```

### 2.3 作用量 3：sqrt(-g~) F(Q) R~ + S_matter

这类作用量比作用量 2 多了一个非常关键的调制函数：

```text
F(Q)
```

因此差异入口不再只有：

```text
R~
```

而是：

```text
F(Q) R~
以及
变分后出现的
∇F, ∇∇F
```

这使得节点附近的高 `Q` 区域会更加重要。

所以：

```text
作用量 3 的差异入口
比作用量 2 更强、更局域、也更危险。
```

## 3. 当前层级下什么是“已经可比较的”

在当前模型里，我们已经可以直接比较三类“差异入口”：

### 3.1 基线物质图样

即：

```text
ρ(x,z)
```

和由此得到的条纹结构。

### 3.2 纯几何诱导量

即：

```text
R~
sqrt(-g~) R~
```

这是作用量 2 相对作用量 1 的直接差异入口。

### 3.3 带 Q 调制的几何量

即：

```text
F(Q)
F(Q) R~
∇F
∇∇F
```

这是作用量 3 相对前两者的直接差异入口。

这些量都已经能在当前固定 `ψ` 的模型上算出来。

## 4. 当前层级下什么还不能直接比较

如果你要的是：

```text
三种总作用量最终给出的“实验条纹预测差异”
```

那么当前还有一个必须补的环节：

```text
引力项对 ψ 的反馈方程
```

也就是说，必须明确回答：

```text
在 S_total^(g~) 或 S_total^(F) 下，
ψ 的演化方程到底如何被修正？
```

否则我们现在看到的只是：

```text
“若按自由 KG 基线态去诱导几何，
几何项大小如何”
```

而不是：

```text
“闭合后的自洽理论最终会给出怎样的新条纹”
```

## 5. 所以三者在当前层级的可比性

现在可以把三者的状态压成一个表。

```text
作用量                   当前已可比较的量                 当前缺失的环节
--------------------------------------------------------------------------------
S_EH[g]                  自由KG条纹、ρ、Q                无（它就是基线）
S_EH[g~]                 R~, sqrt(-g~)R~                g~ 对 ψ 的反馈方程
sqrt(-g~)F(Q)R~         F, F R~, ∇F, ∇∇F              F(Q)引力项对 ψ 的反馈方程
```

## 6. 当前最关键的判断

这一步最重要的不是再写一堆形式主义，而是把下面这句话说清楚：

```text
如果现在就直接说“三种总作用量会让条纹怎样偏移”，
那会过头。
```

因为：

```text
我们目前已经能比较的是
“几何作用量的差异入口有多大”，
还不是“闭合反馈后条纹最终怎么变”。
```

所以当前最稳妥、也最诚实的推进方式是：

```text
先比较差异入口，
再决定反馈闭合该怎么建模。
```

## 7. 下一步最合理的数值目标

现在最合适的下一步不是直接做“条纹偏移”，而是先在当前模型上把：

```text
1. R~
2. sqrt(-g~) R~
3. F(Q)
4. F(Q) R~
5. |∇F|, |∇∇F|
```

都画出来并统计。

这样我们就能直接回答：

```text
在这个具体双束模型里，
作用量 2 和作用量 3 的“差异源”到底主要集中在哪些区域。
```

尤其是：

```text
是主支撑区主导，
还是节点尖峰主导。
```

这一步是后续闭合反馈前最有信息量的工作。
