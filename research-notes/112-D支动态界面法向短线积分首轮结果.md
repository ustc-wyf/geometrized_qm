# D 支动态界面法向短线积分首轮结果

时间：2026-05-01

## 问题

用户问：

```text
这个过渡区域是固定的吗，还是动态的？
```

结论：

```text
物理上是动态的。
```

当前界面定义为

\[
y(t,x,z)=\ell^2\tilde R(t,x,z),
\qquad
y=\pm1.
\]

因此它随着 \(\rho,S,\tilde g\) 的演化而移动。此前使用“左弧窗口”只是诊断窗口，不是把界面固定在空间中。

在完整演化里，界面应作为水平集

\[
F(t,x,z)=|y(t,x,z)|-1=0
\]

追踪。

## 方法

1. 在每个单元边上用线性插值寻找 \(y=\pm1\) 的交点；
2. 用
   \[
   n=\frac{\nabla y}{|\nabla y|}
   \]
   定义局部法向；
3. 沿法向取短线；
4. 先插值 \(y(s)\)，再用解析公式
   \[
   f_R(s)=\operatorname{sech}^2(y(s))
   \]
   重建短线上的 \(f_R\)；
5. 在一维短线上计算
   \[
   [\partial_n f_R],
   \qquad
   \int\partial_n^2 f_R\,dn,
   \qquad
   \int|\partial_n^2 f_R|\,dn.
   \]

这个修正很重要：如果直接对网格上的 \(f_R\) 求导，在极薄层下会因为下溢或欠采样而把尖峰抹掉。

## 解读 1：endpoint jump 与 signed integral 自洽

对所有 case，

\[
[\partial_n f_R]
\]

和

\[
\int \partial_n^2 f_R\,dn
\]

的 p95 基本一致。

这说明短线积分的基本数值一致性是好的；至少这一版没有把导数项完全算坏。

## 解读 2：绝对层强度远大于 signed jump

所有 case 都显示

\[
\int|\partial_n^2 f_R|\,dn
\gg
\left|
\int\partial_n^2 f_R\,dn
\right|.
\]

global signed/abs ratio 大约为 `0.03` 到 `0.13`。

这说明过渡层内部有显著正负抵消：

```text
真正的 jump 可能有限；
但层内部绝对强度很大。
```

因此界面模型必须区分：

- jump/matching 条件：控制两侧解如何拼接；
- layer strength：控制数值 stiffness、散射、相位误差等局部效应。

## 解读 3：ell=30 比 ell=100 更接近可校准界面

`ell=30` 的 240 与 320 结果比较接近：

- endpoint jump p95：`8.06e3 -> 8.93e3`
- abs integral p95：`4.23e4 -> 4.50e4`

这说明 `ell=30` 的界面条件已经开始有收敛迹象。

`ell=100` 仍不稳定：

- endpoint jump p95：`1.36e4 -> 2.09e4 -> 6.87e3`
- abs integral p95：`5.76e5 -> 8.88e4 -> 5.58e4`

这说明 `ell=100` 的界面仍然太薄，或者当前短线/窗口取样还没有进入收敛区。

## 解读 4：界面是动态对象，不是固定网格区域

这轮是在固定参考切片 \(t=16\) 上做的界面诊断。

在真正演化中，界面必须随

\[
y(t,x,z)=\ell^2\tilde R(t,x,z)
\]

移动。

因此完整数值器应采用：

```text
水平集追踪 y=+1 与 y=-1；
bulk 区域内用各自方程推进；
界面上施加 jump/matching 条件；
界面附近做局部短线积分或局部加密来校准。
```

## 当前结论

\[
\boxed{
把极薄过渡层看作动态界面是可行方向。
}
\]

但当前结果也说明：

\[
\boxed{
ell=30 的界面条件开始可校准；
ell=100 仍需更高分辨率或更专门的局部界面算法。
}
\]

这支持下一阶段优先用 `ell=30` 作为 interface 方法的工作样例，而不是直接在 `ell=100` 上硬推全演化。

## 下一步

1. 先在 `ell=30` 上写出 bulk-interface toy evolution；
2. 将界面条件写成显式 jump/matching 源项；
3. 对 `ell=100` 单独做局部贴体坐标或自适应界面采样；
4. 不再把全域网格解析 `ell=100` 极薄层作为主线。
