# B 与 C 两支同步规范原型的主要问题来自几何边界条件而非时间推进

日期：2026-04-29

## 问题背景

在脚本

- `/Users/wangyunfei/Desktop/量子势几何化_codex/kg_examples/simulate_bc_from_a_initial_data.py`

中，`B/C` 两支从 `A` 支平直参考初始 `(\rho,S)` 出发，做完整耦合同步规范演化。此前观测到：

- `10` 步、`dt=5e-4` 时
  \[
  \max|h_{xx}-1|\approx 0.452,\qquad \max|\mathcal H|\approx 35.4
  \]
- `20` 步、`dt=2.5e-4` 时
  \[
  \max|h_{xx}-1|\approx 0.700,\qquad \max|\mathcal H|\approx 130
  \]

这看起来像严重的时间推进不稳定。

## 重新诊断

在修正初始外曲率前后，短时间结果几乎不变，因此：

1. 问题不是二阶与四阶时间推进阶数之差；
2. 问题也不主要来自“初始动量约束没有处理”。

进一步逐步打印 `h_{xx}` 与 `k_{xx}` 的量级后，发现：

- 初始时刻
  \[
  \max|k_{xx,t}|\sim 3.7\times 10^{-2},
  \]
  因而单步 `dt=5e-4` 下的真实几何更新应极小；
- 但数值上 `\max|h_{xx}-1|` 在第一步后就从 `7.8\times10^{-3}` 跳到 `5.8\times10^{-2}`。

这与
\[
\partial_t h_{ij}=-2K_{ij}
\]
的量级明显不相容。

## 根因

问题出在边界条件实现上。此前的

```python
def apply_damping_bc(state):
    for key in state:
        state[key] = edge_damp(state[key])
```

把几何变量

- `h_xx`
- `h_xz`
- `h_zz`
- `beta`
- `k_xx`
- `k_xz`
- `k_zz`
- `k_beta`

也一起做了乘法阻尼。

这会把本应接近背景值的几何量在边界处强行拉向 `0`，从而人为制造出：

- 巨大的 `\max|h_{ij}-h^{\text{bg}}_{ij}|`
- 巨大的空间曲率
- 进而导致 Hamilton 约束残差迅速增大

因此此前看到的主要增长不是物理几何响应，而是边界条件伪影。

## 修正后的边界条件

现在改成：

- 物质变量 `n,S` 继续做边界阻尼；
- 几何变量改成回到背景边界值：
  \[
  h_{xx}\to 1,\quad h_{xz}\to 0,\quad h_{zz}\to 1,\quad \beta\to 0,
  \]
  \[
  k_{xx},k_{xz},k_{zz},k_\beta \to 0;
  \]
- `C` 支辅助场仍取
  \[
  \Phi\to 1,\qquad \Pi_\Phi\to 0
  \]
  作为边界条件。

## 修正后的结果

### 平凡 `C` 初值：`Phi=1, Pi_Phi=0`

`5` 步、`dt=5e-4`：

\[
\max|h_{xx}-1|\approx 7.758\times 10^{-3},
\]
\[
\max|\mathcal H|\approx 2.587\times 10^{-1},
\]
\[
\max|\mathcal M|\approx 2.62\times 10^{-3}.
\]

`10` 步、`dt=5e-4`：

\[
\max|h_{xx}-1|\approx 7.758\times 10^{-3},
\]
\[
\max|\mathcal H|\approx 2.582\times 10^{-1},
\]
\[
\max|\mathcal M|\approx 5.20\times 10^{-3}.
\]

`20` 步、`dt=2.5e-4`：

\[
\max|h_{xx}-1|\approx 7.758\times 10^{-3},
\]
\[
\max|\mathcal H|\approx 2.581\times 10^{-1},
\]
\[
\max|\mathcal M|\approx 5.44\times 10^{-3}.
\]

可见：

1. 时间步敏感性已基本消失；
2. 几何偏离始终维持在初始弱场量级；
3. 约束残差不再出现先前那种灾难性增长。

### 非平凡 `C` 初值：`r3_proxy`

在

\[
\Phi_0=(1+(\ell^2 R_{\text{proxy}})^2)^{-3/2},
\qquad \ell=0.02
\]

下，`200` 步、`dt=2.5e-4` 的结果为：

\[
\max|\Phi-1|\approx 2.61\times10^{-8},
\]

并且 `C` 相对 `B` 的几何差异仍极小。

这说明在当前弱场参数下：

- `C` 的非平凡初值入口已经工作；
- 但它带来的偏离仍处在极弱量级。

## 结论

当前 `B/C` 原型先前的主要数值问题不是时间推进阶数，也不是外曲率初值，而是**几何边界条件实现错误**。

修正后可以得出更可靠的判断：

1. `B` 支在当前弱场参数和当前高斯束初值下，几何响应是稳定且弱的；
2. `A` 支线性化弱场量级
   \[
   \max|\omega_A|\sim 3.9\times10^{-3}
   \]
   与 `B` 支当前几何偏离量级同阶；
3. `C` 支若要在这个问题里明显偏离 `B`，还需要更有针对性的 `\Phi` 初值或更强的曲率尺度。
