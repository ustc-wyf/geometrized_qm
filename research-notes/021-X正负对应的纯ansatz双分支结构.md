# 021 `X` 正负对应的纯 ansatz 双分支结构

## 目标

回答当前新的关键判断：

```text
当 X < 0 时，
是否应该对应另一条变换分支？
```

结论是：

```text
是。
而且这不是模糊猜想，
而是从一般纯 ansatz 的签名、可逆性与幅度实数性
共同推出的结构结果。
```

## 1. 从一般纯 ansatz 出发

现在不再固定最简单解 `C=1`，而是回到一般纯 ansatz：

```text
g~^(mu nu) = C g^(mu nu) + D u^mu u^nu
```

其中

```text
u_mu = ∂_mu S
X = g^(mu nu) u_mu u_nu
Q = - Box sqrt(ρ) / sqrt(ρ)
```

并继续允许 `ρ~` 真正变换。

## 2. HJ 与连续性共同给出的条件

前面已经得到：

### 2.1 HJ 方程

```text
g~^(mu nu) u_mu u_nu = C X + D X^2 = m^2
```

因此

```text
C + D X = m^2 / X
```

这是一条非常关键的关系。

### 2.2 连续性方程

只要定义

```text
sqrt(-g~) ρ~ (C + D X) = sqrt(-g) ρ
```

就会自动回到原连续性方程。

用上面 HJ 关系，这变成

```text
sqrt(-g~) ρ~ = sqrt(-g) ρ X / m^2
```

## 3. covariant 度规与 `u` 方向的符号

纯 rank-1 更新的 covariant 度规是

```text
g~_mu nu
= C^(-1) g_mu nu
 - [ D / ( C (C + D X) ) ] u_mu u_nu
```

现在来看 `u` 方向上的符号：

```text
g~(u,u)
= X / (C + D X)
```

再用

```text
C + D X = m^2 / X
```

得到

```text
g~(u,u) = X^2 / m^2
```

所以：

```text
只要 X ≠ 0，
u 方向在新度规下永远是正的。
```

这点很重要，因为它说明：

```text
新几何会把 Bohm 流方向统一变成“时间样方向”。
```

## 4. 正交子空间的签名

对任意与 `u_mu` 正交的向量 `w_mu`，

```text
g~(w,w) = C^(-1) g(w,w)
```

也就是说：

```text
正交子空间的全部符号只由 C 的符号控制。
```

现在分两种情况讨论。

### 4.1 若 X > 0

这时 `u` 在原度规下是 timelike，
其正交子空间在原度规下的签名是

```text
(---)
```

若要新度规仍保持标准 Lorentz 型（一个正、三个负），则必须要求

```text
C > 0
```

因为：

- `u` 方向已经固定为正
- 正交子空间必须保持三负

### 4.2 若 X < 0

这时 `u` 在原度规下是 spacelike，
其正交子空间在原度规下的签名是

```text
(+--)
```

但新度规下 `u` 方向仍然变成正的。

所以若还取 `C > 0`，则正交子空间仍是

```text
(+--)
```

总签名就会变成

```text
(++--)
```

也就是 ultrahyperbolic，不再是 Lorentzian。

若要新度规仍是 Lorentzian，就必须让正交子空间整体翻号，
也就是要求

```text
C < 0
```

此时正交子空间从

```text
(+--)
```

变成

```text
(-++)
```

再加上 `u` 方向为正，总签名就是

```text
(+++-)
```

这仍然是 Lorentzian（只是与原 convention 相差整体符号选择）。

## 5. 幅度实数性给出的同样条件

我们还知道

```text
det(g~^(..)) = det(g^(..)) C^4 (1 + D X / C)
            = det(g^(..)) C^3 (C + D X)
```

因此

```text
sqrt(-g~) = sqrt(-g) / sqrt( C^3 (C + D X) )
```

而由连续性条件，

```text
ρ~ = ρ [ X / m^2 ] sqrt( C^3 (C + D X) )
```

再用

```text
C + D X = m^2 / X
```

化简为

```text
ρ~ = ρ sqrt( C^3 X / m^2 )
```

若要求 `ρ~` 仍为实数，就必须有

```text
C^3 X > 0
```

也就是

```text
C X > 0
```

所以：

```text
X > 0 时要求 C > 0
X < 0 时要求 C < 0
```

这与签名分析完全一致。

## 6. 分支结构

因此，一般纯 ansatz 的自然分支不是唯一的，而是：

### Branch T（timelike branch）

适用域：

```text
X > 0
```

要求：

```text
C > 0
```

最简单代表：

```text
C = 1
D = Q / X^2
```

### Branch S（spacelike branch）

适用域：

```text
X < 0
```

要求：

```text
C < 0
```

并由

```text
C + D X = m^2 / X
```

决定 `D`：

```text
D = [ m^2 / X - C ] / X
```

也可写成

```text
D = (m^2 - C X) / X^2
```

这就是 `X < 0` 的另一条自然分支。

## 7. 一个最简单的 spacelike 分支例子

为了得到一个明确可用的例子，可以直接取

```text
C = -1
```

那么

```text
D = [ m^2 / X + 1 ] / X
  = (m^2 + X) / X^2
```

再用

```text
X = m^2 - Q
```

得到

```text
D = (2 m^2 - Q) / X^2
```

于是 spacelike branch 的一个最简单代表是

```text
g~^(mu nu)
= - g^(mu nu)
 + [ (2 m^2 - Q) / X^2 ] u^mu u^nu
```

它满足：

```text
g~^(mu nu) u_mu u_nu = m^2
```

并且由于 `C < 0` 与 `X < 0` 同号，
新度规仍保持 Lorentzian，且 `ρ~` 保持实数。

## 8. 这个结果的物理意义

这一步非常重要，因为它说明：

```text
X < 0 并不必然意味着理论失效。
```

更准确地说：

```text
若强行把 X < 0 塞进 timelike branch（C > 0），
新几何会失去 Lorentz 签名；

但若切换到 spacelike branch（C < 0），
则仍可得到良好的 Lorentzian 新几何。
```

所以：

```text
X 的符号变化不是单一公式的失败，
而是提示我们必须切换到另一条几何分支。
```

这正好呼应了用户的判断。

## 9. 当前最稳的结论

因此，现在可以把纯 ansatz 的结构总结成：

```text
1. 纯 ansatz 本身没有失败。
2. 它天然分成 X>0 与 X<0 两个分支。
3. 两个分支分别要求 C 与 X 同号。
4. 若不按分支切换，就会错误地把 X<0 看成“几何失效”。
```

## 10. 下一步建议

接下来最值得做的不是继续局部代数，而是：

```text
研究这两个分支在物理上分别对应什么。
```

尤其是：

1. `X > 0` 是否对应原来可解释为 timelike Bohm 运动的区域
2. `X < 0` 是否正好对应原来“超光速/类空”问题出现的区域
3. 切换 branch 后，新几何是否能把这些区域重新解释为各自良好的 Lorentzian 测地线

如果这一步成立，那么“量子势几何化”就不只是代数技巧，而是真正碰到了项目最初的物理动机。
