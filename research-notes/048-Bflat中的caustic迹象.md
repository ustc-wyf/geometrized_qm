# 048 Bflat 中的 caustic 迹象

## 目标

判断 `Bflat` 出现的中心/轴上尖峰更像：

```text
1. 纯数值噪声
还是
2. 物质系统本身的特征线交叉 / caustic
```

## 测试

固定：

- 平直几何 `tau = beta = 0`
- 只保留 B 的平直物质系统
- 同一初始切片

改变空间分辨率：

```text
n = 81, 121, 161
```

记录 `rho` 最大值及其位置。

## 结果

得到：

```text
n = 81:
peak ≈ 1.12e3
peak at (x,z) ≈ (0, -3)

n = 121:
peak ≈ 5.14e6
peak at (x,z) ≈ (0, -6.67)

n = 161:
peak ≈ 2.77e7
peak at (x,z) ≈ (0, 0)
```

## 解释

这组结果的特征是：

```text
1. 峰值随分辨率上升而迅速增大
2. 峰值集中在两束相交的主轴附近
```

这更像：

```text
无量子压 Bohm/HJ + continuity 物质系统
在束流交叉处形成的 caustic / 密度聚焦
```

而不是普通的平滑数值误差。

## 当前判断

因此当前最合理的理解是：

```text
Bflat 的中心尖峰
至少有相当一部分不是“离散器瞎了”，
而是该物质系统本身就在形成 caustic。
```

## 含义

这一步会改变后续 debug 口径：

```text
不能再把“B 不像 A”
简单全判为数值 bug。
```

更合理的是：

1. 区分平滑区与 caustic 区
2. 在平滑区比较 A/B/C
3. 把 caustic 区单独当作一种物理输出结构来分析
