# 068 混合 ansatz 在 `X=0` 附近的严格局域分析

## 目标

回答一个更严格的问题：

```text
在一般混合 ansatz 下，
X=0 时是否可以让 ρ~ -> 0，
从而避免主奇异？
```

用户特别指出，先前的分析不能直接假定

```text
A ~ 1/X
```

因为也许可以出现

```text
A ~ 1/X^2
```

之类更高阶发散。

下面给出严格的局域分析。

---

## 1. 一般混合 ansatz

取

```text
g~^(μν)
= C g^(μν)
+ D u^μ u^ν
+ E (u^μ r^ν + r^μ u^ν)
+ F r^μ r^ν
```

并记

```text
u_μ = ∂_μ S
r_μ = ∂_μ sqrt(ρ)

X = g^(μν) u_μ u_ν
Y = g^(μν) u_μ r_ν
Z = g^(μν) r_μ r_ν
```

---

## 2. 先写出 `g~^(μν)u_ν`

直接收缩得

```text
g~^(μν)u_ν
= (C + DX + EY) u^μ
+ (EX + FY) r^μ
```

定义

```text
A_u := C + DX + EY
A_r := EX + FY
```

则

```text
g~^(μν)u_ν = A_u u^μ + A_r r^μ
```

---

## 3. 连续性方程真正要求什么

原 `g` 系电流为

```text
J^μ = sqrt(|g|) ρ u^μ
```

变换后 `g~` 系电流为

```text
J~^μ = sqrt(|g~|) ρ~ g~^(μν)u_ν
```

若要求精确恢复原连续性方程，一个最强且最自然的点态条件是

```text
J~^μ = J^μ
```

即

```text
sqrt(|g~|) ρ~ ( A_u u^μ + A_r r^μ )
= sqrt(|g|) ρ u^μ
```

---

## 4. 严格局域结论：在正则开区域里，`r` 分量必须消失

设 `U` 是一个 punctured neighborhood：

```text
U \ Σ_X,   Σ_X = { X = 0 }
```

并假设在这个开区域里：

1. `u^μ` 与 `r^μ` 线性无关
2. 原电流不为零，即 `sqrt(|g|)ρu^μ ≠ 0`
3. `sqrt(|g~|)ρ~` 不是恒等为零

那么向量恒等式

```text
sqrt(|g~|) ρ~ ( A_u u^μ + A_r r^μ )
= sqrt(|g|) ρ u^μ
```

只能成立于

```text
A_r = 0
```

也就是

```text
EX + FY = 0
```

并且

```text
sqrt(|g~|) ρ~ A_u = sqrt(|g|) ρ
```

因此在正则开区域里，点态恢复连续性方程实际上自动推出

```text
g~^(μν)u_ν = A_u u^μ
```

所以：

```text
“只要求乘上 ρ~ 之后对齐方向”
```

在非零电流的开区域里并没有真正放宽方向条件。

---

## 5. HJ 方程如何约束 `A_u`

现在再看 HJ 壳约束。

一般地

```text
g~^(μν)u_μu_ν
= X(C + DX + EY) + Y(EX + FY)
= X A_u + Y A_r
```

但由连续性恢复已得

```text
A_r = 0
```

所以在同一个正则 patch 上，

```text
g~^(μν)u_μu_ν = X A_u
```

若变换后 HJ 方程要求固定非零壳长

```text
g~^(μν)u_μu_ν = κ
```

其中 `κ ≠ 0` 为常数，则必然有

```text
A_u = κ / X
```

这一步是精确结论，不是近似。

因此：

```text
只要同时要求
1. 正则开区域里精确恢复连续性方程
2. 变换后 HJ 壳长固定为非零常数 κ
```

那么控制 `u` 方向的那个组合就不可能是 `1/X^2` 或别的阶数，而只能是

```text
A_u = κ/X
```

---

## 6. 所以用户的疑问该怎样回答

用户质疑：

```text
先前假定 A ~ 1/X 不够严谨，
也许可以是 1/X^2 或别的更高阶。
```

现在可以严格回答：

### 6.1 对单个系数 `C,D,E,F`

这个质疑是成立的。  
单个系数当然可以比 `1/X` 发散得更快，也可以互相抵消。

### 6.2 对真正受 HJ+连续性共同控制的组合

这个质疑不成立。  
一旦要求在正则开区域里同时恢复两条方程，真正起作用的组合是

```text
A_u = C + DX + EY
```

而它被严格锁定为

```text
A_u = κ/X
```

所以这个组合不能是 `1/X^2`。

---

## 7. `ρ~` 的一般公式

由

```text
sqrt(|g~|) ρ~ A_u = sqrt(|g|) ρ
```

记逆度规行列式比值

```text
R_inv := det(g~^(..)) / det(g^(..))
```

则

```text
sqrt(|g~|) = sqrt(|g|) / sqrt(R_inv)
```

所以

```text
ρ~ = ρ sqrt(R_inv) / A_u
```

再用

```text
A_u = κ/X
```

得到

```text
ρ~ = ρ X sqrt(R_inv) / κ
```

因此 `ρ~` 是否在 `X=0` 时趋于 0，完全取决于 `R` 的标度：

- 若 `R_inv = o(1/X^2)`，则 `ρ~ -> 0`
- 若 `R_inv ~ const / X^2`，则 `ρ~` 有限非零
- 若 `R_inv >> 1/X^2`，则 `ρ~` 发散

---

## 8. 最重要的结论

### 8.1 `ρ~ -> 0` 是可能的

例如 rank-1 `C=1` 分支里，

```text
R_inv = κ/X
```

于是

```text
ρ~ ~ sqrt(X)
```

确实趋于 0。

更进一步，在真正的混合 ansatz 中这也不是不可能的。

在 `Y ≠ 0` 的 generic patch 上，由

```text
A_r = EX + FY = 0
```

可解得

```text
F = - E X / Y
```

而

```text
A_u = C + DX + EY = κ/X
```

给出

```text
D = (κ/X - C - EY)/X .
```

把这两条代回四维行列式公式

```text
R_inv = det(g~^(..))/det(g^(..))
```

可化成

```text
R_inv = C^2 (κ/X) ( C - EΔ/Y ) .
```

因此只要 `C` 与 `C - EΔ/Y` 在 `X -> 0` 时保持有限非零，就有

```text
R ~ const / X
```

从而

```text
ρ~ = ρ X sqrt(R) / κ ~ const * sqrt(X) -> 0 .
```

一个显式的 genuinely mixed 例子是：

```text
C = 1 ,
E = α Y / Δ ,
F = - α X / Δ ,
```

其中 `α` 为常数且 `α ≠ 0, 1`。这时

```text
D = κ/X^2 - 1/X - α Y^2/(XΔ),
```

并且

```text
R_inv = (κ/X)(1-α),
ρ~ = ρ sqrt[(1-α)X/κ] .
```

所以在满足 `(1-α)κ/X > 0` 的 patch 上，

```text
ρ~ -> 0
```

依然成立。

### 8.2 但这不能消掉主奇异

因为主奇异来自

```text
A_u = κ/X
```

而这已经被“恢复 HJ + 恢复连续性”共同严格固定。

所以：

```text
ρ~ -> 0
```

最多只能让电流

```text
J~^μ = sqrt(|g~|)ρ~ g~^(μν)u_ν
```

保持有限，

不能让 `X=0` 映到固定非零壳长所需的主奇异消失。

### 8.3 若真想避免 `1/X`

必须至少放弃下列之一：

1. 在正则开区域里精确恢复原连续性方程
2. 变换后固定非零壳长 `κ ≠ 0`
3. 当前这类 regular Lorentzian 图册

---

## 9. 当前判断

因此，对混合 ansatz 的严格结论是：

```text
用户关于“ρ~ 可以在 X=0 时取 0”的想法是对的，
但它只能作为 current-level regularization；
只要还要在开区域里同时恢复连续性方程和固定非零 HJ 壳长，
主组合就必然是 κ/X，
因此 metric/HJ-level 的主奇异不会因此消失。
```
