# D 支全域多界面测试与当前数值路线澄清

时间：2026-05-01

## 背景

用户追问两点：

1. 需要多少个界面是否是拓扑问题；
2. 当前为什么说物质分布与平直时空量子力学差异为零，是否和“只用平直量子力学构造初态、随后做全动力学”矛盾。

本轮先修正并补跑 `prototype_d_bulk_interface_toy.py`。

## 重要实现修正

此前 `prototype_d_bulk_interface_toy.py` 复用了 `integrate_d_interface_jumps.py` 中的 `find_interface_points`，而该函数硬编码了左弧窗口：

```text
-7.4 <= x <= -2.2, 2.6 <= z <= 6.2
```

因此上一版 toy system 的界面短线积分实际是“左弧窗口诊断”，不是全域界面源校准。图中的白色等高线是全域画出的，但界面积分行只来自左弧窗口。

本轮已修正：

- `prototype_d_bulk_interface_toy.py` 新增 `--bbox` 参数；
- 默认 `--bbox global`，全域提取界面；
- 可选 `--bbox xmin,xmax,zmin,zmax` 保留局部窗口诊断；
- 新增 `--levels` 参数，可指定多组正水平集，例如 `--levels 0.5,1,2`。

## 是否是拓扑问题

需要区分两件事。

### 1. 水平集有几个连通分支：这是拓扑问题

给定

\[
y(t,x,z)=\ell^2\tilde R(t,x,z),
\]

每条水平集

\[
y=c
\]

在二维切片中可能有若干条曲线分支；在三维空间中则是若干曲面分支。分支的产生、合并、断裂与临界点 \(\nabla y=0\) 有关，这部分是水平集拓扑问题。

### 2. 选多少个 level：不是拓扑问题

选 `|y|=1`，还是选 `|y|=0.5,1,2`，本质上是如何把连续过渡层离散成若干界面源的数值/渐近近似问题。

对 D 支，

\[
f_R=\operatorname{sech}^2(y),
\]

显著变化集中在 \(|y|=O(1)\)。因此多 level set 更像是在过渡层中做 quadrature / collocation，而不是改变拓扑。

## 与平直时空量子力学的关系

此前说“物质分布差异为零”，只限于当前这类 reference residual 诊断。

当前诊断的做法是：

1. 先用平直时空量子力学生成一整条参考历史 \((\rho_{\rm ref}(t),S_{\rm ref}(t))\)；
2. 由这组参考历史重构 \(\tilde g[\rho_{\rm ref},S_{\rm ref}]\)；
3. 把它代入 D 支 native 场方程，检查残差。

因此，在这个诊断里，\(\rho,S\) 与平直时空量子力学当然完全相同。这不是说最终理论全动力学也把所有物质历史固定为平直量子力学。

真正全动力学路线应是：

1. 只用平直时空量子力学给出实验制备的初态，必要时还给出入流边界态；
2. 从该初态构造初始 \(\tilde g\)、界面 \(y=\ell^2\tilde R\) 与 matching 数据；
3. 之后由 D 支 full action / bulk-interface 系统自洽推进 \(\rho,S,\tilde g\)；
4. 再把演化结果与平直时空量子力学预测比较。

当前 reference residual 诊断的作用是：

```text
在写 full evolution 之前，检查平直 QM 参考历史是不是 D 支的近似解，
并定位如果不是，主要失配集中在 bulk 还是 interface。
```

本轮结果表明：当前刚性主要可由全域动态界面覆盖，但界面邻域在普通网格上太厚，因此下一步应转向 subcell / body-fitted interface 表示，而不是继续盲目增加 level 数。

## 下一步

下一步不应再把主要精力放在增加更多 `|y|` level 上。更稳的方向是：

1. 使用全域 `|y|=1` 作为第一版动态界面；
2. 保留 `|y|=0.5,2` 作为校准界面源的辅助 quadrature 层，而不是作为必须演化的额外边界；
3. 写 subcell / body-fitted interface toy evolution，避免把 interface-near raster mask 当成真实厚带；
4. 在这个新表示下推进一小步，比较 self-consistent D 支演化与平直 QM 参考演化的偏离。
