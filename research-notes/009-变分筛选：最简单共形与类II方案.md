# 009 变分筛选：最简单共形与类 II 方案

## 目标

这一份文档开始真正做“变分筛选”。

我们不再问：

```text
新作用量长得像不像原作用量
```

而是问：

```text
新作用量变分之后，
能不能导出原理论需要保留的物理方程？
```

本轮先处理两个最简单、也最关键的方案：

1. 共形最简单解
2. 类 II 的 `A = 1` 最简单解

最后再抽出一个一般性结论：

```text
若通过选系数让 HJ 条件在 integrand 中被恒等满足，
则几何作用量会退化成零，
这会直接导致动力学塌缩。
```

## 1. 起点：几何候选作用量

我们统一从

```text
I_geom = ∫ d^4x sqrt(-g~) ρ ( g~^(mu nu) ∂_mu S ∂_nu S - m^2 )
```

出发。

定义

```text
u_mu = ∂_mu S
r_mu = ∂_mu sqrt(ρ)
X = g^(mu nu) u_mu u_nu
Y = g^(mu nu) u_mu r_nu
Z = g^(mu nu) r_mu r_nu
Q = - Box sqrt(ρ) / sqrt(ρ)
```

原理论需要保留的两条基本方程是：

```text
连续性方程：
∂_mu ( ρ ∂^mu S ) = 0

HJ 方程：
X = m^2 - Q
```

这一轮我们先看新作用量变分后，至少能不能保住连续性方程。

## 2. 共形最简单解

取

```text
g~_mu nu = A g_mu nu
```

并采用 HJ 层面的最简单吸收解

```text
A = 1 - Q/m^2
```

### 2.1 几何作用量写成旧变量

由于

```text
sqrt(-g~) = A^2 sqrt(-g)
g~^(mu nu) = A^(-1) g^(mu nu)
```

故

```text
I_conf
= ∫ d^4x sqrt(-g) ρ ( A X - A^2 m^2 )
```

注意这里的 `A` 只依赖 `ρ`，不依赖 `S`。

### 2.2 对 S 变分

因为 `A` 与 `S` 无关，所以

```text
δI_conf / δS
```

给出

```text
∂_mu ( ρ A ∂^mu S ) = 0
```

而原理论要求的是

```text
∂_mu ( ρ ∂^mu S ) = 0
```

两者只有在下列特殊情形才重合：

```text
1. A = 常数
2. 或 ∂_mu A 与流线结构发生特殊抵消
```

但对于

```text
A = 1 - Q/m^2
```

一般来说 `A` 不是常数。

### 2.3 直接结论

所以：

```text
最简单共形解虽然在 HJ 层面可以吸收 Q，
但它一般不能保留原连续性方程。
```

这意味着它在当前这个几何作用量下：

```text
不是完整动力学等价方案。
```

## 3. 类 II：相位单向方案，取 A = 1

取

```text
g~_mu nu = g_mu nu + B u_mu u_nu
```

其中 `u_mu = ∂_mu S`。

HJ 条件给出唯一解

```text
B = (X - m^2) / (m^2 X)
```

### 3.1 把解代回 integrand

类 II 的几何作用量密度是

```text
L_II / (sqrt(-g) ρ)
= X / sqrt(1 + B X)
 - m^2 sqrt(1 + B X)
```

代入

```text
B X = (X - m^2)/m^2
```

得到

```text
1 + B X = X / m^2
```

所以

```text
L_II / (sqrt(-g) ρ)
= X / sqrt(X/m^2)
 - m^2 sqrt(X/m^2)
```

两项完全相消：

```text
L_II = 0
```

### 3.2 变分结果

若

```text
I_II = ∫ d^4x 0
```

则对 `S`、`ρ` 的变分都是零：

```text
δI_II / δS = 0
δI_II / δρ = 0
```

这给不出原来的连续性方程，也给不出原来的 HJ 方程。

### 3.3 直接结论

所以：

```text
类 II 的 A = 1 最简单唯一解
虽然能把 HJ 条件“写进去”，
但代价是整个几何作用量塌成零。
```

这不是动力学等价，而是：

```text
动力学退化。
```

因此这一具体 gauge 可以直接排除。

## 4. 一个更一般的结构性结论

当前几何候选作用量的 integrand 具有形式

```text
L_geom ∝ ( g~^(mu nu) u_mu u_nu - m^2 )
```

若通过选 `A,B,C,...` 的方式，让

```text
g~^(mu nu) u_mu u_nu = m^2
```

作为一个对所有场构型都成立的恒等式，

那么立刻有

```text
L_geom ≡ 0
```

于是整个作用量退化。

这意味着：

```text
不能把“吸收 Q”理解成：
直接通过选系数把 HJ 方程硬编码进 integrand。
```

真正应该追求的是：

```text
选取几何结构后，
通过变分自动导出等价的 HJ 方程，
而不是把 HJ 方程先塞进去让 integrand 自己归零。
```

## 5. 这一轮的快速筛选结果

### 可以直接排除的具体方案

```text
1. 共形最简单几何作用量方案
   A = 1 - Q/m^2
   在当前 I_geom 下不能保留原连续性方程。

2. 类 II 的 A = 1 最简单唯一解
   B = (X - m^2)/(m^2 X)
   会使几何作用量恒等为零，动力学退化。
```

### 目前还不能排除的

```text
1. 整个共形类不能排除
2. 整个类 II 不能排除
3. 类 III 不能排除
4. 类 IV 不能排除
```

但后面不能再沿着“把 HJ 恒等塞进 integrand”的路线走下去。

## 6. 下一步建议

现在最有效的下一步是：

```text
放弃“先把 HJ 方程硬编码进系数”的求解方式，
转而直接对更一般的几何作用量做变分。
```

具体说：

1. 对一般共形类 `g~_mu nu = A g_mu nu` 直接变分
2. 对一般类 II `g~_mu nu = A g_mu nu + B u_mu u_nu` 直接变分
3. 检查是否存在某些 `A,B`，让变分后自动导出正确的连续性方程和 HJ 方程
