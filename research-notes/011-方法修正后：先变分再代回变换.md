# 011 方法修正后：先变分再代回变换

## 目标

这一份文档修正上一轮里的一个实质性方法错误。

错误做法是：

```text
先把变换代回新作用量，
再对化简后的作用量做判断。
```

用户指出的正确做法是：

```text
先对新作用量做变分，
得到新变量下的 Euler-Lagrange 方程，
再把变换代回这些方程，
检查是否与原理论等价。
```

这两步在系数依赖场变量时一般不等价。

## 1. 正确的出发点

几何侧作用量应先写成新变量形式：

```text
I_geom[ρ~, S; g~]
= ∫ d^4x sqrt(-g~) ρ~ ( g~^(mu nu) ∂_mu S ∂_nu S - m^2 )
```

这里先把

- `ρ~`
- `S`
- `g~_mu nu`

视为新表述中的变量。

然后再用变换关系把它们与旧变量联系起来。

## 2. 先变分得到的新方程

### 2.1 对 ρ~ 变分

直接得到

```text
g~^(mu nu) ∂_mu S ∂_nu S - m^2 = 0
```

这就是新几何中的 HJ 方程。

### 2.2 对 S 变分

得到

```text
∂_mu [ sqrt(-g~) ρ~ g~^(mu nu) ∂_nu S ] = 0
```

这就是新几何中的连续性方程。

## 3. 再代回密度变换关系

采用项目当前约定：

```text
sqrt(-g) ρ = sqrt(-g~) ρ~
```

于是连续性方程变成

```text
∂_mu [ sqrt(-g) ρ g~^(mu nu) ∂_nu S ] = 0
```

而 HJ 方程则保持为

```text
g~^(mu nu) ∂_mu S ∂_nu S = m^2
```

所以：

```text
后续真正该比较的是这两条方程，
不是先把变换代回作用量后得到的 integrand 外观。
```

## 4. 共形类的正确重检

取

```text
g~_mu nu = A g_mu nu
```

则

```text
g~^(mu nu) = A^(-1) g^(mu nu)
```

### 4.1 HJ 方程

新 HJ 方程变成

```text
A^(-1) X = m^2
```

即

```text
X = A m^2
```

若要求与原 HJ 方程

```text
X = m^2 - Q
```

一致，则仍有最简单选择

```text
A = 1 - Q/m^2
```

### 4.2 连续性方程

新连续性方程变成

```text
∂_mu [ sqrt(-g) ρ A^(-1) ∂^mu S ] = 0
```

而原理论是

```text
∂_mu [ sqrt(-g) ρ ∂^mu S ] = 0
```

因此：

```text
最简单共形解的问题仍然存在，
但这是在“先变分后代回”的正确顺序下得到的。
```

所以共形最简单解目前仍然不满足完整方程等价。

## 5. 类 II 的正确重检

取

```text
g~_mu nu = g_mu nu + B u_mu u_nu
```

其中

```text
u_mu = ∂_mu S
```

其逆度规为

```text
g~^(mu nu)
= g^(mu nu)
 - [ B / (1 + B X) ] u^mu u^nu
```

### 5.1 HJ 方程

收缩后得

```text
g~^(mu nu) u_mu u_nu = X / (1 + B X)
```

所以新 HJ 方程是

```text
X / (1 + B X) = m^2
```

从而得到最简单唯一解

```text
B = (X - m^2) / (m^2 X)
```

这一点不变。

### 5.2 连续性方程

现在关键是：

```text
不要把这个 B 先代回作用量，
而是先代回变分后的连续性方程。
```

我们先算

```text
g~^(mu nu) u_nu
```

有

```text
g~^(mu nu) u_nu
= u^mu - [ B X / (1 + B X) ] u^mu
= u^mu / (1 + B X)
```

所以新连续性方程是

```text
∂_mu [ sqrt(-g) ρ u^mu / (1 + B X) ] = 0
```

再代入 HJ 解

```text
1 + B X = X / m^2
```

于是得到

```text
∂_mu [ sqrt(-g) ρ (m^2 / X) u^mu ] = 0
```

也就是

```text
∂_mu [ sqrt(-g) ρ (m^2 / X) ∂^mu S ] = 0
```

### 5.3 正确结论

这说明：

```text
类 II 的 A = 1 最简单解
并不会在正确方法下自动退化成“零动力学”。
```

上一轮那个“零作用量退化”的结论，
是因为错误地先把解代回作用量 integrand 得到的。

所以这一结论必须撤回。

但是：

```text
它也还没有被证明与原连续性方程等价。
```

因为它给出的是

```text
∂_mu [ sqrt(-g) ρ (m^2 / X) ∂^mu S ] = 0
```

而不是

```text
∂_mu [ sqrt(-g) ρ ∂^mu S ] = 0
```

所以类 II 的最简单解当前状态应修正为：

```text
不能排除；
但也尚未证明动力学等价。
```

## 6. 被修正的结论

上一轮需要撤回或修正的是：

```text
“类 II 的 A=1 最简单解会导致零作用量退化，因此可直接排除”
```

这条结论不成立。

正确版本应是：

```text
类 II 的 A=1 最简单解在正确方法下仍给出非平凡连续性方程，
因此不能直接排除；
但它目前导出的连续性方程与原理论不同，
所以尚未证明等价。
```

## 7. 目前最稳的筛选状态

### 7.1 共形最简单解

```text
HJ 方程可匹配；
连续性方程一般不匹配；
目前仍不通过完整方程等价检验。
```

### 7.2 类 II 的 A=1 最简单解

```text
HJ 方程可匹配；
连续性方程变成
∂_mu [ sqrt(-g) ρ (m^2 / X) ∂^mu S ] = 0；
不能直接排除，
但尚未证明与原理论等价。
```

## 8. 下一步建议

现在最自然的下一步是：

```text
对一般类 II
g~_mu nu = A g_mu nu + B u_mu u_nu
```

不固定 `A=1`，直接要求：

1. 新 HJ 方程与原 HJ 方程匹配
2. 新连续性方程与原连续性方程匹配

看这两条是否能同时成立。

如果类 II 能做到这一点，那么它会重新成为非常强的候选。
