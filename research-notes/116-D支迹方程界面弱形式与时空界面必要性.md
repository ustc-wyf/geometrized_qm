# D 支迹方程界面弱形式与时空界面必要性

时间：2026-05-02

## 背景

用户要求继续推进数值方法，但明确强调：

```text
数值方法不能替代 C/D 作用量本身；
过渡层替换成边界面，必须是 C/D 场方程的物理弱形式，
不能靠人为规则压低发散。
```

本轮因此暂停 ad hoc toy correction，改做两个物理锁定的诊断：

1. D 支迹方程沿界面空间法向的弱形式积分；
2. 界面 \(y=\ell^2\tilde R=\pm1\) 的时空运动学。

## 物理方程

D 支迹方程在 `2+1d` 中为：

\[
f_R\tilde R-\frac{3}{2}f+2\tilde\Box f_R-\frac{\tilde T}{M_P^2}=0.
\]

其中

\[
f=\frac{\tanh y}{\ell^2},
\qquad
f_R=\operatorname{sech}^2 y,
\qquad
y=\ell^2\tilde R.
\]

## 解释

空间法向 jump 项和 algebraic bulk 项远小于完整 trace residual 的线积分。

这说明：

```text
固定时间切片上的空间界面弱形式不够。
```

遗漏的大项来自：

- 时间导数项；
- 切向导数项；
- 协变 box 中的联络项；
- 动态界面几何带来的混合项。

因此不能把 \(t=\mathrm{const}\) 切片中的 \(y=\pm1\) 曲线直接当作完整物理边界条件。

## 时空界面运动学

脚本：

```text
/Users/wangyunfei/Desktop/量子势几何化_codex/kg_examples/diagnose_d_interface_spacetime_kinematics.py
```

定义界面函数：

\[
F(t,x,z)=\ell^2\tilde R(t,x,z)-c.
\]

计算：

```text
coordinate_normal_speed = -F_t / sqrt(F_x^2 + F_z^2)
normal_norm_tilde_inverse = g_tilde^{ab} F_a F_b
```

`coordinate_normal_speed` 衡量界面在坐标网格上的法向移动速度。

`normal_norm_tilde_inverse` 衡量界面法向在 \(\tilde g\) 下的因果类型。采用 \(+--\) 签名时：

- 正值：法向类时，界面近似类空；
- 负值：法向类空，界面近似类时。

## 结论

本轮物理锁定诊断给出清楚结论：

\[
\boxed{
\text{过渡层可以继续作为界面处理，但界面必须是时空中的动态界面，而不是固定时间切片里的空间边界。}
}
\]

因此后续数值方法应改为：

1. 用 \(F(t,x,z)=\ell^2\tilde R(t,x,z)\mp1\) 表示动态时空界面；
2. 从 D 支完整场方程对跨越该时空界面的薄管积分，推导 jump/matching 条件；
3. 数值上再选择 level-set / moving-interface / body-fitted 方法求解这些条件；
4. 不再使用 screened-Poisson \(\delta\chi\) toy 作为物理演化器。

## 下一步

下一步应写出时空界面弱形式的主项：

\[
2\int \tilde\Box f_R\,d\lambda
\]

在 \(F=0\) 动态界面附近的薄层极限。

核心对象应是：

\[
\tilde g^{ab}F_aF_b,
\qquad
\partial_F f_R,
\qquad
\text{界面两侧的 } [\partial_F f_R].
\]

只有得到这一组来自 D 支场方程的 jump 条件后，才进入真正的全动力学界面求解器。
