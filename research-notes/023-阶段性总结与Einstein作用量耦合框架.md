# 023 阶段性总结与 Einstein 作用量耦合框架

## 目标

整理当前阶段最稳的结论，并把下一阶段“引力作用量到底写成 `g` 的衍生量还是 `g~` 的衍生量”这件事正式立起来。

这一份文档分两部分：

1. 阶段性总结
2. Einstein 作用量耦合的两个候选框架与初步比较

## A. 阶段性总结

### A1. 当前最核心的最小模型

我们始终研究的是：

```text
自由 Klein-Gordon 标量场
在固定背景时空上的 Bohm/Madelung 表述
```

约定：

```text
ψ = sqrt(ρ) e^(iS)
X = g^(mu nu) ∂_mu S ∂_nu S
Y = g^(mu nu) ∂_mu S ∂_nu sqrt(ρ)
Z = g^(mu nu) ∂_mu sqrt(ρ) ∂_nu sqrt(ρ)
Q = Box sqrt(ρ) / sqrt(ρ)
```

原理论的两条核心方程是：

```text
HJ:
X = m^2 + Q

Continuity:
∂_mu [ sqrt(-g) ρ u^mu ] = 0
```

其中

```text
u_mu = ∂_mu S
u^mu = g^(mu nu) ∂_nu S
```

### A2. 两条不同但都成立的几何化路线

经过和 Cursor 的对照，现在已经很清楚：

```text
我们手上其实有两条并行但都成立的路线。
```

#### 路线 1：严格 action-level matching 路线

这是 Cursor 的 `DERIV-0015/0016` 主线。

特征：

```text
保持 (R,S) 不变，
把 g~ 设计到使作用量密度严格匹配，
通常以 Z = g^(mu nu) ∂_mu R ∂_nu R 作为几何输入。
```

优点：

- 对 action-level 严格等价最强
- 逻辑最硬

代价：

- 结构更复杂
- 通常要配合共形因子
- 更接近“构造证明”

#### 路线 2：允许 ρ~ 真正变换的表象路线

这是我们后期主线。

特征：

```text
允许 ρ~ 作为新视角下真正变化的幅度，
不再强行固定 sqrt(-g)ρ。
```

在这条路线下，
纯 rank-1 逆度规 ansatz

```text
g~^(mu nu) = C g^(mu nu) + D u^mu u^nu
```

已经足够。

### A3. 当前最强的最简单解

按“直接在拉氏量中消去 Q 项”的要求，最简单解为

```text
C = 1
D = - Q / X^2
```

也就是

```text
g~^(mu nu) = g^(mu nu) - (Q / X^2) u^mu u^nu
```

并且为保持连续性方程，需要

```text
sqrt(-g~) ρ~ = sqrt(-g) ρ X / m^2
```

在这个前提下，已经同时得到：

```text
1. 拉氏量中的 Q 精确消去
2. HJ 方程精确重现
3. 连续性方程精确重现
4. 新几何中的测地线解释
```

### A4. 适用域与分支

对最简单 branch，

```text
X > 0
```

时：

- 可逆
- Lorentz 签名保持
- `ρ~` 保持实数
- 经典极限 `Q -> 0` 正确

更一般地，纯 ansatz 不是只有一条解，而是两条分支：

```text
Branch T:
X > 0, C > 0

Branch S:
X < 0, C < 0
```

因此：

```text
X < 0 不应简单视为理论失效，
而应视为切换到 spacelike branch 的信号。
```

这已经开始触碰我们最初想解释“类空/超光速区域”的物理动机。

## B. Einstein 作用量耦合：两个候选框架

现在进入下一阶段。

用户提出的核心问题是：

```text
引力作用量究竟应写成 g 的 Einstein-Hilbert 项，
还是写成 g~ 的 Einstein-Hilbert 项？
```

当前最合理的态度不是立刻判定谁“真”，而是：

```text
把两者都作为候选总作用量，
先比较它们在弱量子势、近似平直背景上的差异。
```

### B1. 候选框架 G：引力用 g

总作用量可写成

```text
S_total^(g)
= S_EH[g]
 + S_geom[ρ~,S; g~(g,ρ,S)]
 + S_constraint/transform
```

其中

```text
S_EH[g] = (1 / 16πG_N) ∫ d^4x sqrt(-g) R[g]
```

直观解释：

```text
g 仍是“真正引力场”，
g~ 是从物质态构造出来的有效几何。
```

优点：

- 最接近传统“背景引力 + 量子修正几何”的思路
- 在 `Q -> 0` 时自然回到普通 GR + KG

代价：

- 粒子的自然测地线是 `g~` 的，不是 `g` 的
- 因而“引力几何”和“粒子看到的几何”分离

### B2. 候选框架 G-tilde：引力用 g~

总作用量可写成

```text
S_total^(g~)
= S_EH[g~]
 + S_geom[ρ~,S; g~]
 + S_constraint/transform
```

其中

```text
S_EH[g~] = (1 / 16πG_N) ∫ d^4x sqrt(-g~) R[g~]
```

直观解释：

```text
g~ 才是粒子与引力共同使用的真正几何。
```

优点：

- 粒子测地线与引力几何天然统一
- 更符合“量子势几何化”的原始直觉

代价：

- 把 `g~ = g~(g,ρ,S)` 代回去后，会产生更复杂的 matter-gravity 耦合
- `S_EH[g~]` 一般会包含对 `ρ,S` 的额外导数耦合

## C. 在弱量子势 / 近似平直背景下的初步比较

### C1. 先写出最简单解的度规差

在 timelike branch 最简单解中，

```text
g~_mu nu = g_mu nu - [ Q / (X m^2) ] u_mu u_nu
```

当

```text
|Q| << m^2
```

且

```text
X ≈ m^2
```

时，有

```text
δg_mu nu := g~_mu nu - g_mu nu
≈ - (Q / m^4) u_mu u_nu
```

这说明：

```text
g~ 与 g 的差异是量子势控制的小 rank-1 形变。
```

### C2. Einstein-Hilbert 作用量差的主项

把

```text
g~ = g + δg
```

代入 EH 作用量，对 covariant metric 的一阶变分给出

```text
S_EH[g~] - S_EH[g]
= (1 / 16πG_N) ∫ d^4x sqrt(-g)
   [ G^(mu nu)[g] δg_mu nu ]
 + boundary
 + O(δg^2)
```

其中 `G^(mu nu)[g]` 是背景 `g` 的 Einstein 张量。

因此主 bulk 差异量级是

```text
ΔL_grav ~ G^(mu nu)[g] δg_mu nu
        ~ G^(mu nu)[g] * [ - Q/(X m^2) u_mu u_nu ]
```

### C3. 在近似平直背景上的意义

若背景 `g` 近似 Minkowski，或者更一般地近似满足真空 Einstein 方程，则

```text
G^(mu nu)[g] ≈ 0
```

于是：

```text
S_EH[g~] - S_EH[g]
```

的一阶 bulk 差异会被强烈压低，只剩：

- 边界项
- 二阶及更高阶项

也就是说，在

```text
背景近似平直
且
|Q| << m^2
```

时，两种 Einstein 作用量的差异确实天然很小。

### C4. 差异何时会变大

差异在以下场景会被放大：

```text
1. 背景曲率本身不小：G^(mu nu)[g] 不可忽略
2. 量子势不小：|Q| / m^2 不可忽略
3. 二者同时成立：强引力 + 强量子势
```

这和用户的直觉完全一致：

```text
只有在“量子”+“引力”都很强的区域，
两种总作用量才会给出明显不同的预测。
```

## D. 当前阶段最稳的判断

现在最稳妥的说法是：

```text
1. 把 Einstein-Hilbert 作用量写成 g 的衍生量
   和写成 g~ 的衍生量，
   当前都应保留为候选。

2. 在 Q -> 0 的经典极限下，
   两者都回到普通广义相对论形式。

3. 在近似平直背景、弱量子势区域，
   两者差异的 bulk 主项被强烈压低，
   因而确实可能在现有观测上几乎不可分辨。

4. 二者真正的差异窗口
   正是在强引力 + 强量子势区域。
```

## E. 下一步建议

现在下一步最有价值的不是空谈“哪个真”，而是：

```text
把这两个候选总作用量
S_total^(g)
和
S_total^(g~)
分别写成统一记号，
然后对它们做同一套弱场/弱量子势展开。
```

最具体的任务是：

1. 明确 `S_EH[g~] - S_EH[g]` 的一阶与二阶项
2. 识别这些项在什么量级下可能产生可观测差异
3. 提出“强引力 + 强量子势”实验/观测判别思路
