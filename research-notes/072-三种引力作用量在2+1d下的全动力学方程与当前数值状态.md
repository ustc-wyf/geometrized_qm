# 072 三种引力作用量在 2+1d 下的全动力学方程与当前数值状态

## 目标

在当前 `3+1d -> 2+1d` 一致约化框架下，
把三种引力作用量对应的“全动力学方程”与“当前能否数值闭合”明确区分开：

```text
A:  sqrt(-g) R[g]
B:  sqrt(-g~) R[g~]
C:  sqrt(-g~) f(R~)
```

并把它们与当前“高斯波包干涉”数值结果的可信层级对应起来。

用户此轮真正要看的不是：

```text
旧原型能不能勉强吐三张图
```

而是：

```text
1. 三支各自的全动力学方程到底是什么
2. 哪些方程已经真正闭合成可跑 PDE
3. 当前高斯波包干涉的数值结果里，哪些能当正式结果，哪些还只是 exploratory prototype
```

## 1. 共同的 2+1d 约化设定

沿 `y` 方向做 Killing 约化。

对 `g~` 表象，当前 B/C 数值主线采用：

```text
ds^2_{g~}
= e^{2τ(t,x,z)} (dt^2 - dx^2 - dz^2) - e^{2β(t,x,z)} dy^2
```

于是

```text
sqrt(-g~) = e^{β+τ}
g~^(ab)   = e^{-2τ} η^(ab)
η^(ab)    = diag(1,-1,-1)
```

共同的 Bohm 型物质作用量是：

```text
S_matter
= ∫ dtdxdz sqrt(-g~) ρ ( g~^(ab) ∂_a S ∂_b S - m^2 )
```

写成显式形式：

```text
L_matter
= e^{β+τ} ρ [ (∂S)^2 - m^2 e^{2τ} ]
```

其中

```text
(∂S)^2 = S_t^2 - S_x^2 - S_z^2
```

对 `ρ` 与 `S` 变分给出共同的物质方程：

```text
HJ:
S_t^2 - S_x^2 - S_z^2 = m^2 e^{2τ}

Continuity:
∂_t ( e^{β+τ} ρ S_t )
- ∂_x ( e^{β+τ} ρ S_x )
- ∂_z ( e^{β+τ} ρ S_z ) = 0
```

数值上更方便的变量是

```text
E := sqrt( S_x^2 + S_z^2 + m^2 e^{2τ} )
S_t = -E
n := e^{β+τ} ρ E = - e^{β+τ} ρ S_t
```

则连续性方程化成一阶守恒式：

```text
n_t = - ∂_x [ (n/E) S_x ] - ∂_z [ (n/E) S_z ]
ρ   = n / ( e^{β+τ} E )
```

因此，三支共同的“物质动力学骨架”是：

```text
(n, S)
```

引力分支的差异只体现在几何场如何反作用回来。

## 2. B 支：`sqrt(-g~) R[g~]`

### 2.1 约化后的引力部分

当前项目的 `2+1d` 明确闭合主线，是从

```text
S_B
= (M_P^2/2) ∫ dtdxdz e^{β+τ} [ R[h~] - 2 (∇β)^2 ]
+ S_matter
```

在 conformal gauge 下积分分部得到

```text
L_B
= M_P^2 e^{β+τ}
   [ (∂τ)^2 + 2 ∂β·∂τ - (∂β)^2 ]
+ e^{β+τ} ρ [ (∂S)^2 - m^2 e^{2τ} ]
```

其中

```text
∂f·∂g = f_t g_t - f_x g_x - f_z g_z
```

### 2.2 显式 PDE

在物质壳上 `(∂S)^2 = m^2 e^{2τ}` 后，
定义

```text
μ = m^2 e^{2τ} ρ / M_P^2
□f = f_tt - f_xx - f_zz
```

则几何方程可写成

```text
□τ = -1/2 [ (∂τ)^2 + (∂β)^2 + μ ]

□β = - ∂β·∂τ - (∂β)^2 - μ/2
```

所以 B 支的全动力学变量是

```text
(τ, β, n, S)
```

这条支已经在当前项目里写成显式 PDE 并可数值积分。

## 3. C 支：`sqrt(-g~) f(R~)`

### 3.1 辅助场重写

当前选择

```text
f(R~) = R~ / sqrt(1 + (ℓ^2 R~)^2)
```

数值上不直接用四阶 `f(R)`，
而是引入辅助场

```text
Φ = f_R(R~)
U(Φ) = Φ R~ - f(R~)
```

项目实际实现里等价地用 `χ` 求 `Φ(χ)` 与 `U(χ)`，
而传播变量是 `Φ`。

### 3.2 显式 PDE

在 `2+1d` 约化下，
定义

```text
A = Φ (∂τ)^2 + ∂Φ·∂τ + 1/2 e^{2τ} U

B = (∂τ)^2 + ∂β·∂τ + (∂β)^2 + 1/2 e^{2τ} U_Φ

C = 2 Φ (∂β)^2
  + 2 Φ ∂β·∂τ
  + Φ (∂τ)^2
  + 3 ∂Φ·∂β
  + 2 ∂Φ·∂τ
  + 3/2 e^{2τ} U
  + 3 μ
```

其中

```text
μ = m^2 e^{2τ} ρ / M_P^2
U_Φ = dU/dΦ
```

则显式波动系统为

```text
□τ = ( C - 2A - 2ΦB ) / ( 6Φ )

□β = -B - 2□τ

□Φ = -A - 2Φ□τ
```

所以 C 支的全动力学变量是

```text
(τ, β, Φ, n, S)
```

这条支也已经写成显式 PDE 并可数值积分。

## 4. A 支：`sqrt(-g) R[g]`

### 4.1 形式上的总作用量

这一支真正不同之处，是引力项写在 `g` 上而不是 `g~` 上：

```text
S_A
= (M_P^2/2) ∫ d^3x sqrt(-h) e^β [ R[h] - 2(∇β)^2 ]
+ ∫ d^3x sqrt(-h~) e^{β~} ρ ( h~^(ab) ∂_a S ∂_b S - m^2 )
+ S_constraint[g,g~,ρ,S]
```

### 4.2 形式方程

对 `ρ, S` 变分，仍然给出 `g~` 表象中的 HJ 与连续性方程：

```text
g~^(ab) ∂_a S ∂_b S = m^2

∂_a [ sqrt(-g~) ρ g~^(ab) ∂_b S ] = 0
```

但对 `g` 的引力方程只会给出

```text
M_P^2 G_{μν}[g] = T^{(constraint)}_{μν}
```

也就是说：

```text
物质不直接耦合在 g 上，
而是通过 g 与 g~ 的约束关系间接地把源项传回去。
```

### 4.3 为什么当前还没有唯一的 2+1d 数值系统

要把 A 支变成数值可跑的 `2+1d` PDE，
还必须在约化后额外给一个

```text
g ↔ g~
```

的 reduced constitutive law。

例如 note 044 里写过的 schematic 形式：

```text
τ - σ = α[ρ,S]
β~ - β = 0
```

或者别的 rank-1 / mixed reduced closure。

在不额外指定这一条之前：

```text
A 支只有形式方程，
没有唯一的 2+1d 闭合 PDE。
```

因此，当前项目里

```text
“三支的全动力学方程”
```

要严格分两层理解：

1. `A/B/C` 三支的作用量级与变分级方程都已经明确  
2. 但真正写成“显式 2+1d 可积分 PDE”的，当前只有 `B/C` 两支

## 6. 当前最稳的结论

### 理论层面

```text
A: 形式上的全动力学方程已明确，但 2+1d 数值闭合仍依赖额外 closure
B: 已有显式全动力学 PDE
C: 已有显式辅助场全动力学 PDE
```

### 数值层面

```text
当前最可信的高斯波包干涉三支比较结果，
不是 old full Cauchy prototype，
而是 shared-baseline 动态比较：

lambda=1:
  B_vs_A ~ 4.2e-06
  C_vs_A ~ 1.9e-05
  C_vs_B ~ 1.5e-05

lambda=3:
  B_vs_A ~ 1.3e-05
  C_vs_A ~ 4.5e-05
  C_vs_B ~ 3.3e-05
```

### 这意味着什么

如果当前要对外给出“引力作用量不同是否会改变量子干涉后续演化”的最稳回答，
那么可以说：

```text
1. B/C 两支的 full dynamical geometry equations 已经明确
2. A 支的 formal equations 也已明确，但还缺 closure 才能同级数值闭合
3. 在当前最可信的 shared-baseline 数值比较里，A/B/C 的差异已经清楚显影：
   B 偏离 A 较弱，C 偏离 B 更强
```

如果要把这一步升级成真正严格的“同初值三支 full backreacted 比较”，
下一步就不该继续调 B/C，
而该优先补上：

```text
A 支的 2+1d reduced closure
```

因为这是当前唯一真正卡住“同级三支全动力学比较”的位置。
