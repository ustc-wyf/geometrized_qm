# 041 `f(R~)` 分支的辅助场重写

## 目标

把

```text
S_C = (M_P^2 / 2) ∫ sqrt(-g~) f(R~) + ...
```

重写成一个更适合数值积分的二阶系统。

## 1. 辅助场定义

对一般 `f(R)`，
引入辅助标量

```text
Φ = f_R(R~)
```

以及势

```text
U(Φ) = Φ R~ - f(R~)
```

则作用量可等价改写成

```text
S_C
= (M_P^2 / 2) ∫ d^4x sqrt(-g~) [ Φ R~ - U(Φ) ]
 + S_matter
 + S_constraint
```

这是标准 scalar-tensor 形式。

## 2. 当前指定的 f(R~)

当前指定：

```text
f(R~) = R~ / sqrt(1 + (ℓ^2 R~)^2)
```

所以

```text
Φ = f_R = (1 + (ℓ^2 R~)^2)^(-3/2)
```

它始终为正。

这就是它比 Lorentzian 型和 Gaussian 型更稳定的根本原因。

## 3. 数值意义

辅助场重写后，
高阶 `f(R)` 系统被改写成：

- metric 二阶方程
- 辅助标量 `Φ` 的二阶/代数约束方程

这比直接积分四阶系统更现实。

## 4. 当前结论

如果真要做三套完整作用量的联合数值积分，

```text
分支 C 必须先走辅助场重写。
```

否则数值稳定性很差，工程量也会明显增大。
