# 093 3+1d 下 A/B/C 三支的渐进一致性分析

## 目标

在当前 `m\neq 0, C=1` 混合投影分支下，分析三种引力作用量

```text
A:  S_A^grav = (M_P^2/2) ∫ d^4x sqrt(-g)   R[g]
B:  S_B^grav = (M_P^2/2) ∫ d^4x sqrt(-g~)  R[g~]
C:  S_C^grav = (M_P^2/2) ∫ d^4x sqrt(-g~)  f(R~)
```

在 `3+1d` 中何时渐进一致，何时显著偏离。

这里物质部分已假定通过前面的变换构造在理论上等价；本笔记只比较引力部分。

## 1. 当前分支的基本量

记

```text
u_mu = ∂_mu S,
r_mu = ∂_mu sqrt(ρ),
X = g^(mu nu) u_mu u_nu,
Y = g^(mu nu) u_mu r_nu,
Z = g^(mu nu) r_mu r_nu,
Δ = X Z - Y^2.
```

当前 `m != 0, C = 1` 混合投影型分支可写为

```text
g~^(mu nu) = g^(mu nu) - (Q/X) P^(mu nu)
```

其中 `P^(mu nu)` 是 Bohm 二维平面上的逆变投影子。

在 `X>0` 的 timelike branch 上，其协变形式是

```text
g~_(mu nu) = g_(mu nu) + (Q/m^2) Π_(mu nu)
```

其中 `Π_(mu nu)` 是同一 Bohm 二维平面的协变投影子。定义形变量

```text
h_(mu nu) := g~_(mu nu) - g_(mu nu) = (Q/m^2) Π_(mu nu).
```

同时

```text
sqrt(|g~|) / sqrt(|g|) = X / m^2 = 1 + Q/m^2.
```

## 2. B 支与 A 支的差异

引力作用量密度差定义为

```text
ΔL_BA := sqrt(|g~|) R[g~] - sqrt(|g|) R[g].
```

对小形变 `h_(mu nu)` 做标准 Einstein-Hilbert 一阶变分，有

```text
ΔL_BA
= sqrt(|g|) G^(mu nu)[g] h_(mu nu)
  + ∂_mu V^mu
  + O(h^2, ∇h∇h)
```

代入 `h_(mu nu) = (Q/m^2) Π_(mu nu)` 得

```text
ΔL_BA
= sqrt(|g|) (Q/m^2) G_Π
  + ∂_mu V^mu
  + O(h^2, ∇h∇h)
```

其中

```text
G_Π := G^(mu nu)[g] Π_(mu nu).
```

更具体地，二阶和导数项由

```text
(∇(Q/m^2))^2,
(Q/m^2) ∇∇(Q/m^2),
(Q/m^2)^2 (∇Π)^2,
(Q/m^2) ∇(Q/m^2) ∇Π
```

控制。

因此：

### B 与 A 渐进一致的充分条件

若在主要物理支撑区同时满足

```text
|Q|/m^2 << 1,
L |∇(Q/m^2)| << 1,
L |∇Π| << 1,
L^2 |G_Π| << 1,
```

则

```text
sqrt(|g~|) R[g~] = sqrt(|g|) R[g] + 小量 + 边界项.
```

也就是说，`B` 支在弱量子势、缓变包络、弱背景曲率极限下与 `A` 支渐进一致。

### B 与 A 不一致的典型情形

若

```text
|Q|/m^2 ≳ 1,
```

或 `Q/m^2`、`Π` 变化很快，则即使 `g` 本身很弱，`B` 支也不必接近 `A`。特别地：

- `|Q| >> m^2` 但 `X` 仍离 `0` 远时，`g~` 在 Bohm 平面上的形变已是 `O(1)` 或更大；
- `X -> 0` 时，`sqrt(|g~|)` 的塌缩并不能自动消掉 `R[g~]` 的导数奇性。

因此 `X -> 0` 一般不是 `B -> A` 的一致极限。

## 3. C 支与 B 支的差异

取

```text
f(R~) = R~ / sqrt(1 + (ℓ^2 R~)^2).
```

则

```text
ΔL_CB := sqrt(|g~|) f(R~) - sqrt(|g~|) R~
       = sqrt(|g~|) [ f(R~) - R~ ].
```

当 `|ℓ^2 R~| << 1` 时，展开有

```text
f(R~) = R~ [ 1 - 1/2 (ℓ^2 R~)^2 + O((ℓ^2 R~)^4) ]
      = R~ - 1/2 ℓ^4 R~^3 + O(ℓ^8 R~^5).
```

所以

```text
ΔL_CB = -1/2 sqrt(|g~|) ℓ^4 R~^3 + O(ℓ^8 R~^5).
```

同时场方程里的

```text
f_R(R~) = (1 + (ℓ^2 R~)^2)^(-3/2)
        = 1 - 3/2 ℓ^4 R~^2 + O(ℓ^8 R~^4)
```

说明 `C` 支在 `|ℓ^2 R~| << 1` 时渐进退回 `B` 支。

### C 与 B 渐进一致的充分条件

```text
|ℓ^2 R~| << 1,
L^2 |∇∇f_R| << |R~|,
L |∇f_R| << 1.
```

其中后两条保证 `f(R)` 场方程里的高阶修正项也小。

## 4. C 支与 A 支的渐进一致条件

把上两步串起来，`C` 与 `A` 渐进一致的一个充分条件组是：

```text
|Q|/m^2 << 1,
L |∇(Q/m^2)| << 1,
L |∇Π| << 1,
L^2 |G_Π| << 1,
|ℓ^2 R~| << 1,
L |∇f_R| << 1,
L^2 |∇∇f_R| << |R~|.
```

也就是：

1. `B` 必须先接近 `A`；
2. `C` 再接近 `B`。

在这种情况下，三支的引力作用量密度与几何场方程都会趋向一致。

## 5. 三种极限下的判断

### 5.1 弱量子势极限 `|Q| << m^2`

这是最有希望实现

```text
A ≈ B ≈ C
```

的区域。

若再有 `|ℓ^2 R~| << 1`，则 `C` 也会退回 `B`。因此大多数弱 `g`、弱量子势实验若位于这个参数区，三支应给出渐进一致的预测。

### 5.2 强量子势但远离分支边界 `|Q| >> m^2`, `|X| not approx 0`

这时一般只有下面两种可能：

- 若 `Q/m^2` 很大但变化极缓，`B` 仍可能保持有限而非奇异，但通常不再接近 `A`；
- `C` 是否接近 `A` 取决于 `ℓ^2 R~` 是否仍小。若 `|ℓ^2 R~| >> 1`，则 `f(R~)` 进入非线性饱和区，`C` 也不再接近 `B` 或 `A`。

因此该极限一般不是三支一致区。

### 5.3 分支边界 `X -> 0`

这里有

```text
sqrt(|g~|)/sqrt(|g|) = |X|/m^2 -> 0,
```

以及

```text
sqrt(|g~|) ρ~ / (sqrt(|g|) ρ) = |X|/m^2 -> 0,
```

但这不能推出

```text
sqrt(|g~|) R[g~] -> 0.
```

因为 `R[g~]` 含有 `X,Q,Π` 的导数，可能有 `1/X` 型或更强的导数奇性。故 `X -> 0` 一般不是 `A/B/C` 渐进一致区，而是需要单独分析的边界区。

## 6. 对当前项目的结论

当前项目若目标是检验：`B/C` 是否能在大多数弱引力实验里与 `A` 渐进一致，则最核心的判据不是单独看 `g` 是否弱，而是同时看：

```text
(1) |Q|/m^2 是否小；
(2) Q 与 Bohm 平面投影子 Π 的导数是否小；
(3) 对 C 支，还要看 |ℓ^2 R~| 是否小。
```

只有在这三层都小的时候，才可期待

```text
A ≈ B ≈ C.
```

若 `Q` 强、变化快、或 `X` 接近 0，则即使背景 `g` 很弱，`B/C` 也可能明显偏离 `A`。
