# 071 测度密度趋零与 `X=0` 处速度无定义的统一解释

## 目标

澄清用户提出的一个更稳健的解释：

```text
即使某些分支上 ρ~ 本身不趋于 0，
只要 sqrt(|g~|)ρ~ -> 0，
那么该表象下“单位坐标体积中的粒子数密度”仍趋于 0，
于是速度在该点无需定义。
```

这个观点是对的，而且比单纯讨论 `ρ~` 本身更一般。

---

## 1. 强连续性匹配下的统一公式

在当前几何化讨论中，若在某个正则 patch 上采用强连续性匹配：

```text
sqrt(|g~|) ρ~ g~^(μν)u_ν = sqrt(|g|) ρ u^μ ,
```

并且由 HJ 壳约束得到

```text
g~^(μν)u_ν = A_u u^μ ,

A_u = κ/X ,

κ ≠ 0 .
```

那么立刻有

```text
sqrt(|g~|) ρ~ A_u = sqrt(|g|) ρ ,
```

若进一步坚持 `sqrt(|g~|)ρ~` 是正测度密度，并把 `sqrt(|g|)ρ` 也按同样口径理解为正量，则在物理可接受的单个 patch 上必须有

```text
A_u > 0 .
```

由于这里

```text
A_u = κ/X ,
```

这等价于要求

```text
κ/X > 0 .
```

于是

```text
1/A_u = 1/|A_u| = |X|/|κ| .
```

因此正测度密度应写成

```text
sqrt(|g~|) ρ~
= sqrt(|g|) ρ / |A_u|
= (|X|/|κ|) sqrt(|g|) ρ .
```

只要原 `g` 表象下的测度密度 `sqrt(|g|)ρ` 保持有限，就得到

```text
X -> 0
==>
sqrt(|g~|)ρ~ -> 0 .
```

这一步与 `ρ~` 本身是否发散、有限或趋零无关。

---

## 2. 这说明真正有物理意义的是测度密度

在协变连续性方程里，真正进入守恒律的是

```text
N~ := sqrt(|g~|)ρ~
```

它是权重 1 的密度，而不是裸标量 `ρ~`。

因此从 Bohm / 流体解释角度，更自然的“粒子数密度”应理解成：

```text
单位坐标体积里的守恒粒子数密度 ~ sqrt(|g~|)ρ~ .
```

所以：

```text
即使 ρ~ 本身发散，
只要 sqrt(|g~|)ρ~ -> 0，
就仍可把 X=0 解释成该表象里的零密度边界。
```

---

## 3. 速度为何无需定义

在 `g~` 表象里，速度样对象通常写成

```text
V~^μ := g~^(μν)u_ν = A_u u^μ .
```

若 `A_u = κ/X`，则 `X -> 0` 时它可能发散。

但电流是

```text
J~^μ = sqrt(|g~|)ρ~ V~^μ .
```

由强匹配它恰好等于

```text
J~^μ = sqrt(|g|)ρ u^μ ,
```

故保持有限。

这里要注意区分两件事：

```text
- 裸的速度样对象 V~^μ = A_u u^μ 可以带有 κ/X 型符号与发散
- 真正的守恒粒子数密度 N~ = sqrt(|g~|)ρ~ 必须取正根，因此只记录其正值大小
```

这正是 Bohm 节点处的标准现象类比：

```text
速度 = 电流 / 密度
```

当密度趋零时，速度可以无定义或发散，而不必意味着物理电流发散。

因此用户的解释可压缩为：

```text
X=0 在 g~ 表象下是零测度密度边界；
该处速度无需定义，但电流仍可保持有限。
```

---

## 4. 这能解决什么，不能解决什么

### 4.1 能解决的

- 解决“为什么 `V~^μ` 发散不一定是物理灾难”的解释问题
- 说明 `X=0` 可以被看作类似 Bohm 节点的边界
- 说明用 `sqrt(|g~|)ρ~` 而不是裸 `ρ~` 来讨论“该表象里的密度”更稳健

### 4.2 不能自动解决的

- 这并不自动说明 `g~` 图册在 `X=0` 处是光滑可逆的
- 也不自动说明 signature、联络、测地线方程等全部对象都可正则延拓过该面
- 它首先是一个 **current-level / interpretational regularization**
  ，而不是 automatically a chart-level regularization

---

## 5. 与几个典型分支的关系

### rank-1 `C=1`

```text
ρ~ = ρ sqrt(|X/κ|) -> 0 ,
sqrt(|g~|)ρ~ = (|X|/|κ|) sqrt(|g|)ρ -> 0 .
```

### `C=1` 投影型主分支

```text
ρ~ = ρ ,
sqrt(|g~|)ρ~ = (|X|/|κ|) sqrt(|g|)ρ -> 0 .
```

### raw 混合投影块 `D=Z,E=-Y,F=X`

```text
ρ~ = ρ |C| ,
sqrt(|g~|)ρ~ = (|X|/|κ|) sqrt(|g|)ρ -> 0 .
```

所以：

```text
“ρ~ 是否本身趋零”是分支依赖的；
“sqrt(|g~|)ρ~ 是否趋零”在强匹配 + A_u=κ/X 下则是统一成立的。
```

---

## 6. 结论

用户当前这条修正后的解释是成立的，而且比单纯要求 `ρ~ -> 0` 更一般：

```text
在强连续性匹配且 A_u = κ/X 的分支里，
只要工作在 `κ/X > 0` 的单个正密度 patch 上，
就总有
sqrt(|g~|)ρ~ = (|X|/|κ|) sqrt(|g|)ρ -> 0 .
```

因此可把 `X=0` 理解为 `g~` 表象中的零测度密度边界。

这意味着：

```text
该处速度样对象不必有良好定义，
只要电流保持有限，方程本身仍可有意义。
```
