# 008 方法论修正：作用量等价不是必要条件

## 目标

修正当前项目中的一个方法论判断：

```text
“作用量等价”不是本项目的必要条件。
```

它可以是一个很强的充分条件，但不是必须满足的物理要求。

## 1. 原先偏强的判断

此前我们的快速筛选里，隐含使用了这样一个强标准：

```text
I_geom 应尽量直接等价于 I_orig
```

这会导致一个风险：

```text
把“作用量不相同”误当成“理论失败”。
```

但这一步其实走得太快了。

## 2. 更准确的必要条件是什么

对当前项目来说，更准确的必要条件应当是：

```text
由新作用量导出的物理方程
与原理论需要保留的物理内容等价。
```

至少包括：

1. Hamilton-Jacobi 型方程等价
2. 连续性方程/守恒结构等价
3. 轨迹方程的物理内容等价
4. 可观测预测不变

如果这些成立，那么：

```text
即使作用量本身不是逐项相同，
方案仍然可能是物理上可接受的。
```

## 3. 为什么“作用量等价”不是必要条件

原因并不神秘。

不同作用量可能在以下意义上给出相同物理：

### 3.1 差一个边界项

这是最常见的情况。

```text
I' = I + boundary term
```

此时 Euler-Lagrange 方程相同，但作用量表面上不一样。

### 3.2 变量重定义后形式不同

若新理论使用的是不同的几何变量或不同的场变量，那么作用量的外观完全可能改变，但物理方程仍然等价。

### 3.3 只要求动力学等价

本项目真正关心的是：

```text
量子势是否能被几何吸收，
并且新的几何描述是否给出相同物理。
```

这本质上是动力学等价问题，不是“拉氏量逐项一模一样”的问题。

## 4. 因此，筛选标准应如何修正

现在把“作用量等价”降级为：

```text
强充分条件，但不是必要条件。
```

新的分层标准应是：

### 第一层：最低必要条件

```text
新作用量导出的物理方程等价。
```

### 第二层：更强条件

```text
新作用量与原作用量在变量变换后等价，
或至少相差边界项。
```

### 第三层：最强条件

```text
新理论还自然给出测地线解释、
经典极限、
可逆性、
因果结构控制。
```

## 5. 对前面筛选结果的修正

这条修正的直接后果是：

```text
此前“共形最简单解”和“类 II 的 A=1 最简单解”
不能因为作用量不做 off-shell 逐项匹配
就被判出局。
```

更准确的说法应当是：

```text
它们尚未满足“强作用量等价标准”，
但仍可能满足“动力学等价标准”。
```

所以接下来该问的不是：

```text
它们的作用量是不是和原作用量长得一样？
```

而是：

```text
它们变分出来的方程，
是否与原理论需要保留的方程等价？
```

## 6. 对项目推进的直接影响

接下来的优先检查顺序应改成：

1. 先检查新作用量变分得到的 HJ 方程是否正确
2. 再检查连续性方程是否正确
3. 再检查轨迹是否能测地线化
4. 再把“作用量是否更强地等价”作为加分项，而不是硬门槛

## 7. 当前最稳妥的表述

到现在为止，最准确的说法应该是：

```text
我们已经证明了一些方案在 HJ 层面可吸收 Q；
它们是否成立，下一步应主要看变分后的物理方程是否等价，
而不是先要求作用量逐项等价。
```

这会让后续筛选更符合物理逻辑。
