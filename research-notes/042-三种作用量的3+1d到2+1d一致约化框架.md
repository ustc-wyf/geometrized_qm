# 042 三种作用量的 3+1d 到 2+1d 一致约化框架

## 目标

修正之前“直接砍自由度”的不严谨说法，给出一个更正确的 3+1d -> 2+1d 一致约化框架。

当前双缝/双束几何的自然对称方向是：

```text
y 方向
```

因为：

- 条纹和传播主要发生在 `x-z` 平面
- `y` 是狭缝延伸方向

所以最合理的第一步约化是：

```text
保留 (t, x, z)
把 y 方向做成 Killing 方向
```

但：

```text
不能简单把 y 方向几何自由度删掉，
而应该把它变成一个约化场。
```

## 1. 2+1d 约化的 metric ansatz

对前变换背景 `g`，取

```text
ds_g^2 = h_ab(x^c) dx^a dx^b - e^{2β(x^c)} dy^2
```

其中

```text
a,b,c ∈ {t, x, z}
```

并要求

```text
∂_y h_ab = 0
∂_y β = 0
```

也就是：

```text
y 方向是 Killing 方向，
但 g_yy = -e^{2β} 仍然保留成一个动态约化标量 β。
```

对几何化后的 `g~`，同样取

```text
ds_g~^2 = h~_ab(x^c) dx^a dx^b - e^{2β~(x^c)} dy^2
```

## 2. 4d Einstein-Hilbert 的约化

把 4d Einstein-Hilbert 作用量

```text
S_EH[g] = (M_P^2 / 2) ∫ d^4x sqrt(-g_4) R[g_4]
```

在这个 ansatz 下约化到 2+1d，模去边界项后，会得到一个“3d 引力 + dilaton”系统。

其结构可写成：

```text
S_EH[g]  ->  (M_P^2 / 2) ∫ d^3x sqrt(-h) e^β [ R[h] - 2 (∇β)^2 ]
```

这里：

- `R[h]` 是 2+1d metric `h_ab` 的 Ricci 标量
- `β` 是来自 `g_yy` 的约化标量

更准确地说，4d 曲率标量满足（模边界）：

```text
R_4[g]  ~  R[h] - 2 □β - 2 (∇β)^2
```

乘上 `sqrt(-g_4)=sqrt(-h)e^β` 并积分分部后，
得到上面的 2+1d 形式。

### 2.1 重要含义

这说明：

```text
即使只做 2+1d，
你也不是在“丢掉 y 方向物理”，
而是在把它折成一个新的有效场 β。
```

这就是一致约化。

## 3. 物质部分的约化

当前项目中，最终希望保留的物质拉氏量是 Bohm 型的：

```text
L_matter[g~,ρ~,S]
= sqrt(-g~) ρ~ ( g~^(μν) ∂_μ S ∂_ν S - m^2 )
```

在 `∂_y S = 0`、`∂_y ρ~ = 0` 的约化下，
它直接变成：

```text
L_matter^(2+1)
= sqrt(-h~) e^{β~} ρ~ ( h~^(ab) ∂_a S ∂_b S - m^2 )
```

这就是后续三种分支共同的物质部分。

## 4. 三种总作用量的 2+1d 版本

### A 分支：引力写在 g 上

```text
S_A^(2+1)
= (M_P^2 / 2) ∫ d^3x sqrt(-h) e^β [ R[h] - 2(∇β)^2 ]
 + ∫ d^3x sqrt(-h~) e^{β~} ρ~ ( h~^(ab) ∂_a S ∂_b S - m^2 )
 + S_constraint
```

### B 分支：引力写在 g~ 上

```text
S_B^(2+1)
= (M_P^2 / 2) ∫ d^3x sqrt(-h~) e^{β~} [ R[h~] - 2(∇β~)^2 ]
 + ∫ d^3x sqrt(-h~) e^{β~} ρ~ ( h~^(ab) ∂_a S ∂_b S - m^2 )
 + S_constraint
```

### C 分支：引力写成 f(R~)

先记

```text
R~_4 = R[h~] - 2 □~β~ - 2 (∇β~)^2
```

则

```text
S_C^(2+1)
= (M_P^2 / 2) ∫ d^3x sqrt(-h~) e^{β~} f(R~_4)
 + ∫ d^3x sqrt(-h~) e^{β~} ρ~ ( h~^(ab) ∂_a S ∂_b S - m^2 )
 + S_constraint
```

## 5. C 分支的辅助场重写

这一步是必要的。

定义辅助场

```text
Φ = f_R(R~_4)
```

以及势

```text
U(Φ) = Φ R~_4 - f(R~_4)
```

则 C 分支改写成：

```text
S_C^(2+1)
= (M_P^2 / 2) ∫ d^3x sqrt(-h~) e^{β~} [ Φ R~_4 - U(Φ) ]
 + ∫ d^3x sqrt(-h~) e^{β~} ρ~ ( h~^(ab) ∂_a S ∂_b S - m^2 )
 + S_constraint
```

这样原来的高阶 `f(R)` 系统就被改成了更适合数值积分的二阶标量-张量系统。

## 6. 为什么选 2+1d 而不是 1+1d

如果直接约化到 `1+1d`，虽然形式更简单，但会出现两个问题：

1. `x` 方向正是条纹展开方向，不能丢
2. 纯 Einstein-Hilbert 在 `1+1d` 中仍会退化

所以：

```text
2+1d 是当前最合理的第一目标。
```

它既保留了：

- 条纹方向 `x`
- 传播方向 `z`

又把 `y` 方向一致地约化成了一个场。

## 7. 当前结论

因此，后续如果要真正做“从完整总作用量出发”的数值演化，
最合理的路线是：

```text
1. 用上面的 2+1d 一致约化框架
2. 对 A/B/C 三个分支分别变分
3. 尤其对 C 分支先做辅助场重写
4. 再做数值积分
```

这比“直接在 3+1d brute force”或者“简单删自由度到 1+1d”都更合适。
