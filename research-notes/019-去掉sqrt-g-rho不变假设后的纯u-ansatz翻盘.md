# 019 去掉 `sqrt(-g)ρ` 不变假设后的纯 `u^mu u^nu` ansatz 翻盘

## 目标

重新考虑当前核心问题，但这次明确去掉假设

```text
sqrt(-g) ρ = sqrt(-g~) ρ~
```

的“固定不变”理解。

新的观点是：

```text
波函数在换视角时本来就应改变，
因此 ρ~ 也应作为真正的变换对象，
而不是预先固定。
```

在这个前提下，重新检查最简单的纯 `u^mu u^nu` 逆度规 ansatz：

```text
g~^(mu nu) = C g^(mu nu) + D u^mu u^nu
```

结论将是：

```text
一旦允许 ρ~ 正确变换，
这个纯 ansatz 已经足以同时重现
HJ 方程和连续性方程。
```

也就是说，之前很多“结构性失败”其实是由过强的密度固定假设导致的。

## 1. 新变量作用量

从新变量作用量出发：

```text
I_geom[ρ~,S;g~]
= ∫ d^4x sqrt(-g~) ρ~ ( g~^(mu nu) ∂_mu S ∂_nu S - m^2 )
```

这里：

- `ρ~` 是新视角下的幅度
- `S` 保持同一个相位函数
- `g~^(mu nu)` 是新逆度规

不再预先假定 `ρ~` 与 `ρ` 的简单不变关系。

## 2. 先变分

对 `ρ~` 变分得到

```text
g~^(mu nu) ∂_mu S ∂_nu S = m^2
```

对 `S` 变分得到

```text
∂_mu [ sqrt(-g~) ρ~ g~^(mu nu) ∂_nu S ] = 0
```

这两条就是新视角下真正应满足的物理方程。

## 3. 纯 ansatz 下的方程

定义

```text
u_mu = ∂_mu S
u^mu = g^(mu nu) ∂_nu S
X = g^(mu nu) u_mu u_nu
Q = Box sqrt(ρ) / sqrt(ρ)
```

取

```text
g~^(mu nu) = C g^(mu nu) + D u^mu u^nu
```

则有

```text
g~^(mu nu) u_mu u_nu = C X + D X^2
```

以及

```text
g~^(mu nu) u_nu = (C + D X) u^mu
```

因此新方程变成

```text
HJ:
C X + D X^2 = m^2
```

和

```text
Continuity:
∂_mu [ sqrt(-g~) ρ~ (C + D X) u^mu ] = 0
```

## 4. 让 HJ 方程回到原理论

原理论的 HJ 方程是

```text
X = m^2 + Q
```

所以要重现原理论，只需要求

```text
C X + D X^2 = X - Q
```

即

```text
D X^2 + (C - 1) X + Q = 0
```

这正是我们之前从“直接在拉氏量中消去 Q 项”得到的同一个条件。

所以：

```text
纯 ansatz 只要满足
D X^2 + (C - 1) X + Q = 0，
就能精确重现原 HJ 方程。
```

## 5. 让连续性方程也回到原理论

原理论连续性方程是

```text
∂_mu [ sqrt(-g) ρ u^mu ] = 0
```

而新连续性方程是

```text
∂_mu [ sqrt(-g~) ρ~ (C + D X) u^mu ] = 0
```

所以只要定义变换后的幅度满足

```text
sqrt(-g~) ρ~ (C + D X) = sqrt(-g) ρ
```

那么新连续性方程就会精确变成原理论的连续性方程。

这给出最一般的密度变换律：

```text
sqrt(-g~) ρ~ = sqrt(-g) ρ / (C + D X)
```

## 6. 联立 HJ 与连续性条件

由 HJ 条件

```text
C X + D X^2 = m^2
```

可得

```text
C + D X = m^2 / X
```

代回连续性所需条件，得到

```text
sqrt(-g~) ρ~ = sqrt(-g) ρ X / m^2
```

这就是去掉“`sqrt(-g)ρ` 不变”假设后，
新幅度应满足的正确变换关系。

### 6.1 结论

于是可以非常清楚地说：

```text
一旦允许 ρ~ 正确变化，
纯 `u^mu u^nu` ansatz 就足以同时做到：

1. 重现原 HJ 方程
2. 重现原连续性方程
```

## 7. 最简单具体解

最简单取法仍然是

```text
C = 1
D = - Q / X^2
```

此时

```text
C + D X = 1 - Q/X = (X - Q)/X = m^2 / X
```

因此密度变换律化成

```text
sqrt(-g~) ρ~ = sqrt(-g) ρ X / m^2
```

这正是最简单消项解下应采用的正确幅度变换。

## 8. 显式写出 ρ~（可选）

若进一步想把 `ρ~` 单独写出来，需要用到 `sqrt(-g~)`。

对纯 ansatz

```text
g~^(mu nu) = C g^(mu nu) + D u^mu u^nu
```

有

```text
det(g~^(..)) = det(g^(..)) C^4 (1 + D X / C)
            = det(g^(..)) C^3 (C + D X)
```

因此

```text
sqrt(-g~) = sqrt(-g) / sqrt( C^3 (C + D X) )
```

所以

```text
ρ~ = ρ [ X / m^2 ] sqrt( C^3 (C + D X) )
```

再用

```text
C + D X = m^2 / X
```

可化成

```text
ρ~ = ρ sqrt( C^3 X / m^2 )
```

对最简单解 `C = 1` 就得到

```text
ρ~ = ρ sqrt( X / m^2 )
```

这说明：

```text
换到新几何视角后，
波函数幅度确实改变了。
```

而这正是用户指出的深刻含义。

## 9. 这对前面结论的修正

这一步会直接修正我们前面若干基于“过强密度固定假设”的判断。

最重要的修正是：

```text
之前纯 `u^mu u^nu` ansatz 看起来在连续性方程上失败，
不是因为它本身不行，
而是因为当时把 ρ~ 限制得太死了。
```

一旦放开 `ρ~` 的变换，自然地让

```text
sqrt(-g~) ρ~ (C + D X) = sqrt(-g) ρ
```

成立，那么纯 ansatz 就已经足够。

## 10. 当前最稳的结论

到这一步，可以得到一个比前面强得多的结论：

```text
在允许波函数幅度随视角变化的前提下，
纯 `u^mu u^nu` 逆度规 ansatz 已经能够同时重现
原 KG-Madelung 理论的 HJ 方程和连续性方程。
```

如果再结合前面已经得到的结果：

```text
新 HJ 方程 ⇒ 新几何测地线方程
```

那么当前最简单解实际上已经完成了：

```text
1. 拉氏量中的 Q 消项
2. HJ 方程重现
3. 连续性方程重现
4. 新几何中的测地线解释
```

## 11. 下一步建议

现在最自然的下一步不再是“修补连续性方程”，因为这一步已经解决了。

下一步应转向真正剩下的几个问题：

1. 这个变换是否全局可逆
2. 因果结构和签名是否在物理上可接受
3. 经典极限是否正确
4. 实验预言是否真的保持不变

这才是当前主线应继续推进的部分。
