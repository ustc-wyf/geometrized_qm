# 013 类 II 中 A=1 时 B 是否必然含 Z 的复核

## 目标

复核一个非常具体的问题：

```text
在类 II
g~_mu nu = A g_mu nu + B u_mu u_nu
```

里，若取

```text
A = 1
```

那么 `B` 是否会被方程强制出显式的 `Z` 依赖？

这里严格采用当前已经确认的正确顺序：

```text
先对新作用量变分，
再把变换代回方程。
```

## 1. 类 II 的基本定义

定义

```text
u_mu = ∂_mu S
X = g^(mu nu) u_mu u_nu
```

类 II 的度规取为

```text
g~_mu nu = A g_mu nu + B u_mu u_nu
```

这里“类 II”的定义本身不含 `r_mu = ∂_mu sqrt(ρ)` 的张量结构。

因此若 `Z` 出现，只可能来自：

```text
1. 你事先允许 B = B(X,Z,ρ,...)；
2. 或你在额外方程里引入了 Z；
3. 但不会从 g~_mu nu 的纯代数逆运算里自动冒出来。
```

## 2. HJ 方程的直接复核

在新变量作用量下，对 `ρ~` 变分得到

```text
g~^(mu nu) u_mu u_nu = m^2
```

现在取 `A = 1`：

```text
g~_mu nu = g_mu nu + B u_mu u_nu
```

其逆度规由 Sherman-Morrison 公式给出

```text
g~^(mu nu)
= g^(mu nu)
 - [ B / (1 + B X) ] u^mu u^nu
```

于是

```text
g~^(mu nu) u_mu u_nu
= X - [ B / (1 + B X) ] X^2
= X / (1 + B X)
```

所以 HJ 方程变成

```text
X / (1 + B X) = m^2
```

直接解出

```text
B = (X - m^2) / (m^2 X)
```

### 2.1 结论

因此：

```text
若只使用类 II 的 HJ 方程，
并且取 A = 1，
那么 B 被唯一地固定为 X 的函数，
不被强制含 Z。
```

## 3. 连续性方程的复核

新连续性方程为

```text
∂_mu [ sqrt(-g~) ρ~ g~^(mu nu) u_nu ] = 0
```

再用

```text
sqrt(-g~) ρ~ = sqrt(-g) ρ
```

变成

```text
∂_mu [ sqrt(-g) ρ g~^(mu nu) u_nu ] = 0
```

而

```text
g~^(mu nu) u_nu
= u^mu - [ B X / (1 + B X) ] u^mu
= u^mu / (1 + B X)
```

所以连续性方程是

```text
∂_mu [ sqrt(-g) ρ u^mu / (1 + B X) ] = 0
```

若再代入 HJ 解

```text
1 + B X = X / m^2
```

得到

```text
∂_mu [ sqrt(-g) ρ (m^2 / X) u^mu ] = 0
```

### 3.1 结论

即使连同连续性方程一起看：

```text
出现的仍然只是 X，
并没有被方程强制出显式 Z。
```

## 4. 那么 Z 可能从哪里来

如果你算到了“B 含 Z”，那通常意味着你在做的不是上面这个最窄的问题，而是更强的问题之一：

### 4.1 你事先允许 B 是更一般的函数

例如

```text
B = B(X,Z,ρ,...)
```

那么从 HJ 方程解出来的结果会告诉你：

```text
要成立，最终必须满足
B(X,Z,ρ,...) = (X - m^2)/(m^2 X)
```

也就是说：

```text
Z 依赖在这个方程层面并不是“被需要”，
而是会被压掉。
```

### 4.2 你在求的是“更强的同时满足条件”

例如你不只是要求 HJ 方程成立，还额外要求：

- 连续性方程与原理论完全同形
- 某种作用量层面匹配
- 某种测地线条件

那时确实可能出现新的 `Z` 依赖。

但那时解的对象已经不是“单独由 HJ 决定的 B”了。

### 4.3 你实际上已经在做类 III / 类 IV 的事情

只要真正的振幅结构 `r_mu` 进入张量 ansatz，
或进入附加约束，
那么 `Y`、`Z` 出现就是自然的。

但这已经超出了纯类 II 的最小问题。

## 5. 当前最准确的说法

所以，对“`A=1` 时 `B` 是否必然含 `Z`”这个问题，当前最准确的说法是：

```text
在纯类 II、且只由 HJ 方程决定 B 的情况下，
B 不被强制含 Z；
它被唯一固定为
B = (X - m^2)/(m^2 X)。
```

如果 `Z` 出现，那说明你同时加入了额外条件，或者实际上已经离开了纯类 II 的最小问题。

## 6. 对主线的影响

这个复核并不推翻上一份文档的主结论。

上一份文档的主结论是：

```text
类 II 一旦满足 HJ，
其连续性方程会自动变成加权流守恒，
因而泛型地不能再现原连续性方程。
```

这一点仍然成立。

因此：

```text
“A=1 时 B 不必含 Z”
与
“类 II 结构性失配”
这两件事并不矛盾。
```
