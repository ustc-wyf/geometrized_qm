# 002 量子势几何化的成功、失败与可接受判据

## 目标

为“量子势几何化”建立一组可操作的判据，用来评价任意候选几何变换

```math
g_{\mu\nu} \to \tilde g_{\mu\nu}
```

是否真正实现了本项目目标。

这里不直接构造变换，而是先回答一个更基本的问题：

什么样的结果才算“成功”？
什么样的结果只能算“形式改写”？
什么样的结果应直接判为不合格？

## 1. 研究对象再确认

当前最小模型是：

- 自由复 Klein-Gordon 场
- 固定背景时空，暂取闵氏时空作为起点
- Madelung 分解 `\psi = \sqrt{\rho} e^{iS}`
- 量子势

```math
Q = - \frac{\Box \sqrt{\rho}}{\sqrt{\rho}}
```

- 等价作用量形式

```math
I[\rho,S]
\simeq
\int d^4x\,
\rho\left(
\partial_\mu S \partial^\mu S - m^2 + Q
\right)
```

我们的目标不是随意重写这个作用量，而是找到一种具有物理意义的几何重述。

## 2. “成功”至少分三层

为了避免概念混乱，本项目把成功分成三层。

### 2.1 数学成功

存在一个明确的、可写下来的变换规则，使原理论可改写成新几何变量下的等价形式，并且这种改写不是自相矛盾的。

这只是最低门槛，不足以说明物理上成功。

### 2.2 动力学成功

在新变量下：

- 量子势不再以原来的显式势项形式出现
- 场方程仍与原理论等价
- Bohm 轨迹方程可被重写为某种几何自然运动，理想情况是测地线方程

这比纯数学改写更强，但仍不足以保证物理可接受。

### 2.3 物理成功

除了动力学成功，还必须满足：

- 可观测结果与原理论一致
- 因果结构不恶化
- 经典极限合理
- 新几何解释不是靠引入不可接受的病态完成的

只有同时满足这三层，才算本项目意义上的“成功”。

## 3. 成功判据

下面给出后续每个候选变换都要接受检查的成功判据。

### S1. 作用量层面成功

候选变换应使作用量在新变量中可写成“无显式量子势项”的形式，至少达到下述目标之一：

1. 原本的 `\rho Q` 项完全被吸收到 `\tilde g_{\mu\nu}` 或其诱导几何量中。
2. 原本的振幅梯度项不再以“外加量子势能”形式出现，而是被解释为新几何背景的一部分。

注意：

- 这里只要求“量子势不再作为外加势项出现”，不要求所有 `\rho` 依赖都消失。
- 如果只是把 `Q` 改名为某个新符号，但没有变成几何对象，不算成功。

### S2. 方程层面成功

在变换后，新的 Euler-Lagrange 方程必须与原 KG 理论等价，不能偷偷改变理论内容。

至少要检查：

- `\rho` 方程与 `S` 方程是否仍能一一对应回原理论
- 是否引入额外自由度
- 是否出现额外约束或丢失原有解

若新理论只覆盖原理论的一部分解，或引入额外非物理解，则不能直接算成功。

### S3. 轨迹层面成功

这是本项目最重要的判据之一。

若定义 Bohm 四动量

```math
p_\mu = \partial_\mu S,
```

则候选变换应使 Bohm 轨迹可解释为某个几何上的自然运动。理想目标是：

- 存在 `\tilde g_{\mu\nu}`，使轨迹满足 `\tilde g` 下的测地线方程
- 原先由量子势导致的“量子力”项，在新表述中转化为联络项或等价的几何惯性项

如果只有作用量改写成功，但轨迹方程仍显含一个外加“量子力”，则几何化不完整。

### S4. 观测等价成功

新表述不能改变原理论已知的实验预言。

至少应满足：

- 波函数满足的物理内容不变
- 散射、谱线、传播等可观测量与原 KG 理论一致
- 若只是变量重定义，则所有实验预言必须完全一致

如果新几何化带来了新的可观测偏差，那么它已经不只是“重解释”，而是新理论，需要额外论证。

### S5. 经典极限成功

在量子势消失或足够小的极限下，新旧几何应渐近一致。

理想表达是：

```math
Q \to 0
\quad \Longrightarrow \quad
\tilde g_{\mu\nu} \to g_{\mu\nu}.
```

如果经典极限下新度规仍与原度规明显偏离，就说明该几何化并没有正确退回经典理论。

## 4. 可接受判据

即使满足上面的“成功”表面条件，也还必须检查它是否物理可接受。

### A1. 协变性

变换必须写成协变形式，不能靠特定坐标系下的技巧性整理成立。

这意味着：

- 变换规则应使用张量对象构造
- 不能把某个特定参考系中的时间分量硬塞进定义
- 最终表述应能在一般坐标变换下保持形式一致

### A2. 可逆性

变换至少在目标适用域内应可逆。

原因很直接：

- 若不可逆，就不能保证新理论与原理论等价
- 不可逆通常意味着部分信息被压缩或丢失

所以必须明确：

- 变换在哪些区域可逆
- 哪些条件下会退化
- 退化点是否对应真实物理奇点还是纯参数病态

### A3. 因果结构可控

候选新度规不能为了消去量子势而随意破坏因果结构。

至少要检查：

- `\tilde g_{\mu\nu}` 的签名是否保持 Lorentz 型
- 光锥结构是否病态翻转
- 新的“类时/类空”判定是否仍可物理解释

如果量子势几何化只是把“超光速问题”转写成“新度规自己病了”，那并没有真正解决问题。

### A4. 不引入更严重的高阶病态

由于 `Q` 含有 `\Box \sqrt{\rho}`，它本身含二阶导数。若把它吸收到几何中，就要警惕：

- 新度规是否会依赖高阶导数
- 变分时是否引入更高阶方程
- 是否出现 Ostrogradsky 型风险或伪自由度

如果几何化的代价是把原来简单的二阶理论变成病态高阶理论，这种方案需要非常谨慎，通常应判为不优。

### A5. 解释增益真实存在

本项目做几何化，不只是为了换符号，而是为了得到更强的解释力。

因此要检查：

- 负粒子数密度是否得到更清晰的几何解释
- 超光速/类空四动量是否被重新解释为新几何中的正常运动
- 这种解释是否比原 Bohm/KG 叙述更自然，而不是更绕

如果没有解释增益，只是数学重写，那么它的研究价值有限。

## 5. 失败判据

下面这些情形应直接视为失败，或至少视为当前 ansatz 不合格。

### F1. 只消符号，不消结构

把 `Q` 从公式中挪走了，但它只是以另一个非几何函数重新出现。

这不算几何化，只是重命名。

### F2. 改变了原理论的解空间

如果新框架下允许的解不再与原 KG 理论一一对应，则该方案不再是“等价重述”。

### F3. 测地线解释失败

若轨迹动力学仍需外加非几何“量子力”，则几何化只完成了一半。

### F4. 经典极限错误

如果 `Q -> 0` 后新旧度规仍不一致，则该方案与经典极限不兼容。

### F5. 依赖不可接受的奇异点

若变换只能在 `\rho \neq 0`、`Q` 有界、某个分母不为零等极窄条件下成立，且这些限制正好排除了关键物理区域，那么方案意义会大幅下降。

### F6. 解释成本高于收益

若几何化后公式更复杂、病态更多、解释更弱，则即使形式上可行，也应视为研究上的不优路线。

## 6. 本项目当前建议的检查顺序

为了后续高效筛选 ansatz，建议每次都按同一顺序检查：

1. 先检验协变性与可逆性
2. 再检验作用量是否真正去掉显式量子势项
3. 再检验场方程是否等价
4. 再检验轨迹是否成为测地线
5. 最后检验经典极限与解释增益

这样可以避免在一个一开始就不可逆或不协变的 ansatz 上浪费大量代数推导。

## 7. 当前结论

到这一步，我们已经有了后续构造几何变换所需的两个基础：

1. 已知要被几何化的对象是什么：

```math
Q = -\frac{\Box\sqrt{\rho}}{\sqrt{\rho}}
```

2. 已知一个候选几何化方案必须满足什么条件：

- 作用量成功
- 方程等价
- 轨迹测地线化
- 观测等价
- 经典极限正确
- 协变、可逆、因果可控、无严重高阶病态

这意味着下一步终于可以开始讨论具体的 disformal ansatz 了，而且能有明确标准来判断它是不是值得继续推。

## 8. 下一步建议

下一步建议专注一件事：

写出最一般但仍可控的 disformal ansatz 候选集合，并说明每一种候选依赖了哪些对象：

- 仅依赖 `\rho`
- 依赖 `\partial_\mu S`
- 依赖 `\partial_\mu \rho`
- 同时依赖 `\partial_\mu S` 与 `\partial_\mu \rho`

然后先用本文件的判据做第一轮筛选，再决定优先推哪一条路线。
