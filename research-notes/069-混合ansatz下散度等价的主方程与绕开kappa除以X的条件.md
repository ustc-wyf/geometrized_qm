# 069 混合 ansatz 下散度等价的主方程与绕开 `\kappa/X` 的条件

## 目标

在一般混合 ansatz

```text
g~^(μν)
= C g^(μν)
+ D u^μu^ν
+ E(u^μr^ν+r^μu^ν)
+ F r^μr^ν
```

下，不再要求点态电流匹配

```text
J~^μ = J^μ
```

而只要求连续性方程作为 PDE 等价。检查这时：

1. 主方程是什么；
2. `A_r` 是否仍被迫为零；
3. `A_u = \kappa/X` 是否仍是结构性结论；
4. 在何种条件下可以绕开 `1/X` 主奇异。

---

## 1. 定义

记

```text
u_μ = ∂_μ S
r_μ = ∂_μ sqrt(ρ)
```

以及

```text
X = g^(μν)u_μu_ν
Y = g^(μν)u_μr_ν
Z = g^(μν)r_μr_ν .
```

再定义两个组合

```text
A_u := C + DX + EY
A_r := EX + FY
```

于是

```text
g~^(μν)u_ν = A_u u^μ + A_r r^μ .
```

原 `g` 系电流记为

```text
J^μ := j u^μ,
qquad
j := sqrt(|g|)ρ .
```

变换后电流记为

```text
J~^μ := sqrt(|g~|)ρ~ g~^(μν)u_ν .
```

再记

```text
s := sqrt(|g~|)ρ~ .
```

则

```text
J~^μ = s(A_u u^μ + A_r r^μ) .
```

---

## 2. HJ 方程只给出一条代数约束

若变换后 HJ 方程要求固定壳长

```text
g~^(μν)u_μu_ν = κ,
qquad κ ≠ 0 ,
```

则

```text
X A_u + Y A_r = κ .
```

因此

```text
A_u = (κ - Y A_r)/X .
```

这一步非常重要：在只用 HJ 方程时，`A_r` 仍然是自由的。

---

## 3. 变换后电流的标准分解

把上式代回电流：

```text
J~^μ
= s[(κ-YA_r)/X]u^μ + sA_r r^μ
= (sκ/X)u^μ + (sA_r/X)(Xr^μ-Yu^μ) .
```

定义

```text
W^μ := Xr^μ - Yu^μ ,
qquad
B := sA_r/X .
```

则

```text
J~^μ = (sκ/X)u^μ + B W^μ .
```

注意

```text
u_μ W^μ = X(u·r) - Y(u·u) = XY - YX = 0 ,
```

所以 `W^μ` 是相对于 `u_μ` 的正交修正方向。

---

## 4. 散度等价的主方程

若只要求连续性方程等价，一个自然的弱条件是

```text
∂_μ(J~^μ - J^μ) = 0 .
```

代入上式，得到主方程

```text
∂_μ { [sκ/X - j]u^μ + B W^μ } = 0 .
```

这就是散度等价下的一般条件。

也就是说，电流不必逐点等于 `j u^μ`，只要它与 `j u^μ` 的差是无散度流即可。

---

## 5. 与点态匹配的关系

若要求更强的点态匹配

```text
J~^μ = J^μ ,
```

则必须有

```text
B W^μ = 0
```

在 generic patch 上这就退回

```text
B = 0
-> A_r = 0
-> A_u = κ/X .
```

因此：

```text
A_u = κ/X
```

并不是 HJ 单独推出的，而是

```text
HJ + 点态电流匹配
```

共同推出的强结论。

---

## 6. 何时可以绕开 `1/X`

要让 `A_u` 在 `X -> 0` 时不发散，必须让

```text
κ - Y A_r = O(X) .
```

若 `Y ≠ 0`，可取

```text
A_r = κ/Y + Xχ
```

其中 `χ` 为有限函数。

则

```text
A_u = (κ - Y(κ/Y + Xχ))/X = -Yχ ,
```

于是 `A_u` 保持有限。

这说明：

```text
在 Y ≠ 0 的 patch 上，
只要放弃点态电流匹配，
就可以用 r 分量抵消原本的 κ/X 主奇异。
```

---

## 7. 这时连续性方程变成什么

代入

```text
A_r = κ/Y + Xχ ,
qquad
A_u = -Yχ ,
```

得到

```text
J~^μ = s[-Yχ u^μ + (κ/Y + Xχ) r^μ] .
```

散度等价要求

```text
∂_μ { [-sYχ - j]u^μ + s(κ/Y + Xχ)r^μ } = 0 .
```

这条式子在 `X -> 0` 时并不自动发散；只要

```text
s, χ, Y, r^μ
```

保持有限且 `Y ≠ 0`，它就是 regular 的。

---

## 8. `Y = 0` 时无路可绕

若某个 patch 上

```text
Y = u·r = 0 ,
```

则 HJ 约束退化成

```text
X A_u = κ .
```

从而仍然强制

```text
A_u = κ/X .
```

所以：

```text
真正能绕开 κ/X 的必要条件之一是 Y ≠ 0 .
```

---

## 9. 当前结论

### 9.1 强结论的适用范围

```text
A_u = κ/X
```

只是在

```text
HJ + 点态电流匹配
```

下成立的强结论。

### 9.2 弱结论

若只要求散度等价，则主方程是

```text
∂_μ { [sκ/X - j]u^μ + B(Xr^μ - Yu^μ) } = 0 .
```

在这种弱条件下：

- `A_r` 不再被迫为零；
- `A_u` 也不再被迫等于 `κ/X`；
- 在 `Y ≠ 0` 的 patch 上，确实存在绕开 `1/X` 主奇异的可能。

### 9.3 但这还不是最终成功

即便 `A_u` 不再发散，还需要继续检查：

1. `g~^(μν)` 的行列式与 signature；
2. `ρ~ = s / sqrt(|g~|)` 是否保持实且有限；
3. 该弱等价是否仍可由某个清晰的变分原理导出。

所以这一步的真正意义是：

```text
强 no-go 已被降级为强条件下的 no-go；
在弱散度等价口径下，混合 ansatz 出现了真正的逃逸窗口。
```
