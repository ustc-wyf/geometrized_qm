# 066 一般混合逆度规 ansatz 的行列式恒正条件

## 目标

分析一般混合逆度规 ansatz

```text
g~^(μν)
= C g^(μν)
+ D u^μ u^ν
+ E (u^μ r^ν + r^μ u^ν)
+ F r^μ r^ν
```

在什么条件下，行列式比值

```text
det(g~^(..)) / det(g^(..))
```

严格为正。

这里仍定义

```text
u_μ = ∂_μ S
r_μ = ∂_μ sqrt(ρ)

X = g^(μν) u_μ u_ν
Y = g^(μν) u_μ r_ν
Z = g^(μν) r_μ r_ν
Δ = XZ - Y^2
```

---

## 1. 一个最方便的写法

把 `u,r` 两个方向收成矩阵：

```text
U = [u  r]
```

并定义 `2×2` 对称矩阵

```text
A = [[D, E],
     [E, F]]

G = [[X, Y],
     [Y, Z]]
```

则一般混合 ansatz 可写成

```text
g~^(..)
= C g^(..)
+ U A U^T
```

---

## 2. 行列式总公式

在四维时，用矩阵行列式引理（matrix determinant lemma）可得

```text
det(g~^(..)) / det(g^(..))
= C^4 det( I_2 + C^(-1) A G )
```

把 `2×2` 行列式展开后，得到项目里一直在用的显式公式：

```text
det(g~^(..)) / det(g^(..))
= C^2 [ C^2 + C(DX + 2EY + FZ) + (DF - E^2)Δ ]
```

记

```text
Φ(C,D,E,F;X,Y,Z)
:= C^2 + C(DX + 2EY + FZ) + (DF - E^2)Δ
```

则

```text
det(g~^(..)) / det(g^(..)) = C^2 Φ
```

---

## 3. 严格正的充要条件

在四维里，

```text
C^2 ≥ 0
```

所以行列式比值的符号完全由 `Φ` 决定。

因此：

### 3.1 严格正

```text
det(g~^(..)) / det(g^(..)) > 0
```

当且仅当

```text
C ≠ 0
Φ > 0
```

### 3.2 退化

```text
det(g~^(..)) / det(g^(..)) = 0
```

当且仅当

```text
C = 0
```

或

```text
Φ = 0
```

### 3.3 负值

```text
det(g~^(..)) / det(g^(..)) < 0
```

当且仅当

```text
C ≠ 0
Φ < 0
```

所以，**一般 ansatz 的“行列式恒正条件”就是在所讨论的 patch 上始终满足**

```text
C ≠ 0
```

并且

```text
C^2 + C(DX + 2EY + FZ) + (DF - E^2)Δ > 0
```

---

## 4. 这个条件的几何意义

这个公式可以拆成两部分理解：

1. `C^2`
   来自与 `u,r` 平面正交的二维补空间
2. `Φ`
   反映 `u-r` 平面里的有效变换

因此：

```text
行列式恒正
```

本质上等价于：

```text
在正交补上不要把整体缩放退化掉，
并且在 u-r 平面上的有效 2×2 变换保持正定行列式。
```

---

## 5. 特例 1：纯共形

若

```text
D = E = F = 0
```

则

```text
Φ = C^2
```

所以

```text
det(g~^(..)) / det(g^(..)) = C^4
```

于是纯共形严格正的条件就是

```text
C ≠ 0
```

---

## 6. 特例 2：rank-1

若

```text
E = F = 0
```

则

```text
Φ = C^2 + CDX = C(C + DX)
```

故

```text
det(g~^(..)) / det(g^(..)) = C^3 (C + DX)
```

因此 strict positivity 条件是

```text
C ≠ 0
C(C + DX) > 0
```

若再要求恢复 HJ 方程并写成

```text
C + DX = κ / X
```

则条件变成

```text
C ≠ 0
C κ / X > 0
```

也就是说：

```text
sign(C) = sign(κ/X)
```

在该 patch 上必须成立。

---

## 7. 特例 3：投影型混合解

若取

```text
D = λZ
E = -λY
F = λX
```

并记

```text
s = λΔ
```

则

```text
Φ = (C + s)^2
```

于是

```text
det(g~^(..)) / det(g^(..))
= C^2 (C + s)^2
```

这就是为什么这一类解会显得特别漂亮：

```text
行列式比值自动是完全平方。
```

严格正条件退化成

```text
C ≠ 0
C + s ≠ 0
```

若再恢复 HJ 方程，

```text
C + s = κ / X
```

则 strict positivity 变成

```text
C ≠ 0
κ / X ≠ 0
```

但若还想保持同一支 Lorentzian 结构，则通常还会进一步要求

```text
C > 0
κ / X > 0
```

---

## 8. 特例 4：新解 `D=Z, E=-aY, F=aX, C=aXZ`

这时

```text
Φ = aXZ (XZ + aΔ) (2XZ - Y^2) / C
```

更直接地算得

```text
det(g~^(..)) / det(g^(..))
= a^3 X^2 Z^2 (2XZ - Y^2) (XZ + aΔ)
```

所以 strict positivity 条件是

```text
a^3 X^2 Z^2 (2XZ - Y^2) (XZ + aΔ) > 0
```

在 `X,Z ≠ 0` 的 patch 上，等价于

```text
a (2XZ - Y^2) (XZ + aΔ) > 0
```

这比投影型主解复杂得多。

---

## 9. 一个重要提醒

“行列式比值严格为正”只是：

```text
不退化
+ 与原度规行列式同号
```

的条件。

它**不是**

```text
自动保持同一 Lorentzian signature
```

的充分条件。

若还要保持同一支 Lorentzian 结构，通常还需要进一步检查：

1. 时间定向是否翻转
2. `u-r` 平面里的有效特征值是否跨过 0
3. 是否出现双锥（two-cone）冲突

因此：

```text
det 比值 > 0
```

是第一层条件，不是全部因果性条件。

---

## 10. 总结

四维里，一般混合逆度规 ansatz

```text
g~^(μν)
= C g^(μν)
+ D u^μ u^ν
+ E (u^μ r^ν + r^μ u^ν)
+ F r^μ r^ν
```

的行列式比值公式是

```text
det(g~^(..)) / det(g^(..))
= C^2 [ C^2 + C(DX + 2EY + FZ) + (DF - E^2)Δ ]
```

因此 strict positivity 的充要条件就是

```text
C ≠ 0
```

并且

```text
C^2 + C(DX + 2EY + FZ) + (DF - E^2)Δ > 0
```

这就是我们后续分析任何具体 `C,D,E,F` 时都应优先套用的总公式。
