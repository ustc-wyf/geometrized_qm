# 067 在 `X=0` 处让 `ρ~` 吸收奇异性的可能性

## 目标

检查一个新的思路：

```text
是否可以让 ρ~ 在 X=0 时趋于 0，
从而“吸收” u_μ 在 g 下变成 null 所带来的奇异？
```

这里需要严格区分三件事：

1. HJ 壳约束中的奇异
2. 连续性方程中的奇异
3. 行列式 / 体积元中的奇异

---

## 1. 真正需要恢复的不是 `g~u ∥ u`，而是电流

原 `g` 系连续性方程对应的电流是

```text
J^μ = sqrt(|g|) ρ u^μ
```

变换后 `g~` 系电流是

```text
J~^μ = sqrt(|g~|) ρ~ g~^(μν) u_ν
```

若要求精确恢复原连续性方程，一个最强但常用的条件是点态匹配

```text
J~^μ = J^μ
```

也就是

```text
sqrt(|g~|) ρ~ g~^(μν) u_ν = sqrt(|g|) ρ u^μ
```

---

## 2. 一个关键观察：只要原电流不为零，平行性其实自动回来

在某点若

```text
sqrt(|g|) ρ u^μ ≠ 0
```

则上式可改写成

```text
g~^(μν) u_ν
= [ sqrt(|g|) ρ / ( sqrt(|g~|) ρ~ ) ] u^μ
```

因此：

```text
只要 ρ~ 和 sqrt(|g~|) 不是把整个左边乘成 0，
那么 g~^(μν)u_ν 仍必须平行于 u^μ。
```

所以，“要求乘上 `ρ~` 后再平行”并不会在原电流非零的开区域内真正放宽方向条件；它只是在零集上才可能弱化。

---

## 3. 一般缩放公式

现在设在某一类变换族中，仍有

```text
g~^(μν)u_ν = A u^μ
```

于是自动有

```text
g~^(μν)u_μu_ν = A X
```

再记逆度规行列式比值

```text
R_inv := det(g~^(..)) / det(g^(..))
```

若改用协变度规行列式比值，则应定义

```text
R_cov := det(g~) / det(g) = 1 / R_inv .
```

于是协变体积元满足

```text
sqrt(|g~|) = sqrt(|g|) / sqrt(R_inv)
           = sqrt(|g|) sqrt(R_cov) .
```

若再要求电流点态匹配

```text
sqrt(|g~|) ρ~ A u^μ = sqrt(|g|) ρ u^μ
```

则得到一般公式

```text
ρ~ = ρ sqrt(R_inv) / A
   = ρ / ( A sqrt(R_cov) )
```

这条公式非常关键。它说明：

```text
ρ~ 在 X=0 附近是趋于 0、有限还是发散，
不是单由 A 决定，
而是由 R 与 A 的相对标度共同决定。
```

---

## 4. 若想把 `X=0` 映到 `g~` 下有限正壳长，会发生什么

设你想要的是

```text
g~^(μν)u_μu_ν -> L^2 > 0
```

当

```text
X -> 0
```

时。

由于

```text
g~^(μν)u_μu_ν = A X
```

这就强制

```text
A ~ L^2 / X
```

因此：

```text
只要仍保持 g~u = A u 这种结构，
把原来的 null 极限映到有限正壳长，
就必然引入 1/X 型奇异。
```

这一步和 `ρ~` 怎么选无关。

---

## 5. `ρ~` 能吸收什么，不能吸收什么

由

```text
ρ~ = ρ sqrt(R_inv) / A
```

可知：

- 它可以吸收的是
  ```text
  连续性方程中的电流奇异
  ```
- 它不能吸收的是
  ```text
  HJ 壳约束里把 X=0 映到非零壳长所必需的 A ~ 1/X 奇异
  ```

换句话说：

```text
ρ~ 最多能让 J~^μ 保持有限，
但不能让 g~^(μν)u_μu_ν = A X 的奇异缩放本身消失。
```

---

## 6. 三个代表性例子

### 6.1 纯共形

若

```text
g~^(μν) = C g^(μν)
```

则

```text
A = C
R_inv = C^4
```

所以

```text
ρ~ = ρ C
```

若 `A=C ~ 1/X`，则

```text
ρ~ ~ ρ / X
```

发散，而不是趋于 0。

因此：

```text
纯共形里，ρ~ 不能靠“变成 0”来吸收奇异。
```

### 6.2 rank-1 且 `C=1`

这一支上

```text
A = κ / X
R_inv = κ / X
```

因此

```text
ρ~ = ρ sqrt(R_inv) / A
    = ρ / sqrt(A)
    = ρ sqrt(X/κ)
```

所以

```text
ρ~ -> 0
```

当 `X -> 0`。

这里确实出现了用户提出的情形：

```text
ρ~ 在 X=0 附近趋于 0。
```

但注意：

```text
A = κ/X
```

仍然发散，HJ 奇异没有被消掉，只是电流保持了有限。

### 6.3 投影型混合主解且 `C=1`

这一支上

```text
A = κ / X
R_inv = (κ / X)^2
```

因此

```text
ρ~ = ρ sqrt(R) / A = ρ
```

所以这里

```text
ρ~ 既不发散，也不趋于 0。
```

电流的有限性完全由体积元因子来吸收：

```text
sqrt(|g~|) ~ X/κ
```

---

## 7. 一般判据：何时 `ρ~ -> 0`

由

```text
ρ~ = ρ sqrt(R) / A
```

若 `A -> ∞`，则：

- 若
  ```text
  R = o(A^2)
  ```
  则 `ρ~ -> 0`

- 若
  ```text
  R ~ A^2
  ```
  则 `ρ~` 保持有限非零

- 若
  ```text
  R >> A^2
  ```
  则 `ρ~` 发散

所以“让 `ρ~` 在 `X=0` 时为零”并非不可能，但这只是一类标度选择。

---

## 8. 最重要的结论

### 8.1 用户的想法有一部分是对的

在某些分支中，特别是 rank-1 `C=1` 分支里，

```text
ρ~ 的确会在 X -> 0 时趋于 0。
```

因此它确实可以帮助保持变换后电流有限。

### 8.2 但它不能消掉真正的结构性奇异

只要仍坚持

```text
g~^(μν)u_ν = A u^μ
```

且要求

```text
g~^(μν)u_μu_ν -> L^2 > 0
```

当 `X -> 0`，

就必然有

```text
A ~ L^2 / X
```

所以：

```text
ρ~ -> 0 只能吸收电流中的奇异，
不能吸收把 null 映到非零壳长所需的 1/X 奇异。
```

### 8.3 若真想避免这个结果

至少要放弃以下三者之一：

1. `g~^(μν)u_ν ∥ u^μ`
2. `X=0` 时映成非零固定壳长
3. 当前这类 regular Lorentzian 图册

---

## 9. 当前判断

因此，用户提出的思路应这样理解：

```text
让 ρ~ 在 X=0 处趋于 0，
可以让连续性方程里的电流保持良性；
但它不能让 HJ 壳约束中的主奇异自行消失。
```

所以这条思路是：

```text
一个“电流级 regularization”思路，
不是“度规级 regularization”思路。
```
