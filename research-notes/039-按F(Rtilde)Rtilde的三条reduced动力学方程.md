# 039 按 `F(R~)R~` 的三条 reduced 动力学方程

## 目标

在当前双束模型上，先写出三条用于数值积分比较的 reduced 动力学方程。

强调：

```text
这不是从三套总作用量严格变分后得到的最终闭合系统，
而是当前模型上最小、可跑、可比较的 reduced closure。
```

它的用途是：

```text
先看三种总作用量是否会把最终图样拉开。
```

## 1. 共同传播骨架

在准单色近似下，统一采用一维横向包络演化：

```text
i ∂_z A = -(1 / 2k0) ∂_x^2 A + V[A] A
```

其中：

- `z`：传播方向
- `x`：条纹方向
- `A(x,z)`：复包络

## 2. 共同初始条件

初始包络取双缝型高斯叠加：

```text
A(x,0)
= α exp[-(x+a/2)^2/(2w0^2)]
 + sqrt(1-α) exp[-(x-a/2)^2/(2w0^2)] exp[iφ0]
```

## 3. 几何代理量

在当前 reduced 模型里，我们用一个最小的“曲率代理量”：

```text
Q_x = (∂_x^2 sqrt(ρ)) / sqrt(ρ)
ε = Q_x / m^2
R_surr = ∂_x^2 ε
```

这里：

```text
ρ = |A|^2
```

`R_surr` 不是严格的 3+1d Ricci 标量，而是当前 reduced 模型里最接近“由波形结构诱导的局域曲率源”的代理量。

## 4. 三条 reduced 方程

### (I) `S_EH[g] + S_matter`

基线分支：

```text
i ∂_z A_g = -(1 / 2k0) ∂_x^2 A_g
```

也就是

```text
V_g = 0
```

### (II) `S_EH[g~] + S_matter`

最小几何反馈分支：

```text
i ∂_z A_g~ = -(1 / 2k0) ∂_x^2 A_g~ + λ R_surr[A_g~] A_g~
```

### (III) `sqrt(-g~) F(R~) R~ + S_matter`

取

```text
χ = ℓ^2 R_surr
F(χ) = 1 / sqrt(1 + χ^2)
```

则第三条分支写成

```text
i ∂_z A_F = -(1 / 2k0) ∂_x^2 A_F + λ F(χ[A_F]) R_surr[A_F] A_F
```

也就是

```text
V_F = λ R_surr / sqrt(1 + (ℓ^2 R_surr)^2)
```

## 5. 这个版本为什么值得先跑

因为它保留了三种总作用量最核心的相对结构：

```text
g-branch      : 无几何反馈
g~-branch     : 几何反馈 ~ R_surr
F(R~)-branch  : 几何反馈 ~ F(R_surr) R_surr
```

所以虽然它还不是最终严格理论，但已经足以先回答：

```text
把 F(R~) 引进后，
图样会不会比纯 g~ 分支更温和，
又会不会和基线分支显著不同。
```
