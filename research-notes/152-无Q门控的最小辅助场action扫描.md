# 152. 无 \(Q\) 门控的最小辅助场 action 扫描

日期：2026-05-07

## 1. 背景修正

用户指出：在 \(3+1d\) 中

\[
\tilde\nabla^\mu\mathcal C_{\mu\nu}=0
\]

有 4 个分量方程。

这点是正确的。此前“少一条方程”的说法只直接对应当前 `2+1 txz` 约化诊断。

更精确的理论判断是：虽然 \(3+1d\) 中分量数是 4，但当前 gBCD 张量壳

\[
\mathcal C_{\mu\nu}
=
A\tilde g_{\mu\nu}
+Buu+Crr+D\,ur
\]

的守恒主符号为

\[
P_{\nu I}(k)
=
\left[
k_\nu,\,
u_\nu(u\cdot k),\,
r_\nu(r\cdot k),\,
\frac12(r_\nu u\cdot k+u_\nu r\cdot k)
\right].
\]

这些列落在 \(\mathrm{span}\{k_\nu,u_\nu,r_\nu\}\) 内。因此一般主部 rank 至多为 3。也就是说：

\[
\boxed{
\text{问题不是简单的“方程个数少”，而是当前张量壳的主部结构仍有一个退化方向。}
}
\]

因此仍需要辅助场 action 或其它机制来选择剩余自由度。

## 2. 本轮目标

按用户要求，本轮暂时不考虑 \(Q\to0\) 条件，不使用 \(Q\)-门控。

只研究最小辅助场 action 中的三类项：

\[
\frac12 M^{IJ}\lambda_I\lambda_J,
\qquad
\frac12 K_t^{IJ}\tilde\nabla_t\lambda_I\tilde\nabla_t\lambda_J,
\qquad
\frac12 K_s^{IJ}\tilde\nabla_i\lambda_I\tilde\nabla_i\lambda_J.
\]

离散对应：

- `norm_weight`
- `time_weight`
- `space_weight`

## 4. tau=0 空间梯度扫描

输出：

`visualizations/equation_first_gbcd_aux_noq_space_scan_n96_tau0_sw_*/`

固定：

- `time_weight=1e-6`
- `norm_weight=1e-8`

扫描：

\[
space\_weight=0,10^{-12},10^{-11},10^{-10},10^{-9},10^{-8}.
\]

结果：

- `1e-12~1e-10` 基本没有改善；
- `1e-9` 开始轻微抬高残差；
- `1e-8` 把中心残差推到 `0.01996`，同时空间粗糙度和系数 p95 反而变差。

判断：

\[
\boxed{
\text{当前离散实现下，空间梯度项暂不作为默认闭合项。}
}
\]

它可能需要 body-fitted/协变 Laplacian 版本，而不是当前邻点差分惩罚。

## 6. 当前默认候选

`time_weight=1e-4` 最平滑，但 \(\tau=+3.5\) 中心残差到 `5.69%`，略超出当前 `1%~5%` 经验窗口。

`time_weight=1e-5` 是更稳折中：

- tau=-3.5 残差 `3.51%`
- tau=0 残差 `1.24%`
- tau=+3.5 残差 `5.02%`
- tau=+3.5 系数 p95 从 `1.214` 降到 `0.875`
- 时间粗糙度也明显下降

因此下一步默认候选暂取：

\[
\boxed{
norm\_weight=10^{-8},\quad
time\_weight=10^{-5},\quad
space\_weight=0.
}
\]

这对应最小辅助场 action：

\[
S_\lambda
\sim
\int\sqrt{|\tilde g|}
\left[
\frac12M^{IJ}\lambda_I\lambda_J
+\frac12K_t^{IJ}
\tilde\nabla_t\lambda_I
\tilde\nabla_t\lambda_J
\right],
\]

暂不加入 \(Q\)-门控和空间梯度项。

## 7. 下一步

下一步应把该默认候选用于：

1. 检查系数场是否能跨切片形成稳定的半局域演化关系；
2. 尝试从三层离散 Euler-Lagrange 方程还原连续时间方向的辅助场动力学；
3. 若要加入空间平滑，应先改成协变 Laplacian/弱形式，而不是当前简单邻点差分。
