# 038 三种总作用量的最小闭合原型演化

## 目标

在当前已经认可的双束 beam 模型上，先试一个最小闭合原型，让三种总作用量都给出可比较的演化结果。

必须先说明：

```text
这不是从三套总作用量严格变分得到的唯一闭合系统，
而是一个 reduced / exploratory closure。
```

它的用途是：

```text
先看三种作用量是否会把干涉图样明显拉开，
而不是冒充最终严格理论。
```

## 1. 共同初始条件

三种情况下都取相同初始包络

```text
A(x, z=0)
= α exp[-(x+a/2)^2/(2w0^2)]
 + sqrt(1-α) exp[-(x-a/2)^2/(2w0^2)] exp[iφ0]
```

其中：

- `α = 0.5`
- `a = 8`
- `w0 = 1`
- `k0 = 10`
- `φ0 = 0`

## 2. 共同传播骨架

在准单色近似下，统一采用 paraxial 包络演化：

```text
i ∂_z A = -(1/2k0) ∂_x^2 A + V[A] A
```

其中差异全部放进 `V[A]`。

## 3. 三种分支的反馈势

### 3.1 g-branch

```text
V_g = 0
```

即纯基线传播。

### 3.2 g~-branch

从当前几何化直觉抽取一个最小反馈源：

```text
Q_x = (∂_x^2 sqrt(ρ)) / sqrt(ρ)
ε = Q_x / m^2
R_surr = ∂_x^2 ε
```

然后定义

```text
V_g~ = λ R_surr
```

这里的 `R_surr` 是“由 g~ 引出的最小局域曲率代理量”。

### 3.3 F(Q) g~-branch

取

```text
F(Q_x) = 1 / (1 + (κ Q_x)^2)
```

定义

```text
V_F = λ F(Q_x) R_surr
```

## 4. 这套原型的意义

这套闭合原型保留了三种总作用量最核心的相对结构：

```text
g     : 无几何反馈
g~    : 几何反馈 ~ R_surr
F(Q)g~: 几何反馈 ~ F(Q) R_surr
```

因此它虽然不是严格最终版，
但已经能直接回答一个很实际的问题：

```text
三种作用量会不会在同一初始双束条件下
把最终干涉图样拉开。
```
