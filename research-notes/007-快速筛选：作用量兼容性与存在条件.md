# 007 快速筛选：作用量兼容性与存在条件

## 目标

这一份文档的任务是“快速筛选”，但筛选必须建立在已经算出的公式上。

本轮主要做三件事：

1. 检查最简单 HJ 解是否能兼容作用量
2. 明确哪些类的 HJ 解不是总存在，而是带条件存在
3. 把“可作为完整理论候选”和“目前只能算运动学重写”区分开

这里的筛选标准按优先级分成两层：

```text
第一层：HJ 吸收 Q 是否成立
第二层：作用量层面是否离原理论太远
```

完整理论还要继续检查场方程、测地线、经典极限、可逆性和因果结构，但这一步先做最快速的第一轮硬筛选。

## 1. 一个总观察

当前我们采用的几何候选作用量是

```text
I_geom = ∫ d^4x sqrt(-g~) ρ ( g~^(mu nu) ∂_mu S ∂_nu S - m^2 )
```

而原理论的等价形式是

```text
I_orig ≃ ∫ d^4x sqrt(-g) ρ ( X - m^2 + Q )
```

因此：

```text
如果我们只靠 HJ 方程去定 A,B,C，
那么最容易发生的事情是：
I_geom 与 I_orig 在壳上同时为零，
但壳外并不相同。
```

这意味着：

```text
HJ 吸收成功
不自动推出
作用量兼容成功。
```

## 2. 类 I：共形解的快速筛选

取最简单 HJ 解

```text
A = 1 - Q/m^2
```

则几何作用量密度为

```text
L_geom / (sqrt(-g) ρ) = A X - A^2 m^2
```

把它与原密度

```text
L_orig / (sqrt(-g) ρ) = X - m^2 + Q
```

相减，得到

```text
Delta_conf
= A X - A^2 m^2 - (X - m^2 + Q)
```

代入 `A = 1 - Q/m^2` 可化成

```text
Delta_conf
= Q ( m^2 - X - Q ) / m^2
```

### 2.1 结论

因此：

```text
Delta_conf = 0
```

只在

```text
X = m^2 - Q
```

也就是原 HJ 方程成立时才成立。

所以最简单共形解的结论是：

```text
它在 HJ 层面成功，
但在作用量层面只做到 on-shell 兼容，
没有做到 off-shell 等价。
```

### 2.2 快速筛选结果

```text
共形最简单解：
保留为运动学/几何解释候选，
暂不接受为完整作用量等价方案。
```

## 3. 类 II：相位单向 disformal 的快速筛选

你提的观察是对的。

若不考虑共形缩放，直接取

```text
A = 1
```

则 HJ 方程

```text
X / (1 + B X) = m^2
```

唯一解是

```text
B = (X - m^2) / (m^2 X)
```

若再用原 HJ 关系 `X = m^2 - Q`，可写成

```text
B = - Q / (m^2 X)
   = - Q / [ m^2 (m^2 - Q) ]
```

### 3.1 存在性

这个解存在的条件非常清楚：

```text
X ≠ 0
```

也就是

```text
m^2 - Q ≠ 0
```

若 `X = 0`，这个唯一解发散。

所以你的提醒是正确的：

```text
类 II 在 A=1 gauge 下确实有唯一解，
而且存在条件比类 III 更干净。
```

### 3.2 作用量偏差

现在几何作用量密度为

```text
L_geom / (sqrt(-g) ρ)
= X / sqrt(1 + B X) - m^2 sqrt(1 + B X)
```

令

```text
s = sqrt(1 + B X)
```

则与原密度的差为

```text
Delta_phase
= X/s - m^2 s - (X - m^2 + Q)
```

若代入 `B = -Q/(m^2 X)`，则

```text
1 + B X = 1 - Q/m^2
```

所以

```text
s = sqrt(1 - Q/m^2)
```

并且可化成

```text
Delta_phase
= (1 - s) ( X - m^2 + Q ) / s
```

### 3.3 结论

因此

```text
Delta_phase = 0
```

也同样只在原 HJ 方程壳上成立。

所以类 II 的最简单唯一解结论是：

```text
HJ 层面成功；
作用量层面仍只是 on-shell 兼容。
```

### 3.4 额外优点

不过类 II 仍然有一个明显优势：

```text
它的最简单解存在条件清晰，
经典极限也好：
Q -> 0 时 B -> 0
```

并且可逆性/签名条件也简单：

```text
1 + B X = 1 - Q/m^2 > 0
```

即需要

```text
Q < m^2
```

## 4. 类 III：振幅单向 disformal 的快速筛选

这一类的 HJ 条件给出关于 `A` 的二次方程

```text
m^2 A^2 + (C Z m^2 - X) A + C (Y^2 - X Z) = 0
```

所以它的存在性不是自动的，而是要求判别式

```text
Disc_r
= (C Z m^2 - X)^2 - 4 m^2 C (Y^2 - X Z)
```

满足

```text
Disc_r >= 0
```

### 4.1 结论

所以你这个判断也是对的：

```text
包含 r_mu 的这类方案不一定总有实解。
```

它至少需要判别式条件成立。

并且即使判别式成立，还要继续检查：

```text
A ≠ 0
A + C Z ≠ 0
```

否则逆度规仍会退化。

### 4.2 快速筛选结果

```text
类 III 不应被直接排除，
但它不是“无条件存在”的方案。
它是带判别式约束的条件存在类。
```

## 5. 类 IV：最小混合 disformal 的快速筛选

这一类的 HJ 解是

```text
A
= [ X (1 + gamma Z) - gamma Y^2 ]
 / [ m^2 Delta ]
```

其中

```text
Delta = (1 + alpha X)(1 + gamma Z) - alpha gamma Y^2
```

### 5.1 存在性

这里与类 III 不同，它不需要判别式求根，而是显式给出 `A`。

所以只要分母不为零，就有解：

```text
Delta ≠ 0
```

且还要保证分子不把 `A` 压成病态值。

### 5.2 结论

所以混合类在 HJ 层面的存在性，其实比类 III 更稳：

```text
它通常不是“判别式型存在”，
而是“分母不退化型存在”。
```

这也是为什么它在计算上更灵活。

### 5.3 但要注意

灵活不代表已经成功。

它仍然需要进一步通过：

- 作用量兼容
- 场方程等价
- 测地线与因果检查

## 7. 目前可以排除什么

到这一步，能做的“快速排除”其实是有限但明确的。

### 可排除的不是“整个类”，而是“最简单 gauge 的完整理论解释”

```text
1. 共形最简单解：
   不能当作完整作用量等价方案接受。

2. 相位单向最简单解（A=1）：
   也不能当作完整作用量等价方案接受。
```

理由都一样：

```text
它们目前只做到 HJ 吸收成功，
作用量差值只是在原 HJ 壳上才消失。
```

### 还不能排除的

```text
1. 共形类本身不能排除。
2. 相位单向类本身不能排除。
3. 振幅单向类不能排除，但要带判别式条件。
4. 混合类不能排除，而且目前最灵活。
```

## 8. 下一步最应该做什么

现在最有效率的下一步是：

```text
不要再泛泛比较，
而是直接做“作用量层面最简单尝试”。
```

顺序建议：

1. 共形类：
   固定 A = 1 - Q/m^2，看看如何修正几何作用量才能得到 off-shell 兼容

2. 相位单向类：
   固定 A = 1，B = (X - m^2)/(m^2 X)，看需要补什么结构才能从 on-shell 升级到 off-shell

3. 振幅单向类：
   选最简单的 `C`，检查是否有一个分支能在作用量层面自然更接近 `X - m^2 + Q`

4. 混合类：
   看它是否能最小地统一前面三类的优点
