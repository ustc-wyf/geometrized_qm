# 046 A 分支改写为 Helmholtz 边界值问题

## 核心想法

当前用户认可的几何图样是一个：

```text
单频 / 准单色 / 持续相干
```

的 `x-z` 干涉图样。

对 A 分支来说，这比“瞬态 Cauchy 初值问题”更自然地对应于：

```text
平直背景上的单频 Helmholtz 边界值问题
```

而不是：

```text
全边界 Dirichlet 的时间推进问题
```

## 方程

若

```text
ψ(x,z,t) = φ(x,z) e^{-iωt}
```

则平直 KG 方程

```text
(∂_t^2 - ∂_x^2 - ∂_z^2 + m^2) ψ = 0
```

化成：

```text
(∂_x^2 + ∂_z^2 + (ω^2 - m^2)) φ = 0
```

这就是二维 Helmholtz 方程。

## 数值意义

这样做有两个直接好处：

```text
1. A 分支终于和“持续相干入射的实验准备”说同一种语言。
2. 可以直接拿精确 Fourier benchmark 的边界数据做 Dirichlet 边界，
   看离散 Helmholtz 解是否贴近精确 benchmark。
```

## 与之前时间推进法的区别

之前的 leapfrog 时间推进器失败，不只是实现细节问题，
更因为：

```text
它在求解的其实是另一个问题。
```

对单频束流图样，
时间推进器需要同时正确处理：

```text
入射模
出射模
吸收边界
```

而 Helmholtz 边界值问题直接绕过了这层不必要的复杂度。

## 当前用途

这个步骤的目标不是立刻解决 B/C，
而是先把：

```text
A 分支 benchmark
```

彻底校准好。

只有 A 真正站稳以后，
才有资格去谈：

```text
同一种离散思想怎样平移到 B/C。
```
