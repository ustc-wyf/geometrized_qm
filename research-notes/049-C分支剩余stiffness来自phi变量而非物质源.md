# 049 C分支剩余 stiffness 来自 phi 变量而非物质源

## 当前 debug 状态

在修正了两处明显 bug 之后：

1. `B` 的 matter solver 已改成守恒型 Rusanov 通量更新；
2. `C` 的辅助场势函数已经修正到满足平直极限
   ```text
   phi = 1  =>  U(1)=0, U'(1)=0
   ```

此时重新做分解测试：

```text
Bflat  ~ Bfull
Cphi1 ~ Bfull
```

也就是说：

```text
只要把 phi 冻在 1，
C 分支就基本退回 B 分支。
```

## 新的隔离结果

### 1. 只演化 phi，固定 matter、固定 tau/beta

得到：

```text
|phi - 1|_max ~ 1.9e-2
```

说明：

```text
phi 本身并不会立刻剧烈跑飞。
```

### 2. 演化 tau/beta/phi，但固定 matter

即使此时 `rho,S` 完全不更新，也仍然看到：

```text
tau_max = 2.0
beta_max = 2.0
```

也就是几何变量直接顶到当前裁剪上界。

### 3. 参数趋势

代表性扫描：

```text
(mp, ell) = (300, 0.02), (300, 0.005), (3000, 0.02), (3000, 0.005)
```

观察到：

```text
mp 变大几乎不改变 blow-up 结果
ell 变小则明显更糟
```

## 解释

这说明当前 `Cfull` 的剩余问题不是：

```text
1. B 的物质通量更新
2. 物质源 mu 太强
3. phi=1 平直极限未对齐
```

而更像是：

```text
phi 变量本身作为传播辅助场时，
其势函数/源项在 phi -> 1 附近仍然非常 stiff
```

特别是：

```text
U_phi = R(phi)
```

在 `ell` 小时会对微小的 `phi-1` 偏离变得非常敏感。

## 当前最合理的下一步

后续修正不应再继续围绕：

```text
增大 mp
```

而应优先考虑：

```text
1. 改写 C 分支的辅助变量
   例如改成直接传播 chi = R~ 或与之更接近的变量

2. 或对 phi 方程采用更强的隐式/约束求解
```

当前最强判断是：

```text
C 分支剩余的主要 stiffness，
来自 phi 变量表示本身，而不是物质源项。
```
