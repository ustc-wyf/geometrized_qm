# 005 四类变换代回作用量与 HJ 方程的直接计算

## 目标

这一份文档不再做抽象筛选，而是直接把四类候选度规变换代回去计算。

我们统一考察下面这个“几何化后的候选作用量”：

```text
I_geom = ∫ d^4x sqrt(-g~) ρ ( g~^(mu nu) ∂_mu S ∂_nu S - m^2 )
```

然后与原来已经得到的等价形式比较：

```text
I_orig ≃ ∫ d^4x sqrt(-g) ρ ( X - m^2 + Q )
```

其中

```text
X = g^(mu nu) ∂_mu S ∂_nu S
Y = g^(mu nu) ∂_mu S ∂_nu sqrt(ρ)
Z = g^(mu nu) ∂_mu sqrt(ρ) ∂_nu sqrt(ρ)
Q = - Box sqrt(ρ) / sqrt(ρ)
```

目标不是立即证明两者完全一致，而是先把每一类变换代回之后的结构写清楚，看它们“最接近”原理论的哪一部分。

## 1. 统一记号

定义

```text
u_mu = ∂_mu S
r_mu = ∂_mu sqrt(ρ)
```

于是

```text
X = g^(mu nu) u_mu u_nu
Y = g^(mu nu) u_mu r_nu
Z = g^(mu nu) r_mu r_nu
```

比较时关注两个对象：

```text
K := sqrt(-g~) g~^(mu nu) u_mu u_nu
M := sqrt(-g~) m^2
```

则新作用量密度是

```text
L_geom = ρ ( K - M )
```

我们要看 `K - M` 能否被整理成 `X - m^2 + Q` 的形式。

## 2. 类 I：共形变换

取

```text
g~_mu nu = A g_mu nu
```

### 2.1 逆度规与体积因子

四维中有

```text
g~^(mu nu) = A^(-1) g^(mu nu)
sqrt(-g~) = A^2 sqrt(-g)
```

### 2.2 代回动能项

因此

```text
sqrt(-g~) g~^(mu nu) u_mu u_nu
= A^2 sqrt(-g) * A^(-1) X
= A sqrt(-g) X
```

质量项为

```text
sqrt(-g~) m^2 = A^2 sqrt(-g) m^2
```

所以

```text
L_geom / (sqrt(-g) ρ) = A X - A^2 m^2
```

若要与原理论匹配，就需要

```text
A X - A^2 m^2 = X - m^2 + Q
```

这等价于

```text
m^2 A^2 - X A + (X - m^2 + Q) = 0
```

### 2.3 对 HJ 方程的代回

若新几何中的 HJ 方程写成

```text
g~^(mu nu) u_mu u_nu - m^2 = 0
```

则共形变换给出

```text
A^(-1) X - m^2 = 0
```

也就是

```text
X = A m^2
```

而原来的 HJ 方程是

```text
X = m^2 - Q
```

所以只要取

```text
A = 1 - Q/m^2
```

在 HJ 方程层面上，共形变换其实可以直接吸收 `Q`。

### 2.4 当前结论

```text
共形变换没有被计算排除。
它在 HJ 方程层面可以直接吸收 Q。
```

真正待检验的是它能否在作用量层面也自然兼容。

## 3. 类 II：相位单向 disformal

取

```text
g~_mu nu = A g_mu nu + B u_mu u_nu
```

记

```text
alpha = B / A
```

### 3.1 逆度规与体积因子

逆度规为

```text
g~^(mu nu)
= A^(-1) g^(mu nu)
 - [ B / ( A (A + B X) ) ] u^mu u^nu
```

于是

```text
g~^(mu nu) u_mu u_nu = X / (A + B X)
```

体积因子为

```text
sqrt(-g~) = A^2 sqrt(-g) sqrt( 1 + alpha X )
```

### 3.2 代回作用量

动能项变成

```text
K = A sqrt(-g) X / sqrt(1 + alpha X)
```

质量项变成

```text
M = A^2 sqrt(-g) m^2 sqrt(1 + alpha X)
```

故

```text
L_geom / (sqrt(-g) ρ)
= A X / sqrt(1 + alpha X)
 - A^2 m^2 sqrt(1 + alpha X)
```

### 3.3 对 HJ 方程的代回

新 HJ 方程

```text
g~^(mu nu) u_mu u_nu - m^2 = 0
```

现在变成

```text
X / (A + B X) = m^2
```

即

```text
X = A m^2 / (1 - B m^2)
```

若要与

```text
X = m^2 - Q
```

匹配，则只需满足

```text
A m^2 / (1 - B m^2) = m^2 - Q
```

等价地

```text
A = (1 - Q/m^2) (1 - B m^2)
```

### 3.4 当前结论

```text
相位单向 disformal 同样没有被计算排除。
它可以很自然地重写 HJ / 质量壳结构。
```

但它代回作用量后的结构只涉及 `X`，并不直接生成 `Y`、`Z`。

## 4. 类 III：振幅单向 disformal

取

```text
g~_mu nu = A g_mu nu + C r_mu r_nu
```

记

```text
gamma = C / A
```

### 4.1 逆度规与体积因子

逆度规为

```text
g~^(mu nu)
= A^(-1) g^(mu nu)
 - [ C / ( A (A + C Z) ) ] r^mu r^nu
```

因此

```text
g~^(mu nu) u_mu u_nu
= [ X (A + C Z) - C Y^2 ] / [ A (A + C Z) ]
```

也可写成

```text
g~^(mu nu) u_mu u_nu
= [ X (1 + gamma Z) - gamma Y^2 ] / [ A (1 + gamma Z) ]
```

体积因子为

```text
sqrt(-g~) = A^2 sqrt(-g) sqrt( 1 + gamma Z )
```

### 4.2 代回作用量

动能项为

```text
K
= sqrt(-g) A [ X (1 + gamma Z) - gamma Y^2 ] / sqrt(1 + gamma Z)
```

质量项为

```text
M = sqrt(-g) A^2 m^2 sqrt(1 + gamma Z)
```

故

```text
L_geom / (sqrt(-g) ρ)
= A [ X (1 + gamma Z) - gamma Y^2 ] / sqrt(1 + gamma Z)
 - A^2 m^2 sqrt(1 + gamma Z)
```

### 4.3 对 HJ 方程的代回

新 HJ 方程给出

```text
[ X (1 + gamma Z) - gamma Y^2 ] / [ A (1 + gamma Z) ] = m^2
```

等价于

```text
X - A m^2 = gamma ( Y^2 - A m^2 Z ) / (1 + gamma Z)
```

### 4.4 当前结论

```text
振幅单向 disformal 也没有被计算排除。
而且它代回后会直接碰到 Y、Z 结构。
```

这说明它在作用量层面比前两类更直接接触量子势来源。

## 5. 类 IV：最小混合 disformal

取

```text
g~_mu nu = A g_mu nu + B u_mu u_nu + C r_mu r_nu
```

记

```text
alpha = B / A
gamma = C / A
Delta = (1 + alpha X)(1 + gamma Z) - alpha gamma Y^2
```

### 5.1 逆度规与体积因子

体积因子为

```text
sqrt(-g~) = A^2 sqrt(-g) sqrt(Delta)
```

对 `u_mu` 的收缩为

```text
g~^(mu nu) u_mu u_nu
= [ X (1 + gamma Z) - gamma Y^2 ] / [ A Delta ]
```

### 5.2 代回作用量

动能项为

```text
K
= sqrt(-g) A [ X (1 + gamma Z) - gamma Y^2 ] / sqrt(Delta)
```

质量项为

```text
M = sqrt(-g) A^2 m^2 sqrt(Delta)
```

因此

```text
L_geom / (sqrt(-g) ρ)
= A [ X (1 + gamma Z) - gamma Y^2 ] / sqrt(Delta)
 - A^2 m^2 sqrt(Delta)
```

### 5.3 对 HJ 方程的代回

新 HJ 方程变成

```text
[ X (1 + gamma Z) - gamma Y^2 ] / [ A Delta ] = m^2
```

也就是

```text
X (1 + gamma Z) - gamma Y^2 = A m^2 Delta
```

### 5.4 当前结论

```text
混合方案没有被预设保留，而是直接代回计算后显示：
它是最小的同时含 X、Y、Z 的方案。
```

所以它之所以继续作为主攻，是计算结果，不是偏好。

## 6. 四类方案代回后的并排结果

```text
共形：
L_geom / (sqrt(-g) ρ) = A X - A^2 m^2

相位单向：
L_geom / (sqrt(-g) ρ)
= A X / sqrt(1 + alpha X)
 - A^2 m^2 sqrt(1 + alpha X)

振幅单向：
L_geom / (sqrt(-g) ρ)
= A [ X (1 + gamma Z) - gamma Y^2 ] / sqrt(1 + gamma Z)
 - A^2 m^2 sqrt(1 + gamma Z)

最小混合：
L_geom / (sqrt(-g) ρ)
= A [ X (1 + gamma Z) - gamma Y^2 ] / sqrt(Delta)
 - A^2 m^2 sqrt(Delta)
```

其中

```text
Delta = (1 + alpha X)(1 + gamma Z) - alpha gamma Y^2
```

## 7. 目前能下的严格结论

### 结论 1

```text
共形变换没有被计算排除。
```

### 结论 2

```text
相位单向 disformal 没有被计算排除。
```

### 结论 3

```text
振幅单向 disformal 没有被计算排除。
```

### 结论 4

```text
最小混合 disformal 继续作为主攻，
是因为它直接计算后最小且同时含 X、Y、Z，
而不是因为先验偏好。
```

## 8. 下一步建议

下一步应开始做第一轮“拟合任务”：

```text
分别问四类方案：
能否通过选择 A,B,C
把 L_geom / (sqrt(-g) ρ)
整理成 X - m^2 + Q
```

更具体地说：

1. 先在 HJ 方程层面找每类方案吸收 `Q` 的最简单选择
2. 再检查这些选择能否从作用量层面兼容
