# 016 连续性方程中代入 X = m^2 - Q 后的精确比较

## 目标

复核上一份文档中关于连续性方程的判断，并按用户要求把

```text
X = m^2 - Q
```

明确代进去再比较。

问题是：

```text
在最简单消项解
g~^(mu nu) = g^(mu nu) + (Q/X^2) u^mu u^nu
```

下，新连续性方程在把 `X = m^2 - Q` 代入后，是否可能与原连续性方程等价？

## 1. 原连续性方程

定义

```text
u_mu = ∂_mu S
u^mu = g^(mu nu) ∂_nu S
J^mu = sqrt(-g) ρ u^mu
```

原理论的连续性方程是

```text
∂_mu J^mu = 0
```

## 2. 最简单消项解给出的新连续性方程

从上一份文档已经得到

```text
g~^(mu nu) u_nu = (1 + Q/X) u^mu
```

因此新连续性方程为

```text
∂_mu [ (1 + Q/X) J^mu ] = 0
```

而由 HJ 方程

```text
X + Q = m^2
```

可得

```text
1 + Q/X = (X + Q)/X = m^2 / X = m^2 / (m^2 - Q)
```

所以新连续性方程可精确写成

```text
∂_mu [ m^2/(m^2 - Q) * J^mu ] = 0
```

这一步就是用户要求补上的“把 X 的具体表达式代进去”。

## 3. 与原连续性方程的差异

把它展开：

```text
∂_mu [ m^2/(m^2 - Q) * J^mu ]
= m^2/(m^2 - Q) * ∂_mu J^mu
 + J^mu ∂_mu [ m^2/(m^2 - Q) ]
```

若原连续性方程成立，即

```text
∂_mu J^mu = 0
```

则新方程进一步化为

```text
J^mu ∂_mu [ m^2/(m^2 - Q) ] = 0
```

由于 `m^2` 是常数，这等价于

```text
J^mu ∂_mu Q = 0
```

也就是：

```text
量子势 Q 必须沿 Bohm 流线保持常数。
```

## 4. 精确结论

因此，新旧连续性方程之间的关系可以精确表述为：

```text
原连续性方程  +  J^mu ∂_mu Q = 0
    ⇒ 新连续性方程
```

反过来，若新连续性方程成立，也不能单独推出原连续性方程，除非额外知道

```text
J^mu ∂_mu Q = 0
```

所以最准确的结论是：

```text
把 X = m^2 - Q 明确代进去之后，
最简单消项解给出的连续性方程
与原连续性方程并不一般等价；
它们在且仅在 Q 沿流线不变时才重合。
```

## 5. 这说明什么

这一步并没有推翻上一份文档的判断，反而把差异写得更精确了：

```text
缺的不是某个模糊的“权重不对”，
而是一个明确的额外条件：
J^mu ∂_mu Q = 0
```

因此如果将来想保留这个最简单消项解，就有两种可能路线：

1. 证明在所关心的解族中，`Q` 的确沿 Bohm 流线守恒
2. 继续修改逆度规 ansatz，引入振幅结构，使新连续性方程自动回到原来的形式

## 6. 当前判断

到目前为止，最稳的说法应当是：

```text
最简单消项解：
拉氏量消项成功；
HJ 方程成功；
连续性方程一般不等价，
但在满足 J^mu ∂_mu Q = 0 的特殊解族上可以重合。
```
