# 044 2+1d 下三分支动力学方程与数值闭合

## 目标

在 `3+1d -> 2+1d` 一致约化后，保留 `x-z` 平面中两束 `±45°` 相交的几何，写出三种作用量分支可用于数值积分的动力学方程。

这里采用：

```text
y 方向为 Killing 方向
```

并进一步在约化后的 `2+1d` metric 上取 conformal gauge：

```text
ds^2 = e^{2τ(t,x,z)} (dt^2 - dx^2 - dz^2) - e^{2β(t,x,z)} dy^2
```

这不是“删自由度”，而是：

```text
1. 保留了 3+1d -> 2+1d 一致约化里的横向尺度场 β
2. 再用 conformal gauge 固定 2+1d metric 的其余坐标冗余
```

## 1. 共同物质作用量

项目一直坚持的物质部分是：

```text
S_matter
= ∫ dtdxdz sqrt(-g~) ρ~ ( g~^(ab) ∂_a S ∂_b S - m^2 )
```

在上面的 conformal gauge 下，

```text
sqrt(-g~) = e^{β+τ}
g~^(ab) = e^{-2τ} η^(ab)
η^(ab) = diag(1,-1,-1)
```

于是物质拉氏量变成：

```text
L_matter
= e^{β+τ} ρ [ (∂S)^2 - m^2 e^{2τ} ]
```

其中

```text
(∂S)^2 = S_t^2 - S_x^2 - S_z^2
```

对 `ρ` 与 `S` 变分得到：

```text
HJ:
S_t^2 - S_x^2 - S_z^2 = m^2 e^{2τ}

Continuity:
∂_t ( e^{β+τ} ρ S_t )
- ∂_x ( e^{β+τ} ρ S_x )
- ∂_z ( e^{β+τ} ρ S_z ) = 0
```

数值上更方便的变量是：

```text
E := sqrt( S_x^2 + S_z^2 + m^2 e^{2τ} )
S_t = -E
n := e^{β+τ} ρ E = - e^{β+τ} ρ S_t
```

则连续性方程改写成：

```text
n_t = - ∂_x [ (n/E) S_x ] - ∂_z [ (n/E) S_z ]
ρ = n / ( e^{β+τ} E )
```

这样物质部分是一个真正的一阶演化系统。

## 2. `R[g~]` 分支

从约化后的 Einstein-Hilbert 项

```text
S_B
= (M_P^2/2) ∫ dtdxdz e^{β+τ} [ R[h~] - 2 (∇β)^2 ]
+ S_matter
```

在 conformal gauge 下积分分部后，可写成：

```text
L_B
= M_P^2 e^{β+τ}
   [ (∂τ)^2 + 2 ∂β·∂τ - (∂β)^2 ]
+ e^{β+τ} ρ [ (∂S)^2 - m^2 e^{2τ} ]
```

其中

```text
∂f·∂g = f_t g_t - f_x g_x - f_z g_z
```

在物质壳上 `(∂S)^2 = m^2 e^{2τ}` 后，metric 方程可整理成：

```text
□τ = -1/2 [ (∂τ)^2 + (∂β)^2 + μ ]

□β = - ∂β·∂τ - (∂β)^2 - μ/2
```

这里

```text
□f = f_tt - f_xx - f_zz
μ = m^2 e^{2τ} ρ / M_P^2
```

于是 `R[g~]` 分支的全动力学变量是：

```text
(τ, β, ρ, S)
```

## 3. `F(R~) R~` 分支

当前选取

```text
f(R~) = R~ / sqrt(1 + (ℓ^2 R~)^2)
```

直接用 `Φ = f_R` 做 Legendre 反解会遇到 `R~` 正负分支问题。

因此数值上更干净的辅助场写法是：

```text
S_C
= (M_P^2/2) ∫ sqrt(-g~) [ f'(χ) (R~ - χ) + f(χ) ]
+ S_matter
```

其中 `χ(t,x,z)` 是独立辅助场。

记

```text
Φ(χ) := f'(χ) = ( 1 + (ℓ^2 χ)^2 )^(-3/2)
U(χ) := χ Φ(χ) - f(χ)
```

则约化后引力拉氏量可写成：

```text
L_C,grav
= M_P^2 e^{β+τ}
   [ 2 ∂Φ·∂τ
     + 2 Φ ∂β·∂τ
     + Φ (∂τ)^2
     + ∂Φ·∂β
     - 1/2 e^{2τ} U(χ) ]
```

这里 `Φ = Φ(χ)`。

对 `β, τ, χ` 的变分给出一组耦合方程。把它们写成显式的 `□τ, □β, □Φ` 形式最方便：

定义

```text
A = Φ (∂τ)^2 + ∂Φ·∂τ + 1/2 e^{2τ} U

B = (∂τ)^2 + ∂β·∂τ + (∂β)^2 + 1/2 e^{2τ} U_Φ

C = 2 Φ (∂β)^2
  + 2 Φ ∂β·∂τ
  + Φ (∂τ)^2
  + 3 ∂Φ·∂β
  + 2 ∂Φ·∂τ
  + 3/2 e^{2τ} U
  + 3 μ
```

其中

```text
μ = m^2 e^{2τ} ρ / M_P^2
U_Φ := dU/dΦ
```

则线性组合后的显式波动部分可写成：

```text
2 Φ □τ + □Φ = -A

2 □τ + □β = -B

2 Φ □τ + 2 Φ □β + 2 □Φ = -C
```

进一步解出：

```text
□τ = ( C - 2A - 2ΦB ) / ( 6Φ )

□β = -B - 2□τ

□Φ = -A - 2Φ□τ
```

所以 `F(R~)R~` 分支的全动力学变量是：

```text
(τ, β, Φ, ρ, S)
```

数值实现时用 `χ` 计算 `Φ(χ)` 与 `U(χ)`，并把 `Φ` 当作真正传播的辅助场。

## 4. `R[g]` 分支

这一支在当前项目里最微妙。

形式上它来自：

```text
S_A
= (M_P^2/2) ∫ sqrt(-g) R[g]
+ S_matter[g~,ρ,S]
+ S_constraint[g,g~,ρ,S]
```

它和 `R[g~]` 分支真正不同的关键，不在 Einstein-Hilbert 项本身，而在：

```text
g 与 g~ 的约束关系
```

也就是说，要把 `R[g]` 分支变成数值可跑的系统，还必须额外选定一个明确的 `2+1d` 约化闭合，例如：

```text
τ - σ = α[ρ,S]
β~ - β = 0
```

或者别的 rank-1 reduced closure。

在当前项目里，这个 `2+1d` reduced closure 还没有唯一确定。

所以：

```text
R[g]` 分支现在可以写出形式方程，
但若不再多加一个闭合假设，
还不能和 B/C 一样直接做唯一数值积分。
```
