# n384 三切片 gBCD 求解器升级与物理主线判断

日期：2026-05-07

## 本轮目标

用户要求尽快解决当前数值求解器问题，并回到物理问题主线。

本轮只改数值线代与诊断，不改 gBCD 方程本身：

\[
\tilde G_{\mu\nu}
=
\tilde T_{\mu\nu}/M_P^2
+\mathcal C_{\mu\nu},\qquad
\mathcal C_{\mu\nu}
=A\tilde g_{\mu\nu}+Buu+Crr+D\,u_{(\mu}r_{\nu)} .
\]

这里 \(A,B,C,D\) 仍先由 principal/full-conservation 约束投影给出，然后用 full-linear metric update 求下一时间片的 \(\delta\tilde g_+\)。

## 数值求解器升级

### 1. full-linear metric update 的向量化稀疏算子

修改文件：

- `kg_examples/solve_gbcd_full_linear_metric_update_sparse.py`

新增内容：

- `--operator-backend entry-arrays|python-column-loops`；
- 默认 `entry-arrays`；
- 将原先“稀疏列列表 + Python 内层循环”改成 scalar COO/entry arrays；
- matvec 使用 `numpy.bincount` 实现：
  \[
  y=B x,\qquad z=B^T y,
  \]
  其中 \(B=A/\text{column\_norm}\)。

结论：

- 算子逻辑不变；
- n=96 回归与旧结果同量级；
- n=384 分离态单次 full-linear update 可在约 2 分钟内完成，已经适合调试。

### 2. principal-constraint projection 的向量化 LSQR

修改文件：

- `kg_examples/fit_gbcd_principal_constraint_projection_sparse.py`

新增内容：

- 将 row-wise sparse LSQR 的 matvec 也改为 entry arrays + `numpy.bincount`；
- 分离态 `tau=-3.5` 的投影从原先 fast 版 500 步升级到 3000 步。

关键结果：

- `tau=-3.5` projection system residual：
  - 旧 500 步：`6.65e-2`
  - 新 3000 步：`5.39e-3`
- 但中心代数残差只从 weighted mean `1.31` 降到 `1.24`，说明分离态难点不是单纯 LSQR 没收敛。

## 三切片 n=384 core10 结果

共同设置：

- `full_resolution=384`
- `window_um=9`
- `fit_region=core10`
- `core10` 定义：在 fitting mask 内 \(\rho\ge 0.1\rho_{\max}\)
- `force_penalty=principal_penalty=1e4`
- metric update：CG normal equations, `cg_maxiter=6000`, `ridge=1e-6`

### tau = 0，干涉中心

输出：

- `visualizations/equation_first_gbcd_sparse_pipeline_n384_tau0_core10_pen1e4/`
- 诊断图：`visualizations/equation_first_gbcd_sparse_pipeline_n384_tau0_core10_pen1e4/diagnostics/gbcd_metric_update_diagnostic_maps.png`

结果：

- before residual weighted mean：`1.1349`
- linear after residual weighted mean：`5.53e-5`
- exact nonlinear after residual weighted mean：`0.00644`
- exact p95：`0.04337`
- core50 exact weighted mean：`7.56e-5`
- corrected metric determinant：全 mask 正，最小约 `13.12`

解释：

- 干涉中心的最强主支撑区域非常好；
- 这支持 gBCD 在干涉核心物理区不是数值上立即失败。

### tau = -3.5，左侧分离态

输出：

- projection：`visualizations/equation_first_gbcd_principal_constraint_projection_sparse_n384_taum3p5_core10_pen1e4_iter3000/`
- metric update：`visualizations/equation_first_gbcd_sparse_pipeline_n384_taum3p5_core10_pen1e4_iter3000_coeff_cg6000/`
- 诊断图：`visualizations/equation_first_gbcd_sparse_pipeline_n384_taum3p5_core10_pen1e4_iter3000_coeff_cg6000/diagnostics/gbcd_metric_update_diagnostic_maps.png`

结果：

- before residual weighted mean：`1.2408`
- linear after residual weighted mean：`0.1145`
- exact nonlinear after residual weighted mean：`0.1458`
- exact p95：`0.8302`
- core50 exact weighted mean：`0.1124`
- corrected metric determinant：出现 1 个非正/近零点，最小约 `-9.89e-16`

阻尼扫描：

- 对同一 \(\delta\tilde g_+\) 扫描 \(\alpha\in[0,1.5]\)；
- 最优仍在 `alpha=1.0`；
- 欠阻尼不能压低残差。

解释：

- 左侧分离态仍是当前主要卡点；
- 不是 Newton 更新过冲；
- 更可能是当前 core10 区域、软 penalty 约束、或辅助场代表元规范在分离态下不够好。

### tau = +3.5，右侧分离态

输出：

- projection：`visualizations/equation_first_gbcd_principal_constraint_projection_sparse_n384_taup3p5_core10_pen1e4_iter3000/`
- metric update：`visualizations/equation_first_gbcd_sparse_pipeline_n384_taup3p5_core10_pen1e4_iter3000_coeff_cg6000/`
- 诊断图：`visualizations/equation_first_gbcd_sparse_pipeline_n384_taup3p5_core10_pen1e4_iter3000_coeff_cg6000/diagnostics/gbcd_metric_update_diagnostic_maps.png`

结果：

- before residual weighted mean：`1.5946`
- linear after residual weighted mean：`0.01189`
- exact nonlinear after residual weighted mean：`0.03864`
- exact p95：`0.1083`
- core50 exact weighted mean：`0.01879`
- corrected metric determinant：全 mask 正，最小约 `7.22e-4`

解释：

- 右侧分离态明显好于左侧分离态；
- 三切片不呈完全时间反演对称，可能来自窗口裁剪、相位方向、有限差分时间探针或当前代表元规范的时间方向偏置。

## 当前判断

1. 低分辨率和未收敛 fast 投影曾经显著污染判断。本轮已把这两个问题压下去。

2. 高分辨率 solver 现在不是“不能跑”，而是“可跑但左侧分离态仍残差偏大”。

3. 干涉中心和右侧分离态的结果支持继续推进 gBCD 物理主线；左侧分离态要求下一轮处理代表元规范/区域闭合，而不是再盲目换线性求解器。

4. 阻尼线搜索不解决左侧问题，因此不应把 under-relaxation 当成物理解。

## 下一步

优先级：

1. 对 `tau=-3.5` 做局部误差解剖：把高残差点按 \(\rho\)、det、\(|\delta g|/|g|\)、mask 边界距离、张量分量方向分层。

2. 把 soft penalty 的 principal/full-conservation 约束升级成更接近 hard/nullspace 的稀疏投影，至少先在 `tau=-3.5` 对照。

3. 检查当前辅助场代表元规范是否引入时间方向偏置：比较 `time_weight=0,1e-6,1e-5` 与空间平滑项。

4. 在三切片都达到可接受残差后，再把它们接入短时 D 支物质推进，比较 \(\rho^\tilde\) 拉回 \(g\) 表象后的演化与 A 支差异。
