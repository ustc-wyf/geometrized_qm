# 012 一般类 II 能否同时满足 HJ 与连续性方程

## 目标

这一份文档直接回答当前最关键的问题：

```text
一般类 II
g~_mu nu = A g_mu nu + B u_mu u_nu
```

在当前几何作用量 ansatz 下，能否同时满足：

1. 正确的 HJ 方程
2. 正确的连续性方程

这里严格采用当前已经修正后的正确顺序：

```text
先对新作用量变分，
再代回变换。
```

并采用密度变换约定：

```text
sqrt(-g) ρ = sqrt(-g~) ρ~
```

## 1. 新作用量与变分方程

从新变量作用量出发：

```text
I_geom[ρ~,S;g~]
= ∫ d^4x sqrt(-g~) ρ~ ( g~^(mu nu) ∂_mu S ∂_nu S - m^2 )
```

先变分得到：

```text
HJ:
g~^(mu nu) ∂_mu S ∂_nu S = m^2

Continuity:
∂_mu [ sqrt(-g~) ρ~ g~^(mu nu) ∂_nu S ] = 0
```

再用

```text
sqrt(-g~) ρ~ = sqrt(-g) ρ
```

把连续性方程写回旧变量：

```text
∂_mu [ sqrt(-g) ρ g~^(mu nu) ∂_nu S ] = 0
```

这就是类 II 要与原理论比较的真正方程。

## 2. 类 II 的逆度规

令

```text
u_mu = ∂_mu S
X = g^(mu nu) u_mu u_nu
```

并取

```text
g~_mu nu = A g_mu nu + B u_mu u_nu
```

则其逆度规为

```text
g~^(mu nu)
= A^(-1) g^(mu nu)
 - [ B / ( A (A + B X) ) ] u^mu u^nu
```

从而有两个关键收缩：

```text
g~^(mu nu) u_mu u_nu = X / (A + B X)
```

以及

```text
g~^(mu nu) u_nu = u^mu / (A + B X)
```

这两个公式几乎已经决定了整个结论。

## 3. HJ 方程给出的条件

新 HJ 方程要求

```text
X / (A + B X) = m^2
```

等价于

```text
A + B X = X / m^2
```

这是类 II 同时满足原 HJ 方程的必要条件。

注意这里一个非常重要的事实：

```text
HJ 方程只固定 A + B X 这个组合，
而不是分别固定 A 与 B。
```

## 4. 连续性方程在类 II 中的形式

由

```text
g~^(mu nu) u_nu = u^mu / (A + B X)
```

得到新连续性方程：

```text
∂_mu [ sqrt(-g) ρ u^mu / (A + B X) ] = 0
```

原理论的连续性方程则是

```text
∂_mu [ sqrt(-g) ρ u^mu ] = 0
```

因此，要让两者完全一致，至少需要

```text
1 / (A + B X) = 常数
```

更精确地说，若要两条方程对同一组场构型等价成立，则这个系数不能在时空上任意变化。

## 5. 联合 HJ 与连续性方程

现在把 HJ 条件

```text
A + B X = X / m^2
```

代入连续性方程，得到

```text
∂_mu [ sqrt(-g) ρ (m^2 / X) u^mu ] = 0
```

这说明：

```text
一旦类 II 被要求满足新几何的 HJ 方程，
它的连续性方程就自动塌缩成上面这一种形式，
与 A、B 的具体分拆无关。
```

也就是说：

```text
类 II 的 A、B 自由度
在“同时要求 HJ 成立”后，
对连续性方程已经没有进一步调节能力了。
```

这是一个非常强的结果。

## 6. 与原连续性方程比较

原理论要求

```text
∂_mu J^mu = 0
```

其中

```text
J^mu = sqrt(-g) ρ u^mu
```

而类 II 在满足 HJ 后给出的是

```text
∂_mu [ (m^2 / X) J^mu ] = 0
```

把它展开：

```text
∂_mu [ (m^2 / X) J^mu ]
= (m^2 / X) ∂_mu J^mu
 - (m^2 / X^2) J^mu ∂_mu X
```

若原理论的连续性方程成立，即

```text
∂_mu J^mu = 0
```

则类 II 的连续性方程还要求额外满足

```text
J^mu ∂_mu X = 0
```

也就是

```text
沿 Bohm 流线方向，
X 必须保持不变。
```

这不是原理论的一般恒等式。

## 7. 直接结论

因此，在当前作用量 ansatz 下：

```text
一般类 II 不可能在泛型情况下
同时满足原 HJ 方程和原连续性方程。
```

更准确地说：

```text
若要求类 II 的新 HJ 方程与原 HJ 方程一致，
则它的新连续性方程自动变成
∂_mu [ (m^2 / X) J^mu ] = 0，
这一般不等于原连续性方程。
```

### 7.1 只有在特殊情形下才可能一致

两者只有在特殊情形下才会重合，例如：

```text
1. X = 常数
2. 或更弱地，J^mu ∂_mu X = 0
```

但这些不是原理论的一般结论，而只是特殊解族条件。

## 8. 一个更强的理解

这个结果说明：

```text
类 II 的问题不是选了错误的 gauge，
而是这个作用量 ansatz 下的结构性问题。
```

因为：

1. HJ 方程只固定 `A + B X`
2. 连续性方程只依赖 `1 / (A + B X)`
3. 一旦 HJ 成立，连续性方程就自动变成 `m^2 / X` 加权形式

所以：

```text
不管你怎么重新分配 A 和 B，
只要还留在这个类 II + 当前作用量 ansatz 里，
连续性方程的偏差结构就不会消失。
```

## 9. 对类 I 的推论

共形类其实是类 II 的子类 `B = 0`。

因此它的失败现在也可以被看成类 II 结构性失败的特例：

```text
共形类之所以一般不行，
不是偶然，
而是因为它同样属于
“连续性方程只会得到加权流”
这一结构。
```

## 10. 当前筛选结论

在当前几何作用量 ansatz 下：

```text
I_geom = ∫ d^4x sqrt(-g~) ρ~ ( g~^(mu nu) ∂_mu S ∂_nu S - m^2 )
```

并采用

```text
sqrt(-g) ρ = sqrt(-g~) ρ~
```

之后，我们已经可以做出一个比之前强得多的结论：

```text
类 II 作为一个整类，
在泛型情况下不能同时再现原 HJ 方程与原连续性方程。
```

这不是“某个最简单解失败”，而是当前 ansatz 下的整类结构性失败。

## 11. 这意味着什么

现在我们终于可以更果断地收缩路线了：

```text
如果坚持当前这种最简几何作用量 ansatz，
那么类 I 和类 II 基本可以退出主线。
```

剩下最值得继续深推的是：

```text
1. 类 III：振幅单向
2. 类 IV：混合类
```

因为只有它们会把 `Y`、`Z` 结构真正带进连续性方程和 HJ 方程里，仍有机会修正这种失配。
