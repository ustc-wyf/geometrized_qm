## 通过 ell 变化判断左弧尖峰性质

时间：2026-05-01

### 目的

在固定 `t=16` 左弧窗口上，把 `ell` 从 `100` 改到 `10` 与 `1`，观察：

1. 过渡结构是否更容易被解析；
2. 尖峰是变成更规整的过渡层结构，还是仍然无规律乱跳。

### 重要提醒

这不是纯粹的分辨率测试，因为改 `ell` 本身就在改理论：

\[
f_C(\tilde R)=\frac{\tilde R}{\sqrt{1+(\ell^2\tilde R)^2}},
\qquad
f_D(\tilde R)=\frac{\tanh(\ell^2\tilde R)}{\ell^2}.
\]

所以这里得到的是“尖峰性质的线索”，不是严格的数值收敛证明。

- 时间：`t=16`
- 物理窗口（左弧）：
  \[
  -7.4 \le x \le -2.2,\qquad 2.6 \le z \le 6.2
  \]
- 分辨率：`64, 96, 128, 192`
- 比较对象：`C`、`D`

### 结果一：ell=10 时，尖峰开始明显“贴着严格过渡层”

以 `D` 支为例：

- `96x96`：
  - `strict_support_count = 8`
  - `hotspot_inside_strict_fraction = 1.0`
- `128x128`：
  - `strict_support_count = 25`
  - `hotspot_inside_strict_fraction = 1.0`
- `192x192`：
  - `strict_support_count = 44`
  - `hotspot_inside_strict_fraction = 0.636...`

`C` 支也呈现同类现象。

这说明：

\[
\boxed{
当 \ell \text{ 变小、过渡层变厚后，
原来那些看起来很乱的尖峰会更清楚地“贴着过渡层”出现。}
}
\]

所以 `ell=100` 下那些超尖、超薄的热点，确实很可能是“真实过渡层 + 欠分辨”叠加出来的。

### 结果二：ell=1 时，孤立热点基本消失，但残差仍然广泛偏大

对 `ell=1`，左右弧窗口里：

- `hotspot_support_count = 0` 在大多数分辨率下成立；
- 但 `strict_support_count` 和 `broad_support_count` 都明显增大；
- `p95` 仍然在 `10^3` 量级，而不是降到很小。

以 `D` 支为例：

- `96x96`：`p95 ~ 2.54e3`
- `128x128`：`p95 ~ 1.12e3`
- `192x192`：`p95 ~ 1.14e3`

这说明：

\[
\boxed{
当 \ell \text{ 更小、过渡层更厚且更容易解析时，
原来的“像素级孤立尖峰”大多消失，
但左弧区域本身仍保留一整片较大的残差。}
}
\]

也就是说，尖峰在变成“更平滑的过渡失配”，而不是凭空消失。

### 结果三：尖峰成分与物理失配成分可以分开

综合 `ell=100,10,1` 三组结果，当前最合理的分解是：

#### A. 真正的物理结构

- 左弧区域本身稳定存在；
- 过渡带/严格过渡层的重心在固定物理窗口内是稳定的；
- 当 `ell` 变小时，这种结构更容易被解析出来。

这部分应视为真实物理几何结构。

#### B. 欠分辨尖峰

- `ell=100` 下最夸张的 `abs_max` 与最大点位置乱跳；
- `ell=10` 时尖峰开始附着到严格过渡层；
- `ell=1` 时孤立热点大多消失，转成较平滑的整片残差。

这说明原先最夸张的“针尖状爆点”主要不是独立的物理奇性，而是：

\[
\boxed{
\text{很薄的真实过渡层在粗网格上被数值化成的欠分辨尖峰。}
}
\]

### 最终判断

\[
\boxed{
当前这些尖峰既不是纯物理奇性，也不是纯随机网格噪声。}
}
\]

更准确地说：

\[
\boxed{
它们的载体是左弧这一真实过渡结构；
而它们最夸张的“针尖型爆点”外观，主要来自过薄层在大 \ell\ 下的欠分辨数值表现。}
}
\]

### 对后续方法的意义

1. `ell=100` 下不应再把 `abs_max` 当作唯一质量指标。
2. 更稳妥的指标是：
   - 主支撑区 `p95`
   - 左弧固定窗口 `p95`
   - 过渡带/热点重心稳定性
3. 真正的后续数值路线仍应是：
   - 固定物理窗口
   - 局部细化
   - 局部隐式校正
4. 现在已经有足够理由把 `ell=100` 的极端尖峰解释成“过薄过渡层的欠分辨表现”，而不是单纯当作理论病态。
