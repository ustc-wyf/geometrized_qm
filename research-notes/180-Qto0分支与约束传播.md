# \(Q\to0\) 分支与约束传播

日期：2026-05-08

## 一句话结论

当前 trace0 proposal 还必须补两类规则：

1. **分支规则**：
   \[
   Q\to0\quad\Longrightarrow\quad C_{\mu\nu}\to0,
   \]
   否则投影方程只保证 Einstein 残差落在 \(E=\mathrm{span}\{\tilde g,uu,rr,ur\}\)，不能自动回到普通 Einstein 方程。

2. **传播/兼容规则**：
   \[
   \tilde\nabla^\mu C_{\mu\nu}=0
   \]
   在精确解上应由 Bianchi 恒等式和物质守恒推出；但在初值构造、近似求解和数值投影中必须作为硬兼容条件处理，不能靠逐点代数拟合自动满足。

这两条都不是任意数值修补，而是让 equation-first 方程成为一个自洽理论的必要条件。

## 1. 当前 proposal 回顾

当前主候选是：

\[
\tilde G_{\mu\nu}
=
\frac{1}{M_P^2}\tilde T_{\mu\nu}
+C_{\mu\nu},
\]

\[
C_{\mu\nu}\in E,
\qquad
E=
\mathrm{span}
\{
\tilde g_{\mu\nu},
u_\mu u_\nu,
r_\mu r_\nu,
u_{(\mu}r_{\nu)}
\},
\]

\[
C^\mu{}_\mu=0,
\qquad
\tilde\nabla^\mu C_{\mu\nu}=0.
\]

投影写法是：

\[
\Pi_E^\perp\mathcal R_{\mu\nu}=0,
\qquad
\mathcal R_{\mu\nu}
=
\tilde G_{\mu\nu}
-
\tilde T_{\mu\nu}/M_P^2.
\]

trace0 状态方程是：

\[
\tilde g^{\mu\nu}\Pi_E\mathcal R_{\mu\nu}=0.
\]

## 2. 为什么 \(Q\to0\Rightarrow C\to0\) 不是自动结论

若只要求：

\[
\Pi_E^\perp\mathcal R=0,
\]

则只能推出：

\[
\mathcal R_{\mu\nu}=C_{\mu\nu}\in E.
\]

即使 \(Q=0\)，数学上仍可能有：

\[
C_{\mu\nu}\neq0,
\qquad
C_{\mu\nu}\in E,
\qquad
C^\mu{}_\mu=0,
\qquad
\tilde\nabla^\mu C_{\mu\nu}=0.
\]

这会给出一个“非 GR 的经典分支”。如果我们希望弱量子势或经典极限回到普通 Einstein 方程，就必须额外选择 GR 分支：

\[
\boxed{
Q\to0\Rightarrow C_{\mu\nu}\to0.
}
\]

因此 \(Q\to0\) 条件的地位类似边界条件、分支选择或正则性条件，而不是 trace0 方程的代数推论。

## 3. 应该用哪个 \(Q\)

严格说，当前理论已经在 \(\tilde g\) 表象中写方程，因此不能粗糙地把旧 \(g\) 表象的 \(Q\) 当作基本场直接塞入方程。

最自然的 \(\tilde g\)-表象量子强度标量是：

\[
\tilde Q_\rho
\equiv
\frac{\tilde\square\sqrt{\tilde\rho}}{\sqrt{\tilde\rho}}.
\]

由于

\[
r_\mu=\tilde\nabla_\mu\ln\sqrt{\tilde\rho},
\]

有恒等式：

\[
\boxed{
\tilde Q_\rho
=
\tilde\nabla_\mu r^\mu+r_\mu r^\mu.
}
\]

因此它是由 \((\tilde g,\tilde\rho)\) 局域构造出的协变标量。

对 massive branch，可取无量纲量：

\[
\mathcal q
=
\frac{\tilde Q_\rho}{m^2}.
\]

对 massless branch，不能除以 \(m^2\)，必须引入外部物理尺度或局部波数尺度，例如：

\[
\mathcal q_0
=
\ell_Q^2\tilde Q_\rho,
\]

其中 \(\ell_Q\) 需要由实验波包尺度、边界条件或理论常数指定。这也是无质量分支必须单独讨论的原因之一。

## 4. 推荐的分支条件写法

不要写成：

\[
C^\mu{}_\mu=F(Q).
\]

这已经被前面的 trace/Q 检验否定，而且它只约束 trace，不约束整个 \(C_{\mu\nu}\)。

推荐写成张量范数条件：

\[
\boxed{
\|C\|_W
\le
K\,\chi(|\mathcal q|),
\qquad
\chi(0)=0,
\qquad
\chi(s)>0\ (s>0).
}
\]

其中 \(W\) 是非退化张量范数，\(K\) 是有界正则系数。

等价地，在非退化 \(E\)-patch 内，把

\[
C_{\mu\nu}=\lambda_I E^I_{\mu\nu}
\]

写成：

\[
\boxed{
\lambda_I
=
\chi(|\mathcal q|)\,\hat\lambda_I,
\qquad
\hat\lambda_I\text{ 有界}.
}
\]

这说明 \(Q\to0\) 分支选择的是整个允许源 \(C_{\mu\nu}\) 消失，而不是某一个分量或 trace 消失。

## 5. 与辅助场 action 的关系

如果未来 action 化，可以把该条件做成辅助场能量惩罚：

\[
S_{\lambda,\mathrm{mass}}
=
\frac12
\int\sqrt{|\tilde g|}
\,
\mu(\mathcal q)
M^{IJ}\lambda_I\lambda_J,
\]

\[
\mu(\mathcal q)
=
\frac{\mu_0}{(\epsilon+|\mathcal q|)^p}.
\]

当 \(\mathcal q\to0\) 时，\(\mu\to\infty\)，有限能量分支要求：

\[
\lambda_I\to0.
\]

但这只是 action 化候选，不是当前 proposal 的必要写法。当前 equation-first 理论可以先把 \(Q\to0\Rightarrow C\to0\) 作为分支/边界/正则性条件列入。

## 6. 守恒条件是否是额外物理方程

先看精确方程。

Bianchi 恒等式给出：

\[
\tilde\nabla^\mu\tilde G_{\mu\nu}=0.
\]

若物质方程推出：

\[
\tilde\nabla^\mu\tilde T_{\mu\nu}=0,
\]

则

\[
\tilde\nabla^\mu\mathcal R_{\mu\nu}=0.
\]

在投影壳上：

\[
\Pi_E^\perp\mathcal R=0
\quad\Rightarrow\quad
\mathcal R=C.
\]

因此精确解上自动有：

\[
\boxed{
\tilde\nabla^\mu C_{\mu\nu}=0.
}
\]

这说明守恒条件不是任意额外力，也不是人为降低残差的数值规则；它是 Einstein-like 方程与物质守恒的相容性条件。

## 7. 为什么数值中仍必须硬性施加守恒

在数值诊断中，我们常常先逐点求一个 \(C_{\mu\nu}\) 代表元，使它尽量拟合 \(\mathcal R_{\mu\nu}\) 并满足 trace0。

但“逐点代数拟合”不保证：

\[
\tilde\nabla^\mu C_{\mu\nu}=0.
\]

原因是散度包含相邻点和相邻时间切片的导数信息。一个逐点看起来合理的 \(C\)，其空间/时间变化可能完全不守恒。

这正是此前观察到的现象：

- 干涉中点 trace0 局部代表元几乎自然守恒；
- 两个分离态局部代表元自然散度很大；
- 联立 full conservation 后，散度可以显著压低，代数残差只小幅增加；
- ALM 进一步说明这可以接近硬约束实现。

所以在构造初值或做数值解时：

\[
\boxed{
\text{守恒必须作为兼容约束硬性满足。}
}
\]

这并不是加新物理，而是避免选择一个不可能来自任何精确 Einstein-like 解的 \(C_{\mu\nu}\) 代表元。

## 8. trace0 的传播问题

trace0 不像散度守恒那样直接由 Bianchi 恒等式推出。

它是当前 proposal 的标量状态方程：

\[
C^\mu{}_\mu=0.
\]

其作用是固定投影方程主符号中剩下的一个 \(E\)-方向模式。此前主符号分析说明：

\[
\Pi_E^\perp\mathcal R=0
+\text{ harmonic gauge}
\]

仍留下一个 \(w_\mu w_\nu\) 方向的未定模式；trace0 在 \(w^2\neq0\) 的 patch 中可以看见并固定它。

因此 trace0 必须作为方程系统的一部分在每个点成立，而不是只作为初始切片约束。

若用系数写：

\[
C_{\mu\nu}=\lambda_I E^I_{\mu\nu},
\]

trace0 是：

\[
K_I\lambda_I=0,
\qquad
K_I=\tilde g^{\mu\nu}E^I_{\mu\nu}.
\]

实际求解时应直接参数化：

\[
\lambda_I=N_I{}^a y_a,
\qquad
K_I N_I{}^a=0,
\]

也就是像当前数值脚本那样先在 trace-nullspace 里工作，再施加守恒。

## 9. 约束传播的当前状态

目前可以确认：

1. 物质壳方程和连续性方程推出 \(\tilde\nabla^\mu\tilde T_{\mu\nu}=0\)。
2. Bianchi 恒等式要求精确场方程的右侧总源守恒。
3. 因此一旦 \(\mathcal R=C\) 是精确场方程，\(\tilde\nabla C=0\) 必须成立。
4. trace0 是真正的额外状态方程，用于补投影主符号缺口。
5. \(Q\to0\Rightarrow C\to0\) 是 GR branch 选择，不由 trace0 或守恒自动推出。

尚未完成：

1. 还没有严格证明 gauge-fixed PDE 的 Cauchy 适定性；
2. 还没有证明 trace0 状态方程与 \(\Pi_E^\perp\) 演化在所有 patch 内无冲突；
3. 还没有写出 \(\Delta=0,w^2=0,r^\perp=0\) 交界面上的换图规则；
4. 还没有证明 \(Q\to0\Rightarrow C\to0\) 分支在演化中自动保持，只能把它作为边界/正则性条件选择。

## 10. 下一步

最合理的下一步不是继续改数值器，而是做两个理论检查：

1. **branch preservation**：
   若初始/边界上 \(\lambda_I=\chi(\mathcal q)\hat\lambda_I\)，并且 \(\hat\lambda_I\) 有界，演化是否会保持有界性。

2. **patch transition**：
   在 \(\Delta=0\)、\(w^2=0\)、\(r^\perp=0\) 附近，是否存在另一组等价张量基底，使 \(C_{\mu\nu}\) 可以连续延拓，而不是把投影坐标奇点误当成物理奇点。

完成这两步后，proposal v1 才能升级成更接近完整理论框架的 proposal v2。
